## 公開データ（S8）の使い方

元のファイル（https://osf.io/t7dkp/ の `Infidelity.PT.OpenData.sav`）には MTurk の作業者IDが入っているので、Git に入れない・画面に出さない。
CSV に直して `python -I episodes/006-cheating-line/data/osf_pairs.py <data.csv>` で集計し直せる（`--thr 7` で「7だけを浮気」、`--attn` で注意の設問を通った人だけ。どちらも出力ファイルを上書きするので、本番の値は既定の設定で作り直す）。

主な結果（既定：7段階で5以上＝浮気、異性愛、32項目に欠けのない男272・女282人）：

| | 32項目すべて一致 | 食い違う項目数の平均 | 12項目すべて一致 |
|---|---|---|---|
| 男×女 | 0.59%（約170組に1組） | 9.3 | 5.4%（約20組に1組） |
| 男×男 | 0.86% | 8.9 | 6.9% |
| 女×女 | 0.37% | 9.3 | 4.4% |
| 男×女を項目ごとに掛け算（独立と仮定） | 0.001% | — | 0.89% |

確かめ（どれも「男女の組の一致は、同性の組とほぼ同じ」は変わらない）：注意の設問を通った人だけ（男91・女108）→ 32項目 0.30・0.34・0.26%。7だけを浮気 → 1.5・2.4・1.0%。

限界：本物のカップルではなく他人どうしの組み合わせ（本物のカップルは似た人どうしで、話し合ってもいるので、もっと一致するはず）。米国のネット調査。項目数と「どこから浮気とするか」で値が変わるので、必ず「何項目で」とセットで言う。

12項目（日本の調査に近い項目）：性交・強いキス・ほおにキス・一緒にシャワー・色っぽいメッセージを送る・出会い系サイトに登録・2人で気軽な夕食・正式な行事に同伴・心の支えになる・秘密を打ち明ける・暗い部屋で一緒に映画・贈り物。

## 足した計算（構成案のライバル役の指摘から。2026-10-06）

- `osf_more.py` → `osf_more_ci.csv`（男女・男男・女女の95%区間）、`osf_more_items.csv`（項目ごとの男どうし・女どうしの食い違い）、`osf_more_position.csv`（自分の線の位置ごとの一致率）。男女それぞれの多数決の線は32項目すべてで同じ（出力の1行目）。
- `osf_talk_split.py` → `osf_talk_split.csv`：ミクロの「そろえる」計算を、項目を選ぶ人と測る人を分けて確かめたもの（台本はこちらの値を使う）。
