## 7点に届かない理由

1. **人形が小さく、画面の下に沈んでいる。** 760pxの人形のうち見えているのは頭から胸の約300px（画面の高さの4割）。168px幅では約40px。顔のない白い塊で、飾りに見える。左右の外側と、くさびの両脇が空いている。
2. **頭が文字の下端にくっつく。** 文字の下端（y約395）と頭のてっぺん（y約415）が20pxしか離れていない。文字と頭が押し合い、窮屈に見える。かといって離すと人形がさらに小さくなる。逆に、文字の後ろに頭を少し入れるほうが、奥行きが出て人形を大きくできる。
3. **色が少し濁っている。** 橙の上側は茶に近い暗さ（`#8B3010` 前後）、青の上側も沈んでいる。スマホの一覧では暗い赤茶と紺に見え、白い文字は映えるが、地そのものの力が弱い。くさびの下側も灰色で重い。

## 直し案（3つ。効く順）

### 1. 人形を約1.3倍にして、頭を文字の裏に少し入れる
- **何を**：`DOLL_H` 760 → 990。`DOLL_TOP` 392 → 365（頭のてっぺんが y 約380）。文字（「基準は同じ？」の下端 y約395）より人形を後ろの層にし、頭の上の約15〜25pxを文字が隠してよい。文字の層は今のまま上。x は彼 230 → 250、彼女 1050 → 1030（大きくしても外へはみ出さず、くさびに近づけすぎない）。体は下端で切ってよい。
- **なぜ**：見える高さが約300 → 約340pxになり、肩幅は約1.3倍。168pxで約52px。外形（頭・肩・腕組み）が読めるようになる。文字と人が重なると、同じ1枚の絵の中の人に見え、飾りの感じが減る。ただし顔（目線）は隠さない。頭の重なりは頭の高さの1割以下。

### 2. 人形に色の縁光をつけて、背景から浮かせる
- **何を**：いまの `drop-shadow(8px 12px 14px rgba(0,0,0,.45))` に加え、彼に `drop-shadow(0 0 28px rgba(90,160,255,.8))`、彼女に `drop-shadow(0 0 28px rgba(255,150,80,.8))`（それぞれの地の色の明るい版）を重ねる。影は下向きのまま残す。
- **なぜ**：白い人形は白い文字と同じ明るさで、地との境が弱い。色の縁光で外形がはっきりし、168pxでも「青の側の人／橙の側の人」と読める。2人を同じ白のまま、左右の色の意味を絵に足せる。

### 3. 地の色を明るく、くさびを白く光らせる
- **何を**：橙の上端を `#8B3010` → `#C2410C`、下端 `#D4501C` → `#F26A1F`。青の上端を `#0E3A8C` → `#1A55C8`、下端 `#2E6FE0` → `#3C86F5`。くさびは上 `#FFFFFF`、下 `#C9C9D2`（いまの下側は沈んだ灰）。くさびの縁の白線はそのまま。文字の「は」にくさびが重なるので、縁取り12pxは14pxに。
- **なぜ**：一覧では暗い色は沈む。上の暗さを持ち上げると、競合の間で面として目に入る。くさびの白い光が真ん中に「2人を分ける線」を作り、人形の外向きの姿勢が引き立つ。色の意味（青＝男、橙＝女。本編と同じ）は変えない。
