## 考えすぎる葦が作るなら

前半（線のずれ）の予想は第1稿のときと同じ（`rival-outline.md`）。ここでは新しい第3章「人はなぜ線を越えるのか」を葦が1本で作るなら、を、第3稿の第3章を読む前に、テーマだけから書いた。

- タイトル：「なぜ人は、愛しているのに浮気するのか【恋愛×進化心理学】」。
- 最初の30秒：逆説の逸話から入る。「幸せな結婚をしている人も浮気する」（米国のセラピストの有名な主張）や、「浮気した人の多くは、相手をいまも愛していると答える」のような数字で、「不幸だから浮気する」という常識を先に崩す。
- 章立て：立場を回り、だんだん広げる。浮気する本人の欲（進化：多様性への欲求、Schmitt の52か国）→ 2人の関係（投資モデル、愛の欠如・ネグレクト）→ 状況（職場・酒・アプリ、機会）→ 社会と時代（一夫一婦の歴史、女性の経済的自立で男女差が縮む、アプリの時代の「代わりの相手」の無限化）。
- 比喩と締め：比喩を1本通す（たとえば「ダム」：水位＝欲、壁＝関係、雨量＝機会。どこか1つでは決まらない）。締めは「浮気は、心が離れたしるしではない。扉が開いていた、というだけのことが多い」のような言い切り。
- 弱いところ（予想）：自分で数えた数字はない。米国の研究ばかり。相関を「〜だから浮気する」と因果で言い、進化の説明を言い切る。参加の場面はない。

### 特に見てほしい点への答え

**1. 第3章は前半とつながっているか。2本の動画に見えないか。教訓と締めはまとまっているか**

貼り合わせに見える。継ぎ目は3か所ある。①冒頭で問いを2つに割る ②第3章のあとにミクロ（線をそろえる）と答え合わせ（線のずれ）で前半の話へ戻る ③教訓が「そして」でつないだ2文。
いちばん大きいのは、前半と後半をつなぐはずの主張「越えるかどうかは線では決まらない」に、まだ根拠がないこと。第2章の終わりの問い「線の位置が人を浮気から守っているのでしょうか」に、第3章のデータは答えていない。[S16] が示すのは「線の位置は年齢・満足度で動かない」で、「線の位置が違う人どうしで、越える割合が同じ」ではない。しかも手元の GSS では、線に近いもの（不倫への態度）で越える割合が約3〜5倍違う（「いつも悪い」男性14.3%・女性8.5%、「時々悪い」39.4%・45.5%、`gss_evstray.csv`）。これは満足度の約4倍と同じかそれ以上。`research-why.md` は「逆向きが強く疑われる」として外しているが、逆向きの疑いは満足度にもある。**都合の悪いほうだけ逆向きを理由に外すと、えり好みになる**。
一方で、前半と後半を1本にする材料は、すでにデータの中にある。通説「浮気の線のずれは、男と女の違いから生まれる」の「男と女」を軸にすれば、第3章は標準構成の「別の角度で確かめる章」になる。同じ GSS の中で、性別の差は約1.5倍（19.2%・12.9%）、満足度の差は約4倍（6.4%・24.4%）、18〜29歳では男女がほぼ同じ（8.2%・8.6%）[S17]。つまり「ずれも、越える割合も、性別より大きく動かすものがある」で前半と後半が1つの話になり、教訓も1文になる（直し方1・2）。

**2. 第3章で考えすぎる葦に負けていないか**

章の骨組み（投資モデル・動機・機会・男女差）は、葦が作る章立てとほぼ同じで、骨組みでは勝てない。勝てるのは自前の集計・日本の数字・クイズの分だが、第3章は ①絵の瞬間がない ②驚きの山が第2章（170組に1組）より小さい（「不幸な結婚ほど浮気が多い」は見る人が予想している向き。8章「山は後ろほど大きく」に反する）③「広げる」が逆向き（第2章の最後で法律＝社会まで広げ、第3章で1人の要因に戻る）。いまのままなら第3章は葦に負ける。勝てる材料は「並べ替えると色が偏る」絵と、「生まれた年で男女差が消える」（時代へ広げる）の2つ（直し方3・5）。

**3. 相関を因果のように言う所、男女どちらかを見下す所**

- 教訓「人がその線を越えるかどうかは、線の位置より、線の手前の暮らしと一緒に動く」：「一緒に動く」は相関の言い方として気を配っているが、「線の位置より」の比較に根拠がない（上の1）。
- 教訓「ドラマの夫が越えたのは、線の位置のせいではなかった」：作り話の人物に原因を割り当てていて、聞く人には「不幸だったから越えた」に聞こえる。「〜のせい」は因果の言葉。
- 第3章の発見「線は、人を区別しない」：同じデータで性別では線が動く（男13.8・女15.5、区間が重ならない [S16]）。第1章の判定〇と食い違い、さらに教訓の「線は1人ひとりのあいだに引かれている」とも字面がぶつかる（オーナーの指摘集「比喩が字義どおりに聞こえる」型）。
- 「聞き方で理由が変わる」：日本の本人の申告（レゾンデートル第2報）と、米国の満足度別の割合（GSS）を並べて「本人の言う理由と、数えて見える構造は違う」と言うのは、国も調べ方も違うものの比較。言い過ぎになる。
- Munsch [S18]：男女の両方の側を同じ形で出す方針は良い。ただし「約15%」は相対収入の端（妻がすべて稼ぐ）でのモデルの予測値で、そこにいる人は少ない。研究者の「男らしさ」の解釈は、20〜40代の男性の視聴者には「稼げない男は浮気する」と聞こえやすい。読み上げで「男らしさ」を言わず、「配偶者の収入に頼る側は、男女どちらも多い。差の幅は男性で大きい」の向きで出すほうが見下しにならない。
- 「男性は性欲、女性は相手を好きになった」[S19]：数字はあるが、通説（男は体・女は心）をそのまま強める並べ方。第2章で通説を退けた直後に、第3章で同じ型を補強する形になる。使うなら同じ表の「相手に求められた」（男性22.5%・女性17.9%）のような差の小さい項目と並べる。
- GSS の男性「あまり幸せでない」39.3% は51人。画面に出すなら男女計（141人）だけにする（構成案もそうしている。台本でも守る）。

**4. 尺（約16分20秒）と読み上げる数字の量**

- 尺：各節の合計は16分20秒で、標準（13〜18分）の中。ただし構成案の冒頭の注に「約14分」と残っていて、食い違っている。
- 第3章の読み上げる数字：構成のメモは「4つ（約4倍・約4倍・約4割・約3割）」としているが、本文の書き方のとおりに読むと、約15項目・約6%・4人に1人・約1.5倍・約15%と約3%・5%と1.5%・1割ほど・約4割から約1割・約2割から約5%・約3割・1割未満・約8%と約9% となり、4分半で15個を超える（1分に3〜4個どころか、7章の目安を倍近く超える）。「約4倍」は「6%と4人に1人」を言わないと伝わらないので、4つだけ読む、は実際にはできない。
- 第3章は4分半に8つの話と6つの出典（OSF・Le & Agnew・GSS・Munsch・レゾンデートル第2報・相模ゴム）が入っている。第2章（5分）より密度が高い。

## 勝つための直し方（効果の大きい順）

- **つながり・締め（主張の根拠）** → 第3章の「まとめ」と教訓・締めの一文 → 「越えるかどうかは線では決まらない」「線の位置より」「地図のせいではない」を、いまのデータで言える形に変える。言えるのは「越える割合は、性別より関係の満足と一緒に大きく動く」（同じ GSS の中で約1.5倍と約4倍 [S17]）まで。線の位置と越える割合の関係を言いたいなら、GSS の不倫への態度の数字（約3〜5倍）も同じ「逆向きもありうる」の断りつきで出す。その場合、主張は「線と越えることは関係がない」ではなくなるので、言わない。線の位置（何個を浮気とするか）と浮気の経験を同じ人で比べたデータは、OSF の INFEXP（設問の解釈に疑問あり）以外にない。言い切るなら**調べる必要がある**。
- **つながり（1本の話にする）** → 第3章の位置づけと判定 → 第3章を「男と女の違いで説明したくなる、を越える側で確かめる章」にする（標準構成の「別の角度で確かめる章」）。同じ100人の既婚者を性別で分けると差は約1.5倍、満足度で分けると約4倍、18〜29歳では男女がほぼ同じ [S17]。判定に③「越える割合でも、性別の差は満足度の差より小さい」を証拠として足せば、通説は1つのまま、前半と後半が同じ判定に入る。教訓は「浮気を男と女の話にすると、もっと大きく動いているものを見落とす」のように1文にまとめる（言い回しは台本担当が決める）。締めの一文の後半も、この向きに合わせて地図の比喩で作り直す。冒頭の問いは1つ（線のずれ）に戻し、ドラマの夫が越える場面は第3章への伏線として置くだけにする（2つ目の問いのカードを出さない）。
- **絵（第3章）** → 第3章のクイズの答えの場面 → 100人を「浮気の経験あり」に色を付けて並べ、①性別で2列に並べ直す（色の差は小さい）②結婚の満足度で並べ直す（色が片側に寄る）を続けて見せる。第2章のはしご（男女の線では1組も消えず、1人ひとりの線で消える）と同じ「分け方を変えると景色が変わる」になり、前半と絵でつながる。数え方の発見の印もここに置ける。注意：「あまり幸せでない」は既婚者の約5%（2,852人中141人）なので、100人の中に並べると5人ほどしかいない。各列を100人にそろえて割合で見せ、そう画面に書く（面積＝量。1場面は同じ物差し）。
- **ミクロの置き場所** → ミクロの節 → 第3章のあとから、第2章のはしごの最後の段（1人ひとりの線の世界で、そろえる項目の数と選び方だけを変えて回す）へ移す（`docs/script-style.md` 11章「シミュレーションの回は、はしごの最後の段として作る」）。第3章のあとに前半へ戻る継ぎ目が消え、第3章 → 答え合わせ → 教訓がまっすぐになる。第3章の終わりの「次の問い」は答え合わせへの問いにする。
- **広げる・山の大きさ（第3章の後半）** → 第3章の終わり → 「生まれた年」で時代へ広げる：米国で結婚したことのある男性の浮気の経験は、1940年代生まれ 約26%、1980年代生まれ 約12%で、1980年代生まれ以降は男女がほぼ同じ（12.4%・12.5%）[S17 の元データ `gss_evstray.csv`。sources.csv の S17 の値には生まれ年別がないので足す]。「性別の差は、生まれた時代で消える」は、満足度の4倍より予想しにくく、第3章の山になる。ただし若い人は結婚している年数が短く、世代と年数が混ざっている、と必ず言う。法律の線（第2章）と合わせて、後半ほど話が大きくなる。
- **数字の量（第3章）** → 第3章の8つの話 → 4つに絞る。残す案：①線は年齢・満足度で動かない [S16]（性別では少し動く、と言い添える）②並べ替え（性別 約1.5倍・満足度 約4倍）[S17] ③日本の職場 約4割 [S19][S20]（機会。日本の数字）④生まれた年（上）。画面だけに回すか外す案：投資モデル（3つのうち使うのは2つだけなので、名前を出すなら2つで言う。出さなくても章は成り立つ）、Munsch（残すなら画面と1文。上の「見下し」の言い方で）、日本の年代別、「聞き方で理由が変わる」（国も調べ方も違う比較なので外す。残すなら日本どうし：同じ会社の第1報の「愛情はなく結婚 約3割・愛情があって結婚 約1.6割」だが、区分の人数が出ていないので弱い）。
- **参加（第3章のクイズ）** → クイズの問い → 答えが読める「いちばん大きく違うのは？」をやめ、予想が割れる問いにする。案：「米国で結婚したことのある18〜29歳。浮気の経験が多いのは？ A 男性が約2倍 B 男性が約1.5倍 C ほぼ同じ D 女性が多い」→ C（8.2%・8.6% [S17]）。通説（男のほうが多い）が選択肢に入り、9章「よくある説明を先に退ける」にも合う。人数（男164・女309人）が少ないので「ほぼ同じ」までで、どちらが多いとは言わない。
- **言葉** → 第3章の発見・教訓 → 「線は、人を区別しない」を「線の位置は、年齢でも満足度でもほとんど変わらない」のような平たい文に変える。教訓の「ドラマの夫が越えたのは、線の位置のせいではなかった」は消す（作り話の人物に原因を当てる文）。日本の年代別を残すなら「60代 約1割」は 13.1% なので「1割強」に。
- **数字の量（全体）** → 構成のメモ → 冒頭の注の「約14分」を16分20秒に直す。第3章の読み上げる数字を、上の絞り方のあとで1つずつ数え直し、1分4〜5個に収まるかを構成案の表に書く（「約4倍」は2つの割合とセットで数える）。
- **新しさ（第3章）** → 企画カード「この動画だけの数字」 → GSS の結婚の幸福度別の浮気の経験の割合が、研究所の記事（Wang 2018 など）や論文にすでに出ているかを**調べる必要がある**。出ていれば「自分で数えた」とは言えるが「この動画だけ」とは言わない。生まれた年×性別の「1980年代生まれで男女がそろう」も同じく確かめる（Wolfinger 2017 は世代の差を書いているが、男女がそろう点まで書いているかは未確認）。
