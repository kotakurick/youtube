### 特に見てほしい点への答え

1. **予想タイムの4択と第3章の数字（答えが判定まで残るか）**：残らない。第3章のはしごの1段目「掛け算の世界（ほぼ0）→ 実際は数百倍多い。線がつながっているから」で、罠の選択肢D（掛け算の値）が消える。第2章で「1項目で約5割ずれる」と聞いた人はDに引き寄せられるので、Dの罠自体はよくできている。だからこそ、その種明かしを第3章でやると、判定の前に答えがA〜Cにしぼられ、残りも「32項目で170組に1組なら、12項目はその数倍」で C に寄る。もう1つの問題：4択は「男女2人の確率」を聞いているだけで、通説（男女の違い）を選択肢に入れていない（9章「よくある説明を先に退ける」に合っていない）。予想タイムが逆説と別の問いになっている。
2. **日本のデータが弱く、主役が米国の公開データな点**：引きでは負けていない（数字の意外さは国に関係ない）が、**信頼で負ける所が2つある**。①冒頭の最初の数字 [S1] は既婚者向けマッチングサービスの会社の調査。浮気の話でこの出どころは、コメント欄で真っ先に突かれる。②タイトルの「2人の線がぴったり合う確率」は恋人どうしを約束しているのに、本編で数えるのは米国の他人どうしの組（オーナーの指摘集「タイトルの名詞が本編で数えているものと同じか」と同じ型）。さらに企画カードの [S10] が「無作為の夫婦が食い違う確率」になっているが、計算は無作為の既婚男性と既婚女性の組で、夫婦ではない（10章「調査の対象を取り違えない」）。台本でこの言い方が残ると、誇張になる。
3. **「男女差より個人差」が男性視聴者に響くか**：今の並べ方だと響きにくい。第1章で「女性のほうが厳しい」が確かめられ、第2章で「男も心の浮気がつらい」と言われ、最後に「性別ではなく人それぞれ」で終わるので、男性からは「結局どっちもどっち、話し合えという話」に聞こえやすい。響く形は「女性がうるさいのではない。**男どうしでも同じだけずれる**」という向き。データにその材料はある（男×男でも食い違う項目は平均8.9個 [S8]、日本でも手をつなぐで男どうし約4割が食い違う [S10]）。これを「あなたと男友達でも」と見る人に当てはめれば、説教ではなく発見になる。ミクロの「そろえる」は、言い方を誤ると説教の本体になるので注意。

## 勝つための直し方（効果の大きい順）

- **締め・新しさ（判定）** → 通説と判定 → 通説を「浮気の線のずれは、男と女の違いから生まれる」に絞り、判定を×で言い切れる形にする（同性の組でも同じだけずれる [S8][S10]）。「女性のほうが線が手前」は○として判定カードの中で認める（2段の判定）。今の通説の「喧嘩は〜から起きる」は、喧嘩をどのデータも数えていないので、因果の言い過ぎにもなる。△のままにするなら、何の条件で変わるかを一言で言う（8章）。
- **絵（はしご）** → 第3章のはしご → 棒人間の型と同じ「掛け算から始める」ではなく、逆説を見せる段を入れる：①全員が同じ線（100組一致）②男女の平均の差だけがある世界 ③実際の個人差。②で組がほとんど消えず、③で一気に消える、が「性別より人」をそのまま絵にする。②の世界の一致率はまだ計算していないので**計算する必要がある**（例：各人の答えを、性別だけを入れ替えた分布や、男女の平均の線どうしで作り直す。やり方は計算の担当が決める）。あわせて、企画カードの「1項目ごとに組が半分ずつ消える」は「約3割ずつ」などデータに合う言い方に直す。
- **参加（予想タイム）** → 予想の4択と第3章の順番 → 掛け算の種明かし（Dが罠だった理由）を第3章から判定の場面に移す。第3章は「32項目で約170組に1組」と組の種類の比較だけにする（170組に1組はA〜Dのどれよりも小さいので、12項目の答えは漏れない）。判定で「Dを選んだ人は掛け算をした。実際はその約6倍」と明かす（0.89%と5.4%から）。答えの画面は4択を残して C を目立たせる（オーナーの指摘集）。予想の前に、条件の表（米国708人・他人どうし・7段階で5以上を浮気・12項目の中身）を出す（オーナーの指摘集「仮定が恣意的に見える」）。
- **引き** → 冒頭の0:30〜0:50 → 最初の数字を、予想どおりの「女性 約半分・男性 約3割」で止めず、その直後に [S10] を置く：「この割合で、無作為に既婚の男女を2人組ませると、手をつなぐだけで約2組に1組が食い違う」。男女の平均の差（約2割）より、ずれ（約5割）のほうがずっと大きい、が最初の「え？」になる（第2章の山は、男どうし・女どうしとの比較に回す）。冒頭の場面は葦の実物と重ならないよう、スマホの通知・嫉妬から始めない（例：2人で同じ番組を見ていて、出てきた場面に対する「これは浮気」「これは違う」が割れる、など。場面は台本担当が決める）。
- **新しさ（第2章）** → 第2章の分量と中身 → 「男は体、女は心」の論争（[S5][S6]）は葦が1本かけてやった話なので1〜2文に縮め、日本の学生の数字 [S4]（男子学生でも心が約6割）と、それが日本では通説と逆になる点だけを残す。空いた時間で、米国データの項目ごとの食い違い（`data/osf_items_partner.csv`）から見える違いを使う：体の項目（コードの S）は男どうしのほうがずれ、灰色の項目（A・SO）は女どうしのほうがずれる傾向がある（例：DIQ_5S は男×男28.3%・女×女7.5%、DIQ_15A は28.3%・47.1%）。項目名との対応と、差が誤差の範囲を超えるかは**調べる必要がある**。確かめられれば「男が揉めるのは体の線、女が揉めるのは灰色の線」という、この動画だけの発見になり、男女どちらも見下さずに男性視聴者に当てはまる。
- **ミクロ** → ミクロの節 → 「2人でそろえる」算数ではなく、見る人自身の位置で比べる形にする：第1章で引いた自分の線（厳しい・真ん中・ゆるい）ごとに、無作為の相手と全項目が一致する確率がどう違うか。ものさしでつながっているなら、端の人ほど一致しやすく、真ん中の人ほどずれやすい可能性がある（**計算する必要がある**。予想で書かない）。「あなたの線が真ん中なら〜、端なら〜でした」は、自分の位置を確かめる参加と、1人ひとりの違いの比較を兼ね、勧める言い方にならない。今の「そろえる」計算を残すなら、食い違いやすい項目を選んだデータと、確かめるデータを分ける（同じデータで選ぶと高めに出る）。
- **締め（男性視聴者に向けて）** → 第3章の山と教訓 → 「男女の組がとくにずれるわけではない」を、男性の視聴者に向けて「男どうしでも、32項目のうち平均約9個ずれる」として出す（[S8] 8.9個）。結論を「人それぞれ」ではなく「同じルールを持っていると思い込んでいる」という思い込みの話に寄せたまま、地図の回収で終える。教訓に「話し合いましょう」の意味を足さない。
- **広げる（構成）** → 第3章の後半 → 2人の話のまま終わらず、社会の線を1つ足す：日本の法律で離婚の理由になる「不貞行為」がどこに線を引いているか。人ごとにばらばらの線の中で、社会が引いている線が1本だけあり、それが多くの人の線より奥にある、なら「広げる」になる。法律・判例の線は sources.csv にないので**調べる必要がある**（一次資料：民法770条と、判例の定義）。法律の助言にはしない。
- **信頼** → 冒頭の出典と企画カード → [S1] は事業者（既婚者向けマッチングサービス）の調査だと冒頭の画面にも出す。冒頭の数字を [S2]（占いサービス会社。手をつなぐは男性 約55%・女性 約59%で差が小さい）と並べずに [S1] だけを使うと、差の大きいほうを選んだように見えるので、第1章では今の案どおり両方を出す。企画カードの「無作為の夫婦」は「無作為の既婚の男女」に直す。0.86%と0.37%の違いを言うなら、組み合わせの誤差の幅（ブートストラップなど）を**計算する必要がある**。幅が大きければ、主な証拠は「食い違う項目数の平均 9.3・8.9・9.3」に置く（こちらのほうが揺れにくい）。「554人で421通り」は sources.csv に入っていないので、使うなら足す。
- **数字の量** → 第3章（約3分15秒）→ 読み上げる数字が 0.001%・170組・0.59/0.86/0.37・9個・554人・421通り・434組・約半分・9個 と1分4〜5個を超える。物差し（421通り）か本物のカップル [S11] のどちらかを画面だけに回す。[S11] は性感染症のリスクが高い若いカップルの標本なので、使うなら「こういう標本では」と範囲を言う。
- **タイトル** → 題 → 本編で数える「2人」が他人どうしの組であることと矛盾しない題にする（例：「浮気の線」と「一致する確率」は残し、「恋人」「カップル」とは書かない）。題の案は台本担当とサムネイル担当で決める。サムネイルは、オーナーの好み（感情の見える1つの情景＋心の声、明朝体）に合う「スマホを見て固まる1人」は葦の冒頭と同じ絵になるので、別の情景を探す。
