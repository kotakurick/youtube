## 見たこと（0.3秒・競合の間・問い・文字・絵・ポリシーの順）

### 共通の絵
- 良い：ソファに座る白い2体、彼は手を開き、彼女は腕を組んで彼を見る。冒頭の物語（「セーフでしょ」「アウト」）が絵だけで読める。2体は同じ白・同じ縁の光で、どちらも責める絵にも、いじける絵にもなっていない。主役は「2人の間の温度差」の1つ。
- 弱い：地が暗い紺〜赤紫で、全体が沈む。ソファが大きな白い塊なので、人の頭（情報がある所）がソファに負けて小さく見える。左下は何もない暗い面。
- 性別の見え方：「彼がゆるく、彼女が厳しい」と読める絵。本編の結論（ずれは男女の差だけではない）に比べ、絵だけでは「男性はゆるい・女性は厳しい」という決めつけに寄る。悪く見せてはいないが、**絵に「セーフ」「アウト」の札を足して男女に割り振る直しは、決めつけになるのでしない**。

### A「男女で／基準は同じ？」
- 0.3秒：字は104px。168px幅に縮むと、1文字が約14px。「基準は同じ？」の6文字は幅がおよそ590pxで、縮んで約77px。読めるが、Bより一段小さい。
- 位置：2行目の「？」の右端が約640px、ソファの左の肘（約628px〜）と彼の手（約645〜690px、y 360〜380）にほぼ当たる。字と絵の間の余白がゼロで、窮屈。
- 問い：「基準は同じ？」は答えが「同じではない」と見えて、好奇心のすき間が小さい。「基準」は主題の言葉として決まり済み（指摘集「線」→「基準」）で正しいが、日常の言葉としては硬い。
- タイトルとの組み合わせ：推しタイトルは「どこからが浮気か、男女でどれくらい違うのか」。Aの「男女で」はタイトルの「男女で」と同じ語で、補い合わず重なる（meta.md にも既出の指摘）。サムネが言うべき感情が、タイトルの繰り返しになる。
- 長所：性別を前に出すので、男女の対立の回だと一目で分かる。ただし今回の本編はまさにその「男女差と思い込んでいたが…」を扱うので、サムネの断定っぽさがやや先走る。

### B「どこから／浮気？」
- 0.3秒：字は124px。168px幅で1文字約16px。2行とも短く（4字と3字）、一目で読める。「浮気」という強い語が主題で、検索される言葉と同じ。
- 位置：字の右端は約520px、ソファまで約110px。余白に余裕があり、窮屈さがない。
- 問い：「どこから浮気？」はだれもが自分の答えを持つ問いで、絵（手を開く彼／腕を組む彼女）と合って「この2人は食い違っている」と読める。答えを言わないので、好奇心のすき間が大きい。
- タイトルとの組み合わせ：タイトルの頭「どこからが浮気か」と同じ語だが、役割は分けられている。サムネは感情（問いと食い違いの絵）、タイトルは中身（男女の差・32の行動で数えた）。Aのように「男女」を重ねないぶん、サムネとタイトルで言うことが別になる。重複が気になる場合も、サムネの検索語がタイトルの頭で確認されるので、押す理由は強まる。
- 弱い：全部が白一色。「浮気」という一番のクリック語が、「どこから」と同じ強さで、埋もれる。

### 競合との比べ（見本なしの推定）
- 解説系の競合は、明るい地・黄や赤の大きな字が多いはず（`review/title-thumb.md` で確認）。暗い紺の地に白字は「静か」で、並ぶと沈む可能性が高い。4本目のレビューでも同じ宿題が出ていて、今回も見本で確かめる。

## 直し案（B を土台に。効く順。Aに使う場合は下に注記）

1. **「浮気」を黄に、2行目を大きくする**（何を・どれだけ・なぜ）
   - 2行目「浮気？」を size 124→**160**、色を白→**#FFD93B**（縁の黒はそのまま。縁の太さは字の大きさに比例させる）。1行目「どこから」は 124→**116** に下げて白のまま。top は 1行目 **205**、2行目 `top + 116*1.12`（約335）。
   - なぜ：押す語を1つだけ大きく色づけると、168pxでも「浮気」が目に入る。brand.md は「黄や大きさの強調は自然な回だけ」で、この回は主題の語なので自然。2行目の右端は約 60+160×3.3=約590px まで。ソファ（約628px）との間は約40px以上空け、足りなければ「？」を size 130 に落とす。
2. **地を明るく、字の側に光を足す**
   - `ground` を `["#10162E", "#2A1F3A"]` → **`["#1A2658", "#5B2A5A"]`**。左下の暗い面に **#FFB347 の弱い光**（`rgba(255,179,71,.18)` の径700の放射グラデ、中心 x 280・y 560）を足す。テレビの青白い光（右）と、左の暖色（字側）で、画面が左右で別の色温度になり、競合の間でも沈みにくい。
   - 光は2人の人形には当てない（同じ白・同じ光の決まりを守る）。人形にかかる色は今のまま。
3. **人形の頭を目立たせる（ソファに頭が負けない）**
   - `Cutout` を cx 930→**950**、top 170→**150**、h 470→**500**。ソファの右端が約1260pxになるので、`npm run check` ではみ出し0を確かめる（超えるなら h 490）。人形の顔まわりに `brightness(1.15)` をかけ、ソファの座面（下半分）には `Vignette` を濃くして（strength 0.6→**0.75**）暗くする。頭が最も明るく、ソファが一段暗い構図になる。
   - 右下（y 650以降）は空けたまま。ソファの下端は約630pxでよい。
4. **足元に床の気配**
   - 影は現状（top 600・高さ80）のままでよいが、不透明度を .55→**.7**、幅を 660→**760**。ソファの黒い脚は抜けて消えているため、浮いて見える対策。
5. **（Aを選ぶ場合の必須）字の位置と大きさ**
   - size 104→**112**、2行目を「基準は同じ？」のままにして、字の右端を **590px 以下**に収める（実際は約680pxになるので、ソファを cx 930→**980**、h 470→**450** に寄せるか、1行を「男女で基準は」「同じ？」の切り方にしない（助詞だけの行を作らない決まり）。実質は、Aは字が長くてこの様式（左に字・右に人形）に収まりにくい。

## 推し

**Bを推す。** 理由は3つ。
1. 字が短く大きく、168pxでも読める。Aは「？」が絵に当たるほど長く、様式の枠に収まりにくい。
2. 「浮気」はクリックの語として強く、答えを言わない問いになっている。Aは「同じ？」の答えが「違う」と見え、すき間が小さい。
3. タイトルの「男女」と重ならず、サムネ＝感情・タイトル＝中身の分担ができる。性別を字に出さないので、絵の彼／彼女の見え方で決めつけに寄るおそれも小さい。

Aを残す価値があるのは、「男女の対立の回だ」と一目で分からせたいとき。ただしその役目はタイトルの「男女でどれくらい違うのか」が持っているので、サムネは持たなくてよい。
