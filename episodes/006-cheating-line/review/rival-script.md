## 考えすぎる葦が作るなら

（テーマ「どこからが浮気？」とタイトル案だけから。前回までの予想を、台本の段階に合わせて書き直した）

- タイトル：「なぜ『浮気の線』は恋人どうしで合わないのか【恋愛×境界線の哲学】」。
- 最初の30秒：物差しを先に渡す。「法律が浮気とみなすのは体の関係だけ」と言ってから、「でも、手をつないだだけで浮気だという人が、女性の半分いる」と落とす。または「付き合う前に浮気の線を話し合ったカップルは何割か」のような意外な数字。
- 章立て：女性の側（心の浮気）→ 男性の側（体の浮気・進化心理学）→ SNS とアプリの時代（DM・いいね・マイクロ浮気で灰色の行動が増えた）→ 法律と制度（裁判所の線・一夫一婦の歴史）→ 社会（共同体の決まりが消え、線を2人で決めるしかなくなった）。だんだん広げる。
- 比喩と締め：国境・地図・扉のような境界の比喩を1本通し、「浮気の線は、相手の行動ではなく、自分の不安の位置に引かれている」の型の逆説で締める。
- 弱いところ（予想）：自分で数えた数字はない。米国の研究が中心で、相関を因果で言い切る。見る人の参加がない。

## データで語る棒人間が作るなら

- 装置：100組の恋人を並べ、「この行動は浮気か」の札を1枚ずつめくる。答えがずれた組は消える。
- はしご（理想の世界 → 足していく原因）：①全員が同じ線 → 100組残る ②男女の平均の差を足す → 少し消える ③同じ性別の中のばらつきを足す → ほとんど消える ④行動の数を増やす → ほぼ0。最後に「掛け算よりは残る」。
- 途中の発見：「男女の差を消しても、ずれはほとんど減らない」「掛け算の予想より実際は多く残る」。
- 限界の言い方：「他人どうしを組ませた計算。本物のカップルは似た人どうしで、話し合ってもいる」。締めは一般論と登録の呼びかけ。物語・日本の数字・ミクロはない。

## 数字の扱い（勝ち負けより先に直すもの）

うそ・誇張・えり好みで勝つと、うちの約束を失う。台本の第1稿には、そうなっている所が4つある。

1. **163行「同じ人たちを、結婚の満足度で分け直します」は事実と違う**。男女の割合（男性19.2%・女性12.9%、約1.5倍）は「結婚したことがある人」、満足度の割合（6.4%・24.4%）は「いま結婚していて離婚歴のない人」で、集団が違う [S17]。しかも同じ「いま既婚・離婚歴なし」の中で男女を比べると、とても幸せ 男性8.3%・女性4.4%、あまり幸せでない 39.3%・14.4%（`gss_evstray.csv`）で、男女差は約1.5倍ではなく約2倍。「性別 一倍半、満足度 四倍」の対比は、違う集団の数字を並べて差を大きく見せている。
2. **200行のまとめ「越える側でも、男女の差は小さく」と212行の証拠③に、日本の数字が入っていない**。同じ会社の第1報で、浮気の経験は男性22.9%・女性11.6%（約2倍）[S1]、相模ゴムでも既婚の男性21.0%・女性10.2%（約2倍）[S3]。台本が第3章で使っている「愛情なく結婚 約3割・愛情あり 約1.6割」[S22] の差（約1.8倍）は、**同じ調査の男女差（約2倍）より小さい**。日本の数字では「性別より暮らし」が言えない。米国の数字だけで「越える側でも男女の差は小さい」と言うのは、CLAUDE.md の「もう一方の側のデータも出す」に反する。企画カードの「もう一方の側」（S3）が台本から消えている。
3. **62〜76行の「七千人の答えを、百人に縮めて」「ひとりひとりが自分の線の高さに立ちました」「山の幅は、ずれよりずっと広い」は、データから作れない**。S1 は項目ごとの割合（複数回答）しか発表されておらず、1人ひとりがどの段から上を選んだかは分からない。山の位置も幅も描けない。76行「体の関係でさえ、浮気の段を選ばなかった人もいます」は、`sources.csv` の S1 のメモ「複数回答なので『選ばなかった＝浮気でない』とは限らない」にそのまま反する。
4. **満足度の「四倍」は、3つの区分の両端どうしの比べ**。「あまり幸せでない」は既婚者の約5%（2,852人中141人）。真ん中の「まあ幸せ」（男性16.7%・女性8.7%）と「とても幸せ」の差は約2倍。2つに分けた性別と、3つの区分の端どうしを並べて「性別よりずっと大きい」と言うと、比べ方の差が結論の差になる。言うなら「いちばん幸せな人と、いちばん幸せでない約20人に1人の人で」と区分の大きさを添える。

そのほか細かいもの：

- 126行「百組では、一組も残りません」：0.59%なので、100組で残るのは平均0.6組。絵で毎回0にせず「一組も残らないことが多い」程度にする。
- 109行「男子学生でも、心の浮気のほうがつらいと答えた人が、多数派」[S4] は1990年代の大学生316人。10章「研究の時期を越えて今の話にしない」。「1990年代の日本の大学生の調査では」と言う。
- 130行「法律で離婚の理由になる浮気は、体の関係を持つことに限られます」[S14]：`sources.csv` のメモでは一次資料（判決文・e-Gov）の確認がまだで、「言い切らない」とある。慰謝料は性的関係がなくても認められる場合がある、とも書かれている。確認するまで「限られます」と言い切らない。
- 176〜179行「本人は、関係のせいだとは言いません。けれど、数えてみると、浮気は関係と一緒に動いています」：本人の答え（第2報、浮気経験者480人の「夫婦関係が悪いから」）と、数えた形（第1報、6,805人の「結婚したときに愛情があったか」）は、聞いている「関係」が違う（いまの関係と、結婚したときの気持ち）。食い違いに見せるには弱い。「なんとなく」と答えた人の中に、愛情なく結婚した人がいてもおかしくない。

## 勝つための直し方（効果の大きい順）

- **数字の扱い（第3章の主張）** → 161〜166行の対比・200行のまとめ・212行の証拠③ → 性別と満足度を**同じ集団**（いま既婚・離婚歴なし）の数字で並べる。男女の差は約2倍、満足度の両端の差は約4倍、と言う（同じ集団の男女別の全体の割合は `gss_evstray.py` で**計算する必要がある**。区分ごとの値から足し合わせると男性 約12%・女性 約6%になる見込み）。そのうえで、日本の数字（浮気の経験 男性 約2割・女性 約1割、約2倍 [S1][S3]）を「もう一方の側」として必ず読み上げる。言えるのは「越える側では、男女の差ははっきりある（日本でも米国でも約2倍）。ただ、米国では満足度の差のほうが大きく、若い世代では男女の差が消える」まで。まとめの「男女の差は小さく、暮らしの差は大きい」と証拠③の「ずっと小さい」は消すか弱める。判定の後半（ずれは男女の違いから、は×）は第2章の証拠だけで立つので、証拠③は「越える側では男女差がある。でも、それより大きく動く分け方がある」の補いに下げる。こうしても通説の後半の×は崩れない。ここを直さないと、男性の視聴者からは「男をかばうために米国の数字だけ選んだ」、女性の視聴者からは「日本では2倍なのに隠した」と読まれ、両側から信頼を失う。
- **数字の扱い・絵（第1章の100人）** → 62〜76行 → S1 からは1人ひとりの線が作れないので、S1 で100人の山を描くのはやめる。①OSF の個人のデータ（32項目のうち何個を浮気とするか。男性平均13.8・女性15.5 [S16]）で100人を並べ、「アメリカの公開データ」と画面に出す（男女別の分布は**計算する必要がある**）。②日本の第1章は、13項目の男女の棒（S1）と、男女の差がいちばん大きい「気持ち」・同点の「キス」[S2] だけにする。「山の幅のほうが広い」は①で見せれば、第2章の「人で決まる」への橋になり、作った絵ではなくなる。76行は消す。
- **心の動き（山の順番）** → 予想タイム（41〜46行）と第2章のはしご（124〜126行）と判定（216〜221行） → 最後に明かす答えをいちばん大きい驚きにする。案：予想タイムを32項目の問いに変え（選択肢のどれかに「掛け算の値」を置く）、第2章のはしごの3段目は「ほとんどの組が消えた」の絵だけ見せて、数字（約170組に1組）と掛け算との差は判定で明かす。32項目の掛け算の値は `sources.csv` にないので**計算する必要がある**。12項目のままにするなら、第2章で「170組に1組」を言わず、「9個食い違う」だけで進める（ただし、こちらは山が小さいまま）。
- **締め** → 229〜232行 → 教訓と締めの一文が同じことの言い直しになっている。締めの一文は、この動画でしか言えない逆説にする。材料はすでにある：判定で出す「ひとりの線は一本のものさしでつながっている（掛け算の約6倍残る）」と、「それでも、ふたりの線はほとんど重ならない」[S8]。この2つは向きが逆で、並べると逆説になる。地図の回収はこの向きで作り直す（言い回しは台本担当が決める）。教訓の文は、上の第3章の直しに合わせて「越えること」を外すか、言える範囲に絞る。
- **引き（痛み）** → 冒頭 11〜19行 → 2人の食い違いに、小さくても損を起こす。物語の中で（作り話なので数字は要らない）、たとえば彼女がそのあと黙る・彼が自分の先週の同僚との食事を思い出す、など、「浮気をしていないのに責められる／責める」が見える1〜2文を足す。痛みを足したぶん、教訓の「どちらも自分の地図の上では正しかった」が効く。
- **ミクロ** → 133〜139行 → 問いを「本物のふたりの違い」から「計算の上で、どの三つを先にそろえると、残る組が増えるか」に変える。「ほとんど増えませんでした」は「少し増えるだけでした（およそ170組に1組が120組に1組）」のように数字を添える【指摘集「どれくらい」が言えていない】。「2倍以上」は何と比べてかを言う（そろえない組と比べて約2.5倍、無作為の三つと比べて約2倍 [S9]）。
- **参加（自分の位置）** → 61行で線を引かせたあと → 引いた線が返ってくる場面を1つ足す。材料は `osf_more_position.csv`（13〜16項目を浮気とする真ん中の人が約1.3%でいちばん一致しやすく、21項目以上はほぼ0%）[S15]。ただし第1章の13項目と OSF の32項目は数え方が違うので、自分の線を当てはめるなら OSF の項目で段を作り直す必要がある（第1章の100人を OSF で作る案と一緒に直せる）。
- **言葉【指摘集「今は使わない言い方」】** → 138行「出会い系サイトを見ること」 → 1本目で「出会いサイト」を「マッチングサービス」に直した型と同じ。「マッチングアプリを見ること」など、OSF の項目の意味が変わらない範囲で今の言葉に。予想タイムの画面の12項目も同じ。
- **言葉【指摘集「日本語として分かりにくい」「比喩が字義どおりに聞こえる」】** → 140〜141行と第3章の札の「線を引く側」「線を越える側」、199行「満足が国境の手前の暮らしだとすれば、職場は、国境の向こうがよく見える場所です」 → 「〜の側」は「浮気かどうかを決めるとき」「実際に浮気をするとき」のような具体的な言い方に。199行は地図の比喩の使い方が変わっていて（国境＝人ごとの線だったのが、ここでは満足の境目になる）、字義どおりには「職場が浮気を生む」と聞こえる。職場が1位なのは、大人が異性と長く過ごす場所が職場だからでもありうる（配偶者と出会った場所でも職場は上位のはずだが、日本の数字で比べるには**調べる必要がある**）。この1文は消すか、「出会いの多い場所が、そのまま浮気の相手と出会う場所にもなる」程度に。
- **言葉【指摘集「前の文とつながらない」】** → 108行「よく言われる『男は体の浮気、女は心の浮気がつらい』という話も」 → クイズの答え（男どうしは体、女どうしは心で割れる）から話題が変わる。「体と心で割れる、と聞くと、よく言われる話を思い出すかもしれません」のように前の文との関係を言葉にする。
- **新しさ（第3章の男女別の理由）** → 180〜181行 → 「男性は性欲、女性は相手を好きになった」は、第2章で退けた通説（男は体・女は心）をそのまま強める並べ方。同じ表で差の小さい項目と並べるか、差（約1割）と「男女の中のばらつき」を先に言う。前回（`rival-outline-v3.md`）からの持ち越し。
- **絵（棒人間との違い）** → 115〜127行のはしご → 2段目（男女の多数決の線では1組も消えない）がうちだけの段なので、ここに時間をかける（男の線と女の線を重ねて、32本すべてが同じ高さに来る絵）。1段目と3段目は棒人間と見た目が同じなので短くてよい。
