# シミュレーション v2：紹介の町とアプリの町（2026-10-05）

コードは `render/src/lib/sim/towns.ts`（計算）と `render/src/lib/TownsSim.tsx`（描画）。台本 `script-v2.md` の数字は、ここの「種22」の結果（sources.csv の S14）。
画面には必ず「シミュレーション：仮定の世界」と出す。実データではない。

## 仮定（どちらの町も同じ100人）

| | 紹介の町 | アプリの町 | 根拠 |
|---|---|---|---|
| 人 | 男女50人ずつ。1人ずつ魅力の点数（平均0・ばらつき1）。10人ずつの知り合いの輪（男女5人ずつ）、輪は隣の輪とだけつながる | 同じ100人。輪は関係なく、全員が全員を見られる | — |
| 見え方のずれ | ±0.25（知り合いの紹介なので、相手がよく分かる） | ±0.6（他人どうし） | 仮定 |
| 出会い方 | 毎月、輪ごとに世話役が1組（相手のいない男性1人に、届く範囲の女性で点数が近い人）を引き合わせる | 毎月、異性25人のプロフィールを見て、自分より0.3上に見える人にいいね（男性は月8件、女性は月3件まで） | 少し上を狙う：Bruch & Newman 2018（平均約25%上）。送る数の差：同（最初の連絡の81%は男性） |
| 受け入れ | 自分より0.15下まで受け入れる（保証があるので） | いいねが届いたら、自分より0.3下まで返す。ただし、これまでに受け取ったいいねが多いほど基準が上がる（0.2 × log2(1＋累計)） | 基準が上がる：Pronk & Denissen 2020（見続けると受け入れる割合が約27%下がる）。**紹介の「保証」は根拠が弱い仮定**（research-mechanism.md の4） |
| ペア | 2人とも受け入れたらペア | 両思いになった人のうち、相手が多い人はいちばん良く見える1人を選ぶ | — |
| 期間 | 12か月 | 12か月 | — |

数値（0.3、0.2 など）は、いいねの偏りが実際の公表値に近くなるように決めた：種22で、男性の上位8人（16%）がいいねの51%を受け取る（Hinge の公表：男性の上位15%が50%）。女性は上位8人が59%（Hinge：上位25%が50%なので、女性側はやや偏りすぎ）。

調整の経緯：最初の設定（いいねを「いちばん良く見える人から順に」送る）では、男性の上位15%がいいねの9割を受け取り、実際の偏りより極端だった。いいねを「見た順に、上に見える人へ」送るように直し、基準の上がり方を「その月」ではなく「これまでの累計」にした。

## 種を変えても同じか（30通り）

| | 平均 | 最小〜最大 |
|---|---|---|
| 紹介の町 | 27.3組 | 21〜33 |
| アプリの町 | 17.9組 | 14〜22 |
| 少し上を狙わない | 31.6組 | 28〜36 |
| 基準が上がらない | 40.4組 | 36〜45 |
| 紹介の町で保証なし | 11.6組 | 6〜18 |
| 基準の上がり方が半分 | 31.2組 | 26〜35 |

- 紹介の町がアプリの町に勝つのは 30回中30回。
- ただし、紹介の町の「保証」（少し下まで受け入れる）を抜くと、アプリの町に勝つのは30回中1回だけ。
- 基準の上がり方を半分にすると、アプリの町が紹介の町以上になるのが30回中26回。
- つまり「紹介の町が勝つ」は、①紹介には保証がある、②候補が多いと基準が上がる、の2つの仮定に強く依存する。台本の第3章はこの依存をそのまま見せている（声でも「ここは仮定の世界です」と言う）。

## 1人だけやり方を変えたら（2026-10-05。ミクロ戦略の案）

`simulateApp(rs, { personal: { [id]: { aim: 0 } } }, seed)` のように、1人だけの値を変えられる。種1〜20で、各グループから5人に1人を選び、その人だけがやり方を変えたときに1年でペアになれた割合（ほかの99人はそのまま）。

| | そのまま | いいねを倍送る | 倍の人数を見る | 同じくらいの人にも送る | 少し下の人にも送る | 基準を上げない | 返す範囲を広げる |
|---|---|---|---|---|---|---|---|
| 男性・下半分 | 52% | 54% | 52% | 70% | 83% | 73% | 74% |
| 男性・上半分 | 29% | 31% | 31% | 60% | 82% | 89% | 57% |
| 女性・下半分 | 42% | 51% | 42% | 60% | 79% | 74% | 64% |
| 女性・上半分 | 25% | 29% | 26% | 56% | 83% | 93% | 41% |

- 数を増やしても（倍送る・倍見る）ほとんど変わらない。変わるのは「狙う高さ」と「基準を上げないこと」。
- 人気のある側（上半分）ほど、「基準を上げない」の効き目が大きい（女性・上半分 25%→93%）。
- 種22の2人：彼は「同じくらいの人にも送る」でペアになる（倍送るでは変わらない）。彼女は「基準を上げない」だけでペアになる。
- 注意：仮定から出てくる結果（狙いを下げればペアになりやすいのは、モデルの作りからほぼ当たり前）。驚きは「数を増やしても効かない」ほう。全員が同じことをしたとき：全員が同じくらいの人にも送ると 17組→31組（ペアになる人は34人→62人）。1人だけのとき（男性・下半分で70%）と比べて、はっきり小さくなるとは言えない。
- 台本に入れる（2026-10-05 オーナー「その形でOK」）。助言の言い方はせず、「もしも1人だけ〜したら、こうなった」というシミュレーションの結果として見せる（`script-v2.md` の場面 me）。
