## 3. 判定

### この台本が「面白い」と言える点

1. **「割合は倍、数では4割」という結論は10本にない。** 10本の見出しはどれも割合（シェア、格差、何人に1人）で話を進めていて、割合と実数のずれを山にした動画はない。#1 は「4年前よりネット1.8倍」を山場（181秒）にして終わっているが、この台本はその同じ数字を第1章で通過点にし、第3章で「それでも穴は埋まっていない」とくつがえす。#1 を見た人にも新しい。
2. **「ネットが置き換えたのは見合いではなく、友人の紹介と職場」は10本にない。** #1 の節は「見合いから3ルートへ」で、見合い→ネットの流れとして語っている（見出しから）。この台本は2021→2025年の差で、減ったのが友人と職場だと示し、アメリカの研究（S10）で裏付ける。思い込み（ネットが見合いの代わり）を一度言わせてから外す作りで、山が1つ増える。
3. **独自の推計を持つ。** 10本で独自の分析・シミュレーションがあるのは #7・#10 のみ。#7 は57.1万回で伸びた動画。推計を「4割ほど」「幅がある」と誤差の範囲で言い切っているので、#3・#4・#8・#9 に付いた「断定しすぎ」の指摘にも当たらない。
4. **締めが教訓で、物語を閉じる。** #1・#8・#10 は問いかけ、#5 は登録の呼びかけで締めている。この台本は祖母のひと言で冒頭に戻り、「割合の陰で何が消えたか」という、ほかの話題にも使える見方で終える。
5. **男女どちらも責めない。** 似た動画のうち #3・#9 は「対立あおり」、#8 は「企業と利用者の対立」を軸にしている。この台本はアプリを外から（社会全体の出会いの経路として）見ていて、男女のデータを両方出す。収益化ポリシーの面で安全。

### 「負けている」点

1. **冒頭が、伸びなかった #1 とほぼ同じ形。** #1 も「身近な人物の場面で出会い方の違いを描く」物語の入りで、問いも同じ。分析メモは「見出しと前置きの物語導入が地味で驚きが弱い」。この台本の物語は場面描写が丁寧だが、約40秒で出る数字（見合い半分）と問い（どこで出会っているのか）は、見る人の予想の範囲にある。伸びた側の入りは「45.5%」（#2）、「ジニ係数0.58で南アフリカ超え」（#9）、テーマから遠い逸話（#4・#6・#8）で、最初の1割で「え？」と思わせている。
2. **大きい山が後ろに偏っている。** いちばん大きい「4割」は約9.2分（全体の約77%）。前半の山（40年前の1位はお見合い、職場が増えた）は年配の人なら知っている話。#2 は90秒、#3 は45秒で最初の驚きを出している。CLAUDE.md の「冒頭の1割で離脱が決まる」に照らすと、前半で裏の問い（数で見ると？）の予告がないのが弱い。
3. **見る人の損得・痛みに触れていない。** 伸びた7本のうち6本は、問いに「不利」「損」「不幸」「高望み」が入り、見る人が「自分の話だ」と感じる。この台本で自分に当てはめる場面は「両親の出会い」で、過去の話。いま相手を探している人にとっての意味（出会いが用意されない時代にいる）は教訓まで出てこない。
4. **尺が短い。** 約12分で、標準の18分に届かない。伸びた恋愛チャンネル（lovebynumbers 15.5〜25.8分、kangaesugiruashi 17〜24分）より短い。一方で DataStickFigure（#7 9.9分）は短くても伸びているので、尺だけで負けとは言えない（仮説）。

### 「似た動画と重なっていて新しさがない」点

1. **第1章と答え合わせ（判定△）は、#1 の中身とほぼ同じ。** 同じ第17回出生動向基本調査の同じ図表で、「職場・友人・ネットがほぼ並ぶ」「ネットは4年で約2倍」「見合いから別のルートへ」「誤差の範囲」（#1 の「分かること・分からないこと」）まで重なる。#1 は699回で伸びていないので、「既に出ている答え」を目立つ位置に置くことになる。
2. **第2章のクイズ「交際を望まない人は男女でどちらが多い？」の数字は、#5 の冒頭の数字と同じ（3人に1人）。** #5 はそれだけで1本を作っている。
3. **「周りが用意する出会いが消え、相手探しが本人に任された」という説明は、#2「出会いは市場に」、#3「4つの手が撤退」、#4「門番のいない市場」と同じ方向**（いずれも見出しから。中身は未確認）。この台本は研究の内訳（約5割・4割近く）という数字を持つ点で一段深いが、言葉としては聞いたことがある人がいる。
4. **第3章の終わりの50歳時未婚割合（男性約3割）は、#10 や lovebynumbers の未婚化の動画で何度も出ている数字。** いちばん大きい山（4割）の直後にあり、知っている数字で山を下ろしてから判定に入る形になっている。

## 4. 台本で直せること（5つ）

ほかの動画の言い回しや構成はまねず、この台本がすでに持っている材料の並べ方を変える提案にしている。

1. **最初の1割で「数で数え直す」問いを予告する。**（負け1・2、重なり1に対して）
   いまの道案内（約1.5分）の3つ目「割合ではなく夫婦の数で数え直すと」を、冒頭の物語の終わりか通説カードの直後に、問いとして前に出す。例：「アプリで出会う夫婦は4年でほぼ倍。では、出会う夫婦の数は増えたのでしょうか」。答えは言わない。#1 と同じ問いで始まる印象を消し、9分まで待たずに「この動画にしかない問い」を見せる。通説そのもの（アプリがいちばん多い）を変えるかどうかはオーナーの判断が要る（`docs/decisions.md` に決定はない）。

2. **第1章の「割合の移り変わり」を短くし、第2章・第3章に時間を回す。**（重なり1に対して）
   見合い→職場→友人→ネットの順番は #1 と同じなので、両親の出会いを当てはめる場面（この台本の強み）は残し、そのほかの説明は群衆の並び替えの絵に任せて読み上げを減らす。浮いた時間で、第3章に outline.md で予定していた「条件によって変わる」場面を戻す：比べる期間（4年か10年か）で埋まった割合が4割〜6割に動くことを、スライダーで見せる（sources.csv の S9 に値がある）。CLAUDE.md の「言い切れない部分はシミュレーションで見せる」にも合い、尺も18分に近づく。

3. **第2章のクイズを、この台本にしかない発見に替える。**（重なり2に対して）
   「ネットが伸びた4年で、割合を減らしたのはどれ？ お見合い／職場と友人の紹介／学校」と予想させる。多くの人が「お見合い」を選ぶはずで、答え（職場と友人）が山になる。「交際を望まない人は男女とも3人に1人」は、クイズにせず1行の事実として残す（男女両方のデータを出す決まりは守れる）。

4. **研究の内訳を、見る人が当てる場面にする。**（重なり3に対して）
   「結婚する人が減った分のうち、恋愛結婚が減った分はどれくらい？」と聞いてから、100組の人型が「見合い約5割・職場4割近く・その他の恋愛結婚はほぼ動かない」に並び直す絵（outline.md の第3章で予定していた見せ方を第2章で使う）。「周りが用意する出会いが消えた」という、似た動画と同じ方向の説明を、言葉ではなく数字の驚きで伝えられる。2002年までのデータであることは、いまの台本どおり言う。

5. **第3章を「4割」の山で終え、50歳時未婚の数字は外すか教訓の手前に1行で移す。**（重なり4・負け3に対して）
   知っている数字で山を下ろさない。その代わり、教訓の手前に「いま相手を探している人は、出会いが用意されない最初の世代にいる」という、見る人が自分に当てはめられる1〜2文を足す（助言にはしない。「〜すべき」は使わない）。負け3（損得・痛みに触れていない）を、対立をあおらずに補う。
