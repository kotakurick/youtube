## 直すもの（離脱しやすい順）

- **予想タイムの前の決まりの説明が67秒続き、問いもすぐ解けてしまう（1:23–2:56、L36–55）** → いちばん離れやすい最初の15%で、「魅力の点数」「好みのずれ」「8割は男性から」と決まりを聞かされ、何のために聞いているのか分からない時間が1分を超える。やっと出た問いも2択で、冒頭の「入り口は広がったのに出口は細い」とヒントの「何十倍も選べる」から、疲れた人でも「紹介の町でしょ」と分かる。そのため、6:23の答え合わせは「知ってた」で終わり、ためが効かない。→ 町を2つ見せたらすぐに問いを出し、決まりは問いのあとに必要な分だけ（8割の話は第2章のハートの場面へ回す）。問いは2択ではなく「アプリの町のカップルは、紹介の町の何倍？ A 2倍以上 B 同じくらい C 紹介の町より少ない D 半分以下」のように、Cを当てても「どれくらい少ないか」は判定まで分からない形にすると、答え合わせまで引っぱれる。
- **第4章の「世話焼きはどこへ」が80秒の列挙になる（10:29–11:49、L198–215）** → 第3章のいちばん大きい山のすぐあとで、職場3組に1組、仲人の歴史、社員旅行、非正規7人に1人→3人に1人、職場恋愛7割、4人に3人と、数字が80秒で6〜7個並ぶ。問いの答えが1つの数字に決まらないので、どこで分かったのかが分からないまま説明が続く。20〜30代には「仲人」「社員旅行」は遠い話で、ここで閉じやすい。→ 仲人の歴史（L203–205）を画面の注記にまわし、残りは「職場」の1本にしぼる。章で考える場面がないので、「職場恋愛を『したくない』人は何割でしょう」を問いにして〔間〕を置き、7割・女性は4人に3人を答えにすると、自分ごとの場面と山が一度にできる。
- **第4章の山（罠）のあと、ジャムとスピードデートで山が下がったまま章が終わる（13:02–13:54、L235–245）** → 「一人ひとりには正しいのに、町全体では減る」で、見ている人の「なぜアプリはなくならない？」は答えが出て、気持ちは「なるほど」で止まっている。そこへ多くの人が聞いたことのあるジャムの実験が来て、すぐ「いつもそうなるわけではない」と打ち消され、スピードデートは第3章（基準が動く）の話に戻る。新しい問いがないまま50秒進む。→ ジャムは切るか画面の注記にする。スピードデートの「ひと目で分かることで選ぶ」は第3章の犯人2の裏付けに移すと、第3章の山がもう一段高くなる。第4章は「罠」の一文で終え、すぐ L245 の「それでもうまくいく人は？」へつなぐ。
- **第5章の3つ目が、ただし書き2つで終わり、教訓の直前で気持ちが下がる（15:40–16:37、L279–289）** → 1つ目と2つ目は、彼と彼女が実際にペアになる手応えがあったのに、3つ目だけシミュレーションも主人公も出てこない。講義の実験のあとに「嫌いになる場合もある」「アプリも悪くない」と2回打ち消すので、「結局どうなの？」で教訓に入る。動画の85〜90%の位置で、最後まで見るかを決める所。→ 3つ目もシミュレーション（同じ相手に会える回数を増やした1人）で数字を出せるなら出し、出せないなら研究1つと「あなたには、同じ顔ぶれと何度も会う場所がいくつありますか」の問いにして短くする。ただし書きは画面の隅へ回す（brand.md「断り書きは画面の隅と概要欄へ」）。
- **教訓が第5章とぶつかり、冒頭の「ふたりは出会えるのか」に答えない（16:37–17:13、L293–299 と L23・L262・L274）** → 冒頭の「歩いて10分の距離に住んでいて、出会うことはない」は、見ている人に「このふたりがいつか出会う」話を期待させる。けれど教訓では、ふたりはそれぞれ別の相手とペアになる。しかも1分前の第5章で、ふたりともアプリの町でペアになったと聞いたばかりなので、「アプリの町では、ふたりともひとりのままでした」に「あれ？」となる。さらに第5章の「自分の選び方を変えれば変わる」と、教訓の「自分のせいではない、仕組みのせい」が、つながりを言われないまま並ぶ。→ 教訓の最初を「何もしなかったふたりは、ひとりのままでした」のように第5章を受ける言い方にする。最後は outline の「仕組みが細った時代には、仕組みの代わりを自分の手で持った人がうまくいっていた」の方向で、仕組みと個人の話を1文でつなぐ。ふたりどうしが出会えるかはシミュレーションで確かめ、出会えないなら、冒頭の L22–23 を「なぜふたりとも、ひとりのままなのか」という問いに変えて、期待を外さないようにする。
- **第3章のいちばん大きい山のすぐあとに、条件の話が2つ続いて混乱する（9:17–9:55、L177–184）** → 40組で「主犯は基準」と言い切った直後に、保証を抜いた13組と「基準の上がり方を半分にすると、今度はアプリの町のほうが多い」が来る。耳では「アプリの町」が、保証を抜いた紹介の町と比べているのか、元の紹介の町と比べているのか分からない。「どちらが勝つかは条件次第」と聞くと、答え合わせのAまで揺らいだように感じる。→ 13組の実験だけを残して「紹介の町の強さは、知り合いの保証だった」と言い切る。基準の上がり方による違いは画面の隅か概要欄へ回す。残すなら「つまり、勝ち負けを決めていたのは、さっきの主犯、基準の動きでした」と、主犯の話を確かめる形で言う。
- **第4章と第5章に、自分で予想する場面がない（9:58–16:37）** → 第1章（紹介してくれる人は何人）と第3章（犯人を1人だけ捕まえるなら）には考える場面があるのに、後半6分半は答えを順に聞くだけになる。第5章は「自分はどうすれば」がいちばん強い区間なのに、答えの前に間がない。→ 第5章の頭で「いいねを倍にするのと、同じくらいの人にも送るのと、どちらが効くでしょう」と聞いて〔間〕を置くと、L258–261 の「倍は効かない」が予想を外す山になる。第4章は2件目の職場恋愛の問いで足りる。

## よくできている所

- 冒頭の「選ばれない彼と、選べない彼女」（L21）は、男女どちらが見ても自分を重ねられる一行で、オーナーの「男女がフラットに見たくなる」にいちばん応えている。どちらも責めない作りが最後まで続いている。
- 第2章の入り「いきなり11組。やはり、選べる町は強い。そう思った、次の月でした」（L92–94）は、見ている人をいったん説の側に立たせてから崩す。v2 の「結果を順に報告する」淡白さが、ここでは消えている。
- 「彼女もまた、選ばれていなかったのです」（L122）は、勝ち組に見えた側も負けていたと分かる第2章の山。女性の側のデータを、物語のどんでん返しとして出せている。
- 第3章の「犯人をひとりだけ捕まえられるとします」（L164）は、本当に迷える問いで、答えの40組が紹介の町の27組を追い抜くので、予想が外れる気持ちよさがある。v3 でいちばん強い区間。続く「道具が、私たちの選び方を変えていた」（L174）で、アプリを悪者にしない言い方になっている。
- 第4章の「罠」（L230–234）は、「なぜアプリはなくならないのか」に、一人ひとりは正しいのに全体では減る、という仕組みで答える。オーナーの「社会的な構造変化」の求めに応え、移っていくほど輪が細る絵（L224–227）とも合っている。
- 第5章の「いいねを倍にしても、ほとんど変わりません」（L258–259）は、見ている人が真っ先に思いつく作戦を外す。示唆を命令形にせず、「同じくらいの人にも送ると7割」と結果で見せていて、助言にならないまま役に立つ。
- 締めの一文「選べる相手が多いほど、人は選べなくなるのです」（L308）は、短い逆説で、冒頭の「選べない彼女」に戻る。「うまくいかないとき、人は自分に何かが足りないと考えがち」（L300）は、見ている人を少し救ってから終わるので、閉じたあとの気持ちが温かい。
