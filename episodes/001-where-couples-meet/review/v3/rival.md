2026-10-05。台本の段階。対象は `outline-v3.md`（企画カード）と `script-v3.md`。
手順どおり、下の「〜が作るなら」2つは、テーマ「アプリで出会いは増えたのに、なぜ結婚は増えないのか」だけを見て、うちの案を読む前に書いた。相手の分解は `research/benchmark/teardown/` の2本（どちらも1本ずつの分析なので仮説）。

## 考えすぎる葦が作るなら

- タイトル：「なぜマッチングアプリは結婚を増やさないのか【恋愛×経済学】」。または逆説を前に出して「出会いは過去最多、結婚は戦後最少──なぜアプリは結婚を減らすのか【選択×社会学】」。
- 最初の30秒：物差しを先に渡す。「お見合い全盛の時代、結婚の半分は他人が決めていた」→「いま、アプリで出会う夫婦は4組に1組（民間調査）」→「その同じ年に、婚姻数は戦後最少」。数字は10個近く出る。「史上最大の出会いの装置が、結婚の数を1組も増やしていない」と持ち上げて落とし、問いを立てる。3分ごろに「アプリで男が選ばれないから、と思ったでしょう。この動画はそこで終わらない」と先回り。
- 章立て：立場を回り、だんだん広げる。
  1. 選べる側（いいねが届き続ける人。選択のパラドックス、ジャム24種類、「もっといい人がいる」）
  2. 選ばれない側（拒絶の蓄積、ELOスコア、課金）
  3. 企業の側（成功したユーザー＝退会する顧客。結婚させないほうがもうかる帳簿）
  4. 社会の側（お見合いと職場結婚という「結婚させる仕組み」が消えた。非正規、所得）
  5. 歴史の側（村の150人、進化的ミスマッチ）
- 比喩と締め：「市場」「棚」「回転寿司のレーン（次の皿が来ると思うと取れない）」。締めで回転寿司を回収し、「出会いが増えたのではない。結婚を決めてくれる人が消えただけだった」→「そんなことを考えすぎてみました」。研究の強さは言い過ぎ（相関を因果で言う）、データは米国中心、絵は文字が半分、参加の場面はない。

## データで語る棒人間が作るなら

- 装置：男女100人ずつが10年暮らす町。毎年、出会い→デート→交際→結婚の4段の漏斗を通る。出会いの経路（職場・友人・アプリ）ごとに、次の段へ進む確率が違う。「どうなるだろうか。実行してみよう」で毎回回す。
- はしご（理想の世界 → 足していく原因）：
  0. 理想の世界：全員が年に同じ数だけ出会い、同じ確率で次へ進む → 毎年同じ数の結婚。
  1. アプリを足す：出会いの数が3倍に → 結婚も増える（「ここまでは予想どおり」）。
  2. 1回の出会いあたりの進みやすさを下げる（共通の知人がいない、比べられる相手が多い）→ 増え方が小さくなる。
  3. 人気の偏りを足す → 一部に集中、中央値の人は出会いが増えない。
  4. アプリが職場・友人の出会いを「置き換える」→ 結婚はほぼ横ばい。
  5. 若い人口の減少と所得の条件（アプリの外の原因）→ 結婚は減る。
- 途中の発見：「アプリで結婚した人の割合が増えた」は「アプリが結婚を増やした」ではない（ほかの経路が減ったぶん割合が上がるだけ。割合と数）。「出会いの平均は3倍、でも中央値の人はほとんど変わらない」。
- 限界の言い方：確率は仮定、文化とアプリの違いは入れていない、アプリに反対ではない。締めは「仕組みは見え方をゆがめうる」と一般的で、物語・ミクロ・逆説の一文はない。登録の呼びかけで終わる。データは海外。

## 勝つための直し方（効果の大きい順）

1. **絵（まねに見えない）→ 第4章 235〜241行（ジャム24種類）→ 削る。** 葦の当たり回の中心の例そのもので、相手を見た人には「同じ話」に見える。しかも再現性が弱い（S19のメタ分析で平均ほぼゼロ）と自分で断っている。「人は選べるものが多い場所に集まる」は、すぐ後のスピードデート（S20：相手が大勢の回ほど身長・体重で選ぶ）だけで言える。空いた20秒は、うちの独自の発見「1人ひとりには正しいのに、町全体では減る」（230〜234行）を絵で見せる時間に回す（移った人の割合を横軸、町全体の組数を縦軸にした下がる線。数字は outline-v3 のシミュレーション③の表にあるものだけ）。
2. **引き → 冒頭22行「歩いて10分」と教訓296〜299行 → 回収する。** 冒頭で「同じアプリの中、歩いて10分」と言った以上、見る人は「この2人は会えばうまくいくのか」を最後まで抱える。教訓で2人を紹介の町に住ませる場面で、2人が同じ輪にいたら引き合わされたかを `towns.ts` で確かめる（種22の彼と彼女の点数が「0.15下まで受け入れる」範囲に入るか）。入るならその結果を、入らないなら冒頭の「歩いて10分」を「同じ町の、同じアプリの中」までに弱める。数字や結果は新しく作らず、シミュレーションを回して出たものだけを使う（調べる必要がある）。
3. **ミクロ → 第5章 256〜276行 → 戦い方ごとに男女両方を見せる。** `sim-v2.md` の表に両方ある。戦い方1は「女性・下半分も、同じくらいの人に送ると42→60%」、戦い方2は「男性・上半分も、基準を上げないと29→89%」を並べ、「性別ではなく、人気のどちら側にいるかで効くものが違う」と言う（表の注にある読み取りどおり）。同じ数字を読み上げすぎないよう、読むのは片方だけにして、もう片方は画面に出す（1分に数字が7個で lint の注意も出ている）。
4. **締め → 302〜308行 → 最後の一文を、うちの発見から作る。** 「選べる相手が多いほど、人は選べなくなる」は葦と同じ主題。うちにしかない発見は「1人ひとりにとって正しい選択が、町全体の結婚を減らす」と「主犯は数ではなく基準が動くこと」。この2つのどちらかから、選ばれない側と選べない側の両方が入る短い逆説にする（文案は書き手に任せる。例の型：「ひとりずつ正しく選んだ結果、町は選べなくなった」）。305行の言い直しと重ねない。

### 守ったこと
- 数字は新しく作っていない。足りないものは「調べる必要がある」「シミュレーションを回して出たものだけ」と書いた。
- ミクロの直しは「〜すべき」にせず、条件を変えた結果として言う形にした。
- 相手の言い回し（「考えすぎてみました」「実行してみよう」）は台本に持ち込まない。上の相手の案は比べるためだけのもの。
