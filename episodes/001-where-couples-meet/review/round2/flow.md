## 直すもの（離脱しやすい順）

- **第3章の前半：問いのすり替えと数字の洪水が、新しい山の手前で足を引っぱる（8:49–10:50、L151–167・L178）** → 8:49で「穴は埋まった？」と聞いたのに、ケーキのあと「ネットで出会う夫婦は本当に増えたのか」（L158–159）に問いが変わり、答えは「ちゃんと増えていました」。ひねりを期待させてひねりがなく、肩すかしになる。そのあと約50秒で 49万・37万・5万・7万・31万・16万・15万 と7つの数字が続き、疲れた人は15万を覚えたまま予想に入れない。さらに「ネットは5万→7万（約2万増）」を聞いた直後に「ネットと相談所で増えたのは9万組」（L178）が来るので、計算した人ほど「合わない」と混乱し、山の瞬間に気持ちが止まる（9万は2015年に「ネット」の答え方がなかった所からの増え方。sources.csv S9）。→ ケーキの問いは L151 の「穴は埋まったか」のまま通し、L156–159 と L165–167（ネット単独の組数）は削るか画面だけにする。49万・37万も画面に回し、語る数字は「31万→16万、15万が消えた」と「9万・6割」に絞る。
- **第2章の後半が3分かけて下り坂（5:30–8:31、L103–142）** → 「取って代わったのは友人と職場」（5:06–5:30）でいちばん驚いたあと、アメリカ → 共通点 → 2000年代までの研究 → クイズ → 相談所 → まとめ、と納得型の話が3分続く。研究で時代が一度20年前へ戻り、クイズで個人の意識へ行き、相談所で仕組みへ戻るので、話の向きが二度変わる。章は「5:30で聞いた話」の繰り返しで終わり、問いを持たずに第3章へ入る。→ 相談所（L137–140）を共通点・橋（L109–116）のすぐ後ろへ寄せて「周りの代わりに仕組みが用意し始めた」を一続きにし、研究とクイズはその後ろにまとめる。章の最後は1行の答え合わせのあとに「では、新しい仕組みは、消えた出会いの穴を埋めたのでしょうか」と第3章の問いを先に開いて終える。
- **第3章が山のあと、ただし書きと抽象的な一文で終わる（11:05–11:29、L184–188）** → 「4割は空いたまま」「穴そのものが大きかった」で気持ちが上がった直後に、推計の幅・原因は別かもという注意が24秒続き、最後の「割合だけでは見えなかったものが見えてきます」は何が見えたのかを言わないので、ぼんやりしたまま判定に入る。第1回の「まだ分からない」よりは良いが、章の終わりはまだ下り坂。→ 推計の幅（L184–185）は 9万・6割を出す前に1文で済ませる（画面に「推計」の札もある）。章の最後は「4割は空いたまま」という分かっている一点に戻して言い切る。
- **第1章の当てはめで、考えても何も返ってこない（3:27–4:00、L71–78）** → 第1回と同じ形が残っている。「ご両親は多数派でしたか」に返るのは「同じ／珍しい」だけで、「少し珍しい出会い方をしたことになります」は言い換えなので気づきがない。疲れた人は考えるのをやめ、ここで止まる。→ 母の世代（1990年ごろ）を例に「職場が3組に1組」のように数字が返る形にし、画面の年表は結婚した年を選ぶとその年の割合が出るようにする（第1回の案のまま）。
- **第1章、答えのあと問いのない説明が約50秒（2:07–2:57、L52–62）** → 小さな問題で入りは良くなったが、答え（お見合い）のあと、見合いの中身・逆転の時期・調査の名前と対象・並べ替えの予告が続き、次の問いが開かない。「代わりに大きくなったのが、職場です」（L63）も、問われる前に言われる。→ 調査の名前と対象（L58–60）は画面の出典に任せて1文にし、L62 のあとで「では、お見合いの代わりに大きくなったのは、何でしょうか」と短く聞いてから職場を出す。

- **第3章の入りの50歳未婚が、章の問いとつながらないまま置き去り（8:31–8:49、L146–150）** → 章でいちばん重い数字（40人に1人→約3割）で強く引き込むが、すぐ「ネットは穴を埋めたか」に話が移り、最後まで戻ってこない。見ている人は「この3割と、埋まらなかった4割はどうつながるの？」を抱えたまま答えをもらえない。→ 4割空いたまま（L180）のあとで「50歳まで一度も結婚しない人が増えたのは、この空いた分とも重なります」のように1文で結ぶか、入りの一文を「この穴は、どこへ行ったのか」と第3章の問いにつながる言い方にする（因果を言い切らない範囲で）。
- **教訓の最後の2文が、動画で見ていない話（13:33–13:45、L224–225）** → 「割合と数を分けて見る」で「なるほど」となった所に、「うまくいかないことが本人のせいに見えやすい」が新しく来る。動画の中にはこれを支える場面がないので、最後の10秒で少し置いていかれる。→ 締めを「伸びた割合の陰で何が消えたか、全体の数はどうなったか」までで終えるか、第2章の「周りが用意していた出会い」と一言でつないでから言う。

## よくできている所

- 冒頭の居間の場面は、3世代の出会い方の違いが1つの食卓で見え、0:40ごろに「夫婦の半分が見合い」という最初の数字が物語の中で出る。「アプリ」と答えさせ、視聴者を説の側に自然に立たせている。
- 道案内（1:43–2:00）が3つとも問いの形になり、予想の答えを待つ間も「何に取って代わった？」を抱えていられる。
- 第1章は「100組に1組 → ネット4年で倍」の山の高いまま章が終わるようになった（570組の注意を判定へ移したのが効いている）。
- 第2章の入り「ネットが見合いの代わりになった、と思うかもしれません → 見合いはもう残っていなかった → では何が減った？」は、視聴者の予想を言葉にしてから裏返しており、動画の中でいちばん鋭い30秒。
- 第3章の「15万組が消えた → 全部か、半分か、少しか → 6割、4割は空いたまま」は、本当に考えたくなる予想とためがあり、章の山として機能している。第1回の「計算すれば分かるスライダー」より確実に良い。
- 判定の証拠1で順位を言わず、予想の答え（A 職場）を最後まで引っぱれている。△に「どの調査で数えるかで変わる」と条件を一言で添えている。
- 祖母の一言「親せきのおばさんが、アプリだったのね」は、動画全体の答えを人物の言葉で言い直し、笑いと「なるほど」が同時に来る。教訓の「伸びた割合の陰で何が消えたか、全体の数」は第3章の発見を一般化しており、第2章の言い直しではなくなった。
