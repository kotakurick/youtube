## 見る人が最初から予想していること

台本を読む前に、テーマ（見合いからアプリまで）と通説だけを見て書き出したもの。

1. いまはマッチングアプリで出会う夫婦がいちばん多い（通説そのもの）。
2. 昔は見合いが主流で、どこかで恋愛結婚に逆転した。アプリは、消えた見合いの代わりになった。
3. 職場結婚は減った（ハラスメントへの配慮、働き方の変化）。
4. 友人の紹介は、昔もいまも変わらず多い。
5. 出会いの場が減ったから結婚が減った。一方で、アプリ婚は軽い・長続きしないのではないか。

## 持ち帰れる見方

- 第1稿：中（教訓の芯が第2章の研究結論の言い直し）。
- 第2稿：**強（ただし最後の2行は裏付けが薄い）**。
  - 「新しいものが伸びているとき、伸びた割合ではなく、その陰で何が消え、全体の数がどうなったかを見る」は、テーマの外に持ち出せる見方になった。第3章のケーキの比喩と組数の推計がそのまま裏付けになっていて、第2章の言い直しではない。
  - 祖母の「親せきのおばさんが、アプリだったのね」から「出会いの場所を用意していたのは、いつも本人の外にある仕組み」へのつなぎは、第2章の「周りが用意する出会い」を物語の言葉で一般化できていて、よい。
  - 弱いところ：最後の「うまくいかないことが本人のせいに見えやすい」は、この回のデータでは示していない。独身の人自身が理由をどう答えているか（提案4）を足せば、言い切れる見方になる。
  - 判定が△のときの「何の条件で変わるか」は「どの調査で数えるか」と言えている。第3章の「約6割」にも同じ形（どこから比べるかで4〜6割）を当てはめると、教訓の「数を見る」と判定の「調べ方で変わる」が1本につながる。

## 深めるための提案（効果の大きい順、最大5件）

1. **第3章の「埋まったのは約6割」**（章の山の数字）
   → 比べる起点で埋まり具合がどう変わるかを、シミュレーション（起点の年を動かすスライダー）で見せる。手元の CSV で計算すると、①台本どおり 2015→2025年：約6割（91,413組÷153,452組）。②2015年の「その他」4.0%と「メディアを通じて」1.0%を、当時の選択肢がなくてネットを答えられなかった組と見なして差し引く：約4割強（約66,700組÷153,452組）。③どちらの回にもネットの選択肢がある 2021→2025年だけで比べる：約4割（27,424組÷70,326組）。
   → 発見：「どう数えても、消えた分の半分前後は埋まっていない。いちばん甘く数えても6割」。言い切りが強くなり、CLAUDE.md の「言い切れない部分は条件によって変わるとシミュレーションで見せる」も満たす。いまの「約6割」1本だと、起点の分類変更で上ぶれした値だけを言い切っている。あわせて、2020〜2024年はコロナ禍で、対面の出会い（職場・友人）が減ってネットに移りやすかった期間だと一言添える（理由として言い切らない）。
   → 調べ先：社人研 第17回 図表5-3（一次資料。既存の data/ipss_jnfs17_fig5-3.csv と data/estimate_couples_by_channel.csv）https://www.ipss.go.jp/ps-doukou/j/db_17/17GaiyoBaseData/JNFS17gaiyoFigure5-3.csv ／ 人口動態統計 第9.5表（一次資料、S8）。上の3つの値は Claude の計算なので、★工程で確かめて S9 のメモに足す。

2. **第2章の「ネットが置き換えたのは友人と職場」**（起点を 2021年にする）
   → 2015→2025年ではなく、同じ選択肢で聞いた 2021→2025年を主に見せる。ネットは 11.0→20.2%（約9ポイント増）、友人の紹介は 24.9→20.2%、職場は 25.6→20.9%（どちらも約5ポイント減）、学校は 13.8→14.0%でほぼ動かず。
   → 発見：「ネットが増えた分と、友人と職場が減った分が、ほぼぴったり重なる。学校は動いていない」。2015年起点だと、ネットの選択肢を新しく作ったことによる移り（「その他」4.0→0.7%、「メディアを通じて」1.0%が消滅）が混ざるが、2021年起点ならその疑いがなく、強い発見を守れる。国の概要も「職場や友人を介した結婚が減り、アプリ等で知り合った夫婦は2割に」と同じ見出しを立てているので、言い過ぎにもならない。
   → 調べ先：社人研 第17回 図表5-3（一次資料）上と同じ URL ／ 第17回 結果の概要のページ（一次資料）https://www.ipss.go.jp/ps-doukou/j/doukou17/doukou17_gaiyo.html 。注意：2021年は約720組、2025年は約570組なので、1つ1つの差は「割合で見ると」と添える。

3. **第1章の終わり「かつての一番手は、ほとんど姿を消した」**
   → 結婚年次別の図表5-2では、見合い結婚（見合い＋結婚相談所）は 2010〜14年の 5.3%（95%信頼区間 4.0〜7.0）から、2020〜24年の 8.9%（同 6.7〜11.5）へ増えている。区間が重ならない。
   → 発見：「親せきが用意するお見合いは消えたが、相手を用意してもらう結婚そのものは底を打って増えている。担い手が親せきから相談所という仕組みに移った」。第1章に予想2をくつがえす発見ができ、教訓の「親せきのおばさんが、アプリだった」の伏線にもなる。いま第2章にある相談所の話（中）を強く言い直せる。
   → 調べ先：社人研 第17回 図表5-2（一次資料。既存の data/ipss_jnfs17_fig5-2.csv、S2）https://www.ipss.go.jp/ps-doukou/j/db_17/17GaiyoBaseData/JNFS17gaiyoFigure5-2.csv 。注意：図表5-2の「見合い結婚」は相談所を含む定義で、図表5-3の「見合い 1.1%」とは別もの。画面で定義を分けて書く。

4. **教訓の「うまくいかないことが、本人のせいに見えやすくなる」**
   → 独身でいる理由（結婚するつもりの未婚者）で、25〜34歳では「適当な相手にめぐり会わない」がいまも最多だが、前回より下がった、という第17回の結果を第3章の「空いたままの4割」の直後か教訓の手前に置く。WebFetch で取れた値は 25〜34歳の男性 43.3%→39.2%、女性 48.1%→39.9%（第16回→第17回）。取得の過程で表の読み取りが崩れた部分があったので、この値は★工程で CSV を開いて確かめるまで台本に入れない。
   → 発見：「独身の本人たちも、いちばんの理由に『めぐり会わない』を挙げている。つまり本人たちも出会いの仕組みの問題だと感じている。ただしその割合は下がり始めた」。教訓の最後の2行にデータの裏付けが付き、第2章の「距離を置く人も増えた」とも矛盾なくつながる（下がった分が何に移ったかは、確かめるまで言わない）。
   → 調べ先：社人研 第17回 図表1-10「調査別にみた、未婚者が独身にとどまっている理由」（一次資料）https://www.ipss.go.jp/ps-doukou/j/db_17/17GaiyoBaseData/JNFS17gaiyoFigure1-10.csv ／ 図表一覧 https://www.ipss.go.jp/ps-doukou/j/db_17/db_17GaiyoBaseData.html

5. **予想5の後半（アプリ婚は軽い？）にふれる場面**（第2章の相談所の後、または第3章のネットの組数の後）
   → ネットで知り合った夫婦は、恋愛結婚全体と比べて出会った年齢が高く、交際期間が短い、という第16回の報告書の分析を使う。検索結果の要約では、ネットは出会い年齢が夫27.8歳・妻26.2歳、交際期間2.8年（恋愛結婚全体は 25.3歳・23.8歳、4.9年）。要約からの値なので、報告書の本文で表番号と値を確かめるまで使わない。
   → 発見：「仕組みが候補を並べると、遅く出会っても早く決まる」。予想5の「アプリ婚は軽い」を、軽さではなく速さの話に置き換えられ、「仕組みが結果を決める」という教訓にもう1本の裏付けが付く。
   → 調べ先：社人研『現代日本の結婚と出産－第16回出生動向基本調査報告書』（一次資料）https://www.ipss.go.jp/ps-doukou/j/doukou16/JNFS16_reportALL.pdf 。アプリ婚の離婚率は、学生のゼミ論文など一次資料と言えないものしか見つからなかった（未確認の方向性。扱わないなら、それでよい）。

- 補足（第1回の提案4「なぜ職場の出会いが減ったのか」）：第2稿でも扱っていない。手がかりは、労働市場と結婚を扱った『日本労働研究雑誌』の論文（一次資料、職場の出会いの減少を直接分析したものかは未確認）https://www.jil.go.jp/institute/zassi/backnumber/2013/09/pdf/033-042.pdf 。時間（13分45秒）に余裕があるので、提案1〜3を入れたあとで検討する。
