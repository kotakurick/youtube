## 見るところごとの所見

1. **0.3秒（168px）**：「選ばれない」「選べない」（108px）は168pxで約14px。はっきり読める。左右の色の対比も一瞬で入る。弱いのは2つ。「マッチングアプリ」（62px）は168pxで約8pxで、つぶれかける。主題の名詞なのに一番小さい。もう1つは人で、168pxでは「白い四角に丸が乗ったもの」が2つ。彼のハート1つ（`#FF8FA3`・r30）は青の上で約4pxのピンクで、ほぼ見えない。だから「1つと山」の差が絵から伝わらない。
2. **競合の間**：並びの4枚のうち3枚が黒地。そこに青と赤が全面に入るので、明るさと色の面でいちばん浮く。これは大きな武器なので守る。ただし、隣の棒人間と葦の1位（マッチングアプリのパラドックス）も「青＝男・赤＝女」。色の割り当ては一般的な決まりなので丸写しではない。それでも、赤をブランドの橙（`C.female #D9541E`）に寄せると見分けやすくなり、ブランドとも合う。今の `#E0301E` は theme.ts にない赤で、theme.ts では赤は「借金・損」の色（`owner-feedback.md`「色は theme.ts の色だけ」の型）。
3. **問い**：「選ばれない／選べない」は、両方とも困っているという逆説になっていて、「じゃあ誰が得してるの？」という空白が生まれる。悪くない。ただ、右の彼女はハートに囲まれて「モテて楽しい人」に見える。そのため「選べない」のつらさが絵になっていない。困っていると見えれば、逆説が絵だけで成り立つ。
4. **文字とタイトルの重なり**：サムネイルの3語（マッチングアプリ・選ばれない・選べない）はタイトルとほぼ同じ。ふつうは損だが、**今回は重なってよい**と判断する。理由は3つ。新しいチャンネルで、まだ見た目で覚えてもらえていない。オーナーの最優先は「分かること」。ホームでもタイトルは2行目で切れやすく、サムネイルが主題を言わないと分からない（t-voice2 で実際にそうなった）。そのかわり、タイトルにないものは絵で足す。「ハート1つとハートの山」の差が、タイトルにない情報になる（直し2）。
5. **絵**：
   - 2人とも正面向き・左右対称で、両手を胸の前に置く同じ姿勢をしている。棒人間の人たちが感情を伝えているのは、横向きや3/4の向きと、はっきりした身ぶり（前かがみ・頭を抱える・ひじを上げる）。正面で対称の姿勢は、どうしてもマネキンや案内板に見える。
   - 彼は `MAN_SLUMP` という名前なのに、うつむいていない。頭（y -872）が首（-800）の真上にあり、ひじ（x ±128）が肩（±98）より外に張り出している。そのため腕がひし形になり、胸を張っているようにさえ見える。
   - 腕のまわりの「すき間」（`gap` の rgba 0.5・10px）は、原寸だと紺や臙脂のふち取りに見える。切り紙の人形のようで、ここがいちばん安っぽい。
   - 脚は画面の下で切れていて、切り欠きのある四角（ズボン）に見える。腰より下は情報がないので、画面の外に出したほうがよい。
   - 彼女の頭と長い髪は一続きの縦長のカプセルになっていて、首も肩の線も消えている。168pxでは「女性」より「フードの人」に近い。
6. **ポリシーとかぶり**：数字はなく、誇張もない。見下す表現もない。男女の対立はオーナー判断（10/04）で使ってよい。気をつけるのは、背景の色が性別を表すため、左右が「男という側／女という側」、つまり性別全体の話に読まれやすいこと。右が「選べない＝えり好みする女」と読まれると、性別全体を責める絵に近づく。防ぐには、(a) 2人を1人ずつの人として描き分け（違う姿勢・違う感情）、(b) 彼女を「勝っている側」ではなく「困っている側」に見せ、(c) 文字に「男／女」を入れない。今の文字は (c) を守れている。(a)(b) は直し1で入る。

## 直し案（効く順）

### 1. 2人の姿勢を描き分けて、感情を体で言わせる（Silhouette.tsx）
- **何を**：彼は「うつむいて、低い位置のスマホを見る」。彼女は「片手で額を押さえ、もう片方の手のスマホを見る（多すぎて困る）」。どちらも正面のままでよい。ひじの位置と頭の高さだけで感情が出る。
- **どれだけ**（座標は足元(0,0)・身長1000の単位）：
  - `MAN_SLUMP`：`head: [0, -838]`、`headR: [56, 58]`（前に倒れて縦が縮んで見える。-872 から34下げ、首が肩に埋まる）、`neck: [0, -792]`。肩は `shoulderL: [-94, -780]`、`shoulderR: [94, -780]`（8上げてすくめる）。ひじは**肩より内側**へ：`elbowL: [-88, -600]`、`elbowR: [88, -600]`（±128→±88。ひし形をなくす）。手はお腹の前まで下げる：`handL: [-18, -615]`、`handR: [18, -617]`（-655→-615）。スマホの `rect` も手の間へ下げる。
  - `WOMAN_PHONE`：左腕を上げて額へ：`elbowL: [-125, -735]`、`handL: [-46, -895]`（手が額の左にかかる。ひじが肩より上に出る三角が、168pxでも読める形になる）。右手はスマホ：`elbowR: [104, -640]`、`handR: [18, -712]`。頭を手のほうへ傾ける：`headTilt: -10`。
  - 長い髪：今の path の下端（`hy+200` の1点にすぼまる形）をやめて、肩の外へ広げる。左右の下端を `hx-rx-26, hy+150` と `hx+rx+26, hy+150` にし、間をゆるい弧でつなぐ（毛先が肩に乗る形）。頭の輪郭の左右に、髪のふくらみとして各8〜10pxはみ出させる。首が見えて「カプセル」でなくなる。
- **なぜ**：今はハートの数だけで感情を言っている。168pxではハートは点にしかならないので、感情を運べるのは人の外形だけ。「下を向いて縮こまる」と「額を押さえる」は外形の違いがはっきりしていて、白一色でも読める。彼女が困って見えると、「選べない＝つらい側」になる。逆説の問いが立ち、性別全体を責める絵にも見えなくなる。

### 2. ハートを「仕組み」の絵にする。彼の1つははっきり、彼女のほうはあふれる
- **何を**：彼のハートは1つのまま、スマホのすぐ上に置いて光らせる。彼女のハートは今の10個（間をあけて浮く飾り）から、20〜25個に増やす。重なり合いながらスマホへ流れ込む山にする。そのうち4〜5個は、**斜めの境目の上を青い側から赤い側へまたいで**流れ込ませる。
- **どれだけ**：ハートは全部 **白 `#FFFFFF`**（ピンクの `#FF8FA3`・`#FFD0D8` をやめる。青や赤の上では、白でないと168pxで消える）。彼の1つは r30→**r40**、位置はスマホの真上（スマホの上端から約30px上）。後ろに白の放射グラデーション（r 90・不透明度 0.5）を置く。彼女のほうは r 18〜32 をばらつかせ、スマホの上（y 約380〜470）に密に集める。そこから右上へ広がる三角の形に置く。境目をまたぐ4〜5個は、x 620〜760・y 300〜420 の帯に、右下がりに並べる。
- **なぜ**：これがタイトルにない情報になる。「1つ」と「あふれる山」の差は、本編の数字（いいねが一部に集まる）を、数字を書かずに絵で言うもの。境目をまたぐ流れがあると、「男がだめ／女がわがまま」ではなく「アプリの中で、いいねがこう流れる仕組み」に読める。タイトルの「仕組み」とつながる。

### 3. 人を大きくして腰から下を切る。ふち取りをやめ、スマホの光で顔を照らす
- **何を**：`size 0.66 → 0.82`、`y: H+230 → H+340`（彼女は直し1で頭が上がるので `H+360`）。腰が画面の下端あたりに来て、脚の四角が消える。上半身と身ぶりが画面の大部分を占める。
- **どれだけ**：腕の `gap` は `rgba(...,.5)`・`strokeWidth 10` から、**背景の暗い側の色で不透明度 0.85・strokeWidth 5** にする（青の側 `#0A2A6B`、赤（橙）の側はその暗い色）。ふちではなく、腕と胴の間の細い影に見える太さにする。光の `duoGlow` はスマホの位置へ移し、r 110→**160**、0.5→**0.6**。顔の下半分にかかるようにする。人の頭の上端と「選ばれない／選べない」の下端の間は、40px以上あける。
- **なぜ**：168pxで人が「白い四角に丸」から「上半身の人」になる。下からのスマホの光は「夜にひとりで画面を見る」感じを1つで伝える部品で、白い人の上の明るさの差が、質感（光と影）のかわりになる。

### 4. 赤をブランドの橙赤に寄せる
- **何を**：`DUO.red` を `["#6B0A12", "#E0301E"]` から **`["#5C1A08", "#D9541E"]`**（`C.female` と、その暗い色）にする。青は `C.male #2F6FDE` のままでよい。
- **どれだけ**：明るい端（右下）が `#D9541E`。暗い端（左上、文字の後ろ）は文字の白が十分に浮く暗さを保つ。境目の白線 6px は変えない。
- **なぜ**：ブランドの決まり（男＝青、女＝橙）と合う。棒人間・葦の「赤と青」と並んだときに、別のチャンネルに見える。青と橙は補色に近いので、赤より2色の分かれ目がはっきりする（オーナーの「色が明確に分かれる構造」がさらに強くなる）。theme.ts で赤は「損」の色なので、性別の色には使わない。

### 5. 主題の札「マッチングアプリ」を168pxで読める大きさに
- **何を**：札の文字を 62px→**80px**（太さ 900、墨の字に白の地のまま）。左右の「選ばれない」「選べない」は `top: 116 → 136` に下げる（札と文の間は今と同じだけあける。`owner-feedback.md`「文字が詰まって見える」の型）。
- **どれだけ**：札の幅は約680pxになり、境目の白線の上端（x 717）をまたぐ。それでよい。札は左右の両方にかかる「場所」の名前なので、真ん中で境目をまたぐほうが意味に合う。
- **なぜ**：主題の名詞は、関連動画で「自分に関係ある話か」を決める入口（葦の分析でも、伸びた回を分けたのはサムネイルの名詞）。168pxで約8px→約10.5pxになり、読める側に入る。

（変えないもの：斜めの2色の構図、境目の白線、「選ばれない／選べない」の明朝108px・白・影、文字に男女の語を入れないこと、数字を入れないこと。）
