- つなぎ：物語→予想「この問いを、実際に確かめた研究があります」。「400年がたち、ケプラーのような条件の表は、スマートフォンで誰でも作れるようになりました」（表の指す先）。表は「条件ごとに1枚の表に並べると、こうなります」。「答えは、この動画の中ほどで」。ベッカーへの橋「なぜ好きになるのかを説明しにくいのは、経済学者も同じでした」、「自分が付け加えられることはない」（S51 の原文に沿う）、「数式の外」の1文は削った。「同じこと」→「近いこと」。「これは友人の話ですが」→「ここまでは、恋人ではなく友人の話です」。4年前は「まだ1割台」（「残りの2割足らず」と聞き分ける）。脳の断りは1文に。
- 予想の問い「この特別な好意で生まれた点数の差を、会う前の答えから、どれくらい言い当てられたでしょうか」（「8割」が何の割合か。日本語〔中〕）。

### 直さなかった（理由）

- 締めの「表」を「好みの条件」に言い換える案（日本語〔軽〕）：締めは「条件の表に届かない人を…表のほうでした」にし、第3章の山を「好みの条件のほうが書き換わっていた」にして耳でつながるようにした。表の回収を残すため。
- ミクロの好かれやすさに数字を足す案（心の動き3）：「多くて3割」が第2章の会ったあとの数字と重なり、取り違えるので声では足さない（画面に7〜27%）。
- 第3章の最後を問いにしない（チェッカーの注意）：章の最後の文が結論への橋になっているため。

## 第9稿の事実確認（`facts-4.md`）

### 直した

- 「好みの条件のほうが書き換わっていた」は言い過ぎ（下げる調整は、届かなかった人だけ）→「人は、好みの条件のほうを、その人に合わせて下げていました」「好きになった人が条件に届かないとき、動いたのは、条件のほうだったのです」。
- ベッカー「説明しにくいのは、経済学者も同じ」→「なぜ好きになるのかには、経済学者も踏み込みませんでした」（Becker は苦戦したのではなく、範囲を切った）。
- 結論「どれだけ細かくしても」→「100を超える質問で細かくしても」（Joel は、別の変数や大きな標本なら当たる余地を残している）。

### 直さなかった（理由）

- 「多くて3割」の予測に使ったのが、話した直後に好意と同じ場で付けた答え（ケミストリーなど）であること：第2章では「話した直後の印象」と言っており、取り違えはない。細かい中身は画面の隅に出す。
