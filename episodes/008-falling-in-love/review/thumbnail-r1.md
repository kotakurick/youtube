## 見るところごと

1. 0.3秒で何の話か：「好き」「好み」の字と、長い表（条件の一覧）を持つ人形で「恋の好みの話」は分かる。ハートや2人の姿がないので「恋」より「条件」の話に見える。それでよい（本編の主題は条件の表）。表のチェック欄は168pxでは潰れるが、縦長の紙の帯の形で「リスト」は読める。
2. 競合の間で目が止まるか：明るいのは右上の光だけで、画面の7割は暗い紺〜紫。左半分は文字以外ほぼ何もなく、並ぶと「暗い四角」になりやすい。白い人形と白い字のコントラストは高いので、地を少し持ち上げ、光を文字の近くまで広げるのが効く。
3. 押したくなる問い：タイトルは「当てられなかった」（結果）。サムネイルは「だから何が起きているのか」を補う役。B は「当てられない側ではなく、好みが動いている」と別の角度を足していて、分担はよい。ただしタイトルの「当てられなかった」と B の「書き換わる」を、原因と結果のように読ませてはいけない（本編 S20→結論の「かもしれません」まで）。B の字は「書き換わる」の動作で止め、「だから」の言葉は足さない。
4. 文字：A・B は114px（2行とも約6字）、画面幅の約52%。168px幅では字の高さが約15pxで読めるが、余白がまだある（右の人形の肘が x≈895 から）。強調がなく、全部同じ重さで、どこから読むか決まっていない。C は100pxで7字、いちばん弱い。
5. 絵：主役は人形1つ。顔のない白い人形が表を手に持ったまま光を見上げる姿勢は「条件を持っているのに、心は別の所を見ている」と読めて、B の言葉と合う。余白は左下が広く空く（文字ブロックの下 y 460〜720 が空）。右下（人形の足と紙の先 x 900〜1100・y 640〜720）に絵が来ていて、様式の「右下は空ける」とずれ、YouTube の再生時間の表示にも重なる。
6. ポリシー・かぶり：下の「言い過ぎ」。性別の決めつけ・競合の丸写しはなし。

## 言い過ぎがないか（本編との照合）
- A「好きな理由はあとから付く」：本編は「好きな理由の多くが、会う前には、まだなかったからかもしれません」（仮説）。結晶はスタンダールの比喩、フランクファートは哲学の主張で、データの結論ではない。断定にすると、タイトルの「誇張しない」に触れる。やめるか、「付く」を「付いていく」に弱めても、仮説の扱いは残る。非推奨。
- B「好みのほうが書き換わる」：S20（独身763人・5か月）は「最初の好みに届かなかった恋人に合わせて、好みの条件を下げた」。「書き換わる」は少し強いが、本編も「ほうを下げていた／動いたのは条件のほう」と言い切っている。許容。ただし「好きになった人に合わせて」の条件が見えないと「好みは何も当たらない」と取られうる。本編の「好みは網としてある程度当たる」と矛盾しないよう、字では「好みは当たらない」系を使わない（今のままで問題なし）。
- C「理想のタイプはあとで変わる」：「理想のタイプ」は本編が測った量（好みの条件の答え）と少しずれる。「あとで」はいつでも変わると読める。S20は「届かない恋人ができた人」の追跡なので、無条件の断定は言い過ぎ。非推奨。

## 直し案（B を7点にする。効く順）

1. **強調を1か所だけ入れる**：2行目「書き換わる」だけを黄（brand の強調の黄。例 `#FFD84A`。淡い黄は見えないので濃いめ）にし、白＋黒縁の上に黄をのせる。理由：全部白だと読む順が決まらず、競合の間で「何が言いたいか」が弱い。動詞だけが色になると、「何かが動いた」という引きが0.3秒で立つ。縁取りは今のままの黒（太さ変えない）。1行目「好みのほうが」は白のまま。
2. **文字を大きくして、少し下げる**：`size` を114→132（B。A も同じ）。右端は 55+6字×132≒850 で、人形の肘（x≈895）の手前に収まる。行の送りは今のまま（size×1.22）。上の位置は top 190→210（2行の中心が y≈370 で、画面の中心に合う）。理由：168px幅で字の高さを15px→17px超にして、横幅の約65%を使う。
3. **地を持ち上げ、光を文字の側へ広げる**：`ground` を `["#0E1436","#3A1E52"]` → `["#1B2258","#5A2E78"]` に。`Sky` の光の円は、`rgba(255,150,120,.55) 14%` を 20%、`rgba(200,90,150,.22) 34%` を `rgba(200,90,150,.30) 46%` に、中心は x を1190→1150。理由：左半分が暗い穴のままだと競合の間で埋もれる。紫のまま、字の背後の明るさを上げる（白い字との差は残る：最も明るい所でも縁取りの黒で守られる）。`Vignette` の strength は 0.5→0.4。星は x 560 起点のままでよい（右上の3割だけ）。
4. **人形を左に20px寄せ、右下を空ける**：`Cutout` の `cx` を 1010→990、`top` を36→24（高さ720のまま。足元は画面の下を越えてよい）。表の先が x≈1100・y≈700 に残るのを、y 640 より上に収めたい。収まらなければ、`h` を 720→680 にして `top` を 20 にし、足元を y 700 手前で切る（足の切れ目は影で隠す）。理由：様式の右下の空きと、再生時間表示の重なりを避ける。
5. **字を縮めるなら C ではなく B の言い方を磨く**（任意）：1行目「好みのほうが」の「ほう」は、何と比べているかが分からない。タイトル B の「当てられなかった」と並ぶと、比べる相手は「好きになった人」になる。迷うなら「条件のほうが／書き換わる」（表を持つ人形と、本編の「条件の表」「条件のほうが動いた」と同じ呼び名。条件のほうが意味は通る）。ただし「好み」は視聴者が自分に当てはめやすい。次の版で、B（好み）と B'（条件）の2つを並べて、スマホの大きさで読み比べる。

人形の作り直しは不要（姿勢・表の形・光の見上げ方が B に合っている）。作り直しを勧める理由がない。もし将来、表の「書き換え」を絵で見せるなら、Gemini の指示文に「リストの下半分を赤いペンで線を引き直した形跡」と足す案があるが、168pxでは潰れるので今回は勧めない。
