## 質の最低ライン（公開前）

- [ ] テーマが伸びている分野・問いに入っている（themes.csv の優先度、ベンチマーク分析）
- [ ] タイトル・サムネイルは自分たちの型で作り、他チャンネルの言い回しをまねていない
- [ ] サムネイルがチャンネルの様式どおり。大きな文字は2〜3かたまり、主題は1つ、数字は入れても1つ
- [ ] 最初の60秒で問いが出る。動画の最初の1割のうちに最初の具体的な数字が出る
- [ ] 章ごとに1つ、視聴者が自分で答えを考えられる場面（クイズ・実験・自分に当てはまる数字・日ごとの再現）がある
- [ ] 独自のグラフかシミュレーションが1つ以上ある
- [ ] 出典を要所で画面に出している
- [ ] 画面が10〜20秒ごとに変わる。グラフや文字だけの画面が30秒以上続かない
- [ ] 人物の絵柄がチャンネルの決まりどおり（回ごとに変えない）
- [ ] 読み上げが1分390〜400字前後で、長い間がない
- [ ] 読み上げる数字が1分に4〜5個まで。丸めて言い（約3割、4人に1人）、細かい値は画面に出している
- [ ] 締めは「答え」か「教訓」。登録の呼びかけで締めていない
- [ ] 結論を数字の範囲内ではっきり言っている（助言はしていない）

## ポリシー確認（公開前）

- [ ] 問い・データ・結論・構図が過去の回と別物になっている
- [ ] 健康・お金の話は現象の説明だけで、助言（「〜すべき」「〜を買え」）がない
- [ ] 男女の対立を扱う場合：性別全体をおとしめていない。数字を誇張・切り取りしていない。もう一方の側のデータも出している。個人を攻撃していない
- [ ] 外国人・国籍・民族への偏見をあおる構成になっていない。政治は中立
- [ ] （公開後）対立を扱った回は、広告の制限（黄色アイコン）が付いていないか確認した
- [ ] 画面に出典（調査名・年度・論文名）が出ている
- [ ] 他人の動画・画像・文章を素材に使っていない
- [ ] 実在の人物・出来事をリアルに見せる AI 映像があれば AI 開示ラベルを付けた
