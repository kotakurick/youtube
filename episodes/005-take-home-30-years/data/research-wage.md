# 賃金構造基本統計調査：年齢階級別・男女別の賃金（1995〜2025年）

取得日：2026-10-06。調査は厚生労働省「賃金構造基本統計調査」（政府統計コード 00450091）。
対象はどの年も **一般労働者（短時間労働者を除く常用労働者）・民営事業所・企業規模計（10人以上）・産業計**。単位は千円。額面（税・社会保険料を引く前）で、物価で割り戻していない名目値。

- 生データから表を作るスクリプト：`data/wage_census.py`（元ファイルをダウンロードして同じ表を作る）
- 全数値（性 × 学歴 × 年齢 × 年 × 系列）：`data/wage_by_age.csv`（BOM付きUTF-8、783行）
- 最新は **令和7年（2025年）調査**（2026-03-24 公表）。令和6年（2024年）も載せた。

## まとめ（わかったこと）

1. **1995年 → 2025年、男性（学歴計）の年収の目安**は、20代前半 +15%、20代後半 +12%、30代前半 +7% と若いほど上がった。40代前半は +3%、**45〜49歳は −1%、50〜54歳は +1%（ほぼ横ばい）**。55〜59歳は +13%。
2. 2024年までで比べると、**40〜54歳の男性は1995年より下（−1〜−3%）**。2025年の伸びでようやく1995年並みに戻った。
3. 下がった・伸びなかった中身は**賞与**。男性45〜49歳の賞与は 1,730千円 → 1,457千円（−16%）、50〜54歳は 1,774 → 1,581（−11%）。月給（所定内給与）は同じ年齢で +2〜+3%。
4. **大卒（大学・大学院卒）男性に絞ると、中高年の下げははっきりする**：45〜49歳 −7%、50〜54歳 −10%、55〜59歳 −4%（年収の目安、1995→2025）。20〜24歳は +22%。
5. 女性は全年齢で上がった（年収の目安 +18〜+43%）。若い層より40〜50代の伸びが大きい。
6. 2020年の推計方法の変更による段差は、2019年で比べると**月給で0〜−1%、賞与で−3〜−4%、年収の目安で−1〜−2%**（新しい方式のほうが少し低く出る）。1995年と2025年を「そのまま」比べると、2025年側がこの分だけ低めに出る。段差を補正した「つなぎ」の値でも、上の結論（若い層は上がり、中高年男性はほぼ横ばい〜下げ）は変わらない。
7. 大卒男性の初任給（旧定義）：1995年 194.2千円 → 2019年 212.8千円（+10%）。2020年からは定義が変わり（通勤手当を含む等）、2025年は 264.9千円（新定義・大学卒）。**1995年と2025年の初任給はそのまま比べられない**（2019年で新旧の差 +4.4%）。

注意：上の「年収の目安」は「6月分の月給×12＋前年1年間の賞与」。賞与は調査の前年の分なので、2025年の値には2024年の賞与が入っている（1995年の値には1994年の賞与）。

### 1995年の値について（一次資料の扱い）

- e-Stat の賃金構造基本統計調査のファイルは **平成11年（1999年）から**しかない。厚労省サイトの結果の概況も平成12年から。1995年の一次資料は印刷の報告書（『平成7年賃金構造基本統計調査報告』。国立国会図書館デジタルコレクションに収録。一覧：https://www.mhlw.go.jp/toukei/list/xls/chingin_houkokusho-01.xls ）。
- そこで、厚労省の公表値を年ごとに収録した **労働政策研究・研修機構（JILPT）のCSV（1981〜2015年）** から1995年を取った。JILPT は2016年5月で更新停止、「情報の保証はしない」と注記している。
- **照合**：同じCSVの2000・2005・2010・2015年の値を e-Stat の一次ファイルと突き合わせ、男・女・男女計 × 学歴計・大卒 × 年齢の **594個の値がすべて一致**した。さらに1995年の男性・年齢計の所定内給与額 330.0千円は、厚労省の長期時系列表「所定内給与額の推移＜昭和51年〜令和元年＞」第3表（e-Stat statInfId 000031919945、https://www.e-stat.go.jp/stat-search/file-download?statInfId=000031919945&fileKind=0 ）の平成7年・男 330.0 と一致。JILPT「早わかり グラフでみる長期労働統計」図5 賃金カーブ（2026-04-30更新、https://www.jil.go.jp/kokunai/statistics/timeseries/xls/g0405.xlsx ）の1995年の所定内給与額（男性20〜24歳 199.7 など）とも一致。
- ★の照合では、できれば国会図書館の報告書で1995年の数行（男性 40〜44歳・45〜49歳・50〜54歳の3項目）を確かめると確実。

## 定義の切れ目と、比べてよい範囲

### 2020年（令和2年）の変更（厚労省「令和２年に賃金構造基本統計調査が変わりました！」https://www.mhlw.go.jp/toukei/itiran/roudou/chingin/kouzou/detail/chousa_change.html 、「令和２年賃金構造基本統計調査の変更に伴う遡及集計について」https://www.mhlw.go.jp/toukei/itiran/roudou/chingin/kouzou/detail/sokyu.html 、令和2年 結果の概況「利用上の注意」https://www.mhlw.go.jp/toukei/itiran/roudou/chingin/kouzou/z2020/chuui.html ）

- **推計方法（復元倍率）**：事業所の復元倍率を「抽出率の逆数」から「母集団の事業所数に対する有効回答事業所数の割合の逆数」に、労働者の復元倍率を「規定の抽出率の逆数」から「雇用形態別に実際に抽出された労働者数の割合の逆数」に変えた（回収率の影響を受けないようにするため）。
- **学歴区分**：「高専・短大卒」「大学・大学院卒」を「専門学校」「高専・短大」「大学」「大学院」に分け、「不明」を追加。→ 2020年以降は「大学」と「大学院」が別。このファイルでは過去と比べるため、2020年以降の「大学・大学院」を **大学と大学院の値を労働者数で重み付け平均して作った**（平均の定義上、合わせた集団の平均と同じになる。CSVの education=大学・大学院 の2020/2024/2025行がこれ）。
- **短時間労働者**：医師・大学教授など一部の高時給者を除外していたのをやめた（今回使う「一般労働者」には関係しない）。
- **新規学卒者の初任給**：「初任給額」（事業所票、通勤手当を除く確定額）を廃止し、抽出した労働者のうち新規学卒者に当たる人の所定内給与額（通勤手当を含む）に変えた。
- そのほか、職種区分（129→144区分）、労働者の種類（生産・管理事務技術）の廃止、金額を円単位で調査、など。
- 厚労省は **平成18年〜令和元年を令和2年と同じ推計方法で集計し直した「参考系列」** を公表している（「この結果をもって過去の公表値を訂正するものではない」）。1995年はこの参考系列の範囲外。

### それ以前の切れ目

- **平成30年（2018年）**：常用労働者の定義を変更（「1か月を超える期間」→「1か月以上の期間」を定めて雇われている者など。厚労省「賃金構造基本統計調査における平成30年調査からの労働者の定義の変更及び背景について」https://www.mhlw.go.jp/toukei/list/dl/chinginkouzou_02.pdf 。検討時の試算で常用労働者数の変動は1%弱）。
- **平成30年以前**は「宿泊業，飲食サービス業」のうち「バー，キャバレー，ナイトクラブ」を対象外にしていた（長期時系列表の注）。
- 産業分類は年によって改定されている（JILPTのCSVでも旧分類は別扱い）。ただし今回は「産業計」だけを使う。
- 調査対象（10人以上の常用労働者を雇用する民営事業所）は昭和51年以降同じ（長期時系列表の注）。

### 結論：1995年と2024・2025年を比べてよいか

- **比べてよい。ただし「2020年に方式が変わった」と画面か台本で一言断る**。段差は 2019年の新旧比較で、月給（所定内）0〜−1%、賞与 −3〜−4%、年収の目安 −1〜−2%。1995→2025年の変化（若い層 +7〜+15%、中高年男性 ±3%、大卒中高年 −4〜−10%）に比べて小さい。
- 段差を消したいときは **「つなぎ」**：1995→2019年は旧推計どうし、2019→2025年は新推計どうしで比べて掛け合わせる（下の表の「つなぎ*」）。それでも結論の向きは同じ。厳密には45〜54歳の男性（学歴計）は変化が±3%以内なので **「下がった」ではなく「30年でほぼ横ばい」** と言うのが正確（2024年までなら「わずかに下」）。
- **使う表**：1995〜2019年は各年の第1表（旧推計）、2019年の比較用と2010・2015年の新方式は「参考掲載（令和2年と同じ推計方法）」の表番号1、2020年以降は各年の表番号1。
- **学歴計の平均は人の入れ替わりの影響を受ける**：大卒の割合、女性・高齢者の一般労働者の増加などで、学歴計の平均は「同じ人の賃金」の変化ではない。中高年男性の下げは学歴計より大卒のほうがはっきり出る（学歴計では、賃金の低い層の割合が減った効果が下げを打ち消している可能性がある。これはこのデータからは確かめていない）。
- **物価は調整していない**（名目）。実質で言うなら消費者物価指数で割る必要がある（今回は取っていない）。
- **手取りではない**（額面）。

- 旧（〜2019年）は事業所に記入してもらった「初任給額」で、**通勤手当を除く**。新（2020年〜）は抽出された労働者のうち新規学卒者に当たる人の**所定内給与額で、通勤手当を含む**。2019年で比べると新方式（遡及）は旧より男性で +9.3千円（+4.4%）高い。

- 2018年以前の初任給は「バー，キャバレー，ナイトクラブ」を対象外にしていた。

## 取れなかったもの・やらなかったこと

- 1995年の **e-Stat 上の一次ファイル**（e-Stat は1999年から）。代わりに JILPT の転載CSVを使い、上のとおり照合した。
- 1995年・2000年・2005年の **男女計の大卒** の表（当時の第1表に男女計×学歴の欄がない）。CSV にも入れていない。
- e-Stat の「長期時系列表」で年齢階級別の表は見つからなかった（長期時系列は所定内給与額の男女別総数と初任給のみ）。e-Stat データベースの「令和元年以前」系列は API キーが要るため使っていない。
- 物価（消費者物価指数）による実質化、税・社会保険料を引いた手取りの計算。

```bash
python episodes/005-take-home-30-years/data/wage_census.py --raw _local/wage_census
```

元ファイルをダウンロード（上の表のURL）→ 各表の先頭シートで「歳」の単位行から企業規模計の列を見つけ、性・学歴・年齢の行を読む → 2020年以降は大学と大学院を労働者数で重み付けして「大学・大学院」を作る → 年収の目安＝きまって支給する現金給与額×12＋年間賞与その他特別給与額 → `wage_by_age.csv`。.xls は LibreOffice で .xlsx に変換して読む（この環境では LibreOffice を使った）。
