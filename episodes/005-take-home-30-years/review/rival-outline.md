# ライバル（review-rival）

対象：`outline.md` 第1版（2026-10-06）。構成案の段階。
比べる相手の分解はどちらも1本ずつの分析なので仮説（`research/benchmark/teardown/`）。
下の「相手が作るなら」は、うちの案を読む前にテーマ（30年前と今の手取り）とタイトル案だけを見て書いた。

## 考えすぎる葦が作るなら

- タイトル：「なぜ日本人の手取りだけが30年増えないのか【給与明細×社会保障学】」。痛みは「働いても豊かにならない」、主語は「日本人」で大きく取る。
- 最初の30秒：物差しを先に渡す。国民負担率（1995年度35%→2024年度47%。sources.csv の M4。うちの案では使っていない）を出してから「江戸の年貢『五公五民』とほぼ同じ」と落とす。または「この30年でGDPは増えたのに、ある1行だけが増え続けた」という逸話。数字は最初の1分で10個近く並ぶ。
- 章立て：立場を回り、だんだん広げる。①若者（初任給は上がったのに）→ ②中年（昇給が止まった）→ ③高齢者（受け取る側。「誰も得をしていない」）→ ④企業（会社負担も増えて賃上げできない）→ ⑤国家と人口（高齢化、1人の現役が何人を支えるか）→ ⑥歴史（年貢・徴兵と同じ「見えない負担」）。章の終わりに必ず次の問い。予想の先回り「税金が上がったから、と思うだろう。似た動画は多い。だがこの動画はそこで終わらない」を3分ごろに置く。
- 比喩と締め：比喩は「水の漏れるバケツ」「見えない年貢」。締めは「給料は、上がらなかったのではない。届く前に、行き先が決まっていた。……そんなことを考えすぎてみました」。
- 予想される弱さ：国民負担率（国民所得が分母）を、個人の給与明細の割合のように言う。相関を因果で言う（「保険料が上がったから賃上げできなかった」）。自分で計算した手取りはない。世代対立に寄りやすい（「高齢者が得をしている」）。

## データで語る棒人間が作るなら

- 装置：1人の会社員（棒人間）の年収の「棒」を1本立て、上から税・保険料のブロックを削っていく「明細の装置」。または100人の会社員を年齢ごとに並べた町。1回覚えれば最後まで同じ装置。
- はしご（理想の世界 → 足していく原因）：理想の世界＝「30年前と同じ制度・同じ物価」で、今の額面を入れると手取りは30年前と同じ → ①厚生年金の率の上昇を足す →「どうなるだろうか。実行してみよう」→ ②健康保険の率 → ③介護保険（2000年から）→ ④賞与にも保険料（2003年から）→ ⑤税の改正（ここで手取りが逆に増える、が小さな驚き）→ ⑥物価。段ごとに手取りの棒が縮む。最後に中央値で並べ直す。
- 途中の発見：「税は減っていた」「平均の実質賃金が下がったのはパートが増えたから」「会社が払う総額は増えている」。どれも数え方の発見として章の真ん中に置く。
- 限界の言い方：「独身・扶養なしの仮定」「制度の細部は省略」を最後にまとめて言う。締めは「仕組みを知っておくことが大切」と一般的。データは OECD の国際比較（海外の数字）に寄りやすく、主人公も情景もない。

オーナーの指摘集（`docs/owner-feedback.md`）と同じ型が出そうな所：
- **図に数字・単位がない**：「共働き世帯は908万→1,333万」に単位がない（M5 は**万世帯**。直前の「配偶者の収入が月5.5万→10.8万円」と並ぶので、金額に聞こえる）。
- **仮定が恣意的に見える**：手取りは試算で、条件（独身・扶養なし・特別減税なし・賞与の月数）は「概要欄」と「画面の隅」だけ。1本目と同じく「条件次第では」と思われる。
- **サムネイルが響かない**：案の「給与明細が2枚並ぶ情景」は平らな図になりやすい（オーナーは平らな図・猫の絵は響かない、夜の情景＋主人公だけに色＋心の声を明朝体、が好き）。
- **中身より先のことを約束する**：タイトル案「父の45歳と、僕の45歳」は、本編の第1章・第3章で20〜50代の8つの年齢を数えているのに45歳だけを約束している。逆に視聴者の中心（20〜30代）が「自分は対象外」と読む。

## 勝つための直し方（効果の大きい順）

- **絵（対 棒人間で負け）** → 第2章「明細の中身」→ 率の変化を並べる説明を、1枚の明細の上の**はしご**に変える。理想の世界＝「2025年の45歳・額面500万円を、1995年の制度で計算」（手取り406.2万）から始め、①厚生年金の率 ②健康保険の率 ③介護保険（2000年から）④賞与にも保険料（2003年から）⑤所得税・住民税の改正、と1段ずつ今の制度に置き換え、手取りの棒が縮む（⑤だけ伸びる）のを見せる。段ごとに「どうなるでしょうか」の間。最後の段で387.2万（−19万）に着く。⑤で棒が伸びる瞬間が、この回の「え？」の絵になる。**段ごとの手取りは takehome_result.md にないので、takehome.py で段ごとに計算する必要がある**（置き換える順番で各段の大きさが少し変わるので、順番を画面の隅に出す）。装置は群衆ではなく明細なので、棒人間のまねにも見えない。
- **締め（ケーキの使い回しと、名目・物価の混同）** → 第2章の比喩・第3章②・締め → ケーキをやめ、物語の物（父の**給料袋**や明細の「控除」の欄）を比喩にして締めで回収する。締めの一文は「名目（円のまま）で数えた話」だと分かる形にするか、物価で直した会社の総額を takehome.py で確かめてから言う。「大きくなっていた」と言い切るなら、第3章②で「円のままで数えると」と前置きし、物価で直すと会社が払う総額も下がる（計算で確かめてから）ことを1行で出す。教訓「3つの話」は、3つとも円のままの数え方だと明示すれば崩れない。
- **引き（主人公の年齢と「え？」）** → 冒頭0:00〜0:50とタイトル案 → 主人公を35〜39歳にする案をオーナーに出す。takehome_result.md 4章では35〜39歳は「額面は年25.6万円上がった（588.8→614.4）のに、手取りは1.7万円減った（474.5→472.8）」。「昇給したのに増えた気がしない」（企画カードの痛み）にそのまま当たり、視聴者の中心年齢にも入る。45歳の「−29万円」は第1章の年齢の階段で、いちばん沈む棒として出せば失わない。45歳のままにするなら、冒頭に息子の後輩（30歳前後）を1行入れ、「若い人は上がっているのでは」を先に言葉にしておく。どちらにするかは★オーナー判断。
- **参加（予想の答えの穴）** → 1:00〜1:45の予想タイム → 問いを「物価は入れずに、円のままで比べたとき」と明示する。物価で直した差（45〜49歳で約121万円、4章の646.3−525.0）は、第3章①の驚きの山として「29万円ではなく、約120万円」と見せる。後ろほど山が大きくなる（8章）。この値は表の差なので、takehome.py の出力にも足して照合に回す。
- **引き（葦の大きな物差しへの先回り）** → 第1章の終わりの先回り、または第2章の家計調査の場面 → 視聴者がネットで見ている「国民負担率は5割近い」（M4）を通説として1つ退ける案。国民負担率は国民所得が分母で、個人の給与明細の割合ではない。45歳の平均では、会社が払う総額のうち手取りにならない分は約3分の1（C2 の66%の裏返し）。「5割」と「3分の1」の違いを数え方の発見として見せれば、葦が冒頭に使いそうな数字を、うちが数え直す形で上回れる。**国民負担率の定義と、明細の割合と比べてよいかは調べる必要がある**。政治的に使われる数字なので、是非は言わず数え方の違いだけにとどめる。入れるかは★オーナー判断。
- **ミクロ（示唆）②の弱さ** → 第3章③の示唆② → 平均余命だけでなく、厚生年金で「払った保険料（本人分）と、受け取る額の決まり方」を数字で1つ出す（報酬比例の計算式の率など）。「判断材料にする」は助言に聞こえるので、「受け取る側の数字はこうなっている。どちらが得かは、何年受け取るかで変わる」のように、条件で変わることを言い切る形に。**受け取る額の決まり方の数字は調べる必要がある**（いまの research にない）。
- **ミクロ（示唆）③の根拠** → 第3章③ → 「世帯主の収入はほぼ横ばい」の値を家計調査（M3）から取り、sources.csv に書く。共働きは「908万世帯→1,333万世帯」と単位を付ける。家計調査は世帯主の年齢が45.6→51.0歳に上がっているので、配偶者の収入の倍増にも年齢の違いが混じる、と画面の隅に。
- **仮定が恣意的に見える（指摘集の型）** → 第2章の最初 → 2枚の明細を出す前に、試算の条件の表（独身・扶養なし、賞与3.2か月、1995年の特別減税は入れていない）を画面に出し、「特別減税を入れると差はさらに3〜7万円広がる。この動画は小さいほうで数えている」と一言。控えめな側で数えていると言えることが、言い過ぎる葦との違い（信頼）になる。
- **締め（世代対立の読まれ方）** → 14:30〜の教訓の場面 → 「自分の明細の保険料の行の先に、父の年金の通知が重なる」絵は、「自分の保険料が父に取られている」とも読める（書かないこと「上の世代は逃げ切り」に近づく）。父も45歳のときに当時の受け取る側に払っていた、と父の明細の保険料の行も同じ金色で光らせ、受け渡しが続いている絵にする。

守ること（確認）：上の直し方は、どれも数字を盛らず、相関を因果で言わない（「保険料が上がったから額面が上がらなかった」は言わない、を続ける）。示唆は「〜すべき」と言わない。
