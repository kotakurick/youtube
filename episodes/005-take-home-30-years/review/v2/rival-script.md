# ライバル（review-rival）

対象：`script.md` 第1稿（2026-10-06）。台本の段階。構成案の段階の判定は `review/rival-outline.md`。
比べる相手の分解はどちらも1本ずつの分析なので仮説（`research/benchmark/teardown/`）。
下の「相手が作るなら」は、台本を読む前にテーマ（30年前の同い年と、手取りで比べる）とタイトル案だけを見て書いた。構成案の段階の想定（rival-outline.md）とほぼ同じなので、違う所だけ足している。
お金の回なので、ミクロの代わりに「示唆」で判定する。

## 考えすぎる葦が作るなら

- タイトル：「なぜ日本人の手取りは30年増えないのか【給与明細×社会保障学】」。主語を「日本人」と大きく取り、痛みは「働いても豊かにならない」。
- 最初の30秒：物差しを先に渡す。国民負担率（1995年度35%→2024年度47%）を出して「江戸の『五公五民』とほぼ同じ」と落とす。数字は最初の1分で10個近く。
- 章立て：立場を回り、だんだん広げる。若者（初任給は上がった）→ 中年（昇給が止まった）→ 高齢者（受け取る側。「誰も得をしていない」）→ 企業（会社負担も増えた）→ 人口と国家 → 歴史（年貢・見えない税）。3分ごろに「税金が上がったから、と思うだろう。だがこの動画はそこで終わらない」。
- 比喩と締め：「水の漏れるバケツ」「見えない年貢」。締めは「給料は、上がらなかったのではない。届く前に、行き先が決まっていた」。
- 弱いところ（予想）：国民負担率を明細の割合のように言う。「保険料が上がったから賃上げできなかった」と因果で言う。自分で計算した手取りはない。世代対立に寄りやすい。

## データで語る棒人間が作るなら

- 装置：1本の年収の棒から、税と保険料のブロックを削っていく「明細の装置」を最後まで使い回す。
- はしご（理想の世界 → 足していく原因）：理想の世界＝今の額面を30年前の制度と物価で計算 → ①厚生年金の率 ②健康保険 ③介護保険 ④賞与にも保険料 ⑤税（ここだけ手取りが増える）⑥物価。**段ごとに毎回**「どうなるだろうか。実行してみよう」の間を置く。
- 途中の発見：「税はむしろ減っていた」「実質賃金 −15% の大半はパートの増加」「会社が払う総額は増えている」。どれも**自分で数えた**数え方の発見として、具体的な数字と一緒に出す。
- 限界の言い方：最後に「独身・扶養なしの仮定」をまとめて言う。締めは「仕組みを知っておくことが大切」と一般的。主人公も情景もない。

## 勝つための直し方（効果の大きい順）

- **締め（教訓の言い過ぎ）** → 253〜261行 → 教訓の3つの読み方に、第1章・第3章で見せた範囲を戻す。例：「額面の行だけを読むと、若い人は増え、中年は止まった三十年。手取りの行を読むと、35歳から上は減った三十年。物価で直すと、中年がいちばん沈んだ三十年」（構成案の「一言でいうと」と同じ範囲）。締めの一文は、主語を父と彼の2枚の明細に付ける：「二人の明細で、額面の行は、ほとんど動いていませんでした。〔間・短〕動いていたのは、その下の行でした。」 38歳の額面 +4%（S1・S2）なら「ほとんど動いていない」は数字の範囲内。逆説の強さは保ったまま、言い過ぎで負ける所を消せる。
- **引き（冒頭の「え？」の大きさ）** → 26〜31行 → 企画カードの逆説を声に戻す：「額面は、父より年に26万円ほど多い。〔間・短〕なのに、手取りは、父より2万円ほど少ないのです」（S11：588.8→614.4、474.5→472.8）。31行の問いは「増えた26万円は、どこへ行ったのでしょうか」にすると、149行「増えた保険料は、どこへ行ったのでしょうか」と対になる（「消えた」とは言わない。150行の「消えてしまったお金ではありません」と食い違うため）。差が小さい（月に千円ほど）ことを気にして数字を伏せるより、「26万円増えて、2万円減った」の向きの逆転で引くほうが強い。
- **絵（対 棒人間で引き分け）** → 131〜135行（はしごの税の段）→ 先回り（91〜95行）の答えの場面なので、ここにこそ予想の間を置く：「最後の行は、所得税と住民税です。〔間・短〕先ほどの予想どおり、ここで手取りは大きく減るでしょうか」→〔間〕→「青緑の帯は、ほとんど動きません」。厚生年金の段（117〜123行）も、答えの前に「どれだけ縮むでしょうか」を1つ置き、全段で同じ間のリズムにする（棒人間の「実行してみよう」の強みを、うちの装置で取る）。受け取る側（149〜154行）と研究の場面（194〜202行）は、何を描くかを絵コンテで決める（例：金色の行が明細から抜けて、年金・医療・介護の3つの箱に流れる。研究の場面は賞与の棒が年ごとに少しずつ削れる線）。
- **引き・心の動き（第3章の山を大きく）** → 178〜184行・240行 → 第3章の山が「1割前後」の割合だけで、第2章の「年に15万円」より小さく聞こえる（8章「驚きの山は後ろほど大きく」）。メモ7行にある値で、38歳の父の手取りを今の物価に直すと 553.8万（消費者物価）／515.3万（デフレーター）、彼は 472.8万。「物差しによって、年に40万円から80万円ほどの差です」と円で1回だけ言う（S11×S13・S20。差は表の引き算なので、takehome.py の出力に足して★照合に回す必要がある）。
- **第1章の発見（数え方の発見の大きさ）** → 86〜88行 → 「三十年前は、7人に1人ほどでした」（S14：14.5%）、「パートを除いて数え直すと、下がり方は1割半ではなく、数パーセントほどです」（S14：約 −4%。段差ありなので幅で言う）。棒人間の発見は必ず数字で「どれだけ変わったか」を見せている。ここが数字なしだと負ける。
- **示唆③の根拠** → 210〜214行・222行 → 「多くの家では」をやめ、平均で言う：「働く世帯の平均では、世帯主の収入はほぼ横ばいで、配偶者の収入が月に5万円ほど増えました（S15：5.5万→10.8万）。それでも物価で直すと、家の手取りは三十年前に少し届いていません」。214行と222行の順番を入れ替え、「埋めてきた」を「補ってきた。ただし届いていない」にして食い違いを消す。家計調査は世帯主の年齢が45.6→51.0歳に上がっている（S15）ことを画面の隅に。
- **締め（比喩の広がり）** → 109〜113行 → 「控除の欄」は実物なので、比喩として弱い。新しい比喩は足さず（回収しない比喩は置かない）、75行の「年に二回の楽しみが、少しずつ小さくなっていた」のような、暮らしの言葉への置き換えを控除の欄にも1行足す案（例：「額面は、会社が約束したお金。控除の欄は、届く前に寄り道する先の一覧です」）。言い過ぎにならない範囲かは推敲で確かめる。必須ではない。
- **数字と単位の食い違い** → 9行のメモ・140〜142行の表 → 表を38歳の値で作り直すか、表に「30歳の場合」と書く。38歳の額面ごとの差は takehome_result.md にあるか確かめ、なければ takehome.py で出す必要がある。220行に「額面500万円の45歳で」と額面を入れる。152行に「約3年」（S19）を足す。

守ること（確認）：上の直し方は、どれも sources.csv と takehome の出力にある数字だけを使い、新しい数字は作っていない（円の差 40万〜80万円は表の引き算なので照合に回す）。「保険料が上がったから額面が上がらなかった」「多くの家で共働きが手取りを救った」のような因果・分布の言い過ぎはしない。示唆は「〜すべき」と言わない。
