# 事実確認（review-facts）

対象：`script.md` 第1稿（2026-10-06）。`python scripts/check_sources.py` を実行し、`data/takehome.py`・`data/takehome_result.md`・`data/wage_by_age.csv`・`data/research-*.md` と照らした。行番号は script.md の行。sources.csv の URL を開いて確かめることはしていない（「未確認」は下に書いた）。

## 直すもの

- **29行目**：「手取りの行を見ると、父のほうが多いのです」（31・92行目の「手取りが減った」も同じ）→ 数え方を少し変えるだけで向きが逆になる。冒頭の一番大事な事実なのに、言い切れる強さがない → 主人公（35〜39歳）の手取りは 474.5万→472.8万円で、差は −1.7万円（−0.4%）。2020年に推計方法が変わった分を補正すると（S3。research-wage.md の「つなぎ」の値では年収の目安 +5.6%）、2025年は約478万円となり、**今のほうが多い**（takehome.py で計算すると 478.2万円）。逆に、1995年に実際にあった特別減税を入れると、1995年は 481.3万円で差は −8.5万円。構成案103行目の「向きは変わらない」は、額面には当てはまるが、手取りには当てはまらない。さらに2025年の値には、2年間だけの基礎控除の上乗せ（約+1万円）も入っている → 案：「手取りの行を見ると、30年前とほとんど同じでした」として、問いを「額面は増えたのに、なぜ手取りは増えなかったのか」に変える。

- **135行目・236行目**：「むしろ、ほんの少しだけ、手取りが増えるくらいです」「Bの税金は、むしろ、ほんの少しだけ手取りを増やしていました」→ 税の段がプラスになるのは、1995年の特別減税を外し、2025年の一時的な上乗せを入れた場合だけ。特別減税を入れると向きが逆になる → 38歳・額面500万円の税の段は、上乗せありで +1.5万円、上乗せを除くと +0.5万円（takehome_result.md 8章）。1995年の特別減税（S8：所得税15%・上限5万、住民税15%・上限2万）を入れると −4.0万円（takehome.py で計算）。106〜108行目の「差を小さいほうで数えています」は差の合計の話で、税の段だけを取ると「小さいほう」にならない。一方、保険料の段の合計 −16.8万円は、どちらで数えても税の段よりずっと大きい → 案：「税の行は、数え方によって、プラスにもマイナスにも数万円動くだけで、保険料の行よりずっと小さいのです」。Cが答えであることは変わらない。

- **254・256・260行目**（教訓と締め）：「額面の行だけを読むと、止まった三十年」「物価で直すと、中年がいちばん沈んだ三十年」「額面の行は、三十年、ほとんど動きませんでした」→ 研究の範囲を超えて一般化している。第1章で出した「もう一方の側」と食い違う → 額面が止まったのは中年の男性だけ。20〜24歳の男性は +15%、女性は全年齢で +18〜+43%、主人公の年代でも +4%（補正すると +5.6%）（S1・S2、wage_by_age.csv）。物価で直す計算（takehome_result.md 4章・9章）は男性だけで、女性は計算していない。構成案93行目に「『全員が下がった』は言わない」とある → 案：260行目を「中年の男性の額面の行は、三十年、ほとんど動きませんでした」とし、256行目も「中年の男性が」とする。

- **66〜70行目**：「若い人ほど、右の棒が高く」「年齢が上がるにつれて、その差は小さくなっていきます」→ 画面の棒と合わない。55〜59歳は +13% で、20代後半と同じくらい高い → 男性・学歴計 55〜59歳：646.4万→733.3万円（+13.4%。補正すると +15.4%）（S1・S2、research-wage.md）。8本の棒を出すなら、視聴者は最後の棒の高さに気づく → 案：70行目のあとに「ただ、50代の後半だけは、また1割あまり高くなっています」と1文足す（理由は資料にないので言わない）。

- **74行目**：「40代後半の男性のボーナスは、三十年で、およそ6分の1減っていました」→ 推計方法の変更によるずれが、いちばん大きく出る項目（新しい方式のほうが3〜4%低く出る）→ 補正しない値は 173.0万→145.7万円（−15.8%）、補正した値（つなぎ）は −12.8%（research-wage.md の「つなぎ」の表）。「6分の1」（−16.7%）は補正しない値でも少し強めの丸め → 案：「およそ1割半、減っていました」として、画面の隅に「2020年に調査方法の変更あり（S3）」を出す。

- **172行目**：「三十年で、およそ2割近く上がりました」→ 丸めすぎ。上がり方が大きく聞こえる → S13 総合 1.167倍（+16.7%）。2割に近いのは持家の帰属家賃を除いた値（1.194倍）で、手取りの計算（takehome_result.md）では総合を使っている。「およそ」と「近く」が重なってもいる → 案：「三十年で、およそ1割半あまり上がりました」（または「6分の1ほど」）。

- **198行目**：「その通り道は、主にボーナスだったと考えられています」→ 1本の論文の中の、著者の推測を、定説のように言っている → S24（濱秋 2016）：賞与を通じて回ったことは、内生性が残る推定（①）でしか見ておらず、「推測」と著者が書いている。対象は健保組合（大企業）、期間は2001〜2007年、健康保険だけ（research-papers-academic.md A3）。199行目で第1章（全企業・1995→2025年）とつなげているので、範囲の違いが見えなくなる → 案：「この研究の著者は、その通り道は主にボーナスだったのではないか、と推測しています」。

- **222行目**：「1人の手取りが減った分を、多くの家では、二人目の収入が埋めてきました」→ 因果の言い過ぎで、214行目とも食い違う → S15：世帯主の収入は名目で 46.8万→47.1万円とほぼ同じ（減っていない）。配偶者の収入は 5.5万→10.8万円。それでも可処分所得を物価で直すと −5.4〜−7.5%（214行目の「少し少ないまま」）。「埋めてきた」と言うと、埋まったように聞こえる。世帯主の年齢も 45.6歳→51.0歳に上がっていて、同じ人の変化ではない → 案：「三つ目。家の手取りの目減りを、二人目の収入の増加が小さくしてきました。それでも、埋めきれてはいません」。

## 確かめたいもの（判断が要る）

- **175行目**：「安いものに乗り換えた分も入るので、上がり方は、その半分ほどです」→ 「半分」（8.6% ÷ 16.7% ＝ 0.51）は正しい。ただ「乗り換えた分も入るので」は、差の原因を言っているのに出典がない。research-papers-thinktank.md 37行目にあるのはデフレーターの定義だけで、CPI が上に出やすいことの根拠は孫引き（白書の本文は未確認）。範囲の違い（計算のしかた・入っている品目）も効いているはず → 「ので」をやめて、定義の説明と数字を2文に分けるかどうか。

- **201行目**：「ほとんどなし、という研究もあります」→ 該当するのは橘木・横山（2008）だけ。本文は読んでおらず孫引きで、sources.csv に行がない（S25 のメモにあるだけ）。濱秋・岩本（2010）は同じデータをやり直して「一部は回っている」としている → 「ほとんどなし」を残すなら、出典を1行足して本文を確かめる。残さないなら「5割から全部まで、研究によって分かれます」（駒村・山田の版の違い・濱秋 2016）とする。

- **118・152行目**（オーナーの指摘集「『どれくらい』が言えていない」と同じ型）：「保険料の率が、少し上がりました」「65歳を過ぎてから生きる年数は延びました」が、どれだけかを言っていない → S4：本人の率は 8.25%→9.15%、S19：男性の65歳の平均余命は 16.48年→19.68年（約3年）。また 248〜249行目の「父が払っていた保険料は、そのころの年金になっていました。受け取っていたのは、父の親の世代」は、賦課方式の説明なのに出典がない（父の金色の行には健康保険も入っているので、全部が年金ではない）。一般常識として扱うかどうかも決めたい。
