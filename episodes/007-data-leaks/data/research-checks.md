## 3. 1人が使っているネットのサービス・アカウントの数

### 3-1. IPA 2016年度（分布あり。一次）★いちばん細かい

- 資料名：「2016年度 情報セキュリティの脅威に対する意識調査 －調査報告書－」（2016年12月）
- 発行元：独立行政法人 情報処理推進機構（IPA）。調査実施は株式会社ネオマーケティング
- 調べ方：インターネット調査、2016年10月6日〜12日、全国13歳以上。**パソコン調査 5,000人**（この設問はパソコン調査だけ。スマホ調査には同じ設問なし）
- 設問（Q6）：「あなたがインターネットで利用しているID（アカウント）の内、自分で管理しているものはいくつありますか。…※直近1年以内に使用したもので、複数のサービスで共通したIDを使用していても、サイト・サービスが異なれば別々にカウントしてください。」
- ページ：「4-1-9. 管理しているID（アカウント）の数」PDF p.30（印刷 30頁）
- URL：https://www.ipa.go.jp/files/000056568.pdf
- 原文の短い引用：「最も高いのは､「1種類」(27.1％)である。次いで「2種類」(15.1％)､「3種類」(11.0％)､「21種類以上」(9.7％)と続く。」

全体（n=5,000）の分布（図の値。小数第2位を四捨五入）：

| 数 | 割合 |
|---|---|
| 1 | 27.1% |
| 2 | 15.1% |
| 3 | 11.0% |
| 4 | 3.8% |
| 5 | 7.3% |
| 6 | 1.9% |
| 7 | 1.0% |
| 8 | 0.7% |
| 9 | 0.4% |
| 10 | 5.5% |
| 11〜15 | 5.5% |
| 16〜20 | 2.3% |
| 21以上 | 9.7% |
| 自分で管理しているものはない | 8.8% |

- 足し算（Claude の計算）：**3個以下 53.2%（半分強）**、10個以下 73.8%（「ない」を含む。含まなければ65.0%）、11個以上 17.5%。
- 注意：「自分で管理している」IDの数なので、実際に持っているアカウントより少なく答えやすい。5と10に答えが集まっている（大まかに答えた人が多い）。10年前の値。年代別では20〜40代で「21以上」が11.5〜12.6%、70代以上は8.1%。
