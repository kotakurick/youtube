## 切り口（2026-10-06 オーナー「あなたの推しですすめよ」）

軸は「漏れた情報は、なぜこんなに安いのか（漏えいの市場の経済学）」。オーナーが X の投稿（日本のカード情報・氏名・メール・電話・IP のセットが 36.75 ドルで売られている画面）に驚いたのがきっかけ。「フラットに面白くて、ためになる内容に」。投稿の画像は素材に使わない（値段は公開の価格調査から）。

- 物語：漏えいのお知らせメールが届いた、20〜30代の男性の夜
- 第1章：漏えいは本当に増えたのか（報告の義務化で数え方が変わった。数え直し）
- 第2章：漏れた情報はいくらで、どこで実害になるのか（値段と分業）
- 第3章：犯罪者から見た損得（ベッカーの式、身代金の支払い率、ハッカー像の答え合わせ）
- 教訓の仮説：「盗むのは安くなった。だから高くつくのは、最後にだまされる1回」
- 守ること：企業を責めない（被害を受けた側でもある）、助言しない（示唆まで）、手口・闇市場の場所や買い方は説明しない
