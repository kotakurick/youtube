# ライバル（review-rival）台本・第4稿
2026-10-07。章の中のクイズは数えない決まりで判定。構成案の段階の判定（`rival-outline.md`）とは別。

## 考えすぎる葦が作るなら
- タイトル：「なぜ日本の個人情報は『高く盗まれ』『安く売られる』のか【漏えい×経済学】」。
- 最初の30秒：物差しを先に渡す。「日本のカード1枚3,400円。調べた国で最高。ただし裁判の慰謝料は数千円」。続けて「盗む側は誰も得をしていない」と逆説で問いを立てる。
- 章立て：被害者（何度も漏れる人）→ 売る側（闇市場）→ 犯人（若者・下請け）→ 企業の帳簿（おわびの金券500円）→ 国（義務化で件数が増えた）。話をだんだん大きくし、各章の終わりに次の問いを置く。
- 比喩と締め：「質屋」か「棚」を回収し、「盗まれるのは情報だが、売られているのは私たちの不安だ」のような逆説で締める。「そんなことを考えすぎてみました」。

## データで語る棒人間が作るなら
- 装置：日本の1,000人の町。サービスごとに事故が起きる様子を回す。
- はしご：理想の世界（全員が同じ数のサービスを使い、事故は均等）→ 使うサービス数の偏りを足す → 委託先の共有（1事故が複数社）を足す → 0回の人が何割残るか。
- 途中の発見：「延べ2億人でも、一度も漏れない人は残る」「件数は報告した会社の数で数える」「平均2回でも中央値は1回」。

## 台本そのものの弱い所（相手との比較で目立つもの）
- 「最初の驚き」で「日本人の情報は、闇の売り場で高く売れる」と言い、第2章で「なぜ、それほど安いのでしょうか」と問う。同じ3,400円が、片方では高く、片方では安い。「国同士で比べると高いが、被害者への賠償や、お金に換える難しさと比べると安い」と、物差しを替えると言わないと、聞き手は矛盾と受け取る。
- 第2章の「だますメール約120倍、被害額は2倍あまり」は面白い対比だが、件数（届け出）と金額（被害額）は別の物差しで、そのまま「換えられなかった」とは言えない。本文は「質屋で換えられた額」と言い切っている。葦の弱点（相関を因果に寄せる）に近いので、「届け出の件数と被害額は別の数え方」と一言入れるか、言い切りを弱める。また台本の細かい値は123倍、読み上げは「約120倍」と「百倍を超えて」が混在している。
- 「C 天才ハッカーか」の判定の根拠が、捕まった人の年齢（捕まる人の偏り）と、ランサムの分業（別の犯罪）で、不正アクセスの検挙とランサムが混ざっている。捕まらない人は見えないので、「捕まる側は若い」までしか言えない。
- 第1章の結論「6倍」は2012〜14年平均17件と2023〜25年平均108件の比。構成案の「13倍（9件→116件）」から変えたのは良いが、台本で「十年あまり前」の取り方を画面で示すこと。

## 勝つための直し方（効果の大きい順）
- 締め → 最後の一文 → 「数えてみると、景色が変わりました」の前に、教訓を1文足す：「犯罪の大きさは、盗める量ではなく、お金に換える出口の広さで決まる。」そのあとに字幕なしの余韻。比喩（質屋）の言葉で終える。
- 絵（対 棒人間） → 第1章の町 → 町を2段のはしごにする。①全員に同じ確率で赤い点を配る町（0回の人は何人か）②使うサービス数の偏りを足した町（0回3人に1人、多い層は3回以上）。①の数字は `data/town_sim.py` でまだ出していなければ、回して確かめる必要がある（数字は新しく作らない）。
- 引き → 「最初の驚き」→ 「高く売れる」を「調べた国でいちばん高い。それなのに、1枚あたり飲み会一回ぶん」と、高さと安さを同じ場面で並べる。第2章冒頭の「なぜ安いのか」は、その答えとして一続きにする。
- ミクロ → 第1章の町の最後 → 町の3つの層に猫を1匹ずつ置き（サービス5・15・30個）、それぞれ何回漏れたかを並べて見せる。主人公の猫が自分のメールの数（4通）から、どの層かを言う。「〜すべき」は言わない。
- 参加 → 「ログインするサービスが二十を超えるなら」→ 画面に「あなたのサービス数」の目盛りを出し、3つの層のどこかを指す。1文で終えず、数秒の間を置く。
- 新しさ → 第2章の120倍と2倍 → 件数と被害額は別の数え方だと一言添え、「時期が重なる」までに言い切りを留める。
