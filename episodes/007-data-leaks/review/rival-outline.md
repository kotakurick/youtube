# ライバル（review-rival）構成案の段階

2026-10-06。見たもの：`outline.md`（第1版）、`README.md`（切り口）、`data/research-market.md`・`data/research-counts.md`、`docs/owner-feedback.md`。
相手の案は、うちの案を読む前に、テーマ（themes.csv 131）ときっかけ（Xの36.75ドルの投稿）だけから書いた。比べる相手を決めるためのもので、言い回しは台本に持ち込まない。

## 考えすぎる葦が作るなら

- タイトル：「なぜあなたの個人情報は、ランチ3回分で売られているのか【情報漏えい×経済学】」
- 最初の30秒：物差しを先に渡す。「コンゴのカード1枚は1ドル。アメリカは11ドル」。そのあとに本命の数字「日本は22.8ドル。調べた国で最も高い。しかも2年で2倍」。安いと思って見始めた人を、30秒でひっくり返す。続けて「漏えいの報告は過去最多。でも、ほとんどの人は被害に遭っていない。漏れているのに何も起きない。ではこの値段は何の値段なのか」と問いを立てる。
- 章立て（立場を回る → だんだん広げる）：盗む側（若者、腕試し、分業）→ 売る側（闇市場の需要と供給、値崩れと値上がり）→ 企業の側（漏らしても1人500円のおわび。守る費用と漏らす費用）→ 私たちの側（「漏れてもいい」と思ってしまう心理。プライバシーの逆説）→ 社会と歴史（情報が石油になった時代）。どの立場も責めない。
- 比喩と締め：「鍵の値段」「質屋」。締めは「私たちの情報は、もう盗まれている。それでも値段が安いのは、盗むことより、使うことのほうがずっと難しいからだ」→「そんなことを考えすぎてみました」。
- 弱いところ（ここで勝つ）：数字は海外の価格調査を並べるだけ。日本の報告件数の数え方の変化（義務化）には触れないか、触れても「激増」と言い過ぎる。参加の場面はない。

## データで語る棒人間が作るなら

- 装置：日本人100人と、よく使うサービスの箱（アプリ・通販・ポイント）。毎年サービスが一定の確率で漏れ、使っている人に赤い点がたまる。最後に「あなたの情報は何回漏れたか」の分布が出る。
- はしご（理想の世界 → 足していく原因）：漏えいゼロの世界 → ①小さなミス（誤送付）をたくさん足す：赤い点は多いが、1件で数人 → ②年に数件の大事故を足す：1件で数千万人、赤い点がほぼ全員に → ③使うサービスの数の差を足す：たくさん使う人に赤い点が集中 → ④漏れた断片が名寄せされてセットになる → 値段が付く。
- 途中の発見：「延べ2回漏れた」と「2回漏れた人がいる」は違う（重複を数えると一度も漏れていない人が残る）。件数ではミスが9割、人数では大事故1件が9割（件数と人数の逆転）。
- 限界の言い方：漏えいの確率と重なり方は仮定。データは海外の価格調査。
- 弱いところ（ここで勝つ）：主人公も情景もない。「犯人は誰で、儲かっているのか」という物語の側がない。締めは「知っておく必要がある」の一般論。

### 「結論が世間でもう言われている」（owner-feedback 2026-10-06）に当たるか

**当たっている所がある。** いちばん危ないのは第2章の結論と教訓。

- 第2章の着地「被害の9割は番号の盗用。最後に要るのは人をだますこと。フィッシングは7年で120倍」→ 見る人の受け取りは「知ってる。フィッシングに気をつけろ、でしょ」。カード会社・警察・銀行のお知らせと同じ。
- 教訓「高くつくのは、最後にだまされる一歩」も同じ。005の「手取りを減らしたのは社会保険料」と同じ型（正しいが、へー、で終わる）。
- 第1章の「報告の急増は義務化のせい」は委員会自身が書いていて、知っている人は知っている。ただし「でも盗まれる型は13倍」で一段先に行けているので、こちらは大丈夫。
- オーナーのモヤモヤは「36ドル？ 俺の情報、そんなに安いの？」と「お知らせは毎週来るのに、自分は何も起きていない（気がする）」。このずれを解く問いになっていない。

### 論理の穴（構成で直す必要があるもの）

1. **「材料と料理」が中身と合っていない**：outline では「最後の工程に要るのは人をだますこと＝フィッシング」としているが、フィッシングは情報を**盗む入り口**（示唆③でも「入り口のだまし」と書いている）。番号盗用は、盗んだ番号をそのまま使う被害で、持ち主をだます工程は要らない。つまり「盗む → 売る → 使う」の最後の一工程がだましだ、という比喩は、データの並びと逆になっている。
2. **予想タイムの答えCが言い切れない**：「いちばん大きなお金が動く段階」を決めるには、売る段階の総額と身代金の総額が要る。どちらも日本の数字はない（outline の断りのとおり）。「売る段階の約1,500万枚分」は、510億円を1枚の値段で割った物差しで、売られた枚数でも売上でもない。このまま「答えC」と出すと、相関を因果で言う相手と同じ種類の言い過ぎになる。
3. **「不正アクセスで検挙された人の7割が10代・20代」を漏えいの犯人像に使うのは、対象の取り違えの恐れ**：不正アクセス禁止法の検挙には、知り合いのSNSやゲームのIDを使った事件が多く含まれる（警察庁の公表は手口・動機の内訳を出している。**調べる必要がある**）。企業から情報を盗んだ犯人の年代と同じとは言えない。
4. **数字が多い**：第2章（4分15秒）に読み上げそうな数字が12個前後（22.8ドル・2倍・500円・1,000〜6,000円・3,400円・3万円・510億円・1,500万枚・93%・6割・7億円・120倍）。1分4〜5個を超える。葦の弱いところを持ち込んでいる。
5. **第3章が「あなたの情報」から離れる**：身代金・実行役の報酬・DDoS 代行は、組織が被害を受ける話。20〜40代の男性が抱えた問い（自分の情報はどうなる）とつながる一文がないと、第3章で離れやすい。

## 勝つための直し方（効果の大きい順）

1. **締め・新しさ・世間の話 → 企画カードの「逆説の一文」と教訓 → 「盗まれる数は増えたのに、お金に換えるのは難しくなっている」に替える**
   手元の一次の数字だけで組める：盗まれる型の漏えいは約13倍（S11）、フィッシングの報告は約120倍（S16）、日本のカードの値段は2年で約2倍（S13）。一方で、身代金を払う組織は 76% → 20%、被害は5割増えたのに払われた総額は約8%減（S22〜S24）、カードの不正利用の発生率は 0.051%（2023年）→ 0.038%（2025年）、偽造カードの被害は約20億円 → 7億円（S15）。
   「漏えいは増え、闇の値段は上がった。それなのに、犯人の手に入るお金は減り始めている」。これはフィッシング注意の話ではなく、ニュースで聞かない話になる。オーナーの「なぜこんなに安いのか」への答えも「盗むことより、お金に換えることのほうがずっと難しいから」で筋が通る（値段＝買う人が見込める取り分、は経済学の仮説として「仮説です」と言う）。
   比喩は「材料と料理」をやめて、盗品と**質屋（換金の出口）**のように「盗むのは簡単、お金に換える出口が狭い」と合うものにする。締めの一文の例：「情報はもう、いくらでも盗まれている。値段がつかないのは、それをお金に換える出口が狭いからだ」（言い切る範囲は数字が出たあとで決める）。
   **調べる必要がある**：2025年に不正利用の発生率が下がった理由（research-market の未確認。カードの本人認証の強化などが考えられるが、一次資料で確かめるまでは言わない）。日本の身代金の支払い率（なければ「世界の数字」と断る）。
2. **引き → 冒頭と第2章の値段当て → 「世界でいちばん高い」を最初の1割に入れ、値段当てを高い／安いの問いに替える**
   冒頭のSNSの投稿は値段を言わず「日本人のカード情報が、名前・電話・メールとセットで売られていた。値札も付いていた」で止める（値段がもれないように）。予想タイムの直後か第2章の頭で「この値段は、世界の中で高い？ 安い？」を聞き、物差し（コンゴ約1ドル、アメリカ約11ドル）→ 日本22.8ドル、調べた国で最も高い、の順で出す（日本は121件だけ、と画面で断る）。物差しは葦の型なので、言い回しはうちのものにする。最初の1割（1:20ごろまで）に「え？」を置けないなら、「漏れたお知らせは毎週来るのに、自分は被害に遭っていない」というずれで問いを立て、痛みを「知らないうちに売られている」より具体的にする。
3. **参加・新しさ（対 棒人間）→ 第1章の終わり → 題の約束「何回漏れたか」を、延べと実人数の数え直しとして入れる**
   上場企業の公表分だけで延べ2億1,313万人分、人口の約1.7倍（S11・人口推計）。上場企業が自分で言う「国民1人あたり2回」は延べの数で言えない、とすでに資料にある。ここを「100人の町で、延べ170回の漏えいを配ると、一度も漏れない人は何人残るか」を、配り方の仮定ごとに（全員に同じ確率で配る／たくさん使う人に集まる）並べて見せる。ベネッセの「延べ約2億件 → 約4,858万人」という縮み方は、重なりの大きさを示す実際の例として使える（二次の値があるので確かめる）。答えは仮定の幅つきで言い、「シミュレーション（条件は概要欄）」と画面に出す。見る人には「使っているサービスの数」で自分の位置を選ばせる。棒人間の装置と違って、日本の延べの数から始めて、題の約束に答えるので、まねには見えない。数字は新しく作らず、配り方の仮定は条件の表で先に出す（owner-feedback「仮定が恣意的に見える」）。
4. **参加・引き → 予想タイム → 選択肢を通説にして、章ごとに1つずつ退ける**
   「次のうち、データで本当だったのはどれ？ A 漏えいは激増している B 犯人は腕のいいハッカー C 日本人の情報は安く売られている D 犯人は前より儲かっている」。第1章でA（半分〇：件数は数え方、盗まれる型は本当に増えた）、第2章でC（×：世界でいちばん高い）、第3章でBとD（×：若い人が多く、下の層は報酬0、払われた総額は減った）。答えが言い切れない「C 使ってお金に換えるとき」の問いはやめる（論理の穴2）。
5. **ミクロ（示唆）→ 示唆③ → 「フィッシング注意」に聞こえる言い方をやめる**
   ③を「お金が動くかどうかは、漏れた回数ではなく、お金に換える出口で決まる」にして、出口が狭くなった数字（発生率・身代金を払う割合・偽造の減り）で言い切る。最後の場面の「3通目のメッセージで指が止まる」は、助言の絵に見えるので、お知らせのメールを並べて眺める、など「数え直した目で同じメールを見る」場面に替える。
6. **絵 → 第3章の山 → 天秤のはしごを、根拠の強い数字のおもりに替える**
   いちばん重いおもりを「身代金を払う組織 76% → 20%」（被害は増えたのに払われる総額が減る）にして、英国の DDoS 代行の研究は小さなおもり（市場1つ、と断る）に下げる。天秤の皿の片側が軽くなっていく絵は、直し方1の逆説とそのままつながる。
7. **深さ・事実 → 第3章の犯人像 → 「検挙された人の年代」の中身を確かめる**
   **調べる必要がある**：警察庁の不正アクセスの検挙の手口・動機の内訳。企業の情報を盗んだ事件の年代が分からないなら、「捕まった人の多くは、知り合いのIDを使った若者」と対象を正しく言い、「天才集団ではない」の根拠は英国の研究（小さい標本と断る）に寄せる。
8. **数字の数 → 第2章 → 読み上げる数字を半分にする**
   値段の物差しは画面に4つ並べ、読み上げるのは「闇市場3,400円」と「判決の数千円」だけ。偽造7億円・番号盗用93%は、直し方1で使う側（出口が狭くなった）に移すか、画面だけにする。第3章の頭に「ここからは、あなたの情報を盗んだ側の帳簿を見ます」の一文を置き、組織の話（身代金）と見る人の問いをつなぐ。

### 守ること（確認）

- 「漏えいは増えていない」「日本人の情報は安い」「国民1人2回」「〇〇社のせい」は outline のとおり言わない。直し方1の「お金に換えるのは難しくなっている」は、発生率・支払い率・総額の範囲で言い、「被害はなくなった」「漏れても大丈夫」とは言わない（年510億円は残っている）。
- 値段の上がり方の理由（供給が少ないから高い）は NordVPN の説明で、仮説と言う。
- 示唆は「〜したほうがいい」と言わない。
