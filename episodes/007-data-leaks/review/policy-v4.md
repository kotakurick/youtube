# ポリシー確認・第5稿（007 情報漏えい・時事の枠）

2026-10-07。対象：`script.md`（第5稿）。前回 `review/policy-v3.md`、`docs/owner-feedback.md`、`CLAUDE.md`「必ず守ること」に照らした。行番号は第5稿のもの。

## 直すもの

1. **証券口座の「ひと月に数件」「ほぼ閉まった」は、7月だけを取り出している（L140、L195）**
   `sources.csv` S39 のメモに、2026年7月は5件、**8月は25件**、2025年10月にいったん増えた、とある。声は「ひと月に数件まで減っています」、教訓は「一年あまりで、ほぼ閉まりました」。8月の25件（7月の5倍）と10月の再増に触れていない。
   → L140「その期限を過ぎた今年の夏、不正な取引は、月に数十件まで減っています（7月5件・8月25件）。ただ、去年の秋にいったん増えた時期もありました」。L195「証券口座の質屋も、閉まる方向に向かっています」程度に。
   決まり：数字を切り取らない／反対の数字も出す／過去の数字を将来の約束のように言わない。

2. **L132「番号を盗んで使う被害は、その年、はじめて減りました」が S15 と合わない疑い**
   S15 には 2025年51,050百万円・47,540百万円（前年）とあり、総額は2025年に増えている。番号盗用は93%を占めるので、減ったと言える根拠が `sources.csv` にない（前回の指摘9のまま）。L4 にも番号盗用の前年値がない。
   → 年次表（`data/jca_card_fraud_by_year.csv`）で番号盗用の前年比を確かめる。減っていなければ L131〜133 を削る。減っていても、総額は増えたと一言添える。
   決まり：数値は一次資料で確認し sources.csv に書く／切り取りをしない。

3. **L176「実行役の多くは、稼げていません」は「最大」を落としている**
   原文は「最大114人（59%）」（S24 up to）。L153 は「最大6割近く」と直ったが、判定で「多くは」と言い切ると上限が過半に聞こえる。
   → 「実行役の半分ほどは、稼げていなかったとみられます」または「最大で6割近く」。
   決まり：数字を誇張しない。

4. **L155「お金は、道具を作る上の側に集まっていたのです」は2割だけでは言えない（L176の「そうです」も）**
   S41 は「身代金の2割を受け取っていたとされる」（起訴状、疑い）。残りの8割は実行役の側にある。「集まっていた」は断定で、根拠は2割の1数字と、無報酬の実行役が最大6割という上限の数字だけ。
   → 「道具を作る側は、どの攻撃からも2割を取っていたとされます。だから、攻撃の数が多いほど、上の側には積み上がります」のように、仕組みの説明にとどめる。判定は「道具を作る側は、取り分の仕組みがあります。実行役は…」。
   決まり：結論は数字の範囲内／起訴状は疑いの段階。

## 確かめたいもの

5. **教訓の一般化（L190〜196）：前回より弱まったが、まだ安心側に傾く**
   「同じ速さでは増えません」（L191）は未来形の一般化。根拠はカード（2.2倍と120倍）の1例だけ。免許証の画像・名前・メールの使われ方（なりすまし、特殊詐欺）は、この回で数えていない。L190 が「並んでいるかもしれません」と置いたので過度ではないが、L196 の「どの質屋が開いているかで、変わる」の前に「カードでは」と範囲を付けると安全。
   → L191「カードでは、盗まれた量と、お金の被害は、同じ速さでは増えていません」（過去形・範囲つき）。
   決まり：数字の範囲内／将来の約束にしない。助言（「用心しなくてよい」）の含みを避ける。

6. **L93「漏れた2千万件は」の確定表現**
   L25 は「見込みも含めて」と直ったが、L93 と L37「この2千万件」は確定のまま。L93 は「漏れたとされる2千万件」か「見込みも含む2千万件」。S1・S3・S4・S34・S35・S36 の件数は、書き出し前にもう一度確認（公表直後で変わりうる）。

- **偏見・国籍**：盗む側を国や民族で描いていない。検挙の10代・20代（L146）は69.4%で「7割近く」に合い、若者を見下す言い方はない。

- **大量生産・型**：クイズは冒頭の予想タイムだけ。「犯人」「主犯」「窓口」なし。
