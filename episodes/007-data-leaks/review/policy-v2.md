# ポリシー確認・第2稿（007 情報漏えい・時事の枠）

2026-10-06。対象：`script.md`（第2稿）。前回の指摘 `review/policy.md`（第1稿）と対応表 `review/README.md` に照らした。照らした決まり：`CLAUDE.md`「必ず守ること（収益化ポリシー）」、`docs/owner-feedback.md`、outline の「守ること」（企業を責めない／助言しない／手口を説明しない／犯罪を魅力的に見せない／若者や国をおとしめない）。行番号は第2稿のもの。

## 直すもの

1. **「いちばん若い人は、10歳でした」は「捕まった人」に入っていない（L165〜167）**
   L165 で「不正アクセスで捕まった人」と問い、L167 で「いちばん若い人は、10歳」と続けているが、10歳は14歳未満なので検挙人員（248人）に入っていない。補導の数（`data/research-crime.md` 112行：「10歳は14歳未満のため検挙人員には入っていない。ほかに14歳未満の補導7人」）。声で聞くと「10歳が逮捕された」に聞こえ、若者の話を実際より強く見せている。
   → 消す（いちばん安全）。残すなら「補導された子どもには、10歳もいました」と、検挙と分けて言う。
   決まり：数字を誇張・切り取りしない／若者をおとしめない（outline「守ること」）。

2. **「実行役の半分以上が、無報酬だった」は上限を下限として言っている（L176）**
   原文は「up to 114 affiliates…never made any money」（`data/research-crime.md` 242行、`sources.csv` S24「最大114人」）。114人（約6割）は**最大で**の数なので、「半分以上」と言うと逆向き（少なくとも半分）の言い切りになる。対応表（README 12行）は「直した」としているが、前回の指摘6の向きと違う形になっている。判定D（L208「下の多くは稼げていません」）もこの1文に頼っている。
   → 「実行役の、最大で6割近くが、一円も得ていなかったとみられています」。
   決まり：数字を誇張しない。

3. **判定A「報告が増えたのは、ミスまで数えるようになったことが大きい」に、台本の中の根拠がない（L201）**
   2022年4月より前も報告は努力義務として出ていて、ミスも含まれていた（2021年度 5,846件。`data/ppc_reports_by_year.csv`）。2022年度からは、義務に当たるものだけを数えている（同 csv 19行のメモ）。台本はL59〜60で「同じ決まりの中で2年で2倍を超えた」と言っているので、L201 の言い方は第1章の内容と食い違う。言えるのは「報告の8割はミス」（L67）と「要配慮の情報は1人分でも報告する」（L72）までで、**増えた理由**がミスを数えるようになったことだ、とは示していない。前回の指摘1の残り。
   → 例：「報告の多くは、小さなミスでした。ただ、同じ物差しで数えても、盗まれる漏えいは6倍になっていました。半分だけ残ります。」
   決まり：数字を誇張・切り取りしない／結論は数字の範囲内で言い切る。

4. **日本のカードの値段を、1つの小さな調べだけで3回言い切っている（L29〜32、L6）**
   日本のカードは NordVPN の調べの121件だけ（全体の0.24%。S13、`data/darkweb_prices.csv`）。2023年から2025年の「2倍」は、多くの国で同じように起きている（`review/depth.md` 22行、`data/research-market.md` 1-1）。L31「しかも…さらに2倍ほど」は日本だけの動きに聞こえる。L32「日本人の情報は、高く売れるのです」は、カード121件を「日本人の情報」全体に広げている。L6 の断り書きは「民間企業の調べ」だけで、121件・ほかの調べ（S14）で値段が違うことは書いていない。前回の指摘7は対応表に載っておらず、扱われていない。
   → L6 に「日本のカードは121件の調べ／ほかの調べでは値段が違う」を足す。L31 は「この二年で、多くの国と同じく、2倍ほどに」か、「さらに」をやめる。L32 は「日本のカードは、高く売れるのです」。
   決まり：都合のよい数字だけを出さない／反対の結果の資料に触れる。

## 確かめたいもの

5. **実在の企業の件数の見せ方（L17〜18、L6）**
   ナレーションは「会員の記録」「人口と比べると…数」に直っていて、教訓の「町を埋める大事故」も消えている（前回の指摘4はおおむね解消）。ただ、前回求めた L6 の断り書き「件数はアカウント数・おそれのある最大の数」は入っていない。L4 には画面の値として「アカウントの件数・おそれの最大値」とあるので、絵コンテで、11人に1人の画面に「人数ではない」が出るかを確かめたい。公表の直後の数字なので、書き出しの前に S1・S3 の最新のお知らせで件数を確かめ直す（前回の指摘10）。
   決まり：特定の企業を責めない／数値は一次資料の最新版。

6. **教訓の「おそらく二回ほど」は少なく言っている（L223〜224）**
   町は上場企業が公表した分だけで作っていて、「実際の回数はこれより多い」（L110 のメモ）。主人公はその日に2通のお知らせを受け取っている（L13〜19）。「おそらく二回ほど」と言うと、上限のように聞こえる。
   → 「少なくとも二回ほど」。
   決まり：結論は数字の範囲内で言い切る。

7. **抑止の研究の対象が声では分からない（L186〜189）**
   S28 は DDoS 攻撃の請け負い市場1つの研究（`data/research-crime.md` 279行）。L189「ある一つの闇の売り場」は、第2章の「盗品の売り場」や、直後のランサムウェアと同じ市場に聞こえうる。画面の隅（L6「抑止の研究は1つの市場の研究」）に、どんな市場か（攻撃の請け負い）を添えるとよい。攻撃の方法は書かない。
   決まり：数字を誇張しない（研究の範囲）。

8. **判定C の理由に「若く」を使っている（L206）**
   「捕まった人の多くは若く」を「天才ではない」の理由にすると、「若い＝腕がない」と聞こえる。第3章で示したのは、捕まった事件の中身（なりすましのログイン中心。L168）と分業（L172〜177）なので、そちらで判定するほうが根拠と合う。
   → 例：「捕まった事件の多くは、なりすましのログインで、大きな事件も、分業の仕事でした。」
   決まり：若者をおとしめない（挑発はよいが、見下さない）。

9. **004 と、絵だけでなく言葉も重なっている（L160〜163、L183〜190）**
   対応表は「天秤は一場面だけ。絵コンテで見た目を変える」として直していない。004 は「天秤にのせて」「分銅」「天秤が動きはじめます」が比喩の中心（004 script L145〜167）で、007 も「天秤の片方には…のせます」「おもりを一つずつ、のせてみます」「天秤を動かせるのは」と言い方が同じ。問い・データ・結論は違うので決まりに反するとまでは言えないが、声だけで聞くと同じ型に聞こえる。言葉を「帳簿」（L159・L179 にすでにある）にそろえるか、構成役とオーナーに判断してもらいたい。
   決まり：毎回、問い・データ・結論・構図を変える。

## 問題なかったもの

- **前回から直ったもの**：判定D は「上と下で分かれる。半分だけ」になり、支払い率・1回の額・合計（3割ほど少ない。S23 は 2023年12.5億ドル → 2025年約8.2億ドルで28〜34%）の両面を出している（指摘2）。「いちばん重いおもり」は「もう一つのおもり」になった（L190。指摘3）。「細る」はない（指摘5）。「5社に1社」にそろった（L192）。
- **上場企業の系列の「公表」の偏り（前回の指摘8）**：`data/tsr_listed_leaks_by_year.csv` では、不正アクセスの事故は2016年ごろから毎年増えていて（22・29・25・41・51・68・91…）、通知が義務になった2022年に段差はない（68 → 91）。比べているのは3年平均どうし（17 → 108件）で、2012年起点の13倍はやめている。いまの言い方（L83〜90）で範囲内。
- **助言**：「〜すべき」「おすすめ」「〜しましょう」はない。L111 は自分の位置を当てはめる場面で、サービスを減らせとは言っていない。示唆（L214〜218）はニュースの読み方で、L218 で過去が続くとは限らないと断っている。本人確認の仕組み（L148〜152）は「時期が重なる」「それだけが原因かは、まだ分かりません」の範囲。L190「払わない被害者」は起きたことの説明で、払うな、とは言っていない。
- **手口**：L141・L144・L168・L173〜174 は被害の分類と仕事の分け方だけ。道具・売り場の場所・買い方・入り方はない。
- **犯罪を魅力的に見せない**：L175 の取り分2割のあとに、無報酬（L176）・退屈な保守作業（L177）・被害を受けた組織の損（L181〜182）・摘発（L188）を置いている。
- **国籍**：盗む側を国で描いていない。「日本の／日本人の」は被害を受ける側の話（ただし L32 の広げ方は直すもの4）。

- **AI開示**：猫のアニメと合成音声だけで、実在の出来事をリアルに見せる場面はない。SNS の投稿の実物を使わない（L5）。
