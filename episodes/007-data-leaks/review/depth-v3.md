# 深さ（review-depth）第4稿 ／ 「みんなが知りたそうな問い」の抜けと、足せるデータ

対象：`episodes/007-data-leaks/script.md`（第4稿、約9.5分）。2026-10-07。
オーナーの狙い：ニュースの漏えいについて、知りたそうだが知らなかった事実と裏付け。個人のミスの話は要らない。
URL は WebSearch で見つけたもの。中身を開いて数字まで照合できていないものは「要照合」と書く。数字は推測で書かない。

## 見る人が最初から予想していること（台本を読む前に書いた5つ）
1. 漏れた情報はダークウェブで売られて、すぐ悪用される。
2. 漏えいはどんどん増えている（ニュースが毎週ある）。
3. 犯人は海外の天才ハッカーだ。
4. 漏れたら自分に何が起きるのか（詐欺の電話・メールが増える、勝手に契約される、口座を乗っ取られる）。
5. 会社は何の責任も取らない・謝るだけだ。免許証の画像が漏れたら一生悪用されるのでは。

## 持ち帰れる見方
- 「漏れた量」でなく「お金に換える出口の数」で被害が決まる（質屋）。これは回の外でも使える見方（例：詐欺・盗難・転売）。強い。
- 見出しの数字は何を数えているか（延べ・最大・会社単位）。強い。
- 弱点：教訓の最後が「だますメール100倍、質屋で換えた額は2倍」というカード1品目の数字で、見方の一般化がやや薄い。「出口は閉められる」を、カード以外の出口（免許証・証券口座・電話番号）でも言えると、視聴者が自分の持ち物に当てはめられる。

## 見る人が知りたそうな問いのうち、台本が答えていないもの
問いごとに、いまの台本の扱い → 足せるデータ → 足す場所。優先度は高い順。

### 1. 「免許証の画像が漏れたら、何に使われるのか」（高）
- いまの台本：冒頭で免許証を出すのに、第2章以降は回収していない。教訓の「どこかの売り場に並んでいるかもしれません」で終わる。見る人が最も自分ごとにできる所が、つり橋のまま。
- 足せるもの：免許証の画像は「画像で本人確認をする所」を通るための質屋になる。日本では、携帯電話の契約で偽造免許証の不正契約が問題になり、国が本人確認の方法を厳しくする方針を出している（2025年）。つまり国のほうが、この質屋を閉めにかかっている。
- 台本での形：第2章の質屋の話に「質屋は一つではない」として、カード番号（ネットの買い物）、ポイント（交換）、免許証の画像（本人確認）を並べる。教訓の回収も「偽造カードの質屋が閉まった」に、「いま、免許証の質屋を閉めている途中」を並べると、冒頭の免許証が閉じる。約60〜90秒。
- 調べ先（要照合）：総務省「携帯電話の本人確認」資料 https://www.soumu.go.jp/main_content/000988471.pdf ／ https://www.soumu.go.jp/main_content/000942596.pdf （どちらも検索で出たもの。内容は未開封）。報道：https://www.oanda.jp/lab-education/market_news/kn_2025090801001388/ （携帯の本人確認の厳格化、二次）。免許証画像の悪用の件数は、公的統計を見つけられていない。「件数は公表されていない」と声で言うほうが誠実で、強い。

### 2. 「名前・電話番号・住所が漏れたら何に使われるのか」（高）
- いまの台本：焼肉アプリの例で「もう一歩、本人をだます手間がかかります」と言うだけで、だました先に何があるかを言っていない。「質屋に持ちこめません」と言い切るが、見る人は特殊詐欺や闇バイトの強盗の「名簿」を知っているので、そこが抜けて見える。
- 足せるもの：警察庁の2025年の暫定値で、特殊詐欺は認知27,832件・約1,423億円（前年比で件数+32.3%、金額+98.0%）、SNS型投資詐欺は9,523件・約1,288億円（検索結果の要約。要照合）。名前と電話番号の質屋は、カードでなく、人をだます電話・メッセージになる、という接続ができる。
- 言ってはいけない所：警察庁の統計に「漏えいした情報が原因」の内訳は見つかっていない（未確認）。「漏えい→詐欺が増えた」と因果で言わず、「名前と電話番号は、だます側にとって質屋の入り口になりうる。その先の大きな出口が詐欺で、被害額はこの規模」と、規模だけを置く。
- 台本での形：第2章の焼肉アプリの段落の直後に30〜40秒。
- 調べ先：警察庁の特殊詐欺・SNS型投資詐欺の認定状況ページ（検索で出たもの。要照合） https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260213/03.html 、 https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260605/01.html 。闇名簿については弁護士ドットコムの解説（二次）https://www.ben54.jp/news/1587 。一次は警察庁の闇バイト対策資料を探す必要あり（未確認の方向性）。

### 3. 台本の結論への反例になりうる：証券口座の乗っ取り（高。直さないと弱点になる）
- いまの台本：第2章の結論と締めは「だますメール100倍、質屋で換えた額は2倍あまり」。カードの被害額だけが「質屋」の物差し。
- 抜け：2025年に、フィッシングで証券口座に入られて株を勝手に売られる被害が急増した。金融庁の月別公表で、4月だけで不正取引約2,700件・売却額約1,481億円・買付額約1,308億円（検索の要約。二次）。年間では「9,752件・約7,393億円」と書く記事があるが、sources.csv の S16 のメモにあるとおり「約739億円」と書く記事もあり、食い違っている。数字は金融庁の原資料で確かめるまで使えない。
- 使い方：2つあり得る。(a) 「質屋は閉まるとは限らず、新しい質屋が開く」と第2章で言う（深い。「閉めれば減る」の限界を自分で出せる）。(b) 外す場合でも、締めの「質屋で換えた額は2倍あまり」を「カードの」と限定する。限定しないと、証券口座のニュースを知っている視聴者に反論される。
- 注意：これは漏えいではなく、フィッシングで入口を取られた被害。「漏れた情報の質屋」ではなく「ログイン情報の質屋」と分ける。
- 調べ先：金融庁「インターネット取引サービスへの不正アクセス・不正取引の被害」の公表ページ（URL未特定。https://www.fsa.go.jp/ から「不正アクセス・不正取引」で探す。二次の例 https://scan.netsecurity.ne.jp/article/2025/11/27/54109.html ）。

### 4. 「なぜ6倍にもなったのか」（中〜高）
- いまの台本：事実（6倍）と、なぜ続くか（委託先の連鎖）は答えているが、盗む件数が増えた理由がない。第3章の分業（ランサムウェアの貸し出し）が、実はこの答えなのに、章が離れていて結びついていない。
- 足せるもの：警察庁は、身代金の一部を受け取る形（RaaS）により、高度な技術的専門知識を持たない者でもランサムウェア攻撃を実行できる、と書いている（警察庁 令和7年の情勢 本文15頁。research-crime.md 1-7で原文確認済み）。さらに、検挙された不正アクセスの手口の上位は「パスワードの設定・管理の甘さ」84件・「フィッシングサイトから入手」77件で、システムの穴を突く型は8件（2%）。入口は技術でなく、人のログイン情報の使い回しと、だまし（research-crime.md 1-6）。使い回しは84.3%（トレンドマイクロ 2026、S31のメモ）。
- 台本での形：第1章の「6倍」の直後か第3章の冒頭に、「増えた理由は、攻撃の腕が上がったからではなく、参入の敷居が下がったから」という仮説として20〜30秒。分業の話を第1章に前倒しすると、「なぜ続く」の答えが2段（委託先の連鎖＋参入の敷居）になる。
- 言えないこと：検挙の手口は「ログインのなりすまし」の事件で、大規模漏えいの入口の統計ではない。声で「捕まった事件の話」と断る。

### 5. 「自分は被害に遭う確率はどのくらいか」（中。「日本にはデータがない」と言うこと自体が発見）
- いまの台本：町のシミュレーションで「何回漏れるか」は出すが、「漏れたら被害に遭うのか」は無い。
- データ：日本の、漏えい通知を受けた人のうち実害に遭った割合の調査は見つかっていない（research-market.md 5）。米国の Javelin 2013年版は「通知を受けた人の4人に1人」が詐欺被害、2014年版は3人に1人（調査5,249人／5,600人。10年以上前・社会保障番号がある米国の条件）。
- 台本での形：「通知を受けた人のうち、実際に被害に遭う割合は、日本では調べられていません」を示唆の前に15秒。無いことを言うのは、通説（「漏れたら必ずやられる」と「どうせ大丈夫」の両方）に効く。米国の数字は条件つきで1文だけ、または出さない。
- 調べ先：Javelin 2013年版 https://javelinstrategy.com/coverage-area/2013-identity-fraud-report-data-breaches-becoming-treasure-trove-fraudsters （一次の要約ページ）。日本の調査は「未確認の方向性」（IPA の「情報セキュリティ被害実態調査」系を探す余地あり。https://www.ipa.go.jp/ ）。

### 6. 「会社は何か責任を取るのか／払う額は」（中）
- いまの台本：慰謝料1,000〜6,000円だけ。会社側の負担が無い。
- 足せるもの：JNSA の想定損害賠償額は1人あたり約2万9,768円（2018年、想定で払われた額ではない。S19）、IBM の調査で日本の1件あたり平均総コストは約5億5,000万円（2025年版、二次）。「被害者に払われるのは数千円、企業が負う費用は1件で億円」という非対称は、「会社は責任を取らない」という通説の半分を退ける。
- 台本での形：第2章の慰謝料の直後に20秒。ただし「安い理由」の質屋の話とは別の筋で、入れると長くなる。9.5分に収めたいなら後回しでよい。
- 調べ先：JNSA https://www.jnsa.org/result/incident/2019/2019-005.pdf （一次）。IBM 日本の値は発表文を未確認（二次 https://cloud.watch.impress.co.jp/docs/news/2044188.html ）。

### 7. 「身代金を払うと何が戻るのか／払わないとどうなる」（中）
- いまの台本：支払い率が下がったことは言うが、払う理由・払わない理由が無い。
- 足せるもの：警察庁の2025年の被害組織アンケートで、バックアップから復元できたのは20組織、できなかったのは79組織（回答99、約8割。理由の最多は「バックアップも暗号化」48）。復旧に1か月未満で戻ったのは56%。この数字は台本にまだ使われていない。「払わなくなってきたのは、備えができたから」ではなく、「備えができた組織はまだ2割で、残りは復元できない」という、予想と逆の事実が言える（支払い率の低下との食い違いが、なぜの宿題になる）。
- 注意：Coveware の支払い率（世界・自社の顧客）と警察庁（日本・回答した約半分）は別の標本。「食い違うように見えるが、標本が違う」と断る。
- 調べ先：警察庁 令和7年のサイバー情勢（S21と同じ。research-crime.md 1-3、本文14頁）https://www.npa.go.jp/publications/statistics/cybersecurity/data/R7/R07_cyber_jousei.pdf 。一次。

### 8. 「捕まるのか」（低〜中）
- いまの台本：捕まった人の年齢は出すが、捕まる確率は無い。sources.csv に S25（Becker）・S28（抑止の研究）があるのに台本で使っていない。
- 足せるもの：日本の不正アクセスは認知7,190件に対して検挙431件（約6%、目安。同じ事件とは限らない）。米国の推計では届出に対する逮捕が約0.3%（Third Way 2018、政策提言で粗い）。ただし「捕まりやすさ」の論点は、見る人の関心の優先度が低く、9.5分を超えるので優先しない。

## 足す場所の整理（9.5分 → 約12〜13分、標準の13分前後）
追加はおおむね次のとおり。合計で約2.5〜3.5分（1分390〜400字として1,000〜1,400字）。
1. 第2章：質屋を3つ並べる（カード／ポイント／名前と電話番号→特殊詐欺／免許証→本人確認）。約90秒＋証券口座の乗っ取りを「新しい質屋」として30秒。
2. 第1章の「6倍」の直後：なぜ増えたか（参入の敷居）。約30秒。
3. 第3章のバックアップ2割：約30秒。
4. 示唆の前：日本には「漏れたあとの被害率」の調査が無い。約15秒。
5. 教訓の回収：免許証の質屋が閉まる途中、を足して冒頭の免許証に戻る。約20秒。

足すと数字が増える。読み上げる数字は1分に4〜5個までの決まりがあるので、特殊詐欺の「件数と金額」は金額だけに絞る（1,423億円。画面に件数）。数字を絞り、質屋の話の流れ（出口があるか）に乗せる。

## 深めるための提案（効果の大きい順）
- 冒頭の免許証 → 第2章の質屋に「免許証＝本人確認の質屋」を足し、教訓で回収する → 見る人が自分ごとにできる「閉じた物語」になり、「国が質屋を閉めている途中」という発見になる → 総務省の携帯電話の本人確認の資料（https://www.soumu.go.jp/main_content/000988471.pdf 、要照合・一次）。件数が無いことも声で言う。
- 締めの「2倍あまり」→ 証券口座の乗っ取りを「新しい質屋」として足すか、「カードの」と限定する → 反例に自分で触れると、教訓が強くなる（「閉めても、別の出口が開く」）→ 金融庁の月別公表（URL要特定。https://www.fsa.go.jp/ ）。年間の数字の食い違い（7,393億円か739億円か）を原資料で確かめるまで数字を出さない。
- 第2章の焼肉アプリ → 名前・電話番号の出口として特殊詐欺・SNS型投資詐欺の被害額を足す → 「名前とメールだけでは換えられない」と言い切った所が、「その先に大きな出口がある」に深まる。ただし因果は言わず規模だけ → 警察庁（https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260213/03.html 、要照合・一次）。
- 第1章の6倍 → なぜ増えたか（参入の敷居、入口は技術でなくログイン情報）→ 「なぜ続く」の答えが2段になる → 警察庁 令和7年の情勢 本文15頁（一次、research-crime.md 1-7で原文確認済み）＋検挙手口の分類（同1-6、6頁）。
- 第3章 → バックアップを復元できた組織は約2割（警察庁アンケート）を足す → 「払う組織が減った」の裏にある日本の実態になる → 同上（本文14頁、一次）。

## 台本の言い方への注意（オーナー指摘集に当てはめて）
- 「結論が世間でもう言われている」型：A（激増）は、世間で言われている話の確認になる危険がある。台本は「ミス」と「盗まれる」を分けて6倍にし、さらに延べの数え方を足しているので、ここは回避できている。
- 「なぜ」が無い発見：「日本のカードは高い」（なぜ高いか）、「支払い率が下がった」（なぜ下がったか）、「6倍」（なぜ増えたか）の3つ。いずれも資料（NordVPNの顧問の説明、Coveware の説明、警察庁のRaaSの記述）がフォルダにある。
- 「どれくらい」が無い所：「質屋が閉まったとき、その被害は、ほとんど消えました」は、前の段落の数字（160億→2億）を指していて数字がある。問題なし。
