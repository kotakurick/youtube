# ライバル（review-rival）台本の段階

2026-10-06。見たもの：`script.md`（第1稿・推敲済み）、`outline.md`（第2版）、`review/rival-outline.md`（構成案の段階の判定）、`data/research-market.md`（値段の範囲の確認だけ）、`docs/owner-feedback.md`、`docs/script-style.md` の8・9・10・11章、teardown 2本。
相手の案は構成案の段階で、うちの案を読む前にテーマときっかけだけから書いたもの（`rival-outline.md`）をそのまま比べる相手に使う。言い回しは台本に持ち込まない。

## 考えすぎる葦が作るなら

- タイトル：「なぜあなたの個人情報は、ランチ3回分で売られているのか【情報漏えい×経済学】」
- 最初の30秒：物差しを先に渡す（いちばん安い国は約1ドル、世界の平均は約11ドル）→ 本命「日本は22.8ドル。調べた国で最も高く、2年で2倍」。続けて「漏えいは過去最多。でも、ほとんどの人は被害に遭っていない。では、この値段は何の値段なのか」と問いを立てる。
- 章立て：盗む側 → 売る側（闇市場の需要と供給）→ 企業の側（おわび500円）→ 私たちの側（プライバシーの逆説）→ 社会と歴史（情報が石油になった時代）。だんだん広げ、どの立場も責めない。
- 比喩と締め：「鍵の値段」「質屋」。締めは「私たちの情報は、もう盗まれている。それでも値段が安いのは、盗むことより、使うことのほうがずっと難しいからだ」→ 決まり文句。

## データで語る棒人間が作るなら

- 装置：日本人100人と、よく使うサービスの箱。漏えいのたびに使っている人へ赤い点。最後に「あなたは何回漏れたか」の分布。
- はしご（理想の世界 → 足していく原因）：漏えいゼロ → ①小さなミスをたくさん → ②年に数件の大事故 → ③使うサービスの数の差 → ④断片が名寄せされてセットになり、値段が付く。毎回「どうなるでしょうか。実行してみよう」。
- 途中の発見：延べと実人数は違う（一度も漏れない人が残る）／件数ではミスが9割、人数では大事故1件が9割。
- 限界の言い方：確率と重なり方は仮定、価格は海外の調べ。締めは「知っておく必要がある」の一般論。

### owner-feedback の型に当たるか

- **結論が世間でもう言われている**：当たらない。第1版の「フィッシングに気をつけろ」型は消えた。フィッシング120倍は入り口の数字として1行に下がっている。
- **仮定が恣意的に見える**（1本目 v3）：**当たる恐れが大きい**。101行目「数字は、なるべく実際の調べに合わせました」は、まさにこの指摘を呼ぶ言い方。条件の表を予想の前に出す場面が台本にない。さらに町の点は上場企業の公表分だけ（委員会への報告の大半を含まない）なのに、その断りが声にも冒頭の断り書きの一覧にもない。「32人は一度も漏れていない」が「3割は無事」と聞こえる。
- **「どれくらい」が言えていない**：おおむね大丈夫（「大きく増えた」→1万9千件、「大きく偏る」→20人中16人）。
- **前の文とつながらない**：243〜247行目の「列は隣に移る」→「難しくなった」のつながり（上の⑤）。
- **中身より先のことを約束する**：仮題の「盗むのは簡単になった」は本編で測っていない（上の④）。

### 細かい所（事実役・日本語役にも回す）

- 194行目「三年前には」：2022年末の数字。いまは2026年10月なので約4年前。「2022年の終わりには」と言うほうが安全。
- 195行目「5社に1社」と231行目「5人に1人」が食い違う（組織の割合なので「社」）。
- 231行目「下の層の多くは報酬がなく」：根拠は「ある大きなグループ」1つ（184行目）。判定でも「ある大きなグループでは」を残す。
- 228行目、Cの判定の根拠に「捕まるのは10代と20代」を使うと、175〜178行目の「捕まった人の話で、お金が大きく動く事件とは中身が違う」と自分で食い違う。判定の根拠は「大きな犯罪も分業で、下の層は報酬なし」に寄せる。
- 130行目「調べた国の中では、いちばん高い値段でした」は29行目の繰り返し（10章）。2回目は「さきほどの、いちばん高い値段です」と受ける。
- 132行目「なぜ、それほど安いのでしょうか」に、章の中で正面から答えていない（質屋の歴史に移り、157〜159行目で答えているのは「なぜ日本が高いか」）。問いを開けたまま次へ進んでいる（8章）。

## 勝つための直し方（効果の大きい順）

1. **締め → 245〜247行目 → 最後の一文に質屋を入れ、データで測った言葉に替える**
   「簡単になった」は測っていないので、「増えた」に寄せ、比喩で逆説にする。例：「盗まれる情報は、まだ増えています。でも、質屋の窓口は、少しずつ細くなっています。」→ 最後の一文「盗品が積み上がるほど、窓口の細さで、値段が決まる。」のように、仮題とも葦の締めとも違う、比喩の中で完結する一文にする（言い切りの範囲は出口の数字が出たあと、という条件はそのまま）。仮題は、オーナーが決めるときに最後の一文と同じにしないよう README に一言残す。
2. **締め → 243〜244行目 → 「列は隣に移る」と「難しくなった」をつなぐ**
   順番を「出口が一つ閉まると、列は隣の窓口に移った（偽造 → 番号）。でも、その隣の窓口も、細くなり始めた（2025年）」にして、「移るだけ」で終わらせない。241〜244行目の一般化「犯罪は〜出口に集まります」は、2つの系列が時期の重なりまでなので、「この回で見た3つの場面では、犯罪は出口のあるほうへ動いていました」と範囲を付ける。
3. **締め・引き → 教訓の場面（236〜238行目）→ 彼の2つの問いに、彼の言葉で答える**
   「何回」：町の中で彼がいる層の結果を言う（彼の使うサービスの数を物語の設定として決め、町の層の代表値の1つ（5・15・30個）に合わせる）。**調べる必要がある**：`data/town_sim.py` の、真ん中の層の「0回・1回・3回以上」の人数（いまの台本には多い層の値しかない）。「いくら」：「1枚、飲み会一回ぶん。それも、質屋に通れば、の値段」と回収する。痛みで始めた物語を、痛みの答えで閉じる。
4. **絵・参加（対 棒人間）→ 第1章の町（98〜112行目）→ 主人公の猫を町に入れ、実行の前に予想の間を置く**
   町の100人のうち1人を彼（トラ柄・青）にして、赤い点が彼にいくつ付くかを毎回見せる。人型の群衆の中に猫が1匹いることで、棒人間の見た目と分かれる。町1・町2それぞれの前に「一度も漏れていない人は、何人残るでしょうか」の間を置く（11章 はしご）。
5. **新しさの守り（owner-feedback「仮定が恣意的に見える」）→ 101行目 → 条件を声と表で先に出す**
   「数字は、なるべく実際の調べに合わせました」を消し、「配る点は、上場企業が公表した延べの数から170個。使うサービスの数は、調べに合わせて三つの層」と言い切り、画面に条件の表（`docs/brand.md`「シミュレーション」）。続けて「上場企業の公表分だけなので、本当の赤い点はもっと多い。一度も漏れていない人は、これより少ないはずです」と一文足す（点を増やせば0回の人は減る一方なので、新しい数字は要らない）。冒頭の断り書きの一覧にも「町の点は上場企業の公表分だけ」を足す。
6. **引き → 29〜30行目 → 物差しを1つだけ足す**
   「調べた国の中で、いちばん高い」に「世界の平均の、およそ2倍」を添える（日本22.8ドル、全50,705件の単純平均11.48ドル。`research-market.md` に自分で計算した値として載っている。台本に入れるなら sources.csv の S13 に計算と書く）。画面には132か国の棒を並べ、日本だけ色を付ける。「何か国中か」は outline の残りの確認にあるので、**調べる必要がある**（NordVPN 本文の国の数と、データ表の132か国が同じか）。
7. **引き → 32〜33行目 → 答えをもらさずに、問いを見る人の痛みにつなぐ**
   「本当に、そうでしょうか」で反語にせず、「盗まれる数も値段も上がっている。それなら、私たちの損も、増え続けているのでしょうか」と、問いを盗む側の儲けではなく見る人の側に置く。Dの答えも予想タイムまでもれない。
8. **第2章の問い → 132行目のあと → 「なぜ安いか」に1行で答える**
   質屋の比喩の入り口で「盗品の値段は、質屋でいくらになりそうかで決まります。これは私たちの仮説です」と言い、157〜159行目の「日本が高い理由」とつなげる（仮説と言う。9章）。
9. **示唆 → 209行目・212〜213行目 → 言い切りの範囲を数字に合わせる**
   示唆1の「たいてい」を「今日見た数字では」に。示唆3は「被害の大きさが動いた時期は、盗まれた量より、出口の広さの変わり目と重なっていました」とし、154行目と強さをそろえる。言い切りが弱く聞こえる分は、偽造165億円 → 1.5億円の大きさで支える。
10. **細かい所** → 上の「細かい所」の6点（三年前・社と人・ある大きなグループ・Cの判定の根拠・繰り返し）を直す。

### 守ること（確認）

- 直し方1〜3は、測っていない言葉（簡単・難しい）を数えた言葉に寄せるためのもの。「漏れても大丈夫」「被害はなくなった」とは言わない（番号盗用は2025年も475億円）。
- 主人公のサービスの数は物語の設定で、統計の数字として言わない。
- 示唆は「〜したほうがいい」と言わない。本人確認の仕組みも「使え」とは言わない。
