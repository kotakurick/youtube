## 見るところ別

### 1. 0.3秒で何の話か（168px）
- 案1：「盗まれたカード」（高さ約110px→約14px）と金の「約3,400円」（約140px→約18px）は読める。「1枚」（100px→13px）は読めるか怪しい。数字は読めるが、**3,400円に物差しがない**。日本の視聴者は「カードの情報が3,400円」と聞いて高いとも安いとも感じない。本編の驚き（調べた国でいちばん高い）は、サムネイルには出ていない。
- 案2：2行（118px→約15px）が全部読める。主題（盗まれたカード）と問い（いくらで売れる）が一度に入る。**3案で一番速い**。値札の「？円」（72px→約9px）は読めず、ただの白い札。
- 案3：「漏れた情報の／行き先」は読める。カードの値札は約6〜9pxで消え、**カードは「ただのカード」に縮む**。人は大きいが、何をしている人か（スマホを見ている）は168pxでは分からない。

### 2. 競合の間で目が止まるか
- 3案とも地は「暗い紺→青緑」の斜めのグラデーション。**これは「はっきり2色」（2026-10-06 の決定）ではなく、中間が濁った青**。スマホのダークモードでは、紺の左上が画面の黒と溶け、枠が見えなくなる。
- 解説系の競合（赤・黄・白の大文字が多い）の中では、青緑は落ち着いて見えて悪くないが、**面積の半分が暗い**。明るい青緑の面を増やすほうが浮く。

### 3. 押したくなる問い・タイトルとの組み
- タイトルAは「盗む数は増えたが、お金に換えにくくなっている」。サムネイルが「いくらで売られる？」なら、タイトルは**答えの向きだけ**（換えにくい）、サムネイルは**値段という具体**。別のことを言って補い合う。くり返しは弱い（「お金」は両方に出るが、言い方が違う）。
- **案1の数字は、タイトルAと逆向きに読まれる恐れがある**。サムネイルは「3,400円で売れる＝けっこう換えられる」、タイトルは「換えにくい」。意図した「えっ、どっち？」の隙間になるか、ただの食い違いに見えるかは、本編の「高い」の意味しだい（安いから売れにくいのか、品薄で高いのか）。確かめずには出せない。案2はこの食い違いを起こさない。
- **「売れる」は、売る側の目線**。盗んだ人の立場でお金の話を聞くことになり、「手口・助言」に見える余地がある（攻撃の手口には見えないが、広告の判定が気になる語）。被害者側の目線の「売られる」にするほうが安全。タイトルAの「盗んだ情報」とも向きがそろう。
- **「カード」の言葉の位置が中身とずれる**。絵は、チップの付いた**実物のカード**。本編は「カードの情報」が盗まれて売られる話。実物を盗む話に見える（指摘集「中身より先のことを約束する」の型）。「盗まれたカード情報」と言うか、値札に「情報」を入れる。本編でいちばん数えている名詞（カード番号か、カード情報か）と同じ言葉にそろえる。

### 4. 文字
- 白文字の明朝体・縁取り12px・影、金は強調の1語だけ、という6本目の型を守れている。縁取りは十分。
- 案1：「約3,400円」の右端が x=1265 で、**画面の端まで15px**。余白が40px要る。「1枚」は小さく、約の位置とそろっていない（x 878〜1020 に対し、約3,400円は x 600〜1265）。
- 案2：行1は x 230〜1035、行2は x 180〜1060。余白は十分。ただし**金は「売れる」の2文字**で、問いの核（いくら）に色が乗っていない。
- 案3：大きさ130pxで一番強い。ただし行頭が左の人の頭の右（x=380〜）から始まり、**右へ寄りすぎて左右の重さが偏る**。

### 5. 絵
- 案1・2：絵は「カードに値札」の1つだけで、主役は1つ。**ただし平らな図で、感情がない**。指摘集のとおり、平らな図は響かないと言われた型。案2は、値札が小さい（約12%の面積）ので、「問い」を絵が支えていない。
- 案2の接触：カードの右上角が、2行目の文字の下端（y約285）に**ぴったり接している**。文字と絵が詰まり、窮屈。
- 案3：人の仮のシルエットは、腕の線が不ぞろいで、顔もなく、作りが荒い（人形に替えるので、いまは評価の外）。ただし**人が画面の約3割、左を占める**ので、カードが脇役に回り、「主題は1つ」の決まりに反する。人・文字・カードの3つの視線がばらける。

### 6. ポリシーとかぶり
- 特定の企業：3案とも出ていない。**カードの柄**：チップ・緑の帯・伏せ字の灰色の4つの丸角。実在の1社に似せてはいない。ただし帯が青緑で、ブランドの色と同じ。問題なし。
- 助言に見える：なし。攻撃の手口に見える：「売れる」だけが弱い気配（上の3を参照）。
- 他チャンネルの丸写し：なし。6本目と並べると、上に太い文字・下に絵、という同じ型で、**型としてはそろっている**（いいこと）。

## 直し案（効く順。案2を軸に）

### 1. 案2：値札を主役にし、「？円」を約2倍に、地の右下の空きを使う
- **何を**：値札の文字「？円」を72px→**130px**、札の幅を330→**450**、高さ100→**150**に広げる。位置は、札の左の穴がカードの右下の端に掛かるまま、札の中心を x≈870, y≈545 に置く（いまは x≈800, y≈540 で、右の x 1000〜1280 が空き）。「？」は金（#FFC83D）、「円」は墨（C.ink）の2色で、札の白地に重ねる。
- **なぜ**：168pxで9pxだった値札が17pxになり、「値段が分からない札」という問いの絵が読める。右下の約25%の空きも詰まる。タイムスタンプ（右下 x 1120〜1280, y 640〜720）には掛からない。

### 2. 案2：文字の言葉を「盗まれたカード情報／いくらで売られる？」にし、金を「いくら」に移す
- **何を**：行1を「盗まれたカード情報」（9字。118px→**108px**に落とす。幅は約1,020px。x 130〜1150）、行2を「**いくら**で売られる？」（金は「いくら」の3字）。行2は 112px、幅約1,000px。
- **なぜ**：①カードが実物に見える食い違いを、「情報」で直す。②「売れる」の売る側の目線をやめ、被害者の側の「売られる」にする。③金色を問いの核（いくら）に置くと、値札の「？円」の金とそろい、目が「いくら→？円」と流れる。縁取り12pxは変えない。字数は行1が9字で長いので、収まらなければ「盗まれた情報」（6字・118px）に戻す。そのときは値札を「？円」のままにして、カードの絵を情報の意味で足す（次の直しの3の「情報」の札）。

### 3. 案2：カードを文字から離し、地を「はっきり2色」に
- **何を**：カードの位置を (cx,cy)=(420,470)→**(380,520)**、大きさを 0.95→**0.88**に。カードの上の角が y≈335 に下がり、2行目の文字の下端（y約290）との間が約45px空く。地は、グラデーションをやめ、**上半分（y 0〜330：文字の層）を紺 #0B1E3A、下（y 330〜720）を青緑 #1FA390**の、斜めのはっきりした切れ目（左 y≈360、右 y≈300）で分ける。
- **なぜ**：文字（白）は紺の上で最も目立ち、カード（淡い灰色）は明るい青緑の上で浮く。中間のにごった青が消え、ダークモードでも青緑の面が枠になる。「背景ははっきり2色」（2026-10-06）にもそろう。カードの帯の青緑 #1E9483 は地と同化するので、帯だけ**紺**に替える。

### 4. 案3（人形に替えたあと）：主役は人形1人とカードの値札、金の矢印で「行き先」を絵にする
- **何を**：
  - 人形の大きさを約3割→**約2割**（Silhouette の size 1.25→**1.0**、x を 270→**200**）に落とし、スマホの画面を**金**に光らせる（約50×80px）。
  - カードを 0.6→**0.95**倍、位置を (800,530)→**(900,520)**。値札は直し案1と同じく「？円」130px。
  - 金の太い点線の曲線（太さ10px）を、人形のスマホ（x≈300, y≈330）から、カードの値札（x≈760, y≈520）へ引く。
  - 文字は x 380〜 の位置をやめ、**中央ぞろえで x 300〜1250 の範囲**に置く。
- **なぜ**：168pxで絵の流れが「人のスマホ→（情報が流れて）→値札のカード」と読め、「漏れた情報の行き先」を絵だけで言える。いまは3つが張り合い、何も勝っていない。人形の白は地に対して強いので、約2割でも主役を保つ。

### 5. 案1を残すなら：数字に物差しを足すか、案2に統合する
- **何を**：案1は、金の数字に「約3,400円」だけでなく「調べた国で最も高い」を残せないか、という問題が解けない（数字は1つの決まり）。無理に足さず、**案1は捨てる**ほうが安い。やるなら、「1枚」を消して「約3,400円」を 150px、右端の余白を45pxにして、カードの右下の角から値札の形に続ける（x 560〜1240）。
- **なぜ**：「1枚」は小さくて読めず、数字だけが浮く。本編の驚きは、数字そのものではなく、その数字の意味（世界で最も高い）にあるので、サムネイルには置けない。
