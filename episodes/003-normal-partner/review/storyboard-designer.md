# 絵コンテ 第1版 デザイナーの指摘（003-normal-partner）

見たもの：`render/public/sb/003-normal-partner/01〜31.png`、一覧、`storyboard.md`、`scenes/Storyboard.tsx`、`script.md`（第6稿）、`sources.csv`、`data/count_result.md`、`docs/brand.md`、`theme.ts`、`qa.ts`、新しい部品 `SearchScreen.tsx`・`TwoSieves.tsx`（あわせて `Quiz.tsx`・`Verdict.tsx`・`Dumbbell.tsx`・`SourceNote.tsx`）。

## 総評

- 検索画面（自分の画面）から両側のふるい、最後に二つの画面へ戻す流れは、絵の比喩として筋が通っている。色を男女の色と墨だけに絞ったのも守れている（蛍光ペンの黄は使っていない）。
- ただし区画の決まりが全体で崩れている。出典の注を13場面で y930〜968 に置いていて、字幕の帯（y920〜1000）に重なる。文字のはみ出しも7場面ある。絵コンテには字幕の帯がないので、`npm run check` では見つからない。
- データの間違いは少ない。直すのは次の4つ。12 の人型の大きさの違いと端数の丸め、28 の「61人」に出典がないこと、27 で年収の区分が等間隔でないことの注、24 で答えがいちばん小さいこと。

## 場面ごとの指摘

### 01 冒頭：午前1時の部屋（11秒）
- 問題：彼女（猫 size 4.2、高さ約200px）は x1180 にいて、壁の上半分（y150〜700）がほとんど空いている。引きの画としては成り立っている。名札の位置（x96,y64）は、ほかの場面の見出しの位置と同じでよい。
- 直し案：動きで時計（x1080,y300）→ 彼女の順に軽く寄る（寄り終わりに彼女の高さ300px）。直しは要らない。

### 02 冒頭：二回目のお見合い（11秒）
- 問題：通知の札（x1180〜1780, y180〜330）の一行目「翌日　相手の相談所から」は 28px の ink2 で、スマホでは消える。札の中で主役になる「今回はお見送りに…」は 40px。
- 直し案：一行目を label 40px（ink2）、二行目を value 64px に。札を幅680・高さ190にする（x1140〜1820, y150〜340）。22 で同じ札をもう一度出すので、この形を正本にする。

### 03〜06 冒頭：検索画面（5・5・7・16秒）
- 問題1（区画）：断り書きの `SourceNote` が y968 にあり、字幕の帯の中に入る。スマホ（SearchScreen h=820, 中心 y520）は y110〜930 にあって、帯の上28pxの間も割り込んでいる。
- 直し案1：SearchScreen を `h=700, y=480`（y130〜830）にし、断り書きは既定の y844 に置く。
- 問題2：右半分（x1180〜1824）は値のラベル1本だけで、03 では ink2 の 40px が浮いている。視線の流れは、スマホ → 右の「千人 → 132人」の順でよい。ただ、右の数字はスマホの中の数字の繰り返しになっている。
- 直し案2：右側は減った数（「−868人」「−26人」「−47人」）を value 64px で出し、その下に一言（「二割しか減らない」「半分近くが、一度に消える」）を body 44px で置く。減り方を数で見せるのが、この段落の主役。03 の「25〜34歳の結婚していない男性」は、スマホの上の見出しの位置（x96,y56、label 40px）へ移す。
- 問題3（05）：彼女の猫の足元が y900 で、帯の上28pxの間（y892〜920）に入る。
- 直し案3：猫を `y=860, size=2.6` にする。
- 問題4（06）：59人は「身長と年収は関係ない」とみなした見積もり。相関0.1なら約65人になる（`count_result.md` の7）。いまは断り書きの「身長は見積もり」しかない。
- 直し案4：右の「106人 → 59人」の下に「身長は見積もり」を note 28px で添える。台本の第1章で「もう少し多く残るかもしれません」と言うので、画面ではこの一言で足りる。

### 07 冒頭：あの人の画面（7秒）
- 問題：「⇄」（value 64px）は二つの画面の間で小さく、細い。視線は左の「59人」に止まり、右の「？」まで流れにくい。
- 直し案：「⇄」をやめ、二つの画面の間（x760〜1160, y540）に墨の両向きの矢印（LINE.base 7、長さ300）を引く。右の画面の「？」の行は、点線の枠（rest、dash 12 8）で描く。30 で点線を実線に変える前ぶれになる。

### 08 今日の答え合わせ（8秒）
- 直しは要らない。札の文言「普通の相手は、数%しかいない」は 26 と同じなのでよい。台本（「…ほんの数パーセントしか残らない」）と言い方が違うのは、画面を短くしたためとして認める。

### 09 予想タイム（27秒）
- 問題1：問いが2行（「…背に／よる差は？」）になっている。2行目の下端（約 y310）が選択肢の札の上端（y310）にくっつく（`Quiz` の選択肢は y310 に固定、問いの高さを見ていない）。単語の途中で行が変わるのも読みにくい。
- 直し案1：問いを1行18字以内にする（例「年収850万円以上なら、背の差は？」15字）。部品の側では、`Quiz` の選択肢の top を問いの行数から決める（2行なら +90px）。
- 問題2：前提の「160cm以下 27.6%／172cm 37.4%（差 約10ポイント）」が文字だけで、いちばん大事な「差」が絵になっていない。27 秒止まる画面なのに、動く要素がない。
- 直し案2：選択肢の下（y700〜800）に、27 と同じダンベル1行「男性会員全体　27.6% ○——● 37.4%」を 0〜50% の同じ物差しで置く。27 でこの行の下に年収の3行が足されると、場面をまたいで同じ絵が続く。
- 問題3：出典が y930 で、字幕の帯の中に入る。
- 直し案3：y844 へ。

### 10 第1章：千人の正体（11秒）
- 問題1（はみ出し）：SearchScreen を h=600 で描くと、行のラベル（40px 固定。`SearchScreen.tsx` の 42行で k を掛けていない）が画面の枠からはみ出す（「年収 500万円以上」が x650 まで出て、スマホの右端は x606）。
- 直し案1：部品で行のラベルを `max(28, 40*k)` にする。あわせて、ラベルの幅が画面の中の幅（w−104k）を超えたら止める決まりを `SearchScreen` に足す。この場面は h=700 にする。
- 問題2：人型の size 1.1（高さ約55px）は、決まりの「100人で64px以上」（CROWD_SIZE 1.3）に足りない。
- 直し案2：size 1.3、dx 70・dy 68。100人の固まりは x1000〜1640, y200〜820 に収まる。「1人＝10人」は固まりの真上（x1000, y190）に label 40px で置く（右の外に置くと、人型との対応が切れる）。

### 11 第1章：考えてみよう（8秒）

### 12 第1章：8割と5割（13秒） ★データ

- 問題4：右の「大学を出た人 約5割」（x1650）と、左の「大学を出た人 約8割」（y680）の位置と大きさがそろっていない。上の直し案で一緒に解ける。

### 20 第2章：お互いに満たし合う組（24秒） ★データ・新しい部品

- 問題1（はみ出し）：`TwoSieves` の札は幅440なのに、label 40px の「女性の条件を満たす男性」（11字＝約440px）が左右の枠にかかる（画像で「女」の字が欠けている）。

### 21 第2章：自分のふるいと相手のふるい（19秒）

### 23 第3章：考えてみよう（13秒）

## 全体の決まりとして足すべきこと

1. **絵コンテでも字幕の帯を描いて調べる**：`npm run storyboard` と `npm run check` は、絵コンテの場面でも y920〜1000 に仮の字幕の帯（data-qa="sub"）を置いて調べる。今回の13場面の注の位置は、これで止められた。
2. **出典の y は既定（844）から動かさない**：`SourceNote` の `y` に 876 より大きい値が来たら、エラーにする（部品の中で throw）。主役の絵は y820 まで。
3. **見出しと問いは1行**：Heading（72px、幅1500）は20字まで、Quiz の問い（幅1300）は18字まで。超えたらエラー。2行の見出しは区画（y56〜176）からはみ出す。
4. **部品の文字はラベルの長さから枠を決める**：`SearchScreen` の行、`TwoSieves` の札、`Dumbbell` の凡例は、文字の幅（字数×大きさ）で枠や位置を決める。今回の3つのはみ出しはどれもこれが原因。`qa.ts` に「文字が親の枠からはみ出している」を足す（親子の組を、いまは調べていない）。
5. **人型 64px を部品で守る**：`hundred()` か `Figure` で、100人を描くときに size<1.3 なら warn を出す。`TwoSieves` の 0.62 は作り直す。
6. **割合の言い方は2段にそろえる**：声の言い方（「約8人に1人」）を主役の大きさで出し、その下に「100人に13人（13.3%）」を値の大きさで出す。17・19・20・26・28 を同じ形にする。「千人」と「1,000人」も、画面では「1,000人」にそろえる。
7. **出典の書き方を1つに**：「機関『調査名』(年) 表」の形にそろえる。今回は「就業構造基本調査2022」「総務省『就業構造基本調査』2022」「IBJ 結婚みらい研究所（2026）」「IBJ（2026年6月5日 PR TIMES）」が混ざっている。2回目からの略し方（鈴木・八代（2025））はよい。
8. **章の中のクイズは reveal**：`Quiz` の決まりどおり、11・23 は答えを光らせてから次の場面へ移る。
