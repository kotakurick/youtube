## 直すもの（離脱しやすい順）

- **〔重〕予想タイムの論理：Aが本当は外れていないのに「外れます」と言い、Dの答えは判定の前に聞こえてしまう**（予想 l.43-49、l.82、l.123-126、l.190-195）
  → 見る人は冒頭で、条件を3つ重ねただけで約6%、つまり数パーセントまで減るのを自分の目で見ている。つまりAは、冒頭では当たっている。なのに第1章 l.82で「Aは、ここで外れます」と聞くと、「さっきの6%は何だったの」と引っかかる。しかも「相手にも条件がある」は、冒頭の最後の2文と第2章 l.123-126の「相手も自分のふるいを持っています」で先に言い終わっている。判定の予想の答えは、新しく何も出ない確認になり、聞き手には「当たり前だった」と聞こえる（owner-feedback の「世間でもう言われている」型に近い）。ため（考える時間）が、答えを出す所に残っていない。
  → ①問いを「国の調査で挙がった条件で、数パーセントまで減るのは、何を数えたときか」の形にして、冒頭の6%（自分の条件を3つ重ねた数字）とぶつけない。または l.82を「Aは、半分だけ当たりです。三つ重ねれば数パーセントになる。でも、国の調査の六つでは、8人に1人は残ります」と言い直す。②Dの答えは l.123-126ではなく判定まで言わず、l.123 は「二枚のふるいが重なる」と絵だけ見せて、「それが答えのD」と判定で名づける。判定の最後は、「26人に1人、約4%」と数字を声で言ってから終える（いまは「約4%」を一度も声で言わないので、「数パーセント」が数字と結びつかない）。

- **〔重〕終盤（9:00–10:30）で山が連続して下がる**（l.176-178、l.184-195、l.206-210）
  → 第3章の山（身長の差がほとんど消える）のあと、「なぜなのかは分かりません。〜かもしれません」で下がり、答え合わせで26人に1人の話を要約し直し、ミクロは「5倍」の数字を言わず、最後は「大事な条件が外れている組も入っています」という断りで終わる。約90秒、新しい驚きがなく、断りで締めるのが2回ある。教訓の前に気持ちがいちばん冷める。「5倍」は、本来は「3.8%が18.8%」という大きな数字。
  → 判定は縮める（「△。自分の条件だけなら8人に1人、相手の条件も数えると26人に1人」と、数字だけ並べて2文）。ミクロは「約4%が、約19%。お互いに満たし合う組が、5倍になります」と声で言い、最後の2文は、事実の1文（「どの条件が外れるかは組ごとに違い、大事な条件が外れる組も含まれます」）にして、教訓の入口にする。理由の推測（l.176-178）は、一方を残して1文にする。

- **第3章の前半（6:15–7:30）：クイズに選択肢と数字がなく、米国の研究で主語が3回変わる**（l.141、l.146-151）
  → l.141「どれくらい言い当てるのでしょうか」は、答えを考えようにも手がかりがなく、前の章の「8人に1人は？」ほど考えたくならない。そのあと「男性は見た目、女性は稼ぎ」→「言い当てない」→「男女の差も出ない」→「別の実験では差が出る」→「答えはそろっていない」と、30秒で5回向きが変わり、耳では何が結論か残らない。驚き（言い当てない）の直後に断りが続いて、山が小さくなる。
  → 問いを「あなたが条件に書く好みと、会って惹かれる人は、同じでしょうか」の二択（同じ・ずれる）にして自分ごとにする。結論は「言い当てなかった」の1点に絞り、男女の差の話（l.149-151）は1文にまとめるか、双子のあとに回す。

- **第1章 身長の説明（2:35–3:05）：30秒、問いがない**（l.67-72）
  → 「大卒は約8割」の驚きのあと、「身長は、そうではありません」から研究の説明が30秒続き、問いは次の掛け算の所まで出てこない。ここで耳が休む。
  → l.67の前に「では、身長はどうでしょう。年収の高い人は、背も高いのでしょうか」の1問を置く。答えは「弱い関係」と、そのまま言える。

- **第3章 相談所の記録：成婚の割合の言い方が耳で分かりにくく、冒頭の「あの人」に戻っていない**（l.164-178）
  → 「結婚が決まって退会した人の割合」は、何を分母にしているのか耳では分からない。差（10ポイント・2ポイント・13ポイント）だけで、もとの数字（172cm 約37%、160cm以下 約28%）がないので、ポイントの大きさが実感できない。冒頭の「あの人」は160cm台で、この記録の「160センチ以下の男性」と同じ人たちなのに、話が結びつかない。クイズの設計自体はよい（4択、答えは意外）。
  → 「結婚が決まった人の割合が、172センチの男性で約37%、160センチ以下で約28%」と1度は数字を声で言う。「あの人と同じ背の男性」と一言で冒頭へ戻し、「年収が高いと、その差はどうなったか」の問いにつなぐ。

- **第2章 女性の条件の理由（4:20–5:05）と、26人に1人のあとの断り**（l.98-101、l.127-130）
  → 約8人に1人という驚きのあと、「理由は二つ、これは当チャンネルの考えで論文は調べていません」の4文で山が下がる。26人に1人のあとも、「幅をもって見るように」の断りが続く。どちらも必要な断りだが、驚きの直後にまとめて置いているため、驚きが小さくなる。
  → 断りは「二つ考えられます。どちらが強いかは、まだ分かっていません」の1文に縮める。「幅をもって見る」は〔間〕をはさんで、26人に1人の余韻のあとに置く。

- **冒頭（0:00–0:25）：最初の2文は他の婚活の話と入れ替えられる**（l.12-14）
  → 「午前一時。会員を探す画面を開いている。入って三か月、お見合い二回」は、どの婚活の話にも通る。この動画だけの絵は「笑うと目がなくなる人」「同じ160cmくらい」で、そこは3文目以降にあって十分に刺さる。
  → 「入って三か月」と「お見合いは二回しました」を1文にまとめ、「笑うと目がなくなる人」を早く出す。小さな直しでよい。

- **耳だけで聞く場合の小さな引っかかり**（l.97、l.205、l.229）
  → ①「その2倍半です」は、8人に1人と20人に1人を頭の中で比べないと意味が取れない。②「4倍近く違いました」は73人と273人の比だが、そのあいだの「戻ってくる人数」と聞こえるため、どれとどれの比かが分かりにくい。③最後の「〔字幕なし〕〔間・長〕」は、画面が止まったままだと「終わった？」と閉じる人が出る（前回と同じ）。
  → ①は「20人に1人という計算の、倍以上です」と言い直す。②は「73人と273人。4倍近い差です」と数字を並べる。③は end の20秒に、彼女の画面だけがゆっくり動くなど、動きを残す。

## よくできている所

- 冒頭の検索画面（0:25–1:05）：「千人→132人→106人→59人」と、「二割しか、減っていません」「半分近くが、一度に消えたのです」「あの人は、このチェックで、画面から消えていた」。耳だけでも分かり、他のチャンネルと入れ替えられない。冒頭の最後の2文が、動画全体の問いになっている。
- 第7稿の主な直し：予想の選択肢を章ごとに退ける（A：第1章、B・C：第2章、D：判定）形は、章ごとに「いま何を確かめているか」が聞き手に残り、章をまたぐ糸になっている。上の1の論理を直せば、さらに効く。
- 身長×年収の問いを第3章のクイズ（4択、答えは「ほとんど消える」）にしたのは正しい。第3章に、章ごとに1回の「自分で考える」場面と驚きの山が置けた。前回の「第3章の山が小さい」は、半分は解決している（残りは上の3）。
- 第2章（約8人に1人 → 約3人に1人 → 26人に1人）は、女性・男性を同じ手順で出し、片方だけを責める聞こえ方にならない。「数パーセント、ではありません」と、問いに戻って答えるのも聞きやすい。
- 第3章の頭「冒頭の彼女を、思い出してください。彼女は、あの人の画面の欄を通っていました。だから、二人は会えたのです」は、章をまたいで物語に戻る、効いた橋。
- 締め：「相手を数パーセントにしていたのは、条件の多さではありませんでした。選ぶ人が、選ばれる人でもあることでした」は、「なるほど」で終わる。「就職でも、部屋探しでも」の一般化もよい。
- 比喩が「ふるい」1つに絞られ、「物差し」の混ざりがなくなった。「〜の側」も消え、耳で聞いて通る。
