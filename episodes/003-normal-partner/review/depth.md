# 深さ（review-depth）

2026-10-05。対象は `script.md` 第1稿（読み上げ約9分）。読んだもの：`outline.md` 第2版、`research.md`、`data/count_result.md`、`data/ipss_jnfs16_fig3-2-1.csv`、`sources.csv`。
※下の「予想」は、台本を読む前にタイトル案と通説（「普通の人」でいいなら、相手はすぐ見つかる）を見て書いた。構成案の企画カードは先に見ている。

## 見る人が最初から予想していること

1. **条件を重ねると数%しか残らない**。ネットの「普通の男性は上位2.8%」の話（考えすぎる葦の22.7万回の動画もこれ）。多くの人は一度聞いている。
2. **年収500万円は、もう「普通」じゃない**。平均年収のニュースで聞く話。
3. **女性の条件（年収・身長）が厳しい＝高望み**。反対側では「男性も若さと見た目で選んでいる」。どちらの側から見ても「あっちが厳しい」と思っている。
4. **いい人は先に結婚していく**。残っている人の中で探すから、少ない。
5. **結論は「理想を下げよう」か「人柄が大事」**。婚活コラムで見る締め。

## 章ごとの発見と強さ

## 持ち帰れる見方

- いまの教訓「ありふれた条件でも、全部そろったものを探すと、珍しいものを探すことになる」は、ほかのテーマにも使える。ただ、**タイトルと第1章前半の言い直し**で、予想1（重ねると減る）の側の見方になっている。この回でいちばん強い発見（掛け算は少なく出る＝条件は一緒に動く）が教訓に入っていない。
- 足せる見方は3つ。どれもこの回のデータで裏付けがある。
  1. **ばらばらに見える条件は、つながっている**。だから掛け算は少なく出る（第1章、正社員の予想の答え）。健康診断の項目、物件の条件、採用の条件などにも使える。
  2. **探している集団は、すでに選ばれたあとの残り**（冒頭の24%→15%）。中古車市場、転職市場、売れ残りの物件にも使える見方。
  3. **割合がそろっていても、数はそろわない**（提案2）。チャンネルの例「割合と数を分けて見る」そのもの。
- 締めの一文「どこから見ても普通な人は、いちばん珍しい人です」は残してよい。その前に、1か2を一文で入れると第2章の言い直しから抜けられる。

## 深めるための提案（効果の大きい順、最大5件）

### 1. 冒頭と第3章 → 「選ばれたあとの残り」を数え、反対の証拠を出す

- **どこを**：冒頭の「7人に1人」を回収する場所として、第3章の前半（または第3章を差し替えて「別の角度で確かめる章」に）。
- **何を足すと**：同じ第40表で、未婚以外（総数－未婚）の25〜34歳の働く男性を数える。手元の割合から概算すると（★count.py で数え直すこと）：
  - 未婚以外の働く男性のうち、年収500万円以上は**約4割**（(5,936,200×24.3% − 3,647,700×15.1%) ÷ 2,288,500 ≒ 39%）。つまり、すでに結婚した同世代の男性の**約6割は、500万円の線の下**。
  - 年収500万円以上の25〜34歳の働く男性のうち、まだ未婚なのは**約4割**（550,800 ÷ 1,442,500 ≒ 38%）。
  - 女性の側では、未婚と全体の差がほとんどない（7.0%と7.8%。概算すると未婚以外は約9%）。**男性の年収だけが、結婚で先に抜けていく**非対称。
- **どんな発見になるか**：「普通の線」は、実際に結婚した人の多くが越えていない線だった、という反対の証拠（第3章の役目）。そして、「先に結婚したから稼ぐようになった（結婚プレミアム）」のか「稼ぐ人が先に結婚した（選ばれた）」のかは研究で分かれる、という因果の注意も入れられる。予想4を「確認」から「仕組み」に変える。言い方は相関にとどめる。母集団に「死別・離別」が入るので、第40表に有配偶の行があればそちらで数える。
- **調べ先**：
  - 令和4年就業構造基本調査 第40表（手元の `data/shugyo2022_t040_25-34.csv`、S2。一次資料）。配偶関係の列で数え直すだけで足せる。
  - 孫亜文「結婚プレミアム─KHPSを用いた再検証」（慶應義塾家計パネル調査 2004〜2012年。検索結果の要旨では、普通の回帰では男性に結婚プレミアムが出るが、個人の固定効果を入れると有意でない＝選ばれた側の違いの可能性）：https://www.jil.go.jp/institute/zassi/backnumber/2015/special/sum_24.html （要旨。一次の論文。本文は http://www.jeameetings.org/2014s/Pabstract/J-009abstract_YawenSun.pdf 。※どちらもこの環境から開けず、検索結果の要旨でしか確かめていない）
  - 鹿又伸夫「結婚・配偶者と就業所得：結婚プレミアムと結婚ペナルティ」『三田社会学』17号（2012）：https://cir.nii.ac.jp/crid/1050001338949768832 （一次の論文。消費生活に関するパネル調査では男性にプレミアムあり、とする側。未読）
  - JILPT 資料シリーズ No.217「若年者の就業状況・キャリア・職業能力開発の現状③」に「30〜34歳男性の就業状況・年収別有配偶率の推移」の図があるらしい（就業構造基本調査の加工。二次）：https://www.jil.go.jp/institute/siryo/2019/documents/217.pdf （未読。時系列で「年収が高いほど有配偶率が高い」が強まったかを見られる可能性）

### 2. 第3章の「18万人」 → 割合と数を分けて見る

- **どこを**：第3章②「全国で約18万人」。いまは比べる相手がなく弱い。
- **何を足すと**：同じ物差し（第2章の5条件）で、割合は男女とも16人なのに、**数**で見ると未婚男性 約68万人・未婚女性 約54万人（count_result の 3）。母集団が未婚男性 約418万人・未婚女性 約332万人で、**25〜34歳の未婚者は男性のほうが約86万人多い**（S2・S3。手元のデータで確定できる）。同じ物差しを満たす相手1人あたりの「探す人」の数は、男性側が約8人、女性側が約5人（418万÷54万、332万÷68万の概算）。
- **どんな発見になるか**：第2章の「男女の差は数人」が、割合では正しく、数ではそうではない、という数え方の発見。予想3（女性が厳しい）を、もう一度別の方向から崩せる（男女の回で、もう一方の側のデータとしても働く）。教訓の「割合と数を分けて見る」にもつながる。注意：女性の5条件の18万人と、男性の4条件の87万人を並べて「何人が取り合う」と言うと、物差しが違う比較で片方を厳しく見せるので使わない。未婚男性が多い理由（出生の性比、男性の未婚率の高さ）は言い切らず、数だけ言う。
- **調べ先**：令和4年就業構造基本調査 第40表・第118表（S2・S3、一次資料。手元にある）。理由に触れるなら、国勢調査 2020 の配偶関係別人口（e-Stat、一次）で 25〜34歳の未婚者の男女比を確かめる（未確認の方向性。この環境から e-Stat は開けなかった）。

### 3. 第2章の「一枚ずつ足した」と第3章の「人柄」 → いちばん増えたのは、数えられないふるい

- **どこを**：第2章の S1 の段落と、第3章の「数えられないふるい」の段落（いまの最後の一文は根拠がないので差し替える）。
- **何を足すと**：手元の `data/ipss_jnfs16_fig3-2-1.csv` で、「重視する」だけの割合の変化を見る。
  - 女性が男性に：家事・育児の能力や姿勢 **43.6%（1997）→ 70.2%（2021）**、仕事への理解と協力 46.5% → 55.9%。経済力は 33.6%（1992）→ 36.3%、容姿は 12.9% → 18.8%。
  - 男性が女性に：家事・育児 34.9%（1997）→ 42.1%、経済力 3.4%（1992）→ 4.7%。
  - 女性の側で30年間にいちばん重くなったふるいは、年収でも見た目でもなく**家事・育児**（約27ポイント増）。
- **どんな発見になるか**：予想5（人柄が大事）と予想3（女性は年収で選ぶ）を同時に修正できる。「数えられるふるい」はこの30年であまり重くなっていないのに、「数えられないふるい」が大きく重くなった。統計で数えた4人は、いちばん重いふるいをまだ通していない、と言える（減るかどうかは言わない）。第2章の「女性は見た目を一枚足した」は、重視＋考慮だと約7割→約8割で正しいが、重視だけで見るとより大きな変化を見落とす。どちらの指標で言うかをそろえる（重視＋考慮で家事・育児は 89.8% → 96.5%。上限に近いので、増え方は「重視」で見せたほうが分かる）。1992年は家事・育児の項目がないので、起点は1997年（script-style 10章「選択肢がそろっている年どうしで比べる」）。
- **調べ先**：第16回出生動向基本調査 図表3-2-1（S1、社人研、一次資料）：https://www.ipss.go.jp/ps-doukou/j/db_16/16HoukokuBaseData/houkokuFigure3_2_1.csv 。すでに手元にあり、足すのは読み方だけ。

### 4. 第1章の「掛け算は少なく出る」 → 独立の仮定がどれくらい外れるかの裏付け

- **どこを**：第1章の「背の高さとたばこは、今回も掛け算しています」のあと。
- **何を足すと**：日本のデータで、身長と賃金の関係を調べた研究を1つ。正の関係があれば、「4人も、まだ少なめ」と言える根拠になる（いまは声で言う予定だが出典がない）。
- **どんな発見になるか**：掛け算が少なく出る仕組みが、表で数えた3条件だけでなく、身長でも働いている可能性を示せる。発見の「強」を補強する（新しい山にはならない。尺は30秒程度）。
- **調べ先**：田中賢久「身長と体重が賃金に及ぼす影響」慶應義塾大学パネルデータ設計・解析センター DP2009-010（2010年、日本家計パネル調査 2009年）：https://www.pdrc.keio.ac.jp/publications/dp/1035/ 、本文 https://www.pdrc.keio.ac.jp/uploads/DP2009-010new.pdf （一次の論文。検索結果の要旨では体重の結果しか確かめられず、身長の効果の大きさ（research.md の「1cmあたり時給約0.8%」）は**未確認**。本文で確かめてから使う）。

### 5. 第3章の数え直し → 「普通の線」は動いたか（2017年との比較）

- **どこを**：第3章（構成案で「見送り」にした数え直しの案）。
- **何を足すと**：平成29年（2017）就業構造基本調査で、25〜34歳の未婚男性の年収500万円以上・正社員の割合を出し、2022年と並べる。学歴まで重なった表がなくても、雇用形態×所得×配偶関係×年齢の表があれば、年収と正社員の2条件の重なりは比べられる。
- **どんな発見になるか**：「普通の線」が、5年でどちらに動いたか（賃上げで越える人が増えたのか、変わらないのか）。予想2（500万円はもう普通じゃない）を時間の方向で確かめる。結果がどちらに出るかは分からない（**未確認の方向性**）。差が小さければ使わない。
- **調べ先**：平成29年就業構造基本調査 都道府県編 表02300「男女，配偶関係，従業上の地位・雇用形態・起業の有無，所得（主な仕事からの年間収入・収益），年齢別人口（有業者）」：https://www.e-stat.go.jp/dbview?sid=0003222823 （一次資料。この環境から e-Stat は開けず、中身は未確認）。2022年の同じ形の表は 04000（https://www.e-stat.go.jp/stat-search/database?statdisp_id=0004008157 、一次）。
