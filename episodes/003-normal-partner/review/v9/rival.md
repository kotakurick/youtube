# ライバル（review-rival）

2026-10-07。台本 第9稿（`script.md`）と構成案 第4版（`outline.md`）の確認。手順1は、うちの台本を読む前にテーマ（「普通の相手の条件を全部満たす人は何人いるか」）だけで書いた。`docs/owner-feedback.md` も先に読んだ。

前提：葦は婚活の「普通の条件」をすでに扱っている（`rival-outline.md` 参照：22.7万回の婚活動画、lovebynumbers にも類似の回）。「条件を重ねると数%」は、見る人が一度聞いた話として扱う。

## 考えすぎる葦が作るなら
- タイトル：「なぜ『普通の人でいい』は、いちばん難しい条件なのか【統計学×婚活学】」
- 最初の30秒：1950年代の空軍、4,063人の操縦士を10か所測ったら「平均的な操縦士」は0人だった。座席は平均に合わせて作られ、誰にも合っていなかった。そこから「普通の人」も同じではないかと進め、「6つの条件を2人に1人ずつ重ねると1.6%」という掛け算の数字を出す。数字は海外の研究が中心。
- 章立て：①女性の側（上方婚、年収不安）②男性の側（若さ、容姿、男性の側の上方婚）③婚活サービスの側（絞り込み画面が条件を増やす）④歴史（皆婚の時代は普通は結果だった）⑤統計学（平均人の発明）。立場を回って、だんだん広げる。
- 比喩と締め：比喩は「誰にも合わない座席」。締めは「普通の人とは、平均を寄せ集めた、この世にいない人のことだった」→「そんなことを考えすぎてみました」。因果は言い切る（条件が高すぎるから結婚できない）。独自の数え直しはなく、参加する場面もない。

## データで語る棒人間が作るなら
- 装置：1,000人の未婚男性の町。1人ずつ年収・身長・学歴を持ち、条件を1つ言うたびに満たさない人が灰色になって消える。
- はしご（理想の世界 → 足していく原因）：
  1. 理想の世界：全員が各条件に半分ずつ通る、条件はばらばら。6つで16人。「実行してみよう」。
  2. 年収の山を右に長く伸ばす（まん中は半分ではない）→ 人が減る。
  3. 年収と学歴を一緒に動かす → 残る人が増える。
  4. 相手も条件で選ぶ（両側の条件）→ 組が大きく減る。
- 途中の発見：「1つずつは多数派でも重ねると少数派」「条件を相関させると多く残る」「両側に数えると選ぶ側も同じ割合で落とされる」。限界は最後に正直に言う（数字は海外・仮定）。主人公はいない。ミクロはなく、締めは「条件の重ね方が相手の数を決める」程度の一般論。

注意：台本の背骨「SNSの計算の3つの前提を1つずつ確かめる」は、棒人間のはしごと**ほぼ同じ4段**（理想の世界 → まん中でない → 重なる → 相手も選ぶ）になる。違いは、うちがシミュレーションでなく日本の統計の実測と論文の実測でやっている点。ここを絵と言い方で見せないと、「棒人間の型を実データでなぞっただけ」に見える。

## 先に直すべき事実の問題（勝ち負けの前に）
1. **「答えはほとんど当たっていました」は、台本の中の数字と合っていない。** 台本の予想タイムは B「約16組（SNSの計算と同じくらい）」と C「約40組」を別の選択肢にし、答えは C。SNSの16と実際の38は約2.4倍違う。教訓の「ほとんど当たっていた」と判定の「答えだけが近くに来ていた」は、予想タイムの出し方と矛盾する。「数パーセント」という桁は当たっていた、と言い方を狭める。
2. **前提①の「外れた向き」の説明が、数字の順番と合っていない。** 判定は「年収の普通はまん中ではなかった。これで相手はもっと少なくなる」と言う。しかし、S15では、年齢と年収以外の4条件は6〜8割が通る（半分より多い）ので、「SNSの半分ずつ」の16人は、実際の通過率で掛けると52人に**増える**。台本は52人を言うが、16 → 52が「増える」ことを言わないまま、判定で「前提①は少なくなる向き」と言う。聞く人は「16より52は多いのに、どこが少なくなる向き？」と思う。16 → 52 → 133 → 38の4段を、**向き（増える・増える・減る）つきで1枚の階段**にして、前提①は「年収は少なくなる向き、ほかは多くなる向き」と両方言う必要がある。
3. **「132人」と「約150人」が、同じ未婚男性で並ぶ。** 冒頭の132人は働いていない人を含む1000人、第2章の150人は働いている1000人。声では「働いている1000人のうち」と言うが、聞く人には「132と150、どっち？」になる。
4. **「59人」は年収と身長が無関係という仮定の見積もり**（相関0.1を入れると約65人）だが、声では言っていない（画面の断り書きだけ）。台本は「条件はばらばらという前提」を疑う動画なので、冒頭の59人の数字が、自分で同じ前提を使っている点を突かれる。
5. **締めの「よく見かける人は、もう選ばれている」**：第2章の「彼女のまわりで目に入る男性には、もう結婚している人がたくさんいます」は、データのない仮定（彼女の周りに誰がいるか）。「～のかもしれません」と言うか、データのある話（既婚と未婚のずれ）だけで締める。
6. **数の土台のそろえ方が崩れている所**：「約20組に1組」（S19）は、台本が決めた「1000組のうち〇組」に合っていない（同じ表は1000組に約54組）。第1章の「45%・16%」も「100人のうち45人」にそろえる。「男は顔、女はお金」は「よく言われる決まり文句」の引用なので許されるが、前後の地の文は男性・女性になっている。決まりの確認。

## 勝つための直し方（効果の大きい順）
- **絵・新しさ（対 棒人間・葦）** → 第3章の ch3-multiply から verdict まで → 「16 → 52 → 133 → 38」を、1000人の点（または1000組）が1枚の階段で並び替わる絵にする。各段に、増える・減るの向きと理由を1語で付ける（52＝実際の通過率で掛けた、133＝条件が同じ人にそろう、38＝相手の条件も通る）。台本では、判定の「打ち消し合い」の文の直前に、この階段を声で順に読み上げる（いまは52と133が第3章、38が判定、16は冒頭で、4つが同じ場面に並ばない）。これが棒人間の「理想の世界から1段ずつ足す」とは違う、日本の実測の階段になり、まねに見える問題も消える。新しい数字は作らない（全部台本にある）。
- **事実の問題1・2（締め・信頼）** → 教訓の「答えはほとんど当たっていました」と判定の「答えだけが近くに来ていた」 → 「数パーセントという桁は、当たっていました」に直し、前提①は「年収は少なくなる向き、年齢以外の4つはSNSの半分より多く通る向き」と言い直す。これで、約2.4倍の差を認めたうえで、「理由は3つとも外れていた」という逆説は残せる。
- **引き（対 葦）** → 冒頭の最初の30秒 → (1)SNSの投稿の6条件を声で全部言うのをやめ、「年収も背も学歴も、普通。…どれも2人に1人なら、6つ重ねて16人」に縮める。「1000人が500人、250人」は画面に回す。(2)「午前1時、ベッドの中でスマホ」を、定番でない1点に替える（例：お断りの通知が来た日の朝、勤め先の昼休み、など。小説の水準のため、情景は書き手が選ぶ）。引きの「あの人は、身長のチェックで画面から消えていた」は強いので残す。
- **新しさ（第1章が研究の並び）** → 第1章の ch1-hypergamy から ch1-income-couples → S19の妻が上の夫婦（1000組のうち54組）を、1000組の点の絵（妻が上54・同じ階級77・夫が上596・妻の収入なし253）で見せ、自分で数えた数字として前に出す。S11（スピードデート）とS20（120か国）は、どちらも日本のデータでなく、台本の背骨（3つの前提）に直接つながらないので、短くする（S20は「人数の構成でも動く」の1文だけ残す）か、章を半分にする。いまの第1章は約70行で6つの研究が続き、葦の弱点（数字が多すぎる、研究の並べ）と同じ形になっている。
- **参加（ch3-self）** → 「その3つは、同じ人にそろいやすいでしょうか」の〔間〕のあと → 答えを返す1文を足す。「年収と学歴はそろいやすい、身長はほぼ関係ない（相関0.1）」は台本・メモの数字だけで言える（`data/count_result.md` の7）。ここで同時に、冒頭の59人が「身長は年収と無関係と置いた見積もり（関係を入れると約65人）」だと声で言う（事実の問題4を片づける）。
- **ミクロ** → ミクロの場面 → 「年収を外す 273人／大卒を外す 73人」に、「身長を外す 106人」（台本に出ている冒頭の106人と同じ数字）を足して3つ並べる。「同じ1つでも4倍近く違う」は、いまは2つの両端だけを比べているので、3つ並べてから言う（73／106／273）。男性の側の1人（相手の年収を条件にしない男性の325人）との対比を1文で置くと、両側のミクロになる。勧めない言い方はいまのまま。
- **締め** → 教訓の最後の6行 → 逆説の一文を1本に絞る。「答えは当たり、理由は外れ」は判定で言い切り、教訓は「目に入る普通は、もう選ばれた人の普通」の1本だけにする。「就職でも」「SNSの暮らしも」の2例は削るか、1例にして、ものさしの絵を最後まで持ち越す。さらに、冒頭の「あの人はお断りを出す側だった」を締めの近くに戻す（彼女が画面で消していたあの人も、自分を断った。自分も、相手の画面では消えている側）と、物語とデータの逆説が1つに重なる。
- **事実の問題3・5・6（細部）** → 第2章の ch2-married の前に、「働いている人だけで数えると、年収500万円以上の未婚男性は約150人に増えます」の1文を足し、132人との差を先に言う（132人は働いていない人も含むという注意は、台本のメモにすでにある）。「約20組に1組」は「1000組のうち54組」、「45%・16%」は「100人のうち45人と16人」に。

## ほかに気づいた点
- owner-feedback.md の「結論が世間でもう言われている」型：「男性も女性も容姿を約8割が条件にしている」「年収と学歴は重なる」は、聞いて「へー」で終わる危険がある。台本が防いでいるのは、(1)30年で男性の条件が2人に1人まで動いたこと、(2)SNSの計算が当たっているのに理由が全部外れていた、という逆説。この2つを動画のタイトルとサムネイルの言葉に出せるかが、引きの勝ち負けを左右する（タイトル・サムネイルは未決定）。
- タイトルの名詞は、本編でいちばん多く数えているもの（お互いの条件を満たす組・相手の人数）と合わせる（owner-feedback の「中身より先のことを約束する」）。「確かめる」型の題は、小さなチャンネルでは伸びていない（6本ずつ、仮説）ので、「確かめる」より、痛み（普通でいいのに、いない）と数字の逆説をタイトルに出す。
- S15 の38組・133人・325人は、葦がすでに同じ論文を扱っているかが分からない。**調べる必要がある**（相手の動画は分析専用で、素材には使わない）。
