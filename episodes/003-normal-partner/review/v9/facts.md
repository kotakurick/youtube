- **L143（年収の上方婚）**：「子どもが生まれて、妻が働き方を変える夫婦が多いことも、大きく響いています」

### 〔中〕
- **L110-114（S17 の質問）**：「相手の年収を、自分の年収と比べるかどうか」「相手の年収は、もっと高いほうがいいか」→「自分より上の相手と結婚することを、上方婚と呼びます」
  → 問題：S17 の質問は「配偶者との年収の違い」で、選択肢は「相手の年収はもっと高い方が望ましい」。この「もっと高い」は「いまの相手の年収より」で、「自分の年収より上」ではない（既婚者が現在の配偶者について答えたもの。ネットモニター調査）。続けて「上方婚」を定義すると、「自分より上を望む人が女性の45%」と聞こえる。research-hypergamy.md の 3-1(b) 注意も「上方婚の志向をそのまま測った数字ではない」と書いている。
  → 根拠：03.pdf p.78-79「配偶者との年収の違い」、女性20-39歳 44.8%（n=953）・男性 16.3%（n=1,044）は数字どおり。
  → 直し方の案：L110 を「結婚している人に、配偶者の年収についての気持ちを聞いた調査があります」とし、L112 を「いまの相手の年収は、もっと高いほうがいいか」に。「上方婚」の定義は L113 の数字のあとに、別の文として「結婚相手を、自分より学歴や年収が上の人にそろえる傾向を、上方婚と呼びます」と置く。

- **L116-121（S11 Fisman）**：「自分より野心や知性が上だと感じた女性を、選びにくくなっていました」「上を探す女性と、上を避ける男性。2つの好みは、同じ形の夫婦を作ります」
  → 問題：(a) Table IV（p.684）は、野心では男性の係数が 0.031、「相手の野心が自分より上」の追加が −0.058（***）で、上のときの合計は −0.027 と下がる（p<0.05）。知性は追加が −0.043（**）だが、上のときの合計は「負だが有意でない」と原文（p.685）が書いている。「知性が上だと選びにくくなる」とまでは言えず、「評価の上がり方が止まる」まで。(b) 実験は4分の会話のあとの「また連絡先がほしいか」で、米国の一流大学の大学院生、年収は測っていない。S17（日本の既婚者の気持ち）とつないで「同じ形の夫婦を作ります」は言い過ぎ。結婚の組み合わせを作る力は、この資料からは示せない。(c) 「避ける」は「選ぶ確率が下がる」より強い（回避の意図は測っていない。原文は avoidance という語を使っているが、結果の言い方は「選ぶ確率が下がる」）。
  → 直し方の案：L118 を「自分より野心が上だと感じた女性には『また会いたい』と答える確率が下がっていました。知性でも同じ向きでしたが、はっきりした差とは言えません」に。L120-121 は「上を望む女性と、上を選びにくい男性。向きは、組になります」程度に弱め、「同じ形の夫婦を作る」は削る。L117 に「4分の会話の実験」「2002〜2004年」を足す（国・対象は言っている）。

- **L130-138（S20）**：「上方婚は、好みの話に見えて、人数の話でもあったのです」「でも日本の学歴も、同じ向きに動いています」
  → 問題：(a) 好みが変わらなくても起こりうる、というのは Grow and Van Bavel（2015）のエージェント・ベース・モデル（計算機の模擬）の結果で、実際の観察ではない。しかも原文（p.3）は「男性も女性も収入の高い相手を好む好みが続く」ことを前提にしている。「大学を出た男女の人数が入れ替わるだけで」は、好みがゼロでもよいように聞こえる。(b) 日本は S20 に入っていない（台本も言っている）うえ、福田ほか(2021) p.13 によると、日本の4年制大学の進学は今も男性が多い（2023年 60.7%/54.5%）。L136「人数の話でもあった」を日本にも当てはめると読める。S18 の日本の増加は、ほとんど「妻が短大・専門、夫が高卒」の組で、人数の入れ替わりでは説明していない。
  → 直し方の案：L134-135 を「好みが同じでも、大学を出た女性が男性より多くなると、組み合わせが変わる、という計算機の模擬もあります」に。L136 は「上方婚は、好みだけでなく、人数の影響も受けるようです」と弱め、L138 の前に「日本が同じ理由かは、この研究からは分かりません」を足す。

- **L144（学歴「ほどけてきた」と年収を並べる）**：「学歴の上方婚はほどけてきたのに、年収の上方婚は、ほとんど残っているのです」
  → 問題：S18 の表では、妻が上は 11.8→20.9%だが、夫が上も 26.3→30.3%（1980→2010、WP Table A-1 から計算）で減っていない。減ったのは「同じ学歴」（61.7→48.8%）。上方婚が「ほどけた」と言えるのは、論文の対数線形モデルの結果（結びつきの強さの低下）で、台本で見せる割合の推移ではない。年収の20組に1組は「夫30代、2022年、階級で比べた概算、妻が収入なし25.3%を含む」で、学歴の約2割（妻30代、1980〜2010年）とは対象も年も測り方も違う。並べて「ほどけた」対「残っている」と言うのは比べ方に無理がある。
  → 直し方の案：「学歴では、妻が上の夫婦が約1割から約2割に増えました。年収では、妻が上は約20組に1組です。測り方が違うので、単純には比べられません」と、並べるだけにする。

- **L65（予想タイムの問い）**：「結婚相手を探している独身の男女がいます」
  → 問題：S15 の対象は25〜49歳のネット調査の独身者1万人で、結婚を望まない人も含む（sources.csv メモ）。「探している」とは限らない。論文は「結婚市場」と呼ぶが、調査は探しているかを区別していない。
  → 直し方の案：「日本の独身の男女1万人が、結婚相手に求める条件を答えた調査があります」に。

- **L196（年収と結婚の男女差を「同じ形」）**：「第1章で見た、年収を条件にする人の男女の差と、同じ形です」
  → 問題：L189-191 で「どちら向きの因果か分からない」と言ったのに、「条件の男女差が、結婚の差を生んだ」と読める。女性の「結婚している人／していない人」の年収は、25〜29歳 5.7%/4.9%、30〜34歳 10.4%/10.5%と近いが、これは結婚・出産で働き方を変えた人が入れ替わる影響（research-hypergamy.md 3-2「最大の注意」）も入る。S1・S17 の「条件にする割合」と、この結婚の有無の差を、台本は同じ形としてつないでいる。
  → 直し方の案：「結婚しているかどうかで、年収の線が大きく動くのは男性だけでした」と事実だけにし、「第1章と同じ形」を削る。または「第1章の条件の差と、向きは合っています。理由まではここでは言えません」と添える。

- **L189-191 と教訓 L307-308・L312（因果の持ち越し）**：「稼ぐ人が先に選ばれたのかもしれません」と両方向を並べたのに、教訓で「よく目に入る人ほど、もう誰かに選ばれています」「もうあまり残っていない普通」
  → 問題：データで言えるのは「25〜34歳の未婚でない男性は500万円以上が39.0%、未婚は15.1%」まで。年齢の構成も違う（未婚でない男性は30〜34歳が68%、未婚は40%。年収は年齢で上がる）。年齢別でも差は残る（25〜29歳 24.4%/11.8%、30〜34歳 45.8%/20.2%）ので差は本物だが、「もう選ばれて残っていない」は稼ぐ人が先に結婚した向きだけを取っている。
  → 直し方の案：L312 を「探していた普通は、結婚している人の中では普通でも、探している人の中では少ない数字でした」のように、向きに触れない言い方にする。L189 に「年齢の違いもあります」を足してもよい（年齢別でも差は残る、と1文で添える）。
