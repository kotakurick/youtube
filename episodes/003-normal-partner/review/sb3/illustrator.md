## A01（洗面所の夜）の直し案

### 何が問題か（コードと絵の両方から）

- 猫の高さは `50 × size` なので size 5.2 は約260px。画面（1080）の4分の1で、しかも床の真ん中に置かれ、右の洗面台から約300px離れている。**猫が洗面台の前にいない**ので「歯をみがきながらスマホ」に見えない。
- 壁は「ひも模様の灰色」、洗面台は灰色の箱の上に灰色の楕円、鏡は青灰色の板。**どれも洗面所の記号に見えない**（鏡に映るもの・歯ブラシ・コップ・洗濯機がない）。
- 夜を `C.night` を0.5の透明度で全面にかぶせて出しているため、壁・床・洗面台がすべて同じ灰色になり、猫のオレンジだけが浮く。「夜」ではなく「くもり」に見える。
- 光は猫の背後の丸い円（半径240、不透明度0.16）で、**スマホの光に見えない**（猫の頭の後ろの後光になっている）。
- 通知の札が右上に浮いていて、スマホとつながりがない。

### 直し（SVG で描けるもの。1920×1080、床 `FLOOR=840`）

1. **背景は全面の透明度で夜にせず、夜の色で塗る。**
   - 壁：`C.night`（#2B3350）で塗りつぶす。タイルの目地として `C.paper2` の線（不透明度0.12、幅2px）を120px間隔の格子で引く。洗面所らしさが出る（現在の横線はやめる）。
   - 床：`C.ink` の不透明度0.55を `C.floor` の上に重ねる（暗い茶）。
   - 巾木（壁と床の間）：高さ16px、`C.paper2` の不透明度0.25。
   - 青い壁にオレンジの猫になるので、補色で猫がいちばん目立つ。**「夜」と「さびしさ」を色で出せる**。
2. **猫を大きく、洗面台の前に。**
   - `<Cat kind="female" x=1180 y=840 size=8.5 pose="phone" face="sad" look=[0,0.8] />`（高さ約425px、頭の上端が y≈415）。
   - 右下に寄せて、左側に家具を置く構図（左の家具、右の主役、上の通知）。猫の左に洗面台があり、猫は洗面台のほうを向いて立つ。
   - face は `sad` のまま、視線は下（スマホ）。眉が下がる顔は A01 では合っている（F01 の `think` と差が出る）。
3. **スマホの光を、スマホから出す。**
   - `radialGradient`（中心はスマホの位置 x=1180, y=770、半径380）。中心 `C.white` 不透明度0.30 → 外側0。猫の顔・胸・腕をなでるように、猫の**手前**ではなく猫の描画の**あと**に `mix-blend-mode: screen` 相当（不透明度つきの白）で重ねる。後光ではなく「下からの光」になる。
   - 壁に猫の影（`C.ink` 不透明度0.25、頭の形の楕円）を1つ、右の壁に落とすと夜の室内に見える。
4. **洗面所の記号を4つ置く（全部、矩形・円・線だけ）。**
   - 洗濯機：x=120〜470, y=460〜840。`C.white` の不透明度0.85、縁 `C.ink` 5px、角丸 R.md。丸い扉：中心(295,670)、半径105、縁5px、中は `C.tealTint` 不透明度0.25。上のパネルに時刻「22:10」（`font("label")`、28px 以上）。
   - 洗面台：天板 x=520〜1000, y=700, 高さ36、`C.white`、縁5px。下のキャビネット x=540〜980, y=736〜840（`C.paper2`、縁5px、取っ手の小さい横棒1本）。蛇口は天板の上に、幅16・高さ70の縦棒＋先が曲がった短い横棒（`C.ink`）。
   - 鏡：天板の上、x=560〜960, y=190〜620、R.lg、面は `C.tealTint` 不透明度0.18、縁は `C.paper2` 不透明度0.6で6px。鏡の中に、斜めの光の筋2本（白、不透明度0.15）。**消灯した照明バー**を鏡の上に（x=600〜920, y=140, 高さ18、`C.paper2` 不透明度0.5）。「電気はついていない。スマホだけ」。
   - コップと歯ブラシ：天板の上に、コップ（台形、幅44・高さ56）、歯ブラシ1本（斜めの細い棒）。猫の口にも歯ブラシ（口の位置から右上へ、白い棒、長さ60・太さ12、先に `C.teal` の毛）。これで「日曜の夜、歯をみがいている時」が絵になる。
5. **通知は、スマホから出た札にする。**
   - 札は猫の頭の上、x=800〜1560, y=200〜330（幅760、文字は今の2行のまま）。札の下辺の中央から、スマホへ向かう小さい三角のしっぽ（幅40・高さ50、白、縁3px）を猫の頭の上端まで伸ばす。または、札を斜め（-3度）にして「届いた」感じを出す。
   - 動きの表の「右上に札が降りる」は、札がスマホの位置から上へ浮かんで止まる動きに変える（絵コンテの表も変更）。
6. **明るさの階調は3段**：いちばん暗い所＝壁・床、中間＝家具、いちばん明るい所＝スマホの光の中心と猫の顔。これだけで、墨と灰の淡白さがなくなる。

## この回の絵の部品の描き直し案

### 1. 夜の部屋・洗面所（`Washroom`・`Room` を直す）

- 夜の描き方を「全面に半透明」から「夜の色で塗り直す」に変える（A01 の直しを参照）。`Backdrop` に `night` の引数があるので、`night` のとき壁を `C.night`、床を暗くする（夜の窓にも同じ色が使える）。
- 部品として足すもの：`Glow`（スマホの光、放射グラデーション）、洗濯機・洗面台・鏡・コップ（洗面所の家具セット、`washroom` として `Backdrop` に）。夜の場面は A01・F01（本編でも冒頭と教訓で再利用）。
- 猫の大きさの決まり：**物語の場面は size 5 以上**。それ未満（C07 の size 3、C08・F03 の size 2.5）では、顔の表情（眉・口）が読めない。表情を見せたい場面では size 5〜8、群衆や状況の中の1匹にするなら表情を `normal` に固定して、感情の説明に使わない。

### 2. 前提のアイコン（新しい部品 `PremiseIcon`、A12・C00・C13・D09・E06）

| 前提 | 形 | 大きさ・色 |
|---|---|---|
| ① 普通＝まん中 | 横長の物差し（角丸、`C.goldTint` の面と `C.gold` の縁5px）、中央に墨の縦線1本、左半分を薄く（不透明度0.35）、右半分を実色 | 幅150×高さ50 |
| ② 条件どうしは関係なく、ばらばら | 金の横棒と青緑の縦棒が直角に組まれ、間に墨の点が4つ（D07 の縮小） | 150×150 |
| ③ 選ぶのは自分だけ | 猫（橙、size 2.2）の前に角丸の札（白）、猫の向こうに青い猫の点線の輪郭（`C.rest`） | 160×140 |

札の左端に置き、文字は縦中央。結果（C13 など）の「外れ」は、アイコンの線を**途中で欠けさせる**（判定の札は使わない）。

### 3. 検索画面（`SearchScreen`）

- チェックを入れた四角を**軸の色で塗る**（金・金・青緑）。今の左端の幅8の帯は、行全体の縁（幅4）に変える。
- スマホの高さを `h` で縮め、下の空白を作らない。空白があるなら、条件ごとの人数の減り方を示す小さい棒グラフ（金・青緑）に使う。

### 4. 人型の「差」の見せ方（`Hundred` の拡張）

- `lit` のほかに `ghost`（前の条件で脱落した人）を点線の輪郭にする引数を足す。A06（13→11）、A07（11→6）、D02、C05 で、「減った人」が見えると、金の物差し（ほとんど減らない）と青緑の物差し（半分に減る）の差が、色と点線で伝わる。
- 100人の大きさ：`Hundred`（人型 65px）を基準にし、組の記号（A10・D12）は直径56px。

### 5. F04 の描き直し（2つの目盛りの重なり）

- 画面の中央、y=380〜520 に**2本の帯**を、左右からずらして重ねる。左の帯（彼女の目盛り）：x=200〜1150、高さ90、R.lg、面 `C.goldTint`、縁 `C.gold` 5px。右の帯（あの人の目盛り）：x=770〜1720、同じ高さ・面、縁は点線の `C.gold`（A04〜F03 で「見えていなかった目盛り」）。重なり（x=770〜1150）は面を `C.gold` の不透明度0.6にして、**真ん中に小さい人型**（高さ64、`C.other`＝灰ではなく墨）を1つ立てる。
- 左の帯の左端に橙の猫、右の帯の右端に青の猫（size 5.5、向かい合う）。猫の足元は帯の下の床線。
- 重なりの上に一文を出さず、**一文は帯の下**（y=700）に1行。字幕の帯（y=920）との間を 100px 以上あける。
- これで「お互いの目盛りをどちらも通れる人」が、一文を読む前に絵で分かり、D12 の「両方を通る組は？」の答えにもなる。

### 6. 文字と数字の部品の直し

- `SourceNote` の `prefix` の枠が文字に重なって QA の警告印が出ている（B08・B09）。
- 強調の下線（`HeroNumber` や棒グラフの強調）は、数字の下 14px、棒の上端との間 18px。
- 見出し（`Heading`）は、章のドット（右上、x=1740〜1830）に届かない幅（今は 1500）に収まる文字数にする。D04・D12 は17字以内。
