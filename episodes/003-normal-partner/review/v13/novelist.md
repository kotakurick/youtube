# 小説家（review-novelist）第13稿
対象：`episodes/003-normal-partner/script.md`（第13稿）。行番号は script.md のもの。同じ指摘のくり返しは避け、`review/README.md` に載っていない点を中心にした。

## 一言でいうと
冒頭の「お断り → 投稿 → つまみを動かすと人数が落ちる → 59人の中にあの人はいない」は、場面と数字が噛み合っていて、小説として読める。「自分なら選ばなかった人に、断られた」の1行は強い。3つの前提を章ごとに1つずつ確かめる背骨も通っている。

いちばん気になったのは次の3点。
1. **比喩の使い方が締めで割れる**：冒頭〜第2章の「目盛り」は「つまみで選ぶ位置・心の中の普通の位置」だが、締めの「お互いの目盛りを、どちらも通れる人」は「目盛りを通る」になり、ふるいの話に変わっている。いちばん耳に残る1文なので、ここが揺れるのが惜しい。
2. **終盤の問いと言い直し**：予想タイムの問いが、第3章の終わり（261行）と答え合わせ（270〜272行）で、あと2回、選択肢つきで出る。決まり（クイズは冒頭の予想タイムの1回）と、答え合わせの「3回目」になる。判定の結論も 277〜288行で3回言っている。
3. **耳で取り違える所**：「断っています」（291行）は、物語の「お断り」と同じ語で別の意味。「半分より多くの人が通る条件が5つ」（232行）は、直前に「約半分」と言った年齢を数えている。

## 構成の案（必要なときだけ。オーナー承認済みの構成を動かすので、直すべきか好みかを分けて書く）
1. **〔直すべき〕予想タイムの答え合わせ（261、270〜274）の組み直し。** 章の順番は変えない。261行を「問い」から「橋」に、270〜272行を「選択肢を読み直す形」から「答えを先に言う形」にするだけ。変更は5〜6行で、数字・事実は足さない。上の「くどい所」の文案のとおり。
2. **〔直すべき〕締めの比喩（309行）。** 構成ではなく1文の書き換え。教訓の流れ（302〜310行）は変えない。
3. **〔好みの範囲〕第3章に「目盛り」の言葉が出ない（209〜261行）。** 比喩は、冒頭・第2章・教訓にあり、第3章を飛ばしている。2つ目・3つ目の前提も「つまみ」で言うなら、たとえば 249行「でも、まだ3つ目の前提が残っています。選ぶのは、自分だけ。」の前に「つまみを動かせるのは、彼女だけではありません。」と1文置くと、教訓の「相手にも目盛りがある」（304〜305）が、章の中で先に聞こえる。数字・事実は足さない。足すと耳で「つまみ」が増えるので、好みで判断する。
4. **〔好みの範囲〕第1章の順番（上方婚 → 世界 → 日本の学歴 → 日本の年収 → 彼女の画面）。** 第1章の終わり（137〜147）で、「年収で上の妻は少ない」から「人数の話を、冒頭の彼女の画面に戻します」へ飛ぶ。つなぎは「人数の話」の1語。137行のあとに「では、年収で上の相手は、どれくらいいるのか。」と1文を置くと、橋が声で見える。事実は増えない。直さなくても通じる。
5. **〔好みの範囲〕第2章の双子の研究（196〜200）の位置。** 前提1の結論（201）の直前に置かれていて、「年収では外れた」の判定に容姿の話が挟まる。女性の年収（192〜195）のあとに置く現状でも、「国の統計では数えられません」の橋があって通る。動かさなくてよい。

## よく書けている所
- 冒頭の「自分なら選ばなかった人に、断られたのでした。」（60）。第3章の「冒頭のあの人を、思い出してください」（250）で、物語がそのまま第3の前提の導入になる。数字・物語・学術が1つの出来事でつながっている。
- 33行の「相談所の担当の人に『一度だけ』と強くすすめられて、会った人でした」。条件と食い違う行動に理由がある。聞き手が「なぜ？」で止まらない。
- 「ほとんど減りません」（54）で、足しても減らない条件の仕組みを物語の中に置き、第3章の「年収の高い人は、たいてい大学も出ているのです」（213）で裏付けに戻る。仕組みが先に体験になっている。
- 「ここまでだと、数パーセントという説は、外れに見えます。」（245）と「それでも、数パーセントという答えだけは、最後に当たったのです。」（288）の対。判定の落ちが、数字の範囲で言い切られている。
- 「結婚した人のほうが年収が高い」の読みを、「どちらが先なのか分かりません」と言ったうえで、教訓も「かもしれません」にそろえた主張の強さ（188〜190、303）。
- 「Dの130は、女性の条件だけで数えた、男性の人数でした。」（274）。人と組の単位の違いを、はずれの選択肢の説明にして、判定の階段（283〜285）につなげている。
