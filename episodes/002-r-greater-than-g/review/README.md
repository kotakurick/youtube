## 第3稿 → 第4稿（2026-10-05）

第3稿（オーナーの台本レビューで第3章を六つの村に替えたもの）を、facts・policy・rival の3役に見せた（`facts-3.md`・`policy-3.md`・`rival-3.md`）。

| 役 | 指摘 | 対応 |
|---|---|---|
| facts・policy・rival | 「片側に賭けた村ほど幅が広い」は結果と逆（いちばん広いのは株を持つ村） | 消した。発見を「下の1割が資産をほとんど残せなかったのは、お金を借りた二つの村」に替えた |
| facts・policy | 「分けたのは利回りの平均ではなく幅」は誤り | 「平均の利回りが高い置き場所ほど真ん中は上がり、上下の差も広がった。下の端を崩したのは借金」に直した |
| rival・facts | villages.py が起業の借金を差し引いていない、事業を続ける人の年収が会社員の給料になっている | コードを直して回し直した。あわせて「稼ぎが月20万円未満の人は毎年3割がやめる」（稼げない人ほど早くやめる研究に合わせた仮定）を足した。起業の村の真ん中は665→485、下位1割は26→103 |
| facts | 借金のつまみの結果が表にない | 両はしを計算して表に足した（真ん中567〜396）。台本は「真ん中の人の資産は3割ほど動く」 |
| policy・facts | 「両方の村がいちばん高い」は物件が横ばいのときだけ。外れの時代の数字がない | 条件を付け、「積立の村より少し上という程度で、外れの時代を引けば減る人も同じように出る」を足した |
| policy | 起業の村の上の側がない | 44歳の年収の上位1割が六つの村でいちばん高いことを足した |
| policy・rival | 予想の問いが「勝ち村当て」 | 「下の1割が資産をほとんど残せなかった村は？」に替えた |
| policy・rival・facts | 「2億円ぶんの雪」は雪（貯める分）の定義とずれる。「多くの人で2億円前後」は正社員の仮定 | 雲（給料）を第2章で先に置き、示唆は「正社員で働いた場合 1億6千万〜2億6千万円。正社員でないともっと少ない」に直した。締めも「財産は雲のほうにある」で比喩をそろえた |
| policy・facts | 「物価を引くと34年」は S12 と合わない／積立の村なのに一度に入れた人の数字 | 「バブルの頂上で、まとめて株を買った人は、値段がもとに戻るまで34年」（日経平均、S11）に直した |
| facts | 「資格」は計算に入っていない、「過去のデータの幅」は言い過ぎ | 「転職で稼ぐ力を伸ばそうとする村」にし、仮定（部屋の空き方・金利など）を先に声で言う |
| facts | 「九十年代のように」はマンションの記録ではない | 「地価が十五年下がり続けた時期のように」に直した |
| rival | 冒頭と六つの村のつながり | 冒頭に「預金か、投資か、転職か、起業か。二十年後にどうなるのか」を足した |
