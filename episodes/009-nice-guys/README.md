# 009-nice-guys

テーマ: themes.csv 134「『優しい男はモテない』は本当か」

## いまどこまで・次に何をする・未決のこと（2026-10-10）

- **いまどこまで**：フォルダを作り、材料集め中（日本の数字・ダークトライアドの研究・優しさと関係の長さの研究を `research/` に集めている）。
- **決まったこと**：構成は **B案**（2026-10-10 オーナー「B案で組む」。008 と同じく、今日の答え合わせカードと最後の判定のコーナーをやめ、問いは物語の中の1つと予想タイム、予想の答えは山場で1回だけ、最後は結論 → ミクロ → 教訓）。
- **この回の守ること**（制作開始の指示から）：2026-10-10 の方針（事実の可視化＋仮説の解説、シミュレーションはしないか簡単なものを1場面まで）。答えの見込み「どちらも本当で、短い関係と長い関係とで違う」は仮説として確かめる。女性を「悪い男を選ぶ」と描かない、男性を「優しいだけ」と見下さない、両方の側のデータを出す。モテるための助言にしない。海外の研究は画面と声で断る。視聴者は20〜40代の男性（「いい人で終わる」の悩み）。
- **次に何をする**：sources.csv に出典を書く → 企画カードと構成案（`outline.md`）→ `review-rival` → オーナーに確かめてもらう。
- **未決のこと**：テーマの切り口の承認（構成案と一緒に確かめる）。

## 質の最低ライン（公開前）

- [ ] テーマが伸びている分野・問いに入っている（themes.csv の優先度、ベンチマーク分析）
- [ ] タイトル・サムネイルは自分たちの型で作り、他チャンネルの言い回しをまねていない
- [ ] サムネイルがチャンネルの様式どおり。大きな文字は2〜3かたまり、主題は1つ、数字は入れても1つ
- [ ] 最初の60秒で問いが出る。動画の最初の1割のうちに最初の具体的な数字が出る
- [ ] クイズは冒頭の予想タイムだけ。章ごとに1つ、自分に当てはめられる場面（実験・自分に当てはまる数字・日ごとの再現）が問いの形でなくある
- [ ] 事実を分かりやすく見せる独自のグラフが1つ以上ある（シミュレーションは使っても1場面・条件2つまで）
- [ ] 事実と仮説を声で言い分けている（スタンスはとってよい）
- [ ] 出典を要所で画面に出している
- [ ] 画面が10〜20秒ごとに変わる。グラフや文字だけの画面が30秒以上続かない
- [ ] `npm run check` の直すものが0件（図と図、図と文字、字幕の帯に何も重なっていない）
- [ ] 人物の絵柄がチャンネルの決まりどおり（回ごとに変えない）
- [ ] 読み上げが1分390〜400字前後で、長い間がない
- [ ] 読み上げる数字が1分に4〜5個まで。丸めて言い（約3割、4人に1人）、細かい値は画面に出している
- [ ] 冒頭が物語（1人の人物・情景・歴史の一場面）から入っている。数字を並べて始めていない
- [ ] 締めは答えのあとに「教訓」で終えている。答えだけ・問いかけ・登録の呼びかけで締めていない
- [ ] 企画カードが埋まっている（痛み・逆説の一文・この動画だけの数字・日本の数字・絵で分かる瞬間・ミクロ）。`review-rival` で「負け」が残っていない
- [ ] 面白さの仕掛け（先回り・比喩と回収・ミクロ・締めの一文）が台本にある（`lint_script.py` のエラーが0）
- [ ] 結論を数字の範囲内ではっきり言っている（助言はしていない）
