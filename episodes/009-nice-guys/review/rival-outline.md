# ライバル（review-rival）構成案 第1版

2026-10-10。対象：`outline.md` 第1版（B案）。比べる相手の2本は、うちの案を読む前にテーマとタイトルだけで想像して書いた。相手の言い回しは台本に持ち込まない。

## 考えすぎる葦が作るなら

- タイトル：「なぜ『いい人』は選ばれないのか【進化心理学×恋愛】」。「？」は付けない（ヒットは「？」が少ない）。「〜は本当か」という確かめる型は、同じ話題の小さなチャンネルで伸びていなかったので使わない。
- 最初の30秒：意外な数字から。「結婚相手に求める条件は、人柄が女性98%。ところが譲れない条件を3つ選ばせると、『優しい』は6番目の16%」を、物差し（98%と16%）を先に渡して出す。続けて「優しさは、求められているのに、選ぶ理由にならない」と逆説で問いを立て、「優しい男はモテない、という動画は多い。だがこの動画はそこで終わらない」と先回りする。
- 章立て：立場を回って話を大きくする。①選ぶ側（条件の表）→ ②選ばれにくい男性（告白しない・降りる）→ ③「冷たい男」の側（ダークトライアド、一夜では得をする）→ ④結婚の帳簿（離婚の申し立て）→ ⑤人類史（150人の村、長い関係に優しさが要った理由）→ ⑥社会全体の孤立（交際相手なし7割）。どの立場からも「優しさは、短い物差しでは測れない」に着地させる。
- 比喩と締め：「履歴書と面接」か「入場券と座席」あたりの身近な物。締めは「優しさは入場券であって、座席ではなかった。そんなことを考えすぎてみました」。数字は最初の1分で10個近く出し、ダークトライアドの相関を「優しい男は損」と強く言い切る（葦の弱点）。

## データで語る棒人間が作るなら

- 装置：男性100人・女性100人が「1年間の出会い」を回すシミュレーション。各人に「優しさ」「見た目」「積極性」のつまみを付ける。
- はしご（理想の世界 → 足していく原因）：①全員が同じ条件なら、優しさの有無で結果は同じ → ②女性が「優しさ」を最低条件にする（足切り）を足す → ③「一夜」と「結婚」で重みを変える → ④告白する側が男性に偏る、を足す。足すたびにマッチ数が動く。
- 途中の発見：「恋人の人数は平均では差がないのに、中央値は0人」「優しさの有無より、動く回数のほうが結果を動かす」。主人公・日本の数字・ミクロはなく、答えは「優しさは足切りだが、積極性で差がつく」と小さく正直に締める。最後は「アプリの仕組みは…知っておく」のような一般論。

## 判定（尋ねられた4点）

### 物語：案1か案2か
- **案1を推す（案2は外す）**。案2は日本の視聴者に縁がなく、言葉の細部も資料で食い違う。20〜40代の男性が自分を重ねられるのは案1。
- ただし案1には直す所が3つある。
  1. **雨の夜に傘を貸す場面はありきたり**（オーナーの基準は小説の水準）。傘より、「いい人ですよね」と言われる直前の小さな行動を別のものにする（例：飲み会の帰りに、後輩の終電を調べて送り出す。実際の場面は台本で決める）。「扉が閉まる音」の比喩は残してよい。
  2. **主人公は恋人が1人いて4年続いた人**で、動画の問いの中心（恋人0人の46人）とずれる。視聴者の約半分（恋人0人側）は主人公を自分と思えない。主人公に「同期の中で自分だけ、ずっと1人だけ」と言わせて、0人の人たちを遠くから見る立ち位置にするか、主人公を「恋人が一度もいない」にするかを、オーナーに確かめる。
  3. **「年数の表では違って見える」で終わると、負け惜しみ（精神的な慰め）に聞こえる**。主人公の4年を勝ちにしない。結婚（長い関係）の数字は、主人公の気持ちを救うためでなく、数え方が変わった結果として出す。
- 同期の7人を「冷たい男」に見せない、は守れている。

### 比喩「短距離とマラソン」
- **響く。覚えやすく、「物差しが違う」を一言で言える。続けてよい**。ただし直す所がある。
  1. **意味が3つに分かれて使われている**：冒頭は「恋人の人数＝スタートの回数」、第2章は「短距離＝一夜の相手としての魅力」、第3章は「スタートライン＝告白する・しない」。恋人の人数は短距離ではない。1つの意味に絞る（案：短距離＝短い関係の物差し、マラソン＝長い関係の物差し。恋人の人数は「短距離の物差し側」と呼び、「スタートの回数」という呼び名は捨てる）。比喩の言葉を呼び名にすると浮く（006「線」→「基準」の指摘）。
  2. **初出で何を何に当てるかを言う**（004「天秤」の指摘）。冒頭で「恋人の人数は短い物差し、続いた年数は長い物差し」と声で言い切る。
  3. 短距離の勝ち幅は5点中約0.5点、しかも冷たい版でも約2.5点（真ん中の3点より下）。「短距離で勝つ」と言うと盛りすぎる。「短距離では、ほんの少しだけ差が縮む」にとどめる。
  4. 意味の色が男女2色＋短距離・マラソン2色で4色になる。2本の物差しの場面は短距離・マラソンの2色だけ、100人の場面は男女の2色だけ、と場面で分ける。

### 予想タイムの問い（割れるか）
- **このままでは割れない**。理由：
  1. 「結婚相手として、冷たい版は何点」という問いに、多くの人は常識で D（半分以下）を選ぶ（「遊びと結婚は別」は世間でよく言われる）。003 の「自明」の指摘に当たる。
  2. B（ほぼ同じ）・C（2割下）・D（半分以下）は、全部「下がる」で近い（003「CとDが近しい」）。実際に割れるのは A（上）対 B〜D の2つだけ。
  3. 「2割」「半分」は点数の話なので、元の点数が分からないと考えにくい（006「前提の説明が要る」）。
  4. **対比が「優しい版」でない**。論文の比較は、ダークトライアドの特性が高い版と低い版で、低い版は「優しい」と書いたものではない。「優しい版」と呼ぶと事実とずれる（相関・因果の約束に近い問題）。呼び名は「人を操り、思いやりに欠ける人の版」と「そうでない版」にする。
- **直し案**：紹介文の1つを先に見せ（そうでない版は5点中約4点）、問いは「冷たい版は、結婚相手として5点中いくつだったか」にして、選択肢は1点刻みに空ける（A 約4点：ほぼ同じ／B 約3点／C 約2点／D 約1点）。答えは C（約1.7）。D を選ぶ人（「ほぼ最低」）と B を選ぶ人（「少し下がる」）で割れ、答えの C が「真ん中ではなく大きな落ち」になる。画面は、点数を目盛りにした棒でその場で選べる。
- もう1つの案：「短い関係と長い関係の両方で冷たい版が上か下か」の4択（両方上／短いだけ上／長いだけ上／両方下）。ただし答え（短いだけ上）は世間の通説で当たる人が多く、意外さは「差の大きさ」に移るので、割れにくさは同じ。
- 問いのあと、第1章の頭と第2章の頭で選択肢をもう一度画面に残す（答えが約8分先なので）。

## 勝つための直し方（効果の大きい順）

- **引き** → 冒頭の終わり（1:00前後）と予想タイムの前 → 逆説を予告する一文を足す。「先に言うと、ある調査では、冷たい性格の男性の紹介文は、一夜の相手としては点が上がりました。結婚相手としては、半分以下に落ちました。優しさは、どの物差しで測るかで、負けにも勝ちにもなります」。答え（C）は言わず、「点が上がる」「落ちる」の向きだけを出す。向きは予想タイムの答えには関係しないよう、問いは点数の大きさを聞く形にする（上の直し案）。最初の数字は、46人でなく「優しい」が6番目（16%）に置き換える手もある。
- **ミクロ** → 「誰に優しいか」の1研究だけで終わらせない → 同じ場面で、調べた結果を2〜3つ並べる。①S21「自分への優しさ／ほかの男性への優しさ」の研究（アメリカ）②S22 Bhogal 2020「全部あげる人／半分あげる人」③新たに調べる必要がある日本の数字：どちらから告白して付き合い始めたか（出生動向基本調査の「交際のきっかけ」にあたる設問があるか。S8にはある。交際経験者の告白0人は男性17.1%・女性32.0%）。冒頭の主人公の行動（後輩に尽くす）と同じ向きの優しさかを、比較の1つに置く。「〜すべき」と言わない。尺は40秒でなく90秒ほどにする。
- **締め** → 締めの一文 → 「優しさは、スタートの合図ではありませんでした。ゴールまで走りきる脚でした」を、因果に聞こえない短い逆説に変える。案：「優しさは、モテるための武器ではありませんでした。選ばれたあとに、はじめて数えられる物でした。」（「数えられる」で番組の決まり文句につなぐ）。または、第3章の結論に合わせて「優しさが負けたのではありません。まだ、数えられる場所に出ていなかったのです。」。どちらも「0人の多くは優しさで負けたのではない（仮説）」「長い関係では優しさが効く（相関）」のうち、台本が言い切れる側だけを選ぶ。教訓（物差しの長さで見え方が変わる）は残す。
- **新しさ** → 第3章の「既婚の男性は結婚前の恋人も多い（52.7%対24.5%）」→ 使い方を直す。既婚者は「最初の結婚まで」、独身者は「現在まで」で期間が違い、結婚した人に恋人経験が多いのは当たり前（選ばれた結果）。「スタートの多い人がゴールにも着いている」と言い切らず、画面の補足にとどめる。代わりに「上位の約10人が約4割」を冒頭〜第1章の主役の数字にし、女性にも同じ形がある（約35%）ことを並べる。上位の約10人が「冷たい人なのか」という第1章の終わりの問いは、第2章でも日本の数字で答えていない（日本の大学生540人の相関だけ）。この問いは「分からない。恋人の数と性格を一緒に調べた日本の調査は見つからなかった」と言い切って閉じる（調べる必要がある）。
- **絵** → 第3章の「0人の山を『望んでいない』『告白していない』で色分け」→ 数の土台が変わるので、1つの山に重ねて色分けしない（003「数の土台が変わる」）。S5は18〜34歳・交際相手なし全体、S8は25〜34歳・交際経験なし・597人の小さな民間調査、S3は20代・恋人0人で、同じ46人に重ねられない。直し案：「100人のうち」の列を3回、別々に出す（①恋人0人の列、②交際相手がいない人のうち望んでいない人の列、③交際経験のない人のうち告白したことがない人の列）。各列に調査名と対象年齢を出し、「別の調査です」と声でも言う。棒人間の「足すたびに動く」に当たる動きは、この3列が次々に埋まる動き（段は3つまで）で作る。
- **参加** → 「100人の列に自分を置く」場面 → 第1章の46人の場面で、年代別（20代・30代）の列に切り替わって「自分の列」を見られるようにする。声は問いにせず、「30代の独身男性なら、この列の右はしです」と言う形。予想タイムは上の直し案に差し替える。
- **構成（章の順）** → 第2章が詰まりすぎ（ダークトライアドの定義・日本の大学生・先回り・山場・離婚・米国夫婦の6つ、数字5個）→ 声で言う研究は山場の1つに絞り、日本の大学生540人（関係が短く終わるぶん人数が増える、という仮説）は短く。離婚の申し立てか米国夫婦のどちらかは画面だけに回す。outline 自身が候補に書いている削りに従う。
- **構成（結論に近い世間の話）** → 第1章「優しさは最低条件」と第3章「告白は男性が多い」は、ニュースや婚活記事で聞く話に近い（005「へーそうなんだ」型）→ 事実の確認で終わらせず、「優しさは3つの条件のうち6番目なのに、人柄を条件にする人は98%いる」というずれ、「告白する人は男性33%・女性16%、待つ人は女性53%」を、「動く側が偏っていると、誰が損をするか」に引き寄せて語る。
- **言葉** → 「足切り」「スタートの回数」「スタートライン」は、視聴者が普段使う言葉か確かめる。「足切り」は「最低条件」「入れないと始まらない条件」のほうが耳で分かる。
- **タイトル（今回は決めない）** → 「〜は本当か」の確かめる型は伸びにくい仮説がある。逆説の一文（一夜では得、結婚では半分以下）をそのままタイトルの核にする案を、タイトル案を出すときに検討する。

## 守れている所（変えない）
- 女性を「悪い男を選ぶ」と描かない（同じ表で結婚相手の下がりを出し、男性が評価しても同じ形）。恋人のいない男性を性格で見下さない。助言しない。海外の研究は海外と断る。反対の証拠（Carter 2014・Arnocky 2017）を出す。ここは両方の相手より誠実で、強みになる。
- 反対の証拠のうち Carter 2014 は、冷たい男の魅力が d = 0.94 と大きい（文章を読んだ評定）。画面に出すだけでなく、「一夜の差はわずか」と言うときに、この結果もあると断る（盛りすぎ・切り取りに見えないため）。
