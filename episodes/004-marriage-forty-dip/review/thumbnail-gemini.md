# 4本目 サムネイル レビュー（Gemini人形版。2026-10-10）

対象：`render/out/004-thumb.png`、`scenes/Thumb.tsx`。決定済みで動かさないもの（言葉・タイトル・白い人形の様式・夫も妻も悪く見せない）は触らない。
注意：スマホ見本（`thumb_sheet.py` の下の段）は見ていない。以下は原寸の画像とコードからの判断。競合との比べ（手順2）は見本で確かめること。

## 点数：6.5 / 10（あと一歩で7）

ひとこと：文字は強く、白い人形は暗い地でよく浮く。弱いのは「2人の関係」。夫が大きく中央寄りで、妻が端に押されて見え、「妻の不満」の主役が妻に見えない。マネキン店の陳列のように見え、気まずい空気が出ていない。

### 良い点
- 白2行・太い縁取りは0.3秒で読める。字は画面の幅の約4割、高さの約3分の1。
- 白い人形と暗い紺〜赤紫の地は明暗がはっきり。夫の青いふち、妻の橙のふちで2人が分かれ、どちらも悪く見えない。
- 妻の斜め向き・肘を抱える姿勢は、泣かず怒らず静かで、方針（おとしめない）に合う。

### 弱い点
1. 主役が夫。夫は高さ760で全身の約3割の面積を占め、胸元の白い無地が広い。妻は720で後ろ（z=1）、右端で縦にも切れ、顔が小さい。「妻の不満」なのに、妻の表情の手がかり（髪・顔の向き）が弱い。
2. 2人の間が狭い。夫の右端は約990px、妻の左端は約1018px。隙間は30px弱で、肩が触れそうに見え、「離れて外を見る」が伝わらない。かといって離れすぎると関係が切れて見える。ほどよい余白（60〜80px）が要る。
3. 妻の視線が画面の外（右端）へ抜ける。外を見る設定は良いが、目が画面の外に逃げる。右端に光（窓・街の灯）があれば、視線の行き先になる。
4. 地が全体に暗く平ら。左下は暗い紫の面だけで、ぼけの光が文字の後ろにあって字の縁取りと混ざる。
5. 夫のふち（青 rgba(130,170,255,.7)）が白い服に対して薄く、2人の光の強さが釣り合っていない（妻の橙のほうが目立つ）。

## 直し案（効く順）

1. **妻を主役に、2人の間を70px前後に**（面積・間）
   - 夫：`cx={835}`→`815`、`top={70}`→`95`、`h={760}`→`700`
   - 妻：`cx={1135}`→`1140`、`top={95}`→`55`、`h={720}`→`780`、`z`は妻1・夫2のまま
   - 結果：夫は約668〜962px、妻は約1021〜1259px、間は約60px。妻の頭が夫より上になり、「妻」に目が行く。夫は小さくなっても正面・背すじ・白い面で十分に読める。字との間は夫の左端668pxと字の右端約595pxで約70px、重ならない。
   - 妻の右の余白は約20px。切れそうなら `cx` を1135に。
2. **右端に光を寄せ、妻の視線の行き先にする**（背景）
   - `Bokeh` の `x0={900}` の2つ目を足す（`<Bokeh seed={9} x0={930} x1={1280} y0={40} y1={420} n={5} blur={…を現状の0.7倍} colors={["#FFE08A","#FFB347"]} />`）。窓の外の灯に見える。
   - 左の既存 Bokeh は `x1={700}` までにして、字の後ろの明るい丸を減らす（`x0`〜`x1` 指定がない場合は左側に作らないよう範囲を絞る）。
3. **夫のふちを強くして光をそろえる**（光のふち）
   - 夫の `rim`：`rgba(130,170,255,.7)`→`rgba(150,185,255,.95)`。妻の `rim`：`rgba(255,170,120,.7)`→`rgba(255,175,125,.8)`。2人の明るさを同じにする。
4. **地を少し明るく、字の後ろを暗く**
   - `ground={["#141A3A","#5A2846"]}`→`["#18204A","#7A3358"]`（下の赤紫を明るく。人形の足元が沈まない）。
   - `Vignette` に `strength={0.65}`（左の字の周りを暗くして縁取りを締める。人形の縁は光で残る）。
5. **字は少しだけ上げて締める**
   - `WORD` 112→118（字の右端は約620pxで、夫の左端と間は約50px。直し1とセット。単独では上げない）。`top` 220→205（2行の中心を画面の中心360に近づける）。2行は同じ大きさのまま（決定済み）。
