## 2. 直し案（効く順、3つまで）

Bは7点なので「直さなくても出せる」。以下は8点に近づける順。Aを使うなら1・3も入れる。

### 直し1：「うん。」を大きくし、糸から離す（いちばん効く。コードだけで直せる）

- いまの「うん。」は80px。糸（右の外側の線。(940,360)→(1140,680)）が「う」の左を横切り、字と線がぶつかっている。168pxでは約10pxで、ただの黒い点。
- **110px**、x=1070 から右へ（右端は 1250 以内）、y=380〜470。糸の外側に出す。妻の頭（x≈985,y≈400）から約90px離れるが、視線を右へ導く形になる。白に黒6pxの縁は残す。明朝体900のまま。
- ただし文字のかたまりが3つになるので、ほかの文字は足さない。
- **なぜ**：本編の「聞いてもらえていない」を匂わせる唯一の手がかり。360pxでは読めるが、168pxでは読めなくてもよい。糸と重なると、読めるはずの360pxでも汚く見える。

### 直し2：人を足元から切って、さらに約15%大きくする

- いまは文字（y=0〜280）と梁（y=360）の間に約80pxの空き、梁の下の皿の外側にも空きがある。
- 人を高さ310 → **360px**（頭の上端 y≈335。梁 y=360 より上に頭が出るので、梁を y=330 に上げて頭と糸が重ならないようにする）。文字2行の底は y≈280 なので、梁 y=330 まで50px取れる。足元 y=690 のまま。
- 夫 x=300、妻 x=980 は変えない。2人の高さは同じ。
- **なぜ**：168pxでは約40pxから約46pxになるだけだが、人が画面の半分を占めると「顔のない人が2人立っている」という塊として見える。文字と人の間を詰めると、上下が一体になる。

### 直し3：Aの文字の黄色を「増える」に動かす（A専用）

- 1行目「妻の不満が」は白 120px。2行目「**増える**」を黄 #FFE36A 150px、「時期」は白 110px。
- **なぜ**：Bのように、黄色を肝の1点に絞る。「増える」が肝（本編：不満の妻は15人に1人→4人に1人）。いまは1行目全部が黄色で、肝が分からない。

## 3. 人形の指示で気をつけること

画像生成AIは「手」「首」「関節」「立ち位置のずれ」を崩しやすい。次を指示文に入れる。

1. **同じ条件で2枚を別々に作る**：同じ服（なし）・同じ素材・同じ照明（左上から）・同じ高さ・同じ頭の大きさ。のっぺりした白いマネキン（関節のある木製人形ではなく、つるっとした白い樹脂）。顔・髪・服・靴・文字は描かない。**髪型やスカートで性別を示さない**（性別全体の決めつけに寄る。肩幅・腰の線・体の厚みだけで分ける）。
2. **全身・足元まで・正面または3/4・カメラの高さは胸の高さ**。足は皿の上に立つので、足裏が見えること。体が画面端で切れないこと。透明PNG、高さ1500px以上で作って縮小する。
3. **夫**：正面、背すじを伸ばす、腕は体の横に下ろす。頭は上げる。首は切れていないこと（いまの仮の絵は頭と体が離れている）。うつむかせない・腕を組ませない（責めない）。
4. **妻**：体は斜め後ろ（3/4）、頭は外側（右）へ向ける、**片手でもう一方の肘を抱える（手の指は見えなくてよい。指が崩れるので、腕を組む形に近づけて「手を隠す」と指示する）**。肩は落とさず、うつむかせない（かわいそうに見せない）。窓の外を見ている様子。
5. **白の明るさ**：どちらも純白に近い（#F5F5F5）で、影は足元だけ。青や赤の地に溶けないよう、体の縁に細い明るい線（リムライト）を入れる。168pxで人が読めるのは、この縁と白さだけ。
6. **姿勢が168pxで読める誇張**：妻の頭の向きは、体の向きより強く外へ（約60度）。夫と妻の体の向きの差を、シルエットで見て分かる大きさにする。感情の誇張はしない（泣く・怒るは入れない）。
7. 差し替えたら、`Thumb.tsx` の人の位置（夫 x=300、妻 x=980、足元 y=690）に合わせ、糸と重ならないこと、「うん。」と重ならないことを `npm run check` で確かめる。

## 4. タイトルとの組み合わせ（タイトル2を「末っ子が小学生になるころ、夫婦の満足度にずれが出はじめる」に替える）

- **B + 新タイトル2：推奨のまま。** B は「なのに（逆説）」、タイトルは「いつ・誰の話か」。言葉は重ならない。数字は「2分」の1つ。
- 注意が1つ：サムネイルの「差」とタイトルの「ずれ」は近い言葉。Bの「差」は時間の差、「ずれ」は満足度のずれなので、意味は違うが、一緒に見ると「差」「ずれ」「冷める」が同じことを3回言う感じになる。**避けるなら、タイトルを「夫婦の満足度に開きが出はじめる」ではなく「夫婦の満足度の動きが分かれはじめる」**（「分かれる」は離婚に読まれるおそれがあるので、これは避けたい）。決めるのはオーナー。いまの「ずれ」のままでも、7点の判定は変わらない。
- A + 新タイトル2：「時期」と「ころ」が重なる。Aを出すなら、タイトルは「末っ子が小学生になると、夫婦の満足度にずれが出はじめる」のように「ころ」を避ける。
- **40代**がタイトルにもサムネイルにもない点は1回目のとおり。概要欄の1行目に入れる。
