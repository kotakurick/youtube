## 1. 点数

|---|---:|---|
| A「妻が冷める／時期がある」 | **5** | 色で目は止まるが、言い切りが本編より強く、世間でもう言われている話に聞こえる。絵が言っていることと文字が合わない |
| B「差は2分／なのに冷める」 | **6** | 「天秤の絵＝差は2分」が一瞬で通じ、「なのに」で引ける。主語がないので本編とも合う。あと一歩は人の絵。直せば7.5まで行く |

7点に届かない共通の理由は3つ。

1. **絵が「平らな図」のまま**。天秤と白い人が小さく、168pxでは人は高さ約30pxの白い点になる。オーナーが「全然響かない」と言った型（平らな図）に近い。好きだと言ったのは「感情の見える1つの情景＋心の声」。
2. **2人の姿勢が感情を言っていない**。夫はうつむいて腕を組み、妻は額に手。どちらも「悩んでいる」に見え、「冷めた」にも「聞いてもらえていない」にも見えない。夫がスマホ（仮の姿勢）なのも、本編の主役（悩みを聞いてもらえているか）とずれる。
3. **対立の色が定番**。黒い地の中では明るい青赤で浮くが、「赤と青の人型」はこの話題の定番（4/7枚）。浮くのは色の明るさだけで、形（天秤）は新しい。形を強く見せたい。

## 2. 直し案（効く順、5つまで）

### 直し1：人形を大きくし、姿勢で「聞いてもらえていない」を見せる（A・B共通。いちばん効く）

- **大きさ**：人形は高さ320px（画面の44%。いまは約230px）、幅は約120px。2人とも同じ高さ・同じ白（`rgba(255,255,255,.95)`）。顔のない3Dのマネキンで、影は足元だけ。2人の高さを変えない（片方を小さく見せない）。
- **位置**：夫の中心 x=300、妻の中心 x=980、足元 y=650（皿の上）。頭の上端は y≈330。
- **姿勢（人形の画像を作る指示に入れる）**
  - 夫：正面向き、背すじを伸ばして、腕は体の横に自然に下ろす。顔（のない頭）は上がっている。「うちはうまくいっている」と思っている様子。落ち込ませない（責めない）。
  - 妻：体は斜め後ろ向き（3/4）、頭は画面の外（夫と反対の外側）を向く。片手でもう一方の肘を抱える。「うん」とだけ答えて窓の外を見ている様子（冒頭の物語の助手席）。うつむかせすぎない（かわいそうに見せない）。
  - 2人を別々に生成し、同じ照明・同じ色味・透過PNGにする。体型は特定の人に見えないよう細身すぎず、男女は肩幅と腰の線だけで分ける。
- **なぜ**：「同じ重さで皿にのっているのに、向きだけが違う」が一目で伝わり、本編の発見（家事の割合ではなく、悩みを聞いてもらえているか）を答えずに匂わせる。168pxでも、体の向きの違いは30pxの白い点より読める。

### 直し2：天秤を人に譲る（直し1とセット）

- 糸の三角（頂点が梁の中央）は頭と重なるので、**糸は皿の外側2本だけにして台形**にする（梁の端から皿の端 x±170 へ。いまの三角は頂点で幅0）。
- 梁の高さを y=352 → **y=300**、梁の太さ 14 → **22px**、糸 4px → **8px**、柱 18 → **26px**。皿は幅360px。168pxで線が消えるのを防ぐ。
- 文字を 132px → **120px**、上の余白14px（2行の底が y≈265）に詰めて、梁の上に空きを作る。
- **なぜ**：天秤は水平であることが肝（差2分）。水平を強い線で見せ、人を大きくする。梁を傾けない（傾けると「妻が損」の嘘になる）。

### 直し3（B）：数字と「なのに」で文字に強弱をつける

- 1行目「差は**2分**」：「差は」白 120px、「2分」**黄 #FFE36A・170px**（画面でいちばん大きい）。
- 2行目「なのに」白 96px ＋「**冷める**」黄 150px（「なのに」を小さくして、直後の「冷める」に落とす。葦は「の」だけ小さくする）。
- 2行目の幅は約900px以内、左右の余白は190px以上。縁取り（白字の外側に黒 8px）は残す。
- **なぜ**：いまは2行目がまるごと黄色で、強調がどこにもない。数字（新しい情報）と「冷める」（感情）の2点に黄色を分けると、168pxでも「2分」と「冷める」だけで通じる。

### 直し4：心の声を1つ足す（3つ目のかたまり）

- 妻の人形の頭の外側（右上、x=1130〜1250、y=360付近）に、明朝体（FONT_SERIF 900）の白 **84px で「うん。」**。細い縦書きにせず、横書き。字の周りに黒 6px の縁。
- 冒頭の物語の助手席の妻（窓の外を見たまま「うん」とだけ答える）と同じ言葉。オーナーが好んだ型（情景＋心の声）に当たる。答え（悩みを聞いてもらえているか）は言わず、「聞いてもらえていない感じ」だけが残る。
- 大きな文字は3かたまりまで（「差は2分」「なのに冷める」「うん。」）。ほかの文字は足さない。168pxでは「うん。」は約19pxで読めなくてもよい（原寸とスマホ360pxで効く）。
- **なぜ**：平らな図に、1つだけ感情の手がかりを置く。

### 直し5（A）：Aを残すなら、主語と動詞を本編に合わせる

- 「妻が冷める／時期がある」→「**冷めはじめる／時期がある**」（主語なし）か「**妻の不満が／増える時期**」（本編の数字：不満の妻は30歳前後で15人に1人 → 40代半ばで4人に1人近く、に合う）。後者は妻だけだが、測った量（不満の割合）に合う。
- 「妻が冷める」は「妻は夫に冷める」の定説（世間でもう言われている型）に聞こえるので、**数字の新しさがあるBのほうが強い**。Aは、Bに負ける前提でテスト用の2枚目に回す。

## 3. 次の版で確かめること

1. 競合（黒地・白い2行・赤青の人型）を、関連動画の大きさ（168px）で左右に並べ、色で浮くか・形が似ていないかを目で見る。
2. 白黒（彩度を落とした）で見ても、人形の体の向きの違い（夫は正面・妻は斜め後ろ）が分かるか。
3. 168pxで「2分」と「冷める」が読めるか（黄の2点だけ読めればよい）。
4. 妻の人形が「かわいそう」「怒っている」に見えないか。夫が悪役に見えないか（2人が同じ大きさ・同じ白）。
5. 青赤の境目（x=640）が「2分」の2と「冷める」の間を割らないか。割るなら、境目を文字の隙間に合わせて ±30px 動かす。
6. 人形の画像を差し替えたあと、`npm run check`（28px未満の文字・はみ出し）を通す。

## 4. タイトルとの組み合わせ

「タイトルとサムネイルで別のことを言って補い合う」（葦の型、brand の方針）で、3案を見る。**サムネイルがBなら、数字（2分）をタイトルに入れない**（数字は1つまで）。

| タイトル | 言っていること | B と | A と |
|---|---|---|---|
| 1（型A）家事と仕事を足すと夫婦の差は2分。それでも妻の満足度は下がっていく | 本編の逆説を全部言う | **避ける**。「2分」が2回、「差」「冷める＝下がる」も重なる。サムネイルを見る意味がなくなる | **避ける**。「妻が冷める＝妻の満足度は下がる」で同じ主張 |
| 2（型C）末っ子が小学生になると、夫婦の満足度は分かれはじめる | いつ・誰が（子育て中の夫婦） | **◎ 推奨**。B は「何が不思議か」（2分なのに）、タイトルは「いつ・誰の話か」。重ならず補い合う。「差」と「分かれる」は別の意味なので「ずれ」に直す（下） | ○。A の「時期」とタイトルの「小学生になると」が、答えを言い切らず補い合う。ただし「妻」がタイトルから消えて A の主語だけが残る |
| 3（型A）夫婦の時間はつり合っていた。妻の満足度を分けていたのは家事ではなかった | 時間が同じ＝天秤と、「家事ではない」（答えの半分） | 避ける。「つり合っていた」と B の「差は2分」は同じ（天秤）。「家事ではなかった」は答えを割る | △。重なりは少ないが、答えの半分を先に言い、本編の発見の価値を下げる |

**推奨：B ＋ タイトル2。** 理由：（1）サムネイルは逆説と絵、タイトルは時期と対象、で言葉が重ならない。（2）自分に当てはめられる（子育て中の夫婦）という型Cは、CLAUDE.md の「自分に当てはめられるもの」に合う。（3）数字は「2分」の1つだけで、brand の「数字は1つまで」を守れる。

### タイトル2の言い回しの直し案

- 「分かれはじめる」は、夫婦が別れる（離婚）にも読める。「満足度は分かれる」も何が分かれるのか不明。
- 案 a：**末っ子が小学生になるころ、夫婦の満足度にずれが出はじめる**（27字。「ずれ」はサムネイルの「差は2分」の差と言葉が重ならず、「なのに」を受ける）。
- 案 b：**末っ子が小学生になると、夫婦の満足度が離れていく**（25字。「離れる」が離婚に読まれるおそれがあるので a を推す）。
- 「だけ」は使わない（オーナー）。「妻だけが下がる」と書くと、本編（夫の平均も下がる）とも合わない。
- 検索・関連動画の語（夫婦・満足度）は入っている。**40代**がタイトルにもサムネイルにもない。企画カードは「40代」が中心なので、概要欄の1行目に入れる。タイトルに入れるなら案 a の「夫婦」の前に「40代の」を足す（30字）。
- タイトル1・3は、サムネイルが別のことを言うまでは出さない（上の表）。使うなら、2の言い回しが長すぎると言われたときの控え。

## 5. 「妻が冷める」「なのに冷める」は誇張・決めつけに読まれないか

結論：**Bの「なのに冷める」は大丈夫。Aの「妻が冷める」は直す。**

| 観点 | A「妻が冷める」 | B「なのに冷める」 |
|---|---|---|
| 性別全体の決めつけ | 「妻」と全称で言い切る。40代の妻の4人に3人は満足なので、「妻はそういうもの」に読まれる。性別全体をおとしめる決まりに近づく | 主語がなく、青（夫）と赤（妻）が同じ高さに立つので、2人の話に見える |
| 誇張 | 「冷める」は愛情が冷めたに読める。測ったのは満足度で、下がっても多くは満足のまま。しかも夫の平均も下がる | 同じ「冷める」はある。ただし2人の絵なので、本編の「2人とも下がる」に合う |
| 本編との合い | 本編の通説「2人いっしょに冷めていく」は半分当たっていて、「妻だけ」と言い切るサムネイルは、本編の判定とずれる | ずれない |
| 助言になっていないか | なっていない | なっていない |

直す点：

1. **主語を出さない**（B）か、出すなら測った量にする（直し5の「妻の不満が増える時期」。不満の妻は4人に1人近く、は数字の範囲内）。
2. **人形で夫を悪者にしない**。直し1の姿勢は、夫を「うまくいっていると思っている」、妻を「窓の外を見ている」にして、どちらも責めない。2人は同じ大きさ・同じ白（`Thumb.tsx` の方針どおり）。
3. 青赤の塗り分けは「男女の対立の絵」に見えるが、2人が同じ重さで水平の天秤にのる絵なので、対立の勝ち負けは出ない。傾けない。
4. 本編の中で、「冷める」は満足度の言い換え、満足の多くは変わらない、夫も下がる、を言う（すでに冒頭に「40代の妻でも、多くは満足と答えています」がある）。
5. サムネイルに数字（4人に3人が満足）は入れない（数字は1つまで）。誇張の補いは本編と概要欄に任せる。
