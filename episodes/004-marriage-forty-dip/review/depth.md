# 深さ（review-depth）

2026-10-06。台本 第1稿（`script.md`）へのレビュー。視聴者は20〜40代の男性。
根拠は `outline.md`・`sources.csv`（S1〜S21）・`research-micro.md`・`review/rival-outline.md`。下の「予想」は、台本を読む前にテーマ（「40代から、妻だけが冷めていく」）とタイトル案だけを見て書いた。

## 見る人が最初から予想していること

1. 結婚は時間がたてば冷める。新婚のころの気持ちは続かない（ハネムーンの終わり）。
2. 夫婦がいちばん危ないのは、子どもが小さいころ。夜泣きやおむつの時期、いわゆる産後クライシス。
3. 妻の不満の原因は、夫が家事・育児をしないこと（ニュースで聞く「妻の家事時間は夫の何倍」）。
4. 男性の側の言い分：「こっちは外で長く働いている」。妻は、それを分かっていない。
5. 子どもが巣立つと夫婦の関係が試される。熟年離婚、定年後の夫はじゃま者。

1〜4は台本の中で扱われている。5は扱われていない（後で書く提案2）。

## 章ごとの発見と強さ

| 章 | 発見 | 強さ | 理由 |
|---|---|---|---|
| 冒頭 | 満足していない妻は、30歳前後の16人に1人から40代半ばの4人に1人近くまで増える。同じ年ごろの夫は8人に1人（S7c） | 中 | 題で予想できる向きだが、「4人に3人の妻は満足」と同時に言うので、大きさがちょうどよく伝わる。物差しの置き方がうまい |
| 第1章 | 夫と妻の2本の線は30歳前後で重なっていて、30代後半から妻の線だけが下がる（S7c・S14） | 弱〜中 | 題のとおりの確認。2つの調査で同じ形が出たので、裏付けは強い |
| 第1章 | 暮らし全体の満足では、妻だけが大きく沈むことはない。分かれるのは「夫婦の関係」という1つの項目だけ（S6） | 中〜強 | 「40代の女性は全体に不幸になる（中年の危機）」という読み方を消している。ただし S6 はウェブのモニター調査で、聞き方も S7c と違う。声で「分かれない」と言い切るなら、その弱さを画面の隅に出したい |
| 第1章 | 不満な夫婦は別れて数から抜ける。上の年代ほど良く見えやすいのに、それでも妻の線は8割前後（S1 p.27） | 中 | 数え方の発見として正しい。ただ、日本で離婚によって抜ける夫婦がどれくらいいるかは出していないので、「どれくらい良く見えているか」までは分からない |
| 第1章 | くじ：夫は満足、妻は満足でない家は、100組のうち少なくとも10組、多くて23組（S7c から計算） | 中 | この動画にしかない数字で、分からないことを幅として見せる良い装置。ただし締めの「夫の札をいくら見ても、妻の札は当てられません」は言い過ぎ。幅の下限（10組）は、夫婦の満足が強く結びついている場合。組で聞いていないので結びつきの強さが分からない、が正しい。「当てられない」と「この調査からは分からない」は別のことで、ここが第3章の「家事の分数でも当てられない」と教訓にもつながっている（提案3） |
| 第2章 | 満足と答える妻がいちばん少ないのは、末っ子が0〜5歳のころではなく6〜17歳のころ（S14。2018年の S15 でも同じ） | **強** | 予想2（産後クライシス）をくつがえす。2回の調査で同じ形。ただし「なぜ学校に通う時期なのか」の仕組みは台本の中にない。発見が「いつ」で止まっている（提案2） |
| 第2章 | 割合で見ると妻だけが下がる。点数の平均で見ると夫も妻も結婚20年台が底で、男女の差ははっきりしない（S7c と S7） | 中〜強 | 数え方で景色が変わる、良い発見。ただし「夫は満足の側にとどまり、妻は境目を越える」という読みは、台本も認めているとおり確かめていない。海外の大きなメタ分析で同じ構図が確かめられている（提案1）。これを足すと「強」にできる |
| 第2章 | 同じ夫婦を追った海外の研究でも、満足は下がり続ける（S3） | 弱 | 予想1の確認。裏付けとして短いのは正しい |
| 第3章 | 家事の時間は夫が約40分、妻が4時間超（S9c）。夫の家事に満足な妻は、20代の4人に3人から40代の半分へ減る（S8） | 弱 | 予想3のとおり。先回りの前振りとしては必要 |
| 第3章 | 妻の家事に満足な夫は40代でも8割超。夫の家事に満足な妻は7割を切る（S7c） | 中 | 同じ家事を、夫と妻で違うように受け止めている。ここは男女どちらの側のデータも出せている |
| 第3章 | 家事と仕事を足すと、夫9時間6分・妻9時間8分で差は2分（S9c） | **強** | 予想3と4の両方を同時にくつがえす。この動画にしかない数字。ただし主役の時期（末子10〜14歳）の1行だけで、この行は差がいちばん小さい（末子6〜9歳は21分、15〜17歳は41分、0〜5歳は26分。どれも sources.csv にある）。1行だけを使うと切り取りに見える。全部の行を出すと、かえって発見が強くなる（提案2） |
| 第3章 | ほかの条件をそろえると、満足と一緒に動くのは、夫の家事の割合ではなく、相手からの心の支え（悩みを聞く・ねぎらう）。妻でも夫でも同じ（S16、1999年の S19 でも同じ） | **強** | 予想3をくつがえし、仕組みに近づいている。弱いところは2つ。①心の支えも満足も、同じ本人の答えなので、一緒に動きやすい。②心の支えをそろえたあとで家事が効かない、という意味なので、家事が心の支えを通して効いている可能性は残る（S11 の Carlson ほか 2020 はまさにこの形）。台本の「家事の割合は、満足とはっきり結びつきませんでした」は、言い方として少し強い |
| 第3章 | 「配偶者は悩みを聞いてくれる」と答える妻は、ほぼ全員から7割ほどまで下がる。夫は9割前後のまま。満足の2本の線と同じ形（S17。S8b でも同じ向き） | 中〜強 | 第1章の線と形が重なるのは絵で分かる発見。ただし「なぜ妻の側だけが、聞いてもらえていないと感じるようになるのか」の一段が抜けている（提案4） |
| 第3章 | 子育て期の夫は、家事をよくする夫ほど本人の満足も高いが、ほかをそろえると消える（S18） | 弱 | 夫の側のデータとして出す意味はある。発見としては小さい |
| 答え合わせ | 判定は三角。冷めるのは2人とも。境目を越えるのは子育ての真ん中にいる妻 | 中 | 条件（子育ての真ん中）を一言で言えている |

まとめ：強い発見は3つ（谷は学齢期・時間の天秤は2分差・一緒に動くのは家事ではなく心の支え）。どれも日本の一次資料が裏付けている。弱いのは「なぜ」の段。なぜ学齢期なのか、なぜ妻の側だけ「聞いてもらえない」が増えるのか、が台本にない。発見が「いつ・何と」で止まっていて、「どういう仕組みで」まで届いていない。

## 持ち帰れる見方

- 教訓の「数えやすいもの（家事の分数・働いた時間・年収）が、満足と一緒に動いているとは限らない」は、**このテーマの外でも使えるものの見方になっている**。成績・KPI・健康診断の数値にもそのまま当てはまる（測れるものだけで判断してしまう落とし穴）。第2章の言い直しでは終わっていない。合格。
- 弱い点が2つある。
  1. 第2章の「割合で見るか、平均で見るか」も、持ち帰れる見方の候補だった。それが教訓に入っておらず、章の中で消えている。提案1のメタ分析を足すと、「差は平均ではなく端（不満の側）に出る」という2つ目の見方として立つ。ただ、教訓は1つに絞ったほうが締まるので、第2章の山として立てておくだけでもよい。
  2. 「時計では測れないもの」は、実際には調査の答え（本人がどう受け止めているか）で測っている。「量っていなかったもの」は「天秤にのせていなかったもの」と同じ意味なので問題ない。ただ、「測れない」と言い切ると、第3章で S17 を数字として見せたことと食い違う。「時計では」と限っているので、いまの言い方でぎりぎり成り立っている。直すときは、この限定を外さないようにしたい。

## 深めるための提案（効果の大きい順、最大5件）

- **1. 第2章「割合と平均で景色が変わる」→ 海外のメタ分析を1文足す（平均の男女差は一般の夫婦ではほぼない／差が出るのは夫婦カウンセリングに来た、不満の大きい夫婦）→ 「差は平均ではなく端に出る」が、日本の2つの数え方からの読みではなく、10万人規模で確かめられた形になる。第2章の山が「読み方」から「発見」に上がり、教訓の土台にもなる**
  - 調べ先：Jackson, Miller, Oka, Henry (2014) "Gender Differences in Marital Satisfaction: A Meta-analysis", Journal of Marriage and Family 76: 105–129。要旨は確認した：226標本・101,110人。全体では妻がわずかに低い。その差は夫婦カウンセリングを受けている標本のせいで、受けている妻は夫より満足している割合が51%低い。地域の一般の標本では有意な男女差はない。https://scholarsarchive.byu.edu/facpub/2556 （一次資料の要旨。本文は未読）
  - 手元の材料でもできる：S16（永瀬 2021）表1の満足の分布（女性：かなり不満4.3%、男性1.8%。かなり満足は女性26.7%、男性43.7%）。不満の端では女性が2倍以上になっている。画面で「平均」と「不満の側の割合」を並べられる（`research-micro.md` 1-1。照合★はまだ）。
  - 注意：メタ分析は欧米が中心。「日本でも同じ」とは言わず、「海外の大きな分析でも同じ形」まで。

- **2. 第2章と第3章「なぜ学齢期か」と天秤 → 末子の年齢の行をすべて出す（S9c の0〜5歳26分・6〜9歳21分・10〜14歳2分・15〜17歳41分）。満足（S14：0〜5歳は8割台、6〜17歳は7割台）と並べる → 「時間の差がいちばん小さい時期に、満足がいちばん低い」。時間の偏りでは谷を説明できないことが、1行だけを選ばずに示せる。切り取りの疑いも消える。そのうえで、学齢期に何が変わるかとして、妻の働き方を足す**
  - 調べ先（手元、一次資料）：S14 の集計表 表131-2 には、妻の従業上の地位別の満足も入っている（`research-micro.md` 2-1 の注）。正社員・パート・無業で満足がどう違うかを、人数から計算できる。https://www.ipss.go.jp/ps-katei/j/NSFJ7/Mhoukoku/nfs07_c_mar_table_m.xlsx
  - 調べ先（一次資料、数字は未確認）：厚生労働省「2023年 国民生活基礎調査の概況」の、末子の年齢階級別にみた母の仕事の状況（正規・非正規・仕事なし）。末子が学校に上がると母の仕事あり（主に非正規）が増える形かどうかを確かめる。https://www.mhlw.go.jp/toukei/saikin/hw/k-tyosa/k-tyosa23/dl/10.pdf
  - 予想5（巣立ち）への答えも同じ表にある：S14 では「子どもと別居」の妻は80.1%、「18歳以上の子と同居」は72.0%（`research-micro.md` 2-1）。年齢の違う人を同じ年に調べたデータなので「巣立てば戻る」とは言えない。言えるのは「子どもが家を出た妻たちでは8割」まで。短い補足として置けば、予想5を放っておかずにすむ。
  - 注意：時期ごとの時間と満足は、別の調査を並べたもの。因果ではなく「並べると合わない」までにとどめる。

- **3. 第1章のくじ（と第3章・教訓での回収）→ 実際に夫と妻を組で調べた日本のデータで、「夫は満足・妻は不満」の組がどれくらいあるかを1つ足す → くじの幅（10〜23組）のどこに本当の値があるかが分かる。「当てられない」が言い過ぎかどうかも、データで決められる**
  - 調べ先（一次資料・未確認の方向性）：伊藤裕子・相良順子らの中年期夫婦のペアデータ（40〜70代の夫婦、約900人。結婚コミットメント・夫婦関係満足度・離婚願望を夫婦の組で調べている）。科研費 26380900「中高年期夫婦の結婚コミットメントと心理的健康」https://nrid.nii.ac.jp/nrid/1000050296357 。紀要論文：https://www.bgu.ac.jp/library/wp-content/uploads/sites/11/2022/08/hum2012_001-015.pdf ・https://www.bgu.ac.jp/library/wp-content/uploads/sites/11/2022/08/hum2010_163-176.pdf （日本語PDFで、この環境では本文の文字を取り出せなかった。オーナーのPCで、夫と妻の満足の相関や、組み合わせの表があるかを確かめる）。
  - 見つからなければ、台本の文を「夫の札を見ても、この調査では妻の札は分かりません」にする。第3章の「家事の分数を見ても、妻の札はやはり当てられません」も同じように弱める。S16 は予測の当たり外れを測ったものではない。

- **4. 第3章「悩みを聞いてくれる」→ なぜ妻の側だけ下がり、夫の側は9割のままなのかの一段を足す → 「夫は妻に聞いてもらっているが、逆は減る」という向きの違いが見えると、教訓の「量っていなかったもの」が、何が傾いているかとして具体的になる**
  - 手元の材料（一次資料）：S17 の図8の（イ）「能力や努力を高く評価してくれる」も、妻だけが約86%から約68%へ下がる（`research-micro.md` 3-3）。ねぎらいの側でも同じ形なので、悩みを聞くかどうかだけの話ではないと言える。
  - 調べ先（未確認の方向性）：国立社会保障・人口問題研究所 第7回全国家庭動向調査の報告書（S8b と同じ PDF）の第5章に、妻が夫以外（親・きょうだい・友人）に相談する割合が年齢別に出ているかどうか。出ていれば「妻の相談先は夫から外へ移る」が言える。https://www.ipss.go.jp/ps-katei/j/NSFJ7/Mhoukoku/kateidoukou7_kekka_20240426.pdf 。夫の側の相談先は NFRJ18 第一次報告書（S7c と同じ PDF）の、サポートの章にあるかを見る。https://nfrj.org/nfrj18_pdf/reports/1_overview.pdf
  - 注意：夫婦の組ではないので、「夫が聞かなくなる」とは言わない（`research-micro.md` 3-3 の注意どおり）。

- **5. 教訓「量っていなかったもの」→ 時間の表に出ない家事として「段取りを考える・気づく・見張る」仕事（認知的な家事）を1文だけ添える → 冒頭で夫が来週の段取りを話し、妻が「うん」と聞いている場面と結びつく。天秤にのらないものが、心の支えのほかにもあると示せる**
  - 調べ先（一次資料）：Daminger, A. (2019) "The Cognitive Dimension of Household Labor", American Sociological Review 84(4): 609–633。米国の35組70人への聞き取り。必要なことを先に考える・見張る仕事は女性に多い。決める仕事はほぼ半々。https://inequality.hks.harvard.edu/publications/cognitive-dimension-household-labor
  - 注意：聞き取りの研究で人数も少なく、米国の話。日本の数字は未確認の方向性（民間の「名もなき家事」の調査はあるが、一次資料として確かめていない）。入れるなら裏付けとして1文までにする。満足と一緒に動くという主張には使わない。テーマの芯（心の支え）がぼやけるなら入れなくてよい。
