## 中心の3か所で、一度で分かり、納得できるか

- **第2章「なぜ学校の時期のほうが低いのか」（102–117行）→ 納得できる。** 「合計は減る → 変わるのは中身 → 一緒にやっていた育児が減り、一人でやる家事が増える → 夫の育児への満足も同じ時期に下がる」が一本の線で聞こえる。答え合わせの215行とも合う。残りは言い回しだけ（下の3・4）。
- **第3章「なぜ家事の量より心の支えなのか」（175–185行）→ 一度で分かる。ほぼ納得できる。** 「期待どおりか」「話を聞いてほしいときに助言」で絵が浮かぶ。184行で家事と心の支えが同じものさしにまとまるので、問いへの答えとして聞こえる。直さなくてよい。
- **答え合わせの後半（223–236行）→ ここがいちばん残っている。** アメリカの研究が「二つ目」の後ろに来て、日本の別の調査が直前の日本の数字と食い違って聞こえる（下の2）。

## 残っている所（離脱・取り違えしやすい順）

1. **〔重〕228–236行：アメリカの研究が「二つ目（心の支え）」の話に聞こえる。** 228行で「二つ目は、心の支え」と言った直後に、229行「子どもが家を出たあとについては」と一つ目（家族の時期）の話に戻る。耳だけだと、十八年の研究は心の支えの裏付けに聞こえ、「二つ目」は1文だけで流れる。
   → 直し方：並びを「224–227（一つ目）→ 229–234（アメリカの研究）→ 235–236（日本は分かれる）→ 228（二つ目）」にする。228行は「二つ目は、第3章で見た、心の支えがあると感じるかどうかでした。」と、どこで聞いた話か添える。答え合わせが「時間の長さではなかった → 心の支え」で終わり、教訓の「数えやすいもの」へそのまま入れる。

2. **〔中〕235行：「日本の別の調査では、妻の満足があまり戻らない」が、226行と食い違って聞こえる。** 226行で「子どもが家を出たあとの妻は8割ほど」（＝日本でも戻る）と聞いたばかりなので、「さっき戻ってたよね？」となる。
   → 言い換え：「日本でも、さっきのように戻る調査と、あまり戻らない調査があります。」＋236行「国や調査によって、ここは分かれます。」

3. **〔中〕106行「二人とも、一日の合計は1時間ほど短くなります。」** 何の合計かが言われない。直前が育児の話なので「育児の合計」とも取れる。
   → 言い換え：「家事と育児と仕事を足した一日の合計は、二人とも1時間ほど短くなります。」

4. **〔中〕108–109行「減った育児は、夫も4分の1ほどを受け持っていたものでした。かわりに妻の一日には、家事と仕事が入ってきます。」** 108行は「夫も」の「も」と「〜ものでした」で文が回り、耳で詰まる。109行の「入ってきます」は、それまで妻が家事も仕事もしていなかったように聞こえる。
   → 言い換え：「その育児は、夫も4分の1ほど受け持っていました。」「かわりに妻の一日では、家事と仕事の時間が増えます。」

5. **〔中〕76行「その10人の妻の夫は、どう組み合わせても、満足している夫になります。」** 「どう組み合わせても」の理由（不満の夫が全員不満の妻と組んでも余る）が声に出ないので、ここで止まる人が残る。「10人の妻の夫」も区切りで迷う。
   → 言い換え：75行のあとに「満足していない夫13人が、全員、満足していない妻と組になったとしても、妻が10人余ります。」を足し、76行は「余った10人の妻の相手は、満足している夫です。」

6. **〔軽〕38行「家事と仕事と通勤を足した」。** 答え（205行の9時間6分）は育児・買い物も入った数字。第3章145行は「家事と育児と買い物」。
   → 言い換え：「家事や育児と、仕事と通勤を足した、一日の時間を比べます。」

7. **〔軽〕68→69行の切り替え。** 「同じ形が出ています」のあと、急に「不満の大きい夫婦は、途中で別れて」が来るので、なぜその話か1文目では分からない（3文目で分かる）。
   → 69行の前に「ただ、上の年代の数字には、くせがあります。」を1文。

8. **〔軽〕115行「妻の夫婦の満足と、同じ時期に来る谷です。」** 「妻の夫婦の満足」が耳で詰まる（前回からの残り）。
   → 言い換え：「第1章で見た、妻の夫婦の関係への満足と、同じ時期に来る谷です。」
