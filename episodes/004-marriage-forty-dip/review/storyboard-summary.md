# 絵コンテ第1版の見直し：3役のまとめ（2026-10-06）

3つの役に、それぞれ別の目で第1版（53場面・約15:28）を見てもらった。くわしくは各ファイル。

- アニメーター役：`storyboard-animator.md`（時間・動き・つなぎ）
- イラストレーター役：`storyboard-illustrator.md`（比喩の絵・情景・図形の質）
- デザイナー役：`storyboard-designer.md`（視線・データの見せ方の正しさ・文字）

役どうしで割れたときは、**データの正しさ（デザイナー）→ 責めない・答えをもらさない → 動き** の順で決めた。台本の追加が要る案は採らず「オーナーに相談」へ回した（台本は第5稿・改のまま。変えていない）。

## 画面のチェック（`npm run storyboard`）

## オーナーに相談したいこと

1. **組み方のシミュレーション（アニメーター）**：20（百組）のあとに、満足していない妻と夫を「でたらめに組む」と約20組、「不満同士が全部組む」と10組、をつまみで見せる場面（約12秒）。「少なくとも十組に一組。組み方によっては五組に一組」が言い切りと「条件で変わる」の両方になり、見返される場面になる見込み。**台本に1〜2文の追加が要る**ので、入れるかどうかを決めてほしい。
2. 17（上の年代のくせ）は、数字のない「説明のための図」にした。別れた夫婦が抜けると残りの満足がどれだけ上がるかを数字で見せるなら、仮定の数字のシミュレーション（方眼の画面）になる。今のままでよいか。
