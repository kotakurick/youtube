## 直すもの

1. **L234〜236：「子どもが家を出た妻は8割ほど」→「その先には、また上り坂がある」は、数字の切り取りと、縦断の言い方**
   - 決まり：数字を誇張・切り取りしない（男女の切り口の条件）。`outline.md`「書かないこと」（「戻らない」と言い切らない、の裏返しで、「戻る」とも言い切れない）。第1稿のポリシー4（縦断に聞こえる言い方）を README で「消した」としている所に、締めで戻っている。
   - 根拠：
     - 同じ S14 の表で、**18歳以上の子と同居の妻は 72.0%** で、6〜11歳（72.8%）・12〜17歳（73.8%）より低い、いちばん低い区分。妻の年齢別も 50〜54歳 77.8%、60〜64歳 74.7% で、四十代後半（75.5%）からほとんど上がっていない。80.1%（子どもと非同居）だけを出すと「子育てが終われば上る」に見える。
     - S7c（NFRJ）は、妻の線が48〜72歳で 73.6〜78.2% の横ばい。台本自身が L79 で「四十代の半ばから上で、7割台の後半にとどまっています」と言っていて、締めの「上り坂」とぶつかる。平均点（S7）も妻 2.86 → 2.93 で、戻りは小さい。
     - L77〜78 の「不満の大きい夫婦は抜けていくかもしれない」は、子どもが家を出たあとの年代にいちばん強く効く。
     - 横断データなので「その先には」（同じ人がこの先そうなる）とは言えない。「いまの数字で見るかぎり」を付けても、文の中身は縦断のまま。
   - 直し方の例：「子どもが家を出た妻たちでは、満足は8割ほどでした。[S14] ただ、大人になった子と暮らす妻たちでは、7割ほどのままです。[S14]」まで出して、「谷の深さは、家の中の時期によって違って見えます」くらいにとどめる。救いを残すなら「同じ人を追った数字ではないので、この先も下がったままとは言えません」の形（下がったまま、とも、上る、とも言わない）。

2. **L249〜255：車の中で夫が「今日、疲れた？」と聞き、妻が顔を戻す → 「足りなかったのは、時間ではありませんでした」**
   - 決まり：性別全体をおとしめない・片方を責める流れにしない／もう一方の側のデータを出す（男女の切り口の条件）。`docs/script-style.md` 1章「助言しない」、2章「教訓も助言にしない」、11章「ミクロは教訓とは別にする」「特定の性別だけに向けた戦い方にしない」。`outline.md`「書かないこと」の「夫が悪い」「話を聞け」。
   - 根拠：
     - 言葉の上では勧めていない（「〜しましょう」「〜すべき」はない）。でも、夫が一言かける → 妻が顔を戻す → 「足りなかったのは時間ではない」の順で並ぶと、「足りなかったのは夫からの心の支えで、夫が聞けば戻る」という**処方の物語**になる。教訓の場面で、ミクロ（L186〜197）の結果を夫の行動に置き換えて見せている。
     - 動くのが夫だけ。S16 は「妻でも夫でも同じ形」（L177、L190）で、心の支えは夫から妻への一方向の話ではない。締めだけ見ると、満足の谷の責任が夫の側にあるように読める。
     - S16・S17 は「支えがあると**感じるか**」（受け止め）で、相手の行動の量ではない（sources.csv の S17 のメモ「受け止めの差で行動の量ではない」）。どちらが先かも分からない（L192〜195 で台本自身が言っている）。場面は「聞く → 満足が戻る」の向きを一つ選んで見せていて、L195「調査からは、そこまでは言えません」と食い違う。
   - 直し方の例：
     - 両方の側にする。たとえば、夫が「今日、疲れた？」と聞き、妻も「そっちこそ」と返す。あるいは同じ信号で、二人が同時に口を開きかける。
     - 結果を見せない。妻が顔を戻したあとの変化や、それで満足が戻ったという含みを置かず、締めの一文を「欠けていたもの」ではなく見方の一般化に寄せる（例：「天秤は、つり合っていました。天秤にのらないものが、二本の線を分けていました。」）。「足りなかった」は、どちらかに足りないものがある、という言い方で、残すなら主語を二人にする。

3. **L238〜239：「もう余っている時間はほとんどありません」「時間を足さなくても数えられるもの」**
   - 決まり：数字を誇張しない。`docs/script-style.md` 1章「助言しない」・11章「書かないこと」（相関を因果のように言わない）。
   - 根拠：
     - S9c は家事と仕事の合計（週全体の平均で一日9時間ほど）で、自由な時間は数えていない。「余っている時間はほとんどない」はデータにない。
     - S16 は「支えがあると感じるか」の点数で、支えに時間がかかるかどうかは測っていない。悩みを聞くには時間がかかる、とも読める（sources.csv の S13 は、会話時間が長い夫婦ほど円満と答える）。
     - 「時間がない → でも時間を足さなくてもできる」の流れは、「時間のせいにはできない、だからやればいい」という柔らかい勧めに聞こえる。2の場面の直前に置かれているので、とくにそう聞こえる。
   - 直し方の例：L238 を消すか「天秤の上の時間は、二人ともほぼ使い切っていました」（S9c の範囲）に。L239 は「時計では測れないもの」「時間の量とは別に数えられていたもの」（L191 の言い方）に。

## 確かめたいもの

4. **L1 の題「妻の『満足』だけが下がったまま」**
   - 決まり：数字を誇張・切り取りしない。
   - 根拠：第1稿のポリシー8の「だけ」は残っている（L136「冷めていくのは、二人とも」と食い違う）。第3稿では「下がったまま」が足されて、締めの L236「また上り坂がある」ともぶつかる（1を直してもぶつかる）。タイトルはオーナーが決めるので、そのときに見てほしい。

5. **L21・L92・L230・L247〜248：夫が「気づいていない側」に描かれる回数**
   - 決まり：性別全体をおとしめない（見下さない）。`outline.md`「書かないこと」の「夫は鈍い」。
   - 根拠：第1稿のポリシー6の「楽になったと感じているのは彼のほう」は消えていて、よくなった。ただ、冒頭（段取りだけ話す夫・窓の外を見る妻、「うちはうまくいっている、と思っています」）、L92、教訓の L229〜230（「段取りを話し終えました。妻はまだ、窓の外を見ています」）、L248（「うん」の長さ）と、夫が妻の様子に気づかない場面が続き、2の締めで夫が動いて解決する。1つずつは強くないが、合わせると「夫が鈍かった話」に聞こえうる。視聴者の中心が20〜40代の男性なので、README の「オーナーに確かめたいこと」2 と合わせて見てほしい。2を両方の側に直せば、ここもかなり軽くなる。

6. **L68〜69：「男性なら、夫の線の上で自分の年齢のところを…妻の線との間のすき間を考えてみてください」**
   - 決まり：もう一方の側のデータを出す（片方だけに向けない）。`docs/script-style.md` 11章「特定の性別だけに向けない」。
   - 根拠：考えてもらう問いなので助言ではない。ただ男性だけに「自分の妻とのすき間」を考えさせていて、女性の視聴者向けの問いがない。横断の線なので「自分の家にすき間がある」とも言えない。
   - 案：「女性なら、妻の線で自分の年齢のところを」も1文足すか、「自分の年齢のところで、二本の線の間にどれだけすき間があるかを見てください」と性別をはずす。

7. **L183（と L67）：夫の線を「9割前後」**
   - 決まり：数字を誇張しない。
   - 根拠：S17 の夫は 83〜91%（43〜47歳 約86%）。L182 の妻は「7割ほど」（約72%）と丸めていて、夫の側だけ上に丸めると、妻との差が少し大きく聞こえる。L67 の S7c（夫 84.5〜95.0%）は「9割前後で小さく上下」でほぼ許せる範囲。
   - 案：L183「夫の線は、8割台の後半から9割ほどで、ほぼ平らです」。

## 問題なかったもの

- **第1稿の指摘への対応**：ポリシー1（くじ→並べ方、「当てられない」を消した。L82〜92）、2（S8b を声から外した）、3（ほかの時期の差も出した。L217〜219）、5（「7割台の後半」。L79）、7（S16「結婚している人」L171、S19「妻を調べた…同じ向き」L178）、9（冒頭を土曜の夕方の車に）は直っている。

- **ミクロ（L186〜197）**：(a) 勧めていない。(b) 仮定の世界ではなく調査の比較で、相関でどちらが先か分からない、家事が心の支えを通して効く可能性も残る、とはっきり言っている。(c) 「妻にも夫にも」（L190）。(d) 結婚の回で、健康・お金の回ではない。問題は締め（2）でこれを夫の行動に置き換えたところだけ。
- **もう一方の側のデータ**：夫の満足の線（L67）、平均点では夫も下がる（L119〜120）、海外のメタ分析（L129〜132）、夫から見た妻の家事（L157〜160）、仕事と通勤の時間（L164〜167、L212〜221）、S16 の男性の結果（L177）、「悩みを聞いてくれる」の夫の線（L183）。L220〜221「どちらかが楽をしている、という数字ではありませんでした」も両方を立てている。

- **反対の結果・限界**：別れた夫婦が抜ける偏り（L76〜79）、横断データの断り（L80）、数え方で景色が変わる（L117〜128）、夫婦の組ではない（L84〜85）。
