## 考えすぎる葦が作るなら

- タイトル：「なぜ妻の幸せだけが40代で戻らないのか【結婚×心理学】」。題に「？」は付けない。
- 最初の30秒：物差しを先に渡す。「幸福は中年で底を打って戻る（U字）」「子どもが巣立てば夫婦の満足は戻る」を見せてから、「戻るのは夫の線だけだった」。数字は海外の研究が中心で、1分に10個近い。
- 章立て：妻の側（家事・見えない仕事）→ 夫の側（夫は満足している）→ 仕組みの側（長時間労働）→ 歴史の側（人生50年の結婚が100年に延びた）→ 社会の側（熟年離婚・卒婚）。3分ごろに「夫が家事をしないからだ、と思うでしょう。似た動画はそこで終わる」。
- 比喩と締め：「同じ船」。「同じ船に乗っている。ただ、漕ぐ向きが違っていた」の型で、だれも責めずに終える。弱点は、相関を因果で言い切る（「家事の偏りが妻を不幸にする」）、文字中心の画面、日本の数字は終盤に少し。

## データで語る棒人間が作るなら

- 装置：夫婦100組。夫と妻それぞれに満足のメーターがあり、結婚1年目から30年目まで1年ずつ進める。「どうなるだろうか。実行してみよう」。
- はしご（理想の世界 → 足していく原因）：0 夫と妻は同じ出来事に同じだけ反応する（2本の線は重なる）→ 1 子どもが生まれる → 2 家事と育児が妻に偏る → 3 夫の長い仕事と会話の減少 → 4 子どもが手を離れる（夫の線だけ戻る）。
- 途中の発見：「長く続いた夫婦ほど満足に見えるのは、不満な夫婦が離婚して抜けるから」（生き残り）か、「1回だけ聞く調査ではU字、同じ人を追うと下がるだけ」。限界は最後に自分から言い、締めは登録の呼びかけ。主人公・ミクロ・日本の数字はない。

| 新しさ | 勝ち | 勝ち | 日本の数字だけで組み、自分で足した差2分（S9c）、自分で計算したくじの幅（S7c）、集計表から出した末子別の割合（S14）がある。どちらの相手にもない。ただし弱点が2つある。①**2分は「いちばん差が小さい時期」**。同じ表で末子6〜9歳は差21分、15〜17歳は41分、6歳未満は26分（S9c・S9b）。タイトル案「足せば2分差」と締めの「つり合っていた」は、4つのうち1つを切り取った形になる。どの時期でも「1時間に届かない」は言えるので、正直に言っても答えは変わらない。②26行・210行の、横断データを縦断のように言う所 |
| 絵 | 勝ち | 引き分け | 構成段階の「負け」から上がった。くじの装置と、分銅をのせると天秤が水平になる場面（182〜186行・238〜243行）は、結果が目の前で動いて出る瞬間になった。はしごではなく「組み合わせの幅」と「数え直し」の装置なので、棒人間のまねには見えない。2人1組の群衆と主人公の家もある。ただし、くじの言い方が正しくない。夫と妻の札をでたらめに組み合わせる（くじ）と、「夫は満足・妻は満足でない」はほとんどいつも20組の近くに集まり、10組や23組はまず出ない。10組は「満足でない夫を、全員満足でない妻と組ませた」並べ方、23組は「満足でない妻を、全員満足な夫と組ませた」並べ方で、くじの結果ではない。このまま絵にすると、棒人間のような「実行したら出た」場面に見せかけることになる。言い方を直せば、うちの約束「誤差つきの答え」をそのまま見せる、相手にない絵になる |

**全体**：構成段階で負けていた「引き」と「絵」は、それぞれ引き分けと勝ち・引き分けまで上がった。新しさと参加では2つの相手に勝つ。ただ、いま一番危ないのは面白さではない。3か所で、数字の言い方がデータより強くなっている。クイズの答え、くじという言い方、2分の切り取りの3つ。どれも、言い過ぎで勝つという相手の弱いところに、うちが自分から寄っている。直しても面白さは落ちず、むしろ「誤差つきの答え」として相手との違いになる。

## 勝つための直し方（効果の大きい順）

- **参加（クイズの答え）→ 第2章 115〜126行 → 答えが割れない問いに変える。**
  - S14 で確かに言えるのは、「末っ子が小学生より上の時期（7割台前半）は、0〜5歳の時期（8割台）より低い」。B と C の差は言えない。
  - 案：「満足と答える妻が少ないのは、どちらの時期でしょうか。A 末っ子が0〜5歳（夜泣きとおむつ）。B 末っ子が小学生から高校生」。答えは B。そのあとで「18歳以上の子と暮らす妻でも7割台前半のまま」と続ける。横断データなので「戻らない」とは言わず、「上の時期でも高くはない」と言う。
  - 126行は「四年前の調査でも、0〜5歳より小学生以上が低い形は同じ」に絞る（S15 で成り立つのはここまで）。
  - C の名札は「18歳以上の子と同居」と正しく書く。130行「谷は〜去るものではない」は、去るかどうかが分からないので消す。

- **新しさ（差2分）→ 239〜243行の答え合わせと、タイトル案1 → 4つの時期を並べてから2分を出す。**
  - 画面に末子6歳未満・6〜9歳・10〜14歳・15〜17歳の差（26分・21分・2分・41分。S9b・S9c）を並べる。声では「どの時期でも、差は1時間に届きません。彼の家の時期では、2分でした」。予想の答え B は、どの時期でも変わらない。
  - タイトル案1「足せば2分差」は、予想タイムの答えを題でもらす（10章「答えを先にもらさない」）うえに、切り取りにも見える。題に使うなら「ほぼ同じ」まで。最終判断はオーナー。
  - 244行「家で長く働く妻」は、この行の妻は仕事（285分）のほうが家事（263分）より長いので、数字と合わない。「仕事の時間が長い夫と、家事の時間が長い妻」にする。

- **絵（くじ）→ 第1章 92〜103行 → 「くじ」を「並べ方」に言い換え、3つの並べ方を順に見せる。**
  - 1つ目「でたらめに組む」（約20組。何度配っても20組の近くに集まる様子を見せてよい。ここはシミュレーションとして正しい）。2つ目「満足でない夫と満足でない妻が、できるだけ同じ家になる並べ方」（約10組）。3つ目「満足でない妻が、全員満足な夫と組む並べ方」（23組）。
  - 「本当の並べ方は、この幅のどこか。調査からは分からない」と言い切る。これで「実行したら出た」に見せかけず、相手にない「分からなさの絵」になる。
  - 101行「少なくとも10組」は、図の読み取り（±1ポイント）と年齢ごとの約100人ずつの標本の誤差で動く（10章「推計の幅を越えて言い切らない」）。「計算では、少なくとも1割ほど」と丸めて言う。標本の誤差の幅は**調べる必要がある**（年齢ごとの男女別の人数）。
  - 102行「夫の札をいくら見ても、妻の札は当てられません」は、下限に近い並べ方なら夫の札は手がかりになる。「夫の札だけでは、妻の札は決まりません」に弱める。

- **新しさ・絵（縦断に聞こえる言い方）→ 26・67・130・210行 → 横断の言い方にそろえる。**
  - 26行「増えていきます」→「四十代では、満足していない側の妻が、夫よりずっと多くいます」。
  - 67行「十年後、二十年後の場所」は、すぐあとの断り（89行）と食い違う。「いま十年上、二十年上の人たちが、どこにいるか」にする。
  - 210行は S8b の中身どおり、「夫に悩みを相談する、と答える妻は、上の年代ほど少なくなります」にする。

- **ミクロ → 第3章 211〜224行 → 「どれだけ違うか」を感じ取れる形にし、そろえた比較であることを言う。**
  - S16 の表4から、心の支えの点が高い人と低い人で「満足と答える割合」の予測値を出せるか**調べる必要がある**（順序ロジットの切片が表にあるか）。出せれば「心の支えが〇点の人では満足△割、〇点の人では□割。家事の割合を変えても、ほとんど動かない」を妻と夫の両方で並べられる。出せないなら、いまの言い方のままにして、オッズの倍数を作らない。
  - 213行に「心の支えや収入など、ほかの条件をそろえると」を戻す。家事が心の支えを通して効く道は、この分析では切り分けられない、と一言添える（S11 の要旨が示す道。本文は未読なので、台本では出典にしない）。
  - 223行は「家事の割合からは、満足ははっきり当てられませんでした」にする（割合と分数を混ぜない）。
  - 199〜200行の S18（174人、単純な平均）は、話の流れを止めるわりに弱い。外すか、画面の補足に下げる。

- **新しさ（第1章の比べ方）→ 75〜79行 → 「夫婦の関係に絞ったときだけ二本の線が分かれる」を消すか弱める。**
  - S6（10点満点の平均、ネット調査）と S7c（満足の割合）は、測り方が違う。しかも第2章で「平均点で見ると二人とも下がる」（141〜143行）と自分で言っている。平均で比べた S6 の線が分かれないのは、測り方のせいかもしれない。第1章の「だけ」は第2章の発見とぶつかる。
  - 案：S6 は「暮らし全体では、妻だけが大きく沈む形は見えない」までにとどめる。「だけ」は言わない。

- **発見（生き残り）→ 82〜84行 → S1 の言い方に合わせる。**
  - 「不満の大きい夫婦は、途中で別れて数から抜けていきます」→「不満の大きい夫婦は、途中で別れて数から抜けているかもしれません。海外の研究も、そう注意しています」。日本の離婚でどれだけ抜けているかは**調べる必要がある**。

- **締め（対 葦）→ 264〜266行と天秤の絵 → 「量っていなかったもの」を絵の上に置く。**
  - 締めの直前、つり合った天秤の横に、第3章の「悩みを聞いてくれる」の2本の線（S17）を小さく戻す。声は変えず、絵だけで「量っていなかったもの」が何かを指す。「傾いていた」と言える根拠は横断の割合の差までなので、線に「同じ人を追ったものではない」の断りは残す。
  - 広げる（葦の強み）：第3章の終わりの S19（1990年代の研究）を「二十年以上前も、同じだった」として、時代に引く一言に使える。ただし S19 は英文要旨しか読めていないので、本文を確かめるまでは今の短さのまま。
