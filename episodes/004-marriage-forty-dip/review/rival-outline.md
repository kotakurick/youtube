# ライバル（review-rival）

2026-10-05。構成案 第1版（`outline.md`）へのレビュー。根拠は `research.md`・`sources.csv`（S1〜S13）。
相手の作り方は1本ずつの分解（`research/benchmark/teardown/`）から想像したもので、仮説として扱う。
下の「作るなら」は、うちの案を読む前に、テーマ（40代から妻の満足だけが戻らない／見る人は20〜40代の男性）だけを見て書いた。

## 考えすぎる葦が作るなら

- タイトル：「なぜ妻の幸せだけが40代で戻らないのか【結婚×心理学】」。言い切りの「なぜ型」で、題に「？」は付けない。
- 最初の30秒：物差しを先に渡す。「人生の幸福は中年で底を打ち、また上がる（U字）」「子どもが巣立つと夫婦の満足は戻る」と広く知られた曲線を2本見せ、そのあとで本命を出す。「ところが、戻るのは夫の線だけだった」。数字は1分に10個近く並べ、海外の研究が中心になる。
- 章立て：立場を回り、だんだん話を大きくする。
  1. 妻の側：家事と育児、気づかれにくい家の中の仕事、相談する相手がいない
  2. 夫の側：夫は満足している。妻の不満に気づくのは「切り出されたとき」
  3. 仕組みの側：長時間労働と会社中心の働き方、40代は仕事も子育ても重なる時期
  4. 歴史の側：人生50年のころの結婚の形が、人生100年に延びた（結婚してからの年数が昔の倍）
  5. 社会の側：熟年離婚、卒婚、夫婦の「家庭内別居」
  - 3分ごろに先回りを入れる：「夫が家事をしないからだ、と思うでしょう。似た動画はそこで終わる」
- 比喩と締め：比喩は「二人三脚」か「同じ船」。締めは「同じ船に乗っている。ただ、漕ぐ向きが違っていた」の形の逆説の一文で、だれも責めずに終える。弱いところもはっきりしている：相関を因果として言い切る（「家事の偏りが妻を不幸にする」）、絵は文字が中心、日本の数字は終盤に少しだけ。

## データで語る棒人間が作るなら

- 装置：夫婦100組のシミュレーション。それぞれの夫と妻に満足度のメーターがあり、結婚1年目から30年目まで1年ずつ進める。「どうなるだろうか。実行してみよう」で毎回回す。
- はしご（理想の世界 → 足していく原因）：
  0. 理想の世界：夫と妻は同じ出来事に同じように反応する → 2本の線はぴったり重なったまま、ゆっくり下がる
  1. 子どもが生まれる → 2人とも同じだけ下がる
  2. 家事と育児の負担が妻に偏る → 妻の線だけが下がり始める
  3. 夫の長い仕事と、会話の時間が減ること → 差が開く
  4. 子どもが手を離れる → 夫の線だけが戻る
- 途中の発見：数え方の発見をはさむ。「長く続いた夫婦ほど満足、に見えるのは、不満な夫婦が離婚して数から抜けるから」（生き残りの効果）。または「1回だけ聞く調査ではU字、同じ人を追うと下がるだけ」。どちらもうちの研究メモ（S1 p.27、S3）にある話なので、相手が先に使いうる。
- 限界の言い方：「条件は仮定。文化や家庭ごとの差は入れていない」と最後に自分から言い、締めはコメントと登録の呼びかけ。主人公がいない、個人の戦い方がない、データは海外だけ、という弱いところは変わらない。

## 勝ち負け

| 項目 | 対 考えすぎる葦 | 対 棒人間 | 理由 |
|---|---|---|---|
| 引き | 負け | 引き分け | 最初の1割（約1:40まで）で出る数字は「40代の夫の9割近くが満足」だけ。これは「え？」ではなく「そうだろうな」と受け取られる。妻の線が離れる本命の驚きは4:00まで出てこない。痛み（気づいたときには戻らない）は企画カードには書いてあるが、冒頭の台所の場面には数字としてまだ出ていない。棒人間よりは、物語がある分だけ入り口が強い。それでも、驚きの遅さは同じ |
| 新しさ | 勝ち | 勝ち（ただし弱点あり） | 日本の年齢別の割合（S7c、NFRJ18）、自分で計算した下限「少なくとも約1割」、自分で足した「差26分」（S9b）。どちらの相手にもない日本の数字。弱点は2つある。①下限の計算で、妻43〜47歳に夫48〜52歳を組み合わせている（5歳差）。同じ年齢の夫（43〜47歳 87.2%、満足でない12.8%）を使うと23.1−12.8≒10%で、「約12%」から少し下がる。夫婦の年の差を5歳と置く根拠が構成案にない。②26分は末子6歳未満の共働きの数字。一方、この回の主役は40代で、子どもが7〜18歳の時期（S7b）。数字の時期と、話の時期が合っていない |
| 絵 | 勝ち | 負け | 葦の文字中心の画面には勝つ。しかし棒人間と比べると、この回には**装置（シミュレーション）もはしごもない**。2本の折れ線、100組が並び直す場面、積み上げの棒は、どれも「すでにある数字を並べ替えた絵」で、結果が目の前で動いて出てくる場面がない。100人の人型が並び直す見た目だけは棒人間と重なっていて、中身の実験がないぶん、見た目をまねた弱い版に見える恐れがある |
| 参加 | 勝ち | 勝ち | 予想タイム（合計の時間 A〜D）、自分の年齢を線に置く、谷のクイズ。どちらの相手にもない。ただし、谷のクイズの答え（末子7〜18歳）は NFRJ08（2009年）で、データが古い。それに、見る人がうすうす予想できる答え |
| ミクロ | 引き分け | 引き分け | 相手はどちらもミクロを持っていない。ただ、うちの案もまだ「戦い方の比較」になっていない。いまあるのは、会話時間と円満の相関が1つ（S13：ネット調査、「円満でない」は約118人）だけ。どの戦い方の結果を比べたのかが見えないので、「会話を増やせ」という助言に聞こえやすい。構成案も自分で「弱い」と書いている |
| 締め | 負け | 勝ち | 温度計の比喩は良い。ただ、締めの一文の案「同じ家にいても、温度計は2つある」は、事実を言っているだけで逆説になっていない。葦の「その棚は、選べないように設計されている」のような、ひっくり返る一言がない。加えて、比喩の「妻の温度計は台所」は役割の決めつけに見える。これは第3章の「仕事を足すと時間はほぼ同じ」とも食い違う。教訓の「平均で見ると片側の変化は消える」も、根拠とずれている。S7 の平均点は男女別に出したもので、2人をまとめた平均ではない。さらに、その平均点では男女差が有意でない。教訓が自分のデータとぶつかる。登録の呼びかけで終える棒人間には勝つ |

**全体**：新しさと参加では2つの相手に勝つ。引きでは葦に、絵では棒人間に負ける。いちばん大きいのは、この回の芯が「年齢別の横断データの図」1枚にかかっていること。その上で「戻らない」（同じ人がその後どうなるか、という言い方）が題と痛みに入っているのは、うちの決まり（10章「研究の時期を越えて今の話にしない」と、構成案自身の断り「この人たちが年をとるとこうなる、とは言わない」）とぶつかる。いま勝てていない理由は、言い過ぎが足りないからではない。誤差の付いた答えを、絵と装置で見せていないからだ。

## 勝つための直し方（効果の大きい順）

- **絵（対 棒人間）→ 第1章の終わり「100組に並べ直す」→ 並べ直す場面を、組み合わせのくじのシミュレーションに変える。** S7c からは「満足でない夫の割合」と「満足でない妻の割合」しか分からない。同じ家の2人がどう組み合わさっているかは分からない。この分からなさを、そのまま装置にする。
  - 夫の札（満足・満足でない）と妻の札を、組み合わせを変えて何度も配り直す。「夫は満足・妻は満足でない」の組の数が、いちばん少ない並べ方（下限）からいちばん多い並べ方まで動く様子を見せる。
  - 同じ年齢で計算すると、下限は約10組、上限は23組（妻の「満足でない」の割合そのもの）。夫と妻の満足が無関係だと仮定すると約20組（0.872×0.231）。いずれも S7c からの計算なので、台本の前に検算する。
  - 「少なくとも約1割、条件によっては2割を超える」と、幅のある答えを絵で出せる。はしご（原因を足す）ではなく「数え方の幅」を見せる装置なので、棒人間のまねにならない。うちの約束「誤差つきの答え」そのものにもなる。
  - 実際の夫婦の満足には同じ向きに動く傾向があるはずで、本当の値は下限の側に寄るかもしれない。日本の夫婦を組で調べたデータがあるかは**調べる必要がある**。見つからなければ「幅のどこかは分からない」と言い切る。
  - 群衆は「人型1つ」を2体ずつ組（夫婦）で並べ、主人公の夫の家を100組の中に1組だけ置いて、印を付ける。こうすると、棒人間の「1人ずつの200人」と見た目でも分かれる。

- **引き（対 葦）→ 0:00〜1:00 の台所の場面 → 最初の1割で、妻の側の数字を物差しつきで出す。** いまは夫の「9割」だけで、「妻の側は？」と引っぱっている。同じ S7c の値を「満足でない」の側から数える。「30歳前後では、満足と答えない妻は16人に1人ほど。40代半ばでは4人に1人に近い（6.5%→23.1%）。同じ年の夫は8人に1人ほど（12.8%）」。
  - この並べ方なら、物差し（30歳前後）→ 本命（40代半ば）→ もう一方の側（夫）が30秒で入る。しかも「4人に3人の妻は満足」も同時に言えるので、妻を悪く見せない。
  - ただし、年齢ごとの回答者は約200人（男女を合わせて）で、6.5%は数人分の差で動く。「約3倍」と倍数で言えるかは、年齢ごとの男女別の人数と誤差の幅を**調べる必要がある**。幅が広ければ、倍数は言わず「16人に1人ほど → 4人に1人ほど」と、範囲を添えて言うところまでにする。
  - 痛みは数字で出す。夫の猫の「うちはうまくいってる」に、「同じ年の夫の8人に7人がそう答える」を重ねる。

- **新しさ・締め（題と痛みの言い方）→ タイトル案・企画カードの「戻らない」・逆説の一文 → 横断データで言える形に直し、生き残りの効果を「数え方の発見」として使う。**
  - S7c は年齢の違う別の人たちを並べた図なので、「戻らない」は「40代半ばより上のどの年代でも、妻は8割前後のまま」の意味でしか言えない。題を変えないなら、画面と台本でこの意味をはっきり言う。
  - そのうえで、S1 p.27 の「不満な夫婦は別れて数から抜ける」を第1章か第2章に置く。「年が上の年代ほど、続いている夫婦だけが残る。数が良く見えやすい側に偏っている。それでも妻の線は上がってこない」。こうすると「戻らない」が誤差を見たうえでの言い切りになり、棒人間が使いそうな生き残りの発見を先に、うちの日本のデータで取れる。
  - この言い方が成り立つかは、S1 の本文の記述の範囲で確かめる（日本のデータでの離婚の抜けの大きさは、**調べる必要がある**）。

- **締め（対 葦）→ 16:00〜16:50 の教訓と締めの一文 → 温度計の比喩を「家の平均気温」に変え、教訓と一体にする。**
  - 温度計は「居間と台所」ではなく、「夫の部屋と妻の部屋」か「2人それぞれが持つ温度計」にする。役割の決めつけを外し、第3章の「合計はほぼ同じ」とも食い違わないようにする。
  - 教訓は S7 と食い違わない言い方に直す。「平均点で見ると、2人とも少しずつ下がっているだけ。満足の線を割った人を数えると、片側だけが離れている。どこで線を引いて数えるかで、景色が変わる」。
  - 締めの一文は短い逆説にする。案：「平均気温がちょうどいい家にも、寒い部屋はある」。

- **新しさ（数字の時期）→ 第3章と予想タイムの「差26分」→ 40代の時期に合う行を探す。**
  - 社会生活基本調査で、末子の年齢がもっと上の共働き夫婦（たとえば末子が小中学生）の、家事と仕事の合計があるかを**調べる必要がある**。
  - なければ、予想タイムの問題文に「小さい子がいる共働きの夫婦」とはっきり書く。そのうえで、40代の話とは別の時期の数字だと台本で一言断る。

- **新しさ（下限の計算）→ 企画カードの「約1割」→ 夫の年齢を、同じ年齢（43〜47歳）にそろえる。**
  - 5歳差の組み合わせを使うなら、夫婦の平均の年の差の出典（人口動態統計など）を sources.csv に足す。確認するまでは、同じ年齢で「約1割」と言う。どちらで計算しても「約1割」の言い方は保てる。

- **ミクロ（対 両方）→ 第3章の後半 → 相関1つを「戦い方の比較」に替える。データがなければ、ミクロの場面ごと組み替える。**
  - 候補は、構成案に書いてある2つ。社人研 第7回の「夫の家事・育児の度合い別の妻の満足」の集計と、NFRJ18 の (ア)〜(オ) のどの項目が (オ) と一緒に動くか。これを最優先で**調べる必要がある**。
  - 見つかったら、「〇〇な夫の家では、満足と答える妻は△割、そうでない家では□割」を2〜3通り並べる。相関であることは画面に出す。
  - 見つからないときは S13 だけでミクロを立てない。代わりに、上の組み合わせのくじの装置で「夫が満足でも、妻の札は別に配られる」を見せる。そして「夫の満足から妻の満足は当てられない」という、数え方の側のミクロにとどめる。
  - 「会話を増やすと円満になる」と聞こえる並べ方はしない。

- **引き・山（第2章）→ 6:15〜10:45 → 第2章の山を「夫も下がっている」の弱い反論で終えない。**
  - 第1章で「夫は9割のまま」と言ったすぐあとに、「平均で見ると夫も下がっている」（S7）が来る。見る人には言い直しに聞こえ、山が下がる。
  - 第2章は「平均点と割合で、なぜ景色が違うか」を1つの数え方の発見としてまとめ、そこで山を作る。
  - 海外の研究（S1・S3）は裏付けとして短くする。研究を並べて読む場面は葦の土俵で、うちが勝てない所。
  - 谷のクイズは NFRJ08 で古い。新しい回の集計がなければ、クイズにせず短い補足に下げる。
