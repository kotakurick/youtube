# ベンチマーク分析レポート（3チャンネル・143本）

作成：2026-10-04。材料は `summary.md`（数字の集計）、`aggregate.md`（型ごとの伸び方）、`videos/*.json`（bench-analyst による1本ずつの判定）。
まだ入っていないもの：タイトルとサムネイルの分類（`titles.md`、手順3）、伸びていないチャンネルとの比較（`compare/`）。

## 読むときの注意

- **全体の表は、ほぼ「考えすぎる葦」の傾向です。** 143本のうち110本（77%）が葦なので、`aggregate.md` の合計は葦の中での当たり外れを強く映します。このレポートではチャンネル別に分けて読みます。
- **「1日あたり再生数」は新しい動画ほど高く出ます。** 公開直後に再生が集中するためです。たとえば棒人間の「資産格差のシミュレーション」は公開6日で1日7.4万回ですが、これは新しさの分も含みます。
- **判定は Sonnet（思考は浅め）による主観です。** 「物語型の導入」「断定しすぎ」などは目安で、数え間違いもありえます。
- **3チャンネルとも「伸びたチャンネル」です。** ここから分かるのは「伸びたチャンネルの中で、当たった動画と外れた動画の差」です。「伸びるチャンネルと伸びないチャンネルの差」は、別の比較（`compare/PLAN.md`）で調べます。
- 8本の時点で強く見えた傾向（最初のグラフが早いほど伸びる）は、143本では消えました。本数の少ない項目は仮説として扱います。

## 1. 3チャンネルは、それぞれ別の勝ち方をしている

| | データで語る棒人間 | 考えすぎる葦 | 数字で測る恋愛 |
|---|---|---|---|
| 本数・期間 | 25本・約2年 | 116本・約7か月 | 10本・約4週間 |
| 再生数の中央値 / 最大 | **16.8万** / 133万 | 6.3万 / 51万 | 5.7万 / 35万 |
| 長さの中央値 | **9.5分** | 19.9分 | 19.4分 |
| 投稿間隔の中央値 | **25.5日** | 2日 | 2日 |
| 場面転換の間隔 | **12.5秒** | 29.9秒 | 19.6秒 |
| 話す速さ | 380字/分 | 365字/分 | 386字/分 |
| 画面の内訳（棒人間/グラフ/文字だけ） | 40% / **35%** / 10% | 20% / 20% / **30%** | 43% / 20% / 10% |
| 出典の数（中央値） | 6 | **10**（論文中心） | 4 |
| 最初のグラフ（中央値） | **30秒** | 98秒 | 110秒 |
| 導入の型 | 意外な数字（13/23本） | 物語・身近な場面（76/110本） | 物語（9/10本） |
| テーマ | 心理・ネット・世代など幅広い | 心理（40本）と恋愛（21本） | 恋愛・結婚（9/10本） |
| タイトルの目印 | 【データストーリーテリング】 | 【A学×B学】 | ｜データ分析・統計学 |
| 「断定しすぎ」の判定 | 1/23本 | 52/110本 | 9/10本 |
| 「対立あおり」の判定 | 0本 | 6本 | 4本 |

- **棒人間型**：短く、月1本、グラフが多く、絵がよく動く。1本あたりの再生が最も多い。断定や対立あおりがほとんどない。
- **葦型**：長く、2日に1本、論文の数で厚みを出す。画面は文字だけの時間が長い。断定が強め。
- **恋愛型**：葦型の長さと頻度で、テーマを恋愛に絞った特化版。4週間で10本・合計100万再生超と、立ち上がりが最も速い。ただし断定と対立あおりの判定が多い。

**自分たちに近いのは「棒人間の作り（グラフ・シミュレーション・絵の密度・断定しない）」を「15〜20分・週2〜3本」で出す形**です。棒人間型は質が高く、規制にも強いです。ただし月1本では2027年1月の期限に間に合いません。長さと本数は葦型・恋愛型に寄せます。

## 2. 当たった動画に共通すること（チャンネル内の比較）

- 3チャンネルの再生数の上位には、**恋愛・マッチングアプリ・婚活・東京・格差**が並びます（棒人間「ネット恋愛」91万・「マッチングアプリ」57万・「資産格差」52万、葦「ネット恋愛」51万・「港区女子」49万・「東京に出た若者」42万、恋愛「恋愛経験ゼロ」35万）。
- 恋愛・結婚は32本と本数も多いうえで1.89倍なので、偶然とは考えにくい差です。
- お金・格差は全体では平均並みです。ただし**シミュレーションで見せた格差**（棒人間の資産格差）は大きく伸びています。

### データの見せ方

| 項目 | 倍率 |
|---|---:|
| 民間調査を使った | 1.68（56本） |
| 独自シミュレーション | 1.65（6本） |

- 出典を出さない動画は伸びていません。出典を画面に出す方針と合います。

### 締め方とタイトル

| 項目 | 倍率 |
|---|---:|
| 登録の呼びかけで終わる | **0.57（13本）** |
| タイトルに数字（数字型） | 2.05（6本） |
| 「なぜ〜なのか」型 | 0.98（117本。多数派で、それ自体は差を生まない） |

- 締めを登録の呼びかけにした動画は伸びていません。終わり方より中身の満足度の問題かもしれませんが、避けて損はありません。
- 「なぜ型」は当たり前になっていて、それだけでは差がつきません。数字入りのタイトルは本数が少ないので仮説段階です。

### 差が出なかったこと

- **長さ**：チャンネルによって逆向きです（棒人間 −0.25、葦 +0.13、恋愛 +0.55）。9分でも20分でも伸びています。
- **最初のグラフの早さ、出典の数、意外な事実の位置**：143本ではほぼ関係がありませんでした。
- **導入の型**：「問いかけ」が1.63倍（15本）ですが、ほぼ葦の中だけの傾向です。

## 3. 気をつけること

- **「対立あおり」の動画は1.90倍（10本）伸びています。** 男女対立の切り口が再生を稼いでいるのは事実です。2026-10-04 にオーナー判断でこの切り口を解禁しました（`docs/decisions.md`）。ただし性別全体を見下す表現は広告の制限や収益化の審査で引っかかりやすいので、「挑発的だが見下さない」「数字は正確」の線を守ります（`CLAUDE.md`）。
- **「断定しすぎ」は葦で52/110本、恋愛で9/10本です。** 断定は分かりやすさを生みますが、数字の正確さが信用のすべてという自分たちの方針とはぶつかります。2026-10-04 のオーナー判断で、結論は数字の範囲内ではっきり言い切る方針にしました。言い切れない部分は、シミュレーションで「条件を変えるとこうなる」と見せます。

## 4. 制作計画への反映

1. **台本の長さを直す**：話す速さは3チャンネルとも365〜386字/分でした。資料の想定（330字/分）より速いです。**15〜20分なら約5,500〜7,500字**が目安です（`episodes/_template/script.md` を更新済み）。
2. **画面の作り**：場面転換は10〜20秒ごと、グラフや文字だけの画面を30秒以上続けない。人物の絵柄はチャンネル内で固定する。（2026-10-04 訂正：当初は「グラフの画面を3割以上」としたが、伸びた・伸びていないの比較では伸びていない側のほうがグラフが多かったので撤回。`compare/report.md`）
3. **テーマ**：恋愛・結婚、東京と地方、世代を優先します。格差はシミュレーションで見せます。
4. **データ**：身近な数字（公的統計・民間調査）で驚きを作り、論文は裏付けに回します。独自シミュレーションを毎回1つ入れることを目標にします。
5. **締め**：「答え」か「教訓」で終え、登録の呼びかけは途中に置きます。（2026-10-04 訂正：比較では「視聴者への問いかけ」で終わる動画は伸びていない側に多かった）
6. **タイトル**：自分たちの目印（シリーズ名など）は固定してよいですが、言い回しは毎回作ります。数字入りのタイトルを試します。
