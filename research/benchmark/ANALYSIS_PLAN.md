# ベンチマーク分析の手順

2026-10-03 オーナー承認。パソコン上の Claude Code が、**定額プランの中で**この手順どおりに進める（API キーは使わない）。
取得物（字幕・タイル・サムネイル）は分析専用。制作物に流用しない。リポジトリに置くのは分析結果の文章と表だけ。

## 方針：AIに読ませる量を減らし、1本ずつ別々に読む

- **読ませる前にコードで小さくする**（`bench/prep.py`）：字幕から時刻表記と重複行を除き、タイルは 960×540 に縮める。
  画像のトークンは画素数に比例するので、縮小がいちばん効く。数字で済むこと（再生数・長さ・投稿間隔）は `analyze.py` で計算し、AIには読ませない。
- **1本＝1回のサブエージェント**（`.claude/agents/bench-analyst.md`）：Sonnet、思考は浅め（effort: low）。
  材料を読んで決まった形の JSON を書き、返事は `ok <id>` の1行だけ。メインの会話には何も溜まらない。
- **まとめはコードで**（`bench/aggregate.py`）：JSON を表にしてから、メインの会話はその表だけを読んで考察する。

## 手順

### 0. 取得と数字の集計

```bash
bench/bench.sh @lovebynumbers          # 3チャンネル分（bench/README.md）
python bench/analyze.py --out research/benchmark/summary.md
python bench/prep.py                   # 1本ごとの材料を $YT_DATA_DIR/bench/<ch>/<ID>/prep/ に作る
```

### 1. 試しに1チャンネル（@lovebynumbers、8本）

1. 8本それぞれについて `bench-analyst` サブエージェントを呼ぶ。同時に3〜5本まで。
   渡すのは「prep フォルダの絶対パス」と「書き出し先 `research/benchmark/videos/<チャンネル>-<ID>.json`」だけ。
2. JSON を2〜3本開いて、中身が字幕・タイルと合っているかをメインの会話で確かめる。
   ずれていれば `bench-analyst.md` の指示を直してから、その回の JSON を消してやり直す。
3. オーナーに、利用枠の減り具合に問題がないかを確認する。

### 2. 残りの2チャンネル

- 公開から14日未満の動画は除く（再生数が安定していないため）。
- 既に JSON がある動画は飛ばす。途中で利用上限に当たったら、時間をおいて続きから再開する。
- 利用枠が厳しければ、`videos.csv` の1日あたり再生数で各チャンネルの上位10本と下位5本に絞る。

### 3. サムネイルとタイトル

```bash
bench/thumbs.sh @lovebynumbers   # → <チャンネル>/thumbs/thumbs_001.jpg…（再生数の多い順、480×270 を 3×3）
```

タイルのどの位置がどの動画かは `thumbs/thumbs.tsv`（sheet・pos・id・views・title）で分かる。位置は左上が1、右下が9。
メインの会話で読み、`research/benchmark/titles.md` に表にする：再生数、タイトルの型、数字の有無、文字数、分野、サムネイルの型（文字量、配色、人物やグラフの有無）。

### 4. まとめ

```bash
python bench/aggregate.py --out research/benchmark/aggregate.md
```

`aggregate.md`（型ごとの「チャンネル内倍率」）、`summary.md`、`titles.md` を読み、`research/benchmark/report.md` を書く。

- 伸びるテーマ、タイトル、サムネイル、構成の型。3チャンネルで共通するものと、チャンネル固有のもの。
- 自分たちの動画で採る型・避ける型の提案。ポリシー（`CLAUDE.md`）に触れる型は採らない。
- 本数が少ない型の差は偶然の可能性が高い。言い切らず、根拠の本数を添える。
- `themes/themes.csv` の「優先度」案（A/B/C）と理由。
- 1本目のテーマ候補3つと理由。決めるのはオーナー。

## 量の目安（1本あたり、試算）

| 材料 | トークン |
|---|---|
| タイル 10枚（960×540 ≒ 約700トークン/枚） | 約7,000 |
| 整えた字幕（15〜20分） | 約6,000 |
| meta.json | 約500 |
| 出力（JSON） | 約800 |

約155本すべてで入力が約200万トークン。定額プランでは料金ではなく利用枠を使うので、1チャンネルずつ進める。
