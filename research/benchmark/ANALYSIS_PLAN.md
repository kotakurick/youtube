# ベンチマーク分析の手順

2026-10-03 オーナー承認。パソコン上の Claude Code がこの手順で進める。
取得物（字幕・タイル・サムネイル）は分析専用。制作物に流用しない。リポジトリに置くのは分析結果の文章と表だけ。

## 0. 前提

- `bench/bench.sh` で3チャンネルを取得済み（`bench/README.md`）。
- `python bench/analyze.py --out research/benchmark/summary.md` で数字の集計済み。

## 1. 対象を選ぶ

`$YT_DATA_DIR/bench/videos.csv` から、チャンネルごとに選ぶ。

- **詳しく読む**：1日あたり再生数（`views_per_day`）の上位5本と下位3本、計24本程度。
  公開から14日未満の動画は再生数が安定していないので除く。
- **軽く分類する**：残りすべて。タイトルとサムネイルだけ見る。

選んだ一覧は `research/benchmark/targets.md` に書く。

## 2. 詳しく読む（1本ずつ）

読むもの：

- 字幕（`<ID>.ja*.vtt`）。全文を読む。
- タイル（`sheet_*.jpg`）。**最初の2分にあたるタイルはすべて、それ以降は均等に間引いて合計10枚まで**。
  どのタイルが何秒目かは `times.tsv`（sheet・frame・sec）で分かる。

書き出す項目（`research/benchmark/videos/<チャンネル>-<ID>.md`、1本あたり1画面程度）：

1. 問い：動画が立てる問いを1文で
2. 導入（最初の30〜60秒）：つかみの種類、結論を先に言うか、最初のグラフが出る秒数
3. データ：使った統計・研究の数と種類、グラフの種類、出典の見せ方
4. 展開：意外な事実の位置（何分目）、章立て
5. オチ：締め方（問いへの答え、視聴者への投げかけ、次回予告など）
6. 絵：棒人間・グラフ・シミュレーション・文字だけの画面のおおよその比率、場面転換の間隔
7. タイトルの型、サムネイルの型（文字量、配色、人物やグラフの有無）
8. 伸びた（伸びなかった）理由の仮説

## 3. 軽く分類する

サムネイルは1枚ずつ見ずに、3×3のタイルにまとめてから見る（9枚分が1枚の画像代で済む）。

```bash
bench/thumbs.sh @lovebynumbers   # → <チャンネル>/thumbs/thumbs_001.jpg…（再生数の多い順）
```

タイルのどの位置がどの動画かは `thumbs/thumbs.tsv`（sheet・pos・id・views・title）で分かる。位置は左上が1、右下が9。

表（`research/benchmark/titles.md`）にする項目：再生数、タイトルの型、数字の有無、文字数、分野、サムネイルの型。

## 4. まとめ（`research/benchmark/report.md`）

- 伸びるテーマ、タイトル、サムネイル、構成の型。3チャンネルで共通するものと、チャンネル固有のもの。
- 自分たちの動画で採る型・避ける型の提案。ポリシー（`CLAUDE.md`）に触れる型は採らない。
- `themes/themes.csv` の「優先度」案（A/B/C）と理由。
- 1本目のテーマ候補3つと理由。決めるのはオーナー。

## 量の目安

| 対象 | 1本あたり | 合計 |
|---|---|---|
| タイル（1枚 1440×810 ≒ 約1,500トークン） | 10枚 ≒ 1.5万トークン | 24本 ≒ 36万トークン |
| 字幕（15〜20分 ≒ 5,000〜7,000字） | 約1万トークン | 24本 ≒ 24万トークン |
| サムネイルのタイル | 9本で約1,500トークン | 130本 ≒ 2.5万トークン |

合計で約60万トークン（出力を除く）。一度に全部読まず、1チャンネルずつ進めて途中結果をファイルに書く。
