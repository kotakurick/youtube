# ゴサ（「吾輩は数える猫である」の猫）

ひげが横向きの誤差棒になっている黒猫。2026-10-04 オーナー決定（`docs/concepts/2026-10-04-gosa-cat.html` の案C）。
設定表は `sheet.html`（ブラウザで開く）。

## 作り方

```bash
python assets/characters/gosa/make_gosa.py   # svg/、icon.svg、gosa.json を作り直す
```

動画では `render/src/lib/Gosa.tsx` が `gosa.json`（表情の設定）を読んで描く。表情の間はひげ・耳・傾きがなめらかに変わる。
`svg/` はサムネイルや資料用。`icon_800.png` は `icon.svg` を800pxで書き出したもの（アイコンはひげを太くしてある）。

絵は `make_gosa.py` の数字が正本です。SVG を直接書き換えず、表情の設定（`EXPRESSIONS`）や部品の関数を直して作り直します。

## 決まり

- **ひげ＝誤差棒**。ひげの長さで確かさを表す。
  - 短い＝言い切り（`assertive`）
  - 長く垂れる＝条件次第（`depends`）
  - これを毎回の判定と合わせる：〇＝その通り・×＝ちがう（どちらも確かなので短い）、△＝条件次第（長い）。
- **色は墨 `#1D2333` と白だけ**。データの色（男性の青、女性のオレンジ）は使わない。暗い背景の上では反転版（白い体に墨の目）を使う（2026-10-04 決定）。動画は `Gosa dark`、静止画は `_dark.svg`。
- **大きさと場所**：右下に固定（足元 y=880、中心 x=1690）。体の直径で S96／M140／L220。
- **吹き出しは4つだけ**：「答え合わせ。」「ひげ、短め。」「ひげ、のびます。」「！」。声・鳴き声はなし、表情ごとの効果音だけ（30秒に1回まで）。
- **男女の対立の回**：審判に徹する。片方の性別に向けたジト目・落胆は使わない。サムネイルには出さないか「考え中」だけ。
- **原点＝体の中心**。どの表情も枠（viewBox `-130 -100 260 180`）が同じなので、差し替えても位置がずれない。
- **出る場面**：冒頭、章の切り替わり、意外な事実が出た瞬間、締めの判定。画面全体の1割以下。語りはしない（しゃべるかは未定）。
- **助言はさせない**。特にお金・健康の回は、リアクションと判定（現象の説明）だけ。
- 表記は必ずカタカナの「ゴサ」。

## 表情（`svg/`）

| ファイル | 表情 | 主な使いどころ |
|---|---|---|
| `normal` | ふつう | 冒頭・つなぎ |
| `surprised` | 驚き（ひげが跳ね上がる） | 意外な数字が出た瞬間 |
| `assertive` | 言い切り（ひげが短い） | 判定〇、結論 |
| `thinking` | 考え中（ひげが片方ずつ上下） | 問いを立てる場面 |
| `skeptical` | ジト目 | 通説・思い込みを紹介する場面 |
| `depends` | 条件次第（ひげが長く垂れる） | 判定△、「場合による」 |
| `happy` | 喜び | 締めの教訓 |
| `down` | 落胆 | 悪い数字 |
| `panic` | 焦り（ひげが震える） | 急な変化・危機の話 |
| `idea` | ひらめき | 章の切り替わり、仕組みが分かった瞬間 |
| `point` | 指し示し（右のひげを伸ばす） | グラフや数字を指す |

動き（`Gosa.tsx`）：下から弾んで出て12fで下へ抜ける／表情が変わると4fだけ潰れる／3〜5秒ごとにまばたき／驚きは小さく跳ぶ／`point` は `reachTo` で右のひげの先を指す点まで伸ばす（ひげがそのまま注釈の線になる）。
