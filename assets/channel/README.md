# チャンネルの設定（吾輩は数える猫である）

YouTube の「チャンネルのカスタマイズ」に入れるもの。2026-10-04 作成。

## 画像

| 欄 | ファイル | 作り方 |
|---|---|---|
| 写真（アイコン） | `icon_800.png`（800×800） | `python assets/characters/gosa/make_gosa.py` で `icon.svg` を作り、800px に書き出したもの（正本は `assets/characters/gosa/`） |

## 説明（概要）

YouTube の上限は1000字。下の枠の中をそのまま貼る。

```
世の中の“たぶん”に、誤差つきの答えを。

「アプリのおかげで、出会いは増えた」「最近の若い人は恋愛をしない」。よく聞くあの話を、国の統計や調査の数字で数え直すチャンネルです。

・身近な疑問を、公的統計と研究で確かめます
・割合だけでなく「人数」で数え直すと、見える景色が変わることがあります
・言える範囲ではっきり答え、分からないところは「条件しだい」と正直に見せます
・使った資料は、毎回の概要欄に載せています

いまは恋愛・結婚のテーマを中心にお届けしています。
案内役は、ひげが誤差棒になっている黒猫のゴサです。

※動画は、数字から見える世の中の傾向を説明するものです。個別の助言ではありません。
```

- 決まり（`docs/brand.md`）に合わせて、「衝撃」「〜すべき」は使っていない。助言はしない（最後の注記）。
- 投稿の曜日や本数は、決まってから書き足す。

## キーワード（設定 → チャンネル → キーワード）

```
吾輩は数える猫である 数える猫 ゴサ 誤差 統計 データ 恋愛 結婚 婚活 出会い 少子化 社会
```

「ゴサ」は「誤差」と打たれやすいので、両方入れる（`docs/decisions.md` 2026-10-04）。

## 代名詞

**空欄（設定しない）**。代名詞の欄は、個人が「彼／彼女」などを示すためのもの。このチャンネルは個人ではなく、ゴサにも性別を決めていないので、入れない。
