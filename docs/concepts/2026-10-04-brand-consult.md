# 動画ブランドをそろえる相談のまとめ（2026-10-04）

## 進め方

- 4つの役割をサブエージェントに与えて、別々に提案させた。
  - ブランド担当：約束、性格、語り口、部品の名前
  - マーケター：パッケージ（タイトル・サムネイル）、視聴維持、ショート
  - 動画ディレクター：18分の構成、場面の部品、音
  - アートディレクター：レイアウト、文字、色、動き、グラフ
- いずれも Claude に役割を与えたもので、実在の専門家の意見ではない。根拠はリポジトリのベンチマーク分析と、今のデモの画像。
- この文書は相談のまとめで、まだ決定ではない。決まったものから `docs/decisions.md` に移す。

## 1. ブランドの核（4人とも同じ向き）

**視聴者への約束**：「よく聞くあの話」を、100人の絵と一次資料で確かめ、言える範囲ではっきり答える。毎回渡すのは3つ。

1. 答え（〇△×）
2. 自分がどこにいるか
3. 世の中の見え方が変わる教訓

キャッチコピー：「世の中の"たぶん"に、誤差つきの答えを。」

**性格（○○であって、△△ではない）**

| 性格 | ではない |
|---|---|
| 言い切る | 盛って煽る |
| 公平（両側のデータを出す） | どっちつかず |
| 人に温かい（1人の物語から入る） | 説教・上から目線 |
| 茶目っ気（ゴサの小さな反応） | 数字を茶化す |
| 正直（分からない所は「条件次第」と見せる） | 自信がない |

**語り口の例**

- ナレーション：よい「答えは約4割。思ったより、ずっと少ない数字です。」／悪い「衝撃！男はみんな○○だった！」「あなたも条件を下げるべきです。」
- 画面の文字：よい「大きく『約4割』、小さく『38.2%』」／悪い「【悲報】」「ヤバすぎ」「！！」「女はこう」

**ゴサの役目**：ひげ＝確かさの正直な表示。墨色＝どちらの側でもない審判。判定するのは「説」で、人ではない。

## 2. 毎回同じにするもの／毎回変えるもの

| 毎回同じ（型） | 毎回変える（中身） |
|---|---|
| 色（墨・紙・男性の青・女性のオレンジ）、男女の左右（青が左） | 問い、物語の主人公と情景 |
| 書体1つ（Noto Sans JP）、太さの段階 | データの組み合わせ、グラフの種類 |
| 字幕の帯、出典の書式と位置 | シミュレーションの条件と見せ方 |
| 100人の群衆、人型1つ、追う1人の印 | 判定の結果（〇△×の配分） |
| 判定カード、判定の効果音（音のロゴ） | 教訓、タイトルの言い回し |
| ゴサの決まり（11の表情、出番は1割以下） | サムネイルの主題と絵、BGM |
| 冒頭は物語・締めは教訓という流れ | 章の数と長さ（標準はあり） |

確かめ方（ブランド担当）：

- 判定カードのような「枠」は、合わせて1分以内にする。
- 10本のサムネイルを並べて、主題がすべて違って見えるかを確かめる。
- 2本の冒頭30秒を入れ替えて気づかれないなら、作り直す。

## 3. 部品の名前（ブランド担当）

| 部品 | 名前 | 補足 |
|---|---|---|
| 判定のコーナー | 答え合わせ | 〇＝その通り、×＝ちがう、△＝条件次第 |
| 100人の場面 | 100人実験 | 画面のラベルだけに使う |
| 追う1人 | ○番さん | 「27番さんは32歳。」毎回違う番号 |
| 自分に当てはめる場面 | ふつうの幅 | 範囲を誤差棒で見せる＝ゴサのひげとつながる |

- ひげと印の対応：〇と×はどちらも確かなのでひげが短い（`assertive`）。△だけ長い（`depends`）。
- ゴサの吹き出しは3つに限る：「答え合わせ。」「ひげ、短め。」「ひげ、のびます。」と、驚きの「！」。

## 4. 18分の標準構成（動画ディレクター）

| 時間 | 中身 | ゴサ |
|---|---|---|
| 0:00–0:40 | 物語の冒頭：1人に寄った絵 → 引くと100人の中の1人。0:30ごろに最初の数字 | 0:05に1秒だけのぞく |
| 0:40–0:48 | 「今日の答え合わせ」カード：通説を1行で | 考え中 |
| 0:48–1:45 | 問いの立て直し、予想タイム（4択。答えは判定で明かす）、3章の道案内 | 考え中 |
| 1:45–6:15 | 第1章：身近な公的統計で驚かせる。自分の年齢に当てはめる | 驚き1回 |
| 6:15–10:45 | 第2章：仕組み。もう一方の性別のデータもここで出す。クイズ | 指し示し1回 |
| 10:45–15:15 | 第3章：「もしも」のシミュレーション（ここだけ1000人も可） | 条件次第1回 |
| 15:15–16:30 | 答え合わせ：通説 → 証拠3つ → 〇△× → 予想の答え | 大きく出る |
| 16:30–17:40 | 教訓：冒頭の人物に戻り、一般化する | 喜び |
| 17:40–18:00 | 終了画面（20秒、次の1本と再生リスト） | 喜び |

- 冒頭にロゴやあいさつは入れない。0〜5秒に右上へチャンネル名の帯が1.5秒すべり込むだけ。
- 章の切り替えは墨の帯のワイプ＋章の札で3秒以内。
- 登録のお願いは30〜40%の位置に画面の文字で1行だけ（マーケター）。声で登録を呼びかけて締めない。
- ゴサの画面時間は合計約100秒（約9%）。

## 5. パッケージ（マーケター）

**タイトルの型**（言い回しは毎回作る）

- A 答えをにおわせる断定：「婚活で条件を下げても、成功は1.6倍止まりだった」
- B シミュレーションの結果：「全員が"少し上"を狙うと、婚活でペアになれるのは4割」
- C 自分に当てはめる：「30代独身が5年以内に結婚する割合を、年齢ごとに数えた」
- 数字は1つまで。【〇〇学×〇〇学】、「」、「なぜ〜なのか」は使わない（伸びていない側に28ポイント多い。16チャンネル）。

**サムネイル**

- 左6割：100人を10×10のマス目に並べ、主役の人数だけ色を付ける（散らばった配置はスマホで割合が読めない）。
- 右4割：特大の文字を2かたまり。
- ゴサは右下の決まった位置に、高さの12〜15%。
- 〇△×はサムネイルに出さない（答えのネタバレになる）。
- 地の色は意見が割れた（7章の論点1）。

**再生リスト（最初の20本）**：「100人で数える婚活」（シミュレーション回）、「恋愛・結婚の答え合わせ」（判定回）、「あなたは何%側？」（自分に当てはめる回）＋全話の「恋愛・結婚を数える」。

**ショート**：縦に組み直した30〜50秒。型は「100人クイズ」と「判定」の2つ。長尺1本につき1本、公開の1〜2日後。手間は全体の2割まで。

**最初の10本で見る数字**（目安。10本未満なので仮説）

| 指標 | 下回ったら直す所 |
|---|---|
| クリック率 4% | サムネイルとタイトル |
| 30秒時点の維持率 65% | 冒頭 |
| 平均視聴率 35% | 中盤（場面転換、考える場面） |
| 1,000回あたり登録 3人 | 再生リストと終了画面 |

## 6. 見た目と音の決まり（アートディレクター・動画ディレクター）

コードの定数にできる形。決まったら `render/src/lib/theme.ts` に入れる。

**レイアウト（1920×1080）**

```
HEADER  y56–176   問い（左寄せ、2行まで）
STAGE   y200–880  x96–1824（ゴサがいるときは x96–1520）
NOTE    y884–916  出典（グラフの左下）
DOCK    ゴサの足元 y=880、中心 x=1690（右下に固定）
SUB     y920–1000 字幕（中央、幅1440まで、2行まで）
下80px  YouTube の再生バーが重なるので何も置かない
```

- 文字は28px未満を作らない。スマホ確認は640×360に縮めた静止画で読めるか。
- 100人の群衆は1人の高さ64px以上（今は約50px）。
- ゴサの大きさは体の直径で S96／M140／L220 の3段階（今は約70pxで、スマホで表情が読めない）。

**文字**：主役の数字200/900、章の扉96/900、問い72/900、グラフの値64/900、ラベル40/700、本文44/500、字幕54/700、出典28/500。数字はすべて等幅（tabular-nums）。

**色の役割**：色はデータの意味（男・女・注目・その他）にだけ使う。〇△×は墨だけで描く。

| 名前 | 色 | 用途 |
|---|---|---|
| paper2 | #EBE6D9 | 面・帯・方眼の地 |
| ink2 | #5B6070 | 補足の文字（opacity で薄くしない） |
| maleTint / femaleTint | #B9CBE6 / #EDC3AD | 話の対象外の人（opacity 0.25 の代わり） |
| other（読ませる棒） | #8C877E | 今の #9A958C は紙の上でコントラスト不足 |
| rest | #CFC9BC | 背景の固まり |
| marker | #FFD23F | 蛍光ペン（決定待ち） |

**線・角・動き**

- 線は 2／4／7／14 の4段階、端はすべて丸。角の丸みは 8／16／28。
- ばねは3種類だけ：enter（文字・カード）、move（群衆）、pop（ゴサと答えの数字だけ）。
- 回転・文字の弾み・クロスフェードは使わない。続く場面は1つ以上の要素を引き継ぐ。
- 決まり手：群衆がそのまま10×10のマスや棒に並び直す（棒グラフを別に出さない）。

**音**

- BGM：歌なし、テンポ90〜110、声より18〜20dB下げる。5〜6曲を場面の種類ごとに固定。
- ゴサの効果音：0.5秒以下、表情ごとに1つ（驚き＝上がる音、言い切り＝カチッ、条件次第＝下がる音 など）。鳴き声は使わない。30秒に1回まで。
- 判定：1.5秒の刻み → 0.3秒の無音 → 打撃音（〇＝明るい、△＝2音、×＝低い）。
- 全体は -14 LUFS、ピーク -1 dBTP。

## 7. 意見が割れた所

1. **サムネイルの地の色**
   - マーケター：生成り（紙色）の地。競合は黒地が多いので並んだときに見分けがつく。
   - アートディレクター：墨の地か墨の帯に紙色の文字。紙色の地は一覧の中で溶ける。
   - ブランド担当：濃い帯。
   - **Claude の推奨**：紙色の地に、文字を載せる墨の帯（両方の利点を取る）で始める。全面墨の地を YouTube の「テストと比較」で比べて決める。
2. **出典の位置**：今は右上に固定（`render/README.md`）。ディレクターは大きさだけ（28〜30px、調査名と年度）、アートディレクターはグラフの左下へ移す案。→ **推奨**：グラフの左下に移し、28px 以上にする。
3. **サムネイルのゴサの表情**：マーケターは驚き・ジト目・条件次第の3つ。ブランド担当は、男女の対立の回ではゴサを出さないか「考え中」だけにする。→ **推奨**：ジト目は男女の対立の回では使わない。
4. **途中の判定**：マーケターは45〜55%に途中経過の判定を置く案。ディレクターは判定を最後に1回にして、冒頭の予想を最後に回収する案。→ **推奨**：ディレクターの形を標準にし、第2章の終わりに「ここまでの答え合わせ」を1行だけ入れる。

## 9. 決定がなくても直すもの（今のデモへの指摘）

方針（誇張しない・スマホで読める）に沿った直しなので、決定を待たずに進めてよいもの。

1. 群衆を画面の中央に置き、ゴサは右下の地面（DOCK）に置く。今は左半分だけで、ゴサが浮いている。
2. 追う1人を目立たせる：輪で囲む、1.25倍、名札（「27番さん（32）」）、寄りの絵。
3. 対象外の人を opacity 0.25 で薄くせず、tint の色に置き換える。
4. 群衆のあとに同じ数字の棒グラフを出し直さない。群衆が10×10や棒に並び直す。主役の数字「38人」を数え上げる。
5. ゴサの位置と大きさを固定する（今は場面ごとに x と幅がばらばら）。判定ではカードの外に L で置く。
6. 判定の△が2回出ている（大きな印と文字）。印は1つにまとめる。
7. 問いの見出しを場面をまたいで出し続けない。
8. 出典を28px 以上にし、調査名と年度を入れる。
9. 字幕の帯の幅を固定する（今は文の長さで変わってちらつく）。下80px にかからない位置へ。
10. 締めの「数字は、選び方の地図になります」は助言に寄って聞こえる。世の中の見え方を言う形に直す。
11. 人型の面積をそろえる：女性の胴は裾が広く、男性より約3割面積が大きい。群衆でオレンジが多く見え、誇張しない方針とぶつかる。男性は幅22、女性は上16・裾26にする。
12. 「その他・無回答」用に中立の人型を作る。
13. ゴサのアイコン：小さい表示でひげが消えるので、アイコン用にひげを太くする。耳の角を少し丸める。暗い背景用（今は白い縁取りだけ）を、白い体に墨の目の反転版と比べる。
