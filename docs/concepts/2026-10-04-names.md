# チャンネル名の出し直しとレビュー（2026-10-04）

## 条件（オーナーと合意）

1. テーマも形式も名前で縛らない（恋愛、日本・ニッポン、もしも、1000人、シミュレーションを入れない）。
2. 検索でほぼ自分たちだけが出る言葉を含む（造語、キャラ名、珍しい言い回し）。
3. 競合の言葉を使わない（数字の〜、数字で、本音、ラボ、研究所、実験室、統計学、データで語る、考えすぎる、棒人間、【A×B学】の型）。
4. 「データで確かめる」という視点が伝わる。言いやすく覚えやすい（8字以内が理想）。

形式（1000人のシミュレーション、〇△×の判定）は、名前ではなく中のシリーズ・コーナーにする。

## 進め方

- Claude が16案を出した。ブランド担当（サブエージェント）がそれを講評し、自分の案を足して22案にした。
- その22案を、パッケージ担当と、視聴者4人のパネル（サブエージェントが演じたもの）が別々に評価した。
- いずれも Claude に役割を与えたもので、実在の専門家や視聴者の調査ではない。

## 分かったこと

- **3つとも上位なのは「ゴサの答え合わせ」だけ。** 名前・アイコン・キャラが一致し、「答え合わせ」が毎回の締め（答えを言い切る、〇△×の判定）にそのままつながる。テーマも縛らない。
- 視聴者パネルでは、データに興味がない人（4人中3人）に効くのは「答えがもらえそう」「自分のことだと感じる」「覚えやすい」の3点だった。統計用語の名前は、統計に詳しい層にしか届かない。
- クリックを決めるのは、サムネイルとタイトル。チャンネル名が効くのは、登録するときと、次の動画を探すとき。
- 「？」「、」を含む名前や、ひらがなと漢字で表記がゆれる名前は、検索で失敗しやすい。
- ゴサ系の名前どうしは記憶の中で混ざる。使うなら1つに絞る。

## ゴサの答え合わせの注意点

- 耳で聞いて「ごさ」と打つと「誤差」に変換される。対策は次の3つ。
  - 表記は必ずカタカナにする。
  - 概要欄とキーワードに「誤差」も入れる。
  - 動画の中で、カタカナの「ゴサ」を見せる。
- 初めて聞いた人には「ゴサ」が人名に聞こえる（キャラを見れば分かる）。
- 「答え合わせ」で、クイズ番組と勘違いされる軽いおそれがある。
- キャッチコピー案（パッケージ担当）：**「世の中の"たぶん"に、誤差つきの答えを。」**

## 名前にしない案の使い道

- 「平均にいない人」「ふつうの幅」：恋愛の回のシリーズ名やコーナー名として強い。
- 「1000人シミュレーション」：シミュレーションの回のシリーズ名。

## まだ確認していないこと

Web 検索では、主な候補とかぶる名前は見つからなかった（近いのは鼻毛ワックスの「GOSSO」くらい）。
ただし、Web 検索では YouTube のチャンネル名を確実には調べられない。決める前に次を確認する。
- YouTube のチャンネル名と@ハンドル（gosa_kotaeawase など）
- X・TikTok のアカウント
- 商標（J-PlatPat、第41類・第38類）
