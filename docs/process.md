# 動画の作り方（流れと担当）

2026-10-05 時点。1本ごとのチェックリストは `episodes/_template/README.md`（`scripts/new_episode.sh` で各回にコピーされる）。決まりの中身は `docs/brand.md`・`docs/script-style.md`、経緯は `docs/decisions.md`。

## 担当

- **オーナー**：★の工程。決める・確かめる・公開する。
- **クラウドの Claude**：PCを閉じていても進む作業（考える・調べる・書く・コード・静止画）。GitHub にあるものだけで作業する。
- **ローカルの Claude**（オーナーのPC）：APIキーや `_local/` の音声・BGM が要る作業（本番の音声・書き出し・音量）。
- **スマホで聞く仮の音声**（8b）だけはクラウドで作る（2026-10-06）。オーナーは日中ほぼスマホなので、台本のあとの確認をスマホで済ませるため。クラウドの環境変数 `ELEVENLABS_API_KEY` が要る。
- **サブエージェント**（`.claude/agents/`）：書いた会話とは別の目でのレビュー。絵コンテは アニメーター `review-animator`・イラストレーター `review-illustrator`・デザイナー `review-designer` の3役。事実 `review-facts`・ポリシー `review-policy`・心の動き `review-flow`・深さ `review-depth`・ライバル `review-rival`・視聴者代表 `review-viewer`（目が肥えた30歳男性の一般視聴者。作り手の決まりを知らないフラットな目で、おもしろいかを判定）・日本語 `review-japanese`（耳だけで一度聞いて分かるか。ほかの役を反映したあとに最後に通す）。
- **自動のチェック**：台本 `scripts/lint_script.py`、出典 `scripts/check_sources.py`、画面 `npm run check`、BGM `npm run bgm`。

引き継ぎはすべてリポジトリで行う（クラウドには Claude のメモがない）。各回の進み具合は `episodes/<回>/README.md`。

本線への合流：決まりの変更はすぐ、各回の作業は 12（音声）の前にローカルへ渡すとき（`CLAUDE.md` の「ブランチの決まり」）。

## 流れ

| # | 工程 | 担当 | 中身・道具 | 出てくるもの |
|---|---|---|---|---|
| 1 | テーマ選び | クラウドが案 → ★オーナーが承認 | 最初の20本は恋愛・結婚（`themes/first20.md`） | `themes/themes.csv` |
| 2 | データ集め | クラウド | 一次資料の最新版 | `sources.csv`、`data/` |
| 3 | 企画カード | クラウド | 痛み・逆説の一文・この動画だけの数字・日本の数字・絵で分かる瞬間・ミクロ。空があれば進まない | `outline.md` の一番上 |
| 4 | 構成案 | クラウド＋ライバル役 | 考えすぎる葦・データで語る棒人間と比べ、負けている所を直す | `outline.md`、`review/rival-outline.md` |
| 5 | 台本 | クラウド＋チェッカー | 仕掛けの印を置き、lint のエラーを0に。script-review スキルで推敲 | `script.md` |
| 6 | 別の目でのレビュー | サブエージェント6役（視聴者代表 `review-viewer` を含む）→ 直したあと日本語役 | 直した／直さなかった（理由）を1行ずつ。直した稿を事実・ポリシー・心の動きにもう一度見せてから、最後に日本語役 | `review/` |
| 7 | 一次資料との照合 | ★オーナー | 数字を一次資料と突き合わせる | `sources.csv` の照合欄 |
| 8 | 台本レビュー | ★オーナー | Claude が企画カード・ライバル役の判定・直さなかった指摘をまとめて渡す。オーナーはチャットで返すだけ | `review/owner.md` |
| 8b | 仮の音声で聞く | クラウド → ★オーナーがスマホで聞く | **まず無料の読み上げページ**：`python tts/readaloud.py episodes/<回>` で作ったページを Artifact で公開（`capabilities={"db": {}}`。回と版ごとに別のページ）してリンクを渡す（スマホの声で読む。Claude アプリの中では読み上げが動かないので、リンクをスマホのブラウザ（Edge・Safari）で開いてもらう）。オーナーは文の番号をタップして「いらない」「言い換え」「メモ」を付け、チャットで「付けた」と言う → クラウドが ArtifactData でそのページの `notes` を読み、台本を直す（直した指示は消すか、直した版のページを新しく作る）。db が使えないときは「指示をコピー」で貼ってもらう。**Yui の声で聞きたいときだけ**、本番と同じ Yui で `python tts/narrate.py episodes/<回> --voice eleven-yui` → `python tts/preview.py episodes/<回>`。できた mp3（通し・章ごと）と早見表（1文ずつの時刻）をアプリに送る。オーナーは「2:10の話いらない」とチャットで返す → 台本を直し、変えた文だけ作り直してもう一度送る。音声は Git に入れない。同じセッションの中なら変えた文だけの料金、日をまたぐとクラウドの入れ物が消えて全文の料金（1本約1万2千クレジットの見込み。語り方の指示の分を含む）。日をまたいで台本を直したときの尺は `--voice silent` でよい | 読み上げページのリンク、`_local/episodes/<回>/preview/`（アプリに送る） |
| 9 | 絵コンテ | クラウド＋絵コンテの3役 → ★オーナーが確認 | `episodes/<回>/scenes/Storyboard.tsx` に場面を描き（秒数 sec と動き move も書く）、`cd render && npm run storyboard -- <回のid>` で一覧と表（30秒を超える場面に ⚠）を作る。**第1版をアニメーター `review-animator`・イラストレーター `review-illustrator`・デザイナー `review-designer` に見せ**、まとめ（`review/storyboard-summary.md`）で直してからオーナーへ。色はその回の意味の色 | 一覧の画像、`storyboard.md`、`review/storyboard-*.md` |
| 10 | 場面のコード | クラウド | シミュレーションも含む | `scenes/Episode.tsx` |
| 11 | 仮通し | クラウド | 無音の仮の尺と字幕で13〜18分を通し、テンポを直す | `timing.json` |
| 12 | 音声 | ローカル | 先にクラウドの作業を本線に合流させる。ElevenLabs の Yui（`--voice eleven-yui`）。8b の音声はクラウドから移さず、PCで作り直す（パソコンを触れる時間が短いので、移す手間を増やさない） | `_local/episodes/<回>/audio/` |
| 13 | 書き出し・BGM・音量 | ローカル | `npm run render`、`npm run master` | 動画ファイル |
| 14 | 画面のチェック | 自動 | `npm run check` の「直すもの」を0に | `render/out/qa/<回>/` |
| 15 | 通しで見る | ★オーナー | 1.25倍速 | |
| 16 | タイトル・サムネイル | クラウドが案 → ★オーナーが決定 | サムネイルはコードで作る（画像生成AIはここだけ使ってよい） | `meta.md` |
| 17 | 公開 | ★オーナー | YouTube Studio | URL |
| 18 | 公開後の確認 | オーナー＋Claude | 広告の制限（黄色アイコン）、透かし | |
| 19 | 振り返り | オーナーが数字を貼る → Claude が記録 | 公開7日後と28日後。離れた所・見返された所と仕掛けの位置を照らし、学んだことを決まりかレビュー役に1行足す | `retro.md` |
| 20 | ショート | クラウド（構成）→ ローカル（書き出し） | 3本目から、長尺1本につき1本 | `scenes/Short.tsx` |

オーナーの出番（★）：テーマの承認、資料の照合、台本レビュー、仮の音声を聞く（スマホ）、絵コンテの確認、通しで見る、タイトルとサムネイルの決定、公開、（公開後）数字を貼る。

## 学ぶ流れ

- ほかのチャンネルの1本を分解したら `research/benchmark/teardown/` に残し、効きそうなことを決まり（`docs/script-style.md` の11章など）かレビュー役に足す。
- 自分の回は `retro.md` に残す。10本たまるまでは、1本の結果をルールにしない。
