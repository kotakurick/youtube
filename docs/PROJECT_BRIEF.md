## 1. 目的

- 日本向けのYouTubeチャンネルを、**AIを最大限使ったパイプライン**で継続的に制作し、広告収益を得る。
- ジャンルの条件は「企画が100本以上出せること」「再生数が稼げること」。

## 2. 決定したジャンル：「データ×疑問」

- **中身**：身近な疑問（恋愛、お金、仕事、地域、世代、心理など）を、公的統計と査読付き研究を根拠に解き明かす長尺の解説動画。
- **視聴者層**：主に20〜40代。
- **最初に作る分野**：**恋愛・結婚**と**お金・格差**。ベンチマークの3チャンネルで最も再生が伸びている領域です。
- テーマ候補100本は末尾の付録にあります。

## 3. 動画の仕様

- **長尺が中心**：1本15〜20分（中間広告を入れるため最低8分以上）。
- **Shortsは集客用**：長尺の見どころを切り出すだけにする。Shortsの広告収益は長尺の約1/20〜1/100で、収益源にはならない。
- **投稿頻度の目安**：週2〜4本。1日に何本も上げると量産型のシグナルになるので避ける。
- **絵はコードで描く**。画像生成AIは原則使わない（サムネイルのみ例外）。
  - 棒人間・シルエット：SVG素材のポーズ差分（20〜50種類）を作って使い回す。男性は青、女性は赤など、色で役割を表す。
  - グラフ・数字の強調：データから自動でアニメーションを生成する（Remotion / Manim / D3などを想定。どれにするかは未決定）。
  - シミュレーション：エージェントの動き（婚活市場、格差、デマの拡散など）をコードで計算して描画する。毎回結果が違う独自コンテンツになり、規制にも強い。
  - 背景：線画のSVG素材を数種類用意して使い回す。
- **画面に出典を表示する**：調査名、年度、論文名。
- **サムネイル**：ベンチマークに倣い、型は固定して中身を変える。画像生成を使ってよいのはここだけ（1本あたり数十円程度）。

## 4. 収益化ポリシー上の制約（必ず守る）

- **2025-07-15のYouTube改定**：「繰り返しの多いコンテンツ」が「量産型（inauthentic）コンテンツ」に変わった。汎用テンプレートで大量生産されたAIコンテンツ、説明の少ないスライドショー、読み上げただけの動画は収益化の対象外。**判定はチャンネル全体に対して行われる。**
- **2026-07の改定（報道ベース）**：次の3つが収益化の対象外になった。
  1. テンプレート的・反復的なコンテンツ
  2. 感情をあおるショック系のコンテンツ
  3. **健康・金融・法律・政治について助言するAIペルソナ**
- **このプロジェクトのルール**
  - 毎回、問い・データ・結論・構図を変える。型（シリーズ、サムネイルの様式、構成の枠）は固定してよいが、中身は毎回別物にする。
  - 健康・お金のテーマは**「現象の説明」に限り、助言をしない**（「〜すべき」「〜を買え」は禁止）。
  - 政治は中立に扱う。男女対立や外国人への偏見をあおる構成にしない。
  - 実在の人物や出来事をリアルに見せるAI映像を使う場合は、AI開示ラベルを付ける。迷ったら付ける。
  - 他人の動画・画像・文章を素材として使わない。ベンチマークから取得したデータは**分析専用**。
- **スケジュール上の制約**：2027-02-01から、新規チャンネルの収益化条件が総再生時間8,000時間（現行4,000時間）またはShorts 90日2,000万回に上がる。**2027年1月末までに現行条件で収益化を達成すること**を目標にする。

## 5. 制作体制：人とAIの分担

- AIが制作の大半を担い、人が編集者として関わる形にする。人が関わらない完全自動は収益化停止の対象そのものなので採らない。
- **人（オーナー）が必ず行う工程**：1本あたり約1〜1.5時間。
  1. テーマと切り口の承認（約10分）
  2. **統計・論文の一次資料との照合**（30〜60分）。この型は数字の正確さが信用のすべてなので、ここは削らない。
  3. 完成動画を1.25倍速で通し確認（約20分）
  4. サムネイルとタイトルの最終決定（約10分）
- **AIが行う工程**：統計・論文の下調べ、台本、シーンのコード、音声合成、レンダリング、メタデータ（タイトル案、概要欄、Shorts案）。

## 6. 1本あたりのパイプライン（想定）

1. テーマを選ぶ（付録から）→ 使う統計・論文を集め、一次資料のURLと数値をデータファイル（CSVなど）に保存する
2. 構成案を作る（問い → データ → 意外な事実 → 解釈 → 結論）
3. 台本を書く（約330字/分なので、15〜20分で5,000〜6,600字）
4. **人による出典照合と修正**
5. シーン分割 → 各シーンのコードを生成（棒人間、グラフ、シミュレーション）
6. 音声合成
7. 合成・字幕・レンダリング（手元のパソコンで15〜30分）
8. 書き出した画面をAIに見せて、レイアウト崩れを確認
9. **人による通し確認** → 公開
10. Shortsの切り出し（`ffmpeg -ss 開始 -to 終了 -c copy`。再エンコードなし）

## 8. 最初のタスク：ベンチマークの取得と分析

オーナーが帰宅後に実行する予定。目的は、3チャンネルの全動画の構成を分析して、伸びるテーマ、タイトル、構成のパターンを抽出すること。

- **必要なツール**：`yt-dlp`、`ffmpeg`（Macなら `brew install yt-dlp ffmpeg`）。インストール前にオーナーの許可を取ること。
- **取得するもの**：動画一覧（ID・長さ・再生数・タイトル）、サムネイル、自動字幕（ja）、メタデータ（info.json）、場面転換ごとのキャプチャ（3×3のタイル画像にまとめる）。
- **注意**
  - yt-dlpでの取得はYouTube利用規約上グレー。個人の調査用にとどめ、`--sleep-requests` で間隔を空ける。
  - 取得したものは分析専用で、制作物に流用しない。
- **公式API（YouTube Data API v3）**：登録者、再生数、動画の長さ、投稿日などの公開データは取れる（オーナーがキーを発行した場合）。収益や視聴維持率は取れない。字幕は公式APIでは取れない。
- **台本の中身を分析する別の方法**：Gemini APIに公開動画のURLを渡して要約させる（公式の機能。有料）。

### スクリプト（Mac・Linux用。Windowsの場合は書き直す）

```bash
#!/bin/bash
# 使い方: ./bench.sh @lovebynumbers
CH="$1"; export OUT="bench/${CH#@}"; mkdir -p "$OUT"
URL="https://www.youtube.com/$CH/videos"

# 1. 動画一覧（ID・秒数・再生数・タイトル）
yt-dlp --flat-playlist --print "%(id)s	%(duration)s	%(view_count)s	%(title)s" "$URL" > "$OUT/list.tsv"

# 2. サムネイル・自動字幕・メタデータ（動画本体は落とさない）
yt-dlp --skip-download --write-thumbnail --convert-thumbnails jpg \
  --write-auto-subs --sub-langs ja --write-info-json --sleep-requests 1 \
  -o "$OUT/%(id)s/%(id)s.%(ext)s" "$URL"

# 3〜4. キャプチャ（場面転換のみ）＋ 3x3 タイル
cap() {
  d="$OUT/$1"; mkdir -p "$d"
  yt-dlp -q -f "bv*[height<=360]/b[height<=360]" -o "$d/v.%(ext)s" "https://youtu.be/$1" || return
  ffmpeg -loglevel info -skip_frame nokey -i "$d"/v.* \
    -vf "select='gt(scene,0.3)',scale=480:-1,showinfo" -vsync vfr "$d/f_%04d.jpg" 2> "$d/times.log"
  ffmpeg -loglevel error -i "$d/f_%04d.jpg" -vf "tile=3x3" "$d/sheet_%03d.jpg"
  rm -f "$d"/v.*
}
export -f cap
cut -f1 "$OUT/list.tsv" | xargs -P 3 -I{} bash -c 'cap {}'
```

- 3チャンネル約155本で30分〜1時間程度の見込み。
- `times.log` に各コマの秒数が残るので、字幕と突き合わせて「何秒目に何の絵で何を話しているか」を分析する。
- AIに画像を見せるときは3×3のタイルで渡す（1枚あたり約1,800トークンで9コマ分。1本10円以下）。
- 保存先はGitの外（同期フォルダなど）。

### 分析で出してほしいもの

## 9. 検討して見送ったもの（蒸し返さない）

- **避けるジャンル**：2ch・スカッと定型、海外の反応、AI猫・動物Shorts、子ども向け、フェイクニュース・芸能ゴシップ、AI作業用BGM、AIペルソナによる健康・金融・法律の助言。
