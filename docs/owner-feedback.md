# オーナーの指摘集（次の回で先回りするため）

オーナーが台本・動画を見て指摘したことのうち、**次の回でも起きうるもの**を、型ごとにまとめる。
レビュー役（`.claude/agents/review-*.md`）と台本の推敲（`.claude/skills/script-review`）は、毎回これを読んで同じ指摘が出ないかを確かめる。
回ごとの指摘と対応は `episodes/<回>/review/owner.md`。機械で捕まえられるものは仕組みに入れ、下の「仕組み」の欄に書く。

指摘が増えたら、同じ型の所に1行足す（日付と回）。

## 言葉

| 型 | 例（回・日付） | 先回りのしかた | 仕組み |
|---|---|---|---|
| 比喩が字義どおりに聞こえる | 「犯人」「主犯」がミスに聞こえる（1本目 v3、10/06） | 比喩の言葉は、字義どおりに受け取っても意味が通るか読み直す。迷ったら「原因」のような平たい言葉 | `scripts/wording.tsv` |
| 今は使わない言い方 | 「出会いサイト」→「マッチングサービス」（1本目 v3、10/06）、「細る」→「少なくなる」（1本目 v3、10/05） | 視聴者（20〜40代）がふだん使う言葉か | `scripts/wording.tsv` |
| 日本語として分かりにくい | 「選び方の側を変える」（1本目 v3、10/06） | 「〜の側」「〜という形」のような抽象語を、具体的な名詞に置き換える | `scripts/wording.tsv` |
| 前の文とつながらない | 「ただ、女性が送る数は、男性の4分の1ほどでした」が唐突（1本目 v3、10/06） | 話題が変わる文は、前の文との関係（それなのに・だから・一方で）を言葉にする。主語を省かない | レビュー役（流れ） |

## 数字と根拠

| 型 | 例 | 先回りのしかた | 仕組み |
|---|---|---|---|
| 仮定が恣意的に見える | 町の条件が見えず「パラメータ次第では」と思う（1本目 v3、10/06） | シミュレーションは予想の前に条件と根拠の表 | `docs/brand.md`「シミュレーション」 |
| 図に数字がない | 論文の模式図に%がない、「約73」に単位がない（1本目 v3、10/06） | 模式図でも論文の数字を画面に入れる。大きな数字には単位 | `npm run check`（模式図・単位） |
| 「どれくらい」が言えていない | 「最初の十数枚で急に下がる」だけで、どれだけ下がったかがない（1本目 v3、10/06） | 「急に」「大きく」と言うときは、数字を1つ添える | レビュー役（深さ・事実） |
